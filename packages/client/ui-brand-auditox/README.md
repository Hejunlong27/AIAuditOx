# @deepseek-ai/dsh-client-ui-brand-auditox

AuditOx paper-ledger brand, theme overrides, blank-home artwork and dossier extension for the DSH Web Client.

## Surfaces

- `sidebar.brand.mark` / `sidebar.brand.name`
- `conversation.hero.brand.mark` / `conversation.hero.frame`
- `conversation.session.header.actions`
- `sidebar.right.pane.tab` / `sidebar.right.pane.tab.title`
- `ctx.theme.overrideTokens()`

The node half has no behavior. The browser half is loaded only by the Web bundle.

## Known limitations

The dossier tab is a product shell. Project data and evidence are owned by the Python AuditOx Runtime and are not yet projected into this panel.
