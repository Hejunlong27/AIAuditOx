# P03 税务合规、争议与特殊税收项目检查

> 来源：S6403 程序库 其他4、其他5｜认定：E、A、V｜产出：S-8-03
> 执行方式：人工为主（税务检查结论/争议判断）｜确定性工具：rule_check｜**必须留人**（Agent 不得代替执行）

## 输入

- 税务机关近期检查结论文件
- 税务行政处罚或罚金记录
- 税收豁免或减免的批准文件
- 管理层关于税务争议的书面说明
- 外部税务咨询意见（如有）

## Steps

1. 【规则】复核是否遵守税务机关的规定
   - （1）税务机关是否在近期进行检查，如是，则获取一份检查结论文件，并确保任何额外付款（包括罚金和返还给税务机关）已正确处理；
   - （2）是否存在实际或者可能的争议税收事项；3.考虑是否需要为尚未支付的税费或者罚金计提任何准备。
   - 复核是否遵守税务机关的规定，并询问：
2. 【规则】检查特殊税收项目（如税收豁免等）
   - 如果有特殊的税收项目（如税收豁免等），确保已遵守相关的税收法律法规并已按照要求对有关税费进行了调整。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 事项类型 | 文本 | 检查结论/管理层说明 | 枚举（税务检查/争议事项/税收豁免/税收减免/罚金返还） |
| 事项描述 | 文本 | 支持性文件 | 非空 |
| 金额影响 | 金额 | 结论文件或计算表 | 与文件一致 |
| 会计处理 | 文本 | 账务记录 | 枚举（已处理/未处理/处理不当） |
| 是否需计提准备 | 文本 | 人工判断 | 枚举（是/否） |
| 结论 | 文本 | 人工填写 | 非空 |

## 质量门

- 税务机关近期检查结论 100% 获取并复核，额外付款（含罚金、返还）已正确处理
- 税收豁免或减免的依据充分、合法、有效，会计处理正确
- 本卡必须人工执行，Agent 仅可整理底稿

## 升级路径

- 存在未计提的税务罚金或争议准备 → 升级项目经理，按或有事项处理并检查披露
- 税收优惠依据不充分 → 升级，评估对税金及附加与递延所得税的连带影响
