# P02 各税种计算与勾稽复核

> 来源：S6403 程序库 其他2、其他3、其他6、其他7｜认定：E、A、V｜产出：S-8-02
> 执行方式：自动（逐税种重算+申报表核对）｜确定性工具：recalc_check、excel_read、rule_check

## 输入

- 各税种纳税申报表
- 完税凭证
- 已审定的应税收入或应税数量基础数据
- 本期应纳增值税与消费税申报数
- 上年申报数

## Steps

1. 【规则】复核税种核算是否符合税收政策
   - 复核有关税种的核算是否符合当地税收政策。考虑是否需要利用专家的工作。
2. 【规则】核对纳税申报表与科目金额
   - 获取当年有关税种的纳税申报表，检查申报金额与本科目列报金额是否存在差异。检查差异形成原因。
3. 【规则】复核各项税金列报
   - （1）根据审定的本期应纳增值税的营业收入和其他纳税事项，按规定的税率，分项计算、复核本期应纳增值税税额，检查会计处理是否正确；
   - （2）根据审定的本期应税消费品销售额（或数量），按规定适用的税率，分项计算、复核本期应纳消费税税额，检查会计处理是否正确；
   - （3）根据审定的本期应纳资源税产品的课税数量，按规定适用的单位税额，计算、复核本期应纳资源税税额，检查会计处理是否正确；
   - （4）检查城市维护建设税、教育费附加等项目的计算依据是否和本期应纳增值税、消费税合计数一致，并按规定适用的税率或费率计算、复核本期应纳城建税、教育费附加等，检查会计处理是否正确。
4. 【脚本】复核应交税费勾稽关系
   - 结合应交税费各明细科目的审计，复核其勾稽关系。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 税种 | 文本 | 纳税申报表 | 非空 |
| 计税依据（审定数） | 金额 | 已审定收入或数量 | 与审定数一致 |
| 适用税率或征收率 | 百分比 | 当期税收政策 | 与政策一致 |
| 重算应纳税额 | 金额 | 计税依据 × 税率 | = 乘积 |
| 申报表金额 | 金额 | 纳税申报表 | 与申报表一致 |
| 差异 | 金额 | 重算 − 申报 | = 差额 |
| 与应交税费勾稽 | 文本 | 与 2221 明细账比对 | 枚举（勾稽一致/不符） |
| 说明 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 各税种 100% 重算，重算差异超实际执行的重要性水平的项目均有说明
- 城建税、教育费附加的计税依据与本期应纳增值税、消费税合计数一致
- 与应交税费科目勾稽关系验证通过，不符项已查明原因

## 升级路径

- 重算差异超重要性水平且无法解释 → 升级项目经理，考虑补提或申请退税调整
- 城建税或教育费附加计税依据与流转税不符 → 升级，评估连带影响的其他税种
