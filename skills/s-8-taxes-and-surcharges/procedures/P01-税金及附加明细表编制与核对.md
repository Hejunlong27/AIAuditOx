# P01 税金及附加明细表编制与核对

> 来源：S6403 程序库 其他1｜认定：C、E、A｜产出：S-8-01
> 执行方式：自动（脚本核对）｜确定性工具：recalc_check、balance_confirm

## 输入

- 税金及附加明细表（按税种）
- 总账 6403 余额及明细账合计数
- 各税种纳税申报表与完税凭证
- 上年审定数

## Steps

1. 【规则】获取税金及附加明细表
   - 获取或编制税金及附加明细表，复核加计是否正确，并与报表数、总账数和明细账合计数核对是否相符。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 税种 | 文本 | 明细表 | 枚举（城建税/教育费附加/地方教育附加/房产税/土地使用税/车船税/印花税/资源税/消费税 等） |
| 计税依据 | 金额 | 纳税申报表 | 与申报表一致 |
| 税率或征收率 | 百分比 | 当期税收政策 | 与政策一致 |
| 本期计提额 | 金额 | 明细账 | 与总账一致 |
| 本期缴纳额 | 金额 | 完税凭证/银行流水 | 与凭证一致 |
| 期末应交余额 | 金额 | 本期计提 − 本期缴纳 | = 计提 − 缴纳 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数（四方相符）
- 逐税种税率与当期税收政策一致，税率变更已反映
- 差异项均有初步说明，无说明不得提交

## 升级路径

- 与总账差异无法解释 → 升级 S-8 助理，联动 P02 逐税种复核
- 发现应计提税种遗漏（如未计提印花税）→ 升级项目经理，按完整性错报处理
