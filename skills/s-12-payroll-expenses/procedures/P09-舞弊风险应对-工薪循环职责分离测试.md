# P09 舞弊风险应对—工薪循环职责分离测试

> 来源：S6604 程序库 其他11｜认定：E｜产出：S-12-09
> 执行方式：人工为主（职业怀疑+舞弊迹象判断）｜确定性工具：rule_check｜**必须留人**（Agent 不得代替执行）

## 输入

- 工薪循环的岗位职责说明与人员分工
- 工资发放权限与银行代发协议
- 工资单编制与复核记录
- 员工名册与银行账号清单
- 离职人员清单

## Steps

1. 【规则】舞弊—针对与工薪循环相关的职责分离不充分的测试
   - 获取员工名单，检查是否存在多记录的员工（如重复的姓名、地址、驾照、纳税号等），确保实施程序测试IPE的可靠性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 测试项 | 文本 | 测试类型 | 枚举（职责分离/离职人员工资/重复银行账号/工资单篡改迹象/幽灵员工） |
| 涉及人员或事项 | 文本 | 员工名册/工资单 | 非空 |
| 关联记录数 | 整数 | 比对结果 | ≥ 2 |
| 涉及金额 | 金额 | 工资单 | 合计 |
| 风险等级 | 文本 | 人工判断 | 枚举（高/中/低） |
| 已实施程序 | 文本 | 人工填写 | 非空 |
| 结论 | 文本 | 人工填写 | 非空 |

## 质量门

- 工资单编制、复核、发放、对账四个环节的职责分离情况已评价
- 离职人员工资、重复银行账号、幽灵员工三个维度全覆盖比对
- 本卡必须人工判断，Agent 仅提供比对结果与线索

## 升级路径

- 发现幽灵员工、离职人员继续发放或工资单被篡改 → 立即升级项目经理与项目合伙人，按舞弊事项处理
- 职责分离严重缺失 → 升级，评估控制缺陷并扩大实质性程序范围
