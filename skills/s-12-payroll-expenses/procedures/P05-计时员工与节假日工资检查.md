# P05 计时员工与节假日工资检查

> 来源：S6604 程序库 其他5、其他6｜认定：C、E、A｜产出：S-12-05
> 执行方式：自动（抽样+工时费率重算）+人工确认｜确定性工具：sampling_draw、recalc_check

## 输入

- 计时员工档案与经批准的小时费率
- 经批准的工时卡或考勤记录
- 员工合同、工会合同及人事手册中的休假政策
- 节假日工资计提计算表

## Steps

1. 【规则】计时员工
   - （1）核对员工档案的详细信息，核实员工是否真实存在；
   - （2）将小时工资与经批准的小时费率进行核对；
   - （3）将工时与经批准的工时卡进行核对；确保实施程序来验证考勤卡的可靠性（通过控制测试或其他实质性程序）；
   - （4）检查按照小时费率*工时计算的工资金额是否恰当；
   - （5）调查所有差异。
   - 获取本期采用计时工资制支付工资的员工清单，执行IPE程序检查清单的完整性和准确性。考虑获取服务机构报告（如适用）。选取样本执行下列工作：
   - 记录样本规模和选样依据。
2. 【规则】检查节假日工资的计提
   - （1）复核员工合同、工会合同及/或人事手册，确定休假政策及每个工作日应计提的节假日工资率；
   - （2）将人工成本金额与人事档案进行抽样核对，验证用以计算的输入数据。记录样本量和选样依据；
   - （3）检查应计节假日工资的计算，确保其符合被审计单位的会计政策和适用的财务报告编制基础。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 员工姓名 | 文本 | 员工档案 | 与人事记录一致 |
| 员工是否存在（核实） | 文本 | 员工档案 | 枚举（是/否） |
| 经批准小时费率 | 数值 | 人事档案 | 与批准文件一致 |
| 实际工时 | 数值 | 工时卡 | 与批准工时卡一致 |
| 测算工资 | 金额 | 小时费率 × 工时 | = 乘积 |
| 账面工资 | 金额 | 工资单 | 与工资单一致 |
| 差异 | 金额 | 测算 − 账面 | = 差额 |
| 节假日工资计提 | 金额 | 计提计算表 | 与会计政策一致 |
| 说明 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 计时员工档案 100% 核实真实存在，小时费率与批准文件一致
- 工时与经批准的工时卡核对，考勤记录可靠性已验证
- 节假日工资计提符合被审计单位会计政策与适用财务报告编制基础

## 升级路径

- 发现工时卡未经批准或考勤记录不可靠 → 升级，评估控制缺陷并扩大实质性程序
- 节假日工资计提政策与准则不符 → 升级项目经理，评估对损益的影响
