# P10 董事与关键管理人员薪酬检查

> 来源：S6604 程序库 其他12｜认定：C、E、A、P｜产出：S-12-10
> 执行方式：自动（预期值测算）+人工判断｜确定性工具：threshold_flag、rule_check、excel_read

## 输入

- 董事和关键管理人员的个人薪酬清单（含报销费用与津贴）
- 董事会决议与薪酬委员会文件
- 个人所得税申报记录
- 上年薪酬与预算数
- 人事变动记录

## Steps

1. 【规则】检查董事和关键管理人员的薪酬
   - （1）获取董事和关键管理人员的个人薪酬清单，包括报销费用和提供的津贴。执行程序测试IPE的可靠性；
   - （2）对于本期支付样本，执行下列工作：
   - （3）比较实际薪酬与预期值（考虑以前年度、预算、人事变动等）。如果与预期值存在重大差异，就差异的原因获取佐证证据；
   - （4）检查财务报表披露是否符合相关会计准则、被审计单位的会计政策、适用的财务报告编制基础以及当地的法律规定。"
   - ①将月度薪酬样本与支持性文件进行检查；
   - ②与劳动合同或已批准的工资单进行核对；
   - ③记录样本量和选样依据；

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 姓名 | 文本 | 薪酬清单 | 非空 |
| 职务 | 文本 | 薪酬清单 | 枚举（董事/监事/高级管理人员） |
| 基本薪酬 | 金额 | 薪酬清单 | 与决议一致 |
| 奖金与津贴 | 金额 | 薪酬清单 | 与决议一致 |
| 报销费用 | 金额 | 薪酬清单 | 与凭证一致 |
| 薪酬合计 | 金额 | 各项之和 | = 基本 + 奖金 + 报销 |
| 预期薪酬 | 金额 | 按上年/预算/人事变动测算 | 重算一致 |
| 差异 | 金额 | 实际 − 预期 | = 差额 |
| 披露是否符合准则 | 文本 | 人工判断 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 董事和关键管理人员清单 100% 取得并核实，无遗漏
- 实际薪酬与预期值（上年、预算、人事变动）差异已调查并取得佐证
- 披露符合相关会计准则、被审计单位会计政策、适用财务报告编制基础及当地法律规定

## 升级路径

- 存在未披露的董事或关键管理人员薪酬 → 升级项目经理，按关联方交易与列报错报处理
- 薪酬超出决议授权范围 → 升级，评估内控缺陷与合规风险
