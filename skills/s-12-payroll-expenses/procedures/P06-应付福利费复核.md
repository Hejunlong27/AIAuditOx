# P06 应付福利费复核

> 来源：S6604 程序库 其他7｜认定：C、E、A｜产出：S-12-06
> 执行方式：自动（计提重算）+人工判断｜确定性工具：recalc_check、provision_calc

## 输入

- 应付福利费明细账（计提与使用）
- 福利费计提政策与标准
- 福利费使用凭证与审批记录
- 税法规定的税前扣除限额

## Steps

1. 【规则】复核并验证应付福利费
   - 复核被审计单位对员工福利（保险、休假、节假日、病休、养老金、分红等）的计算，并将计算与支持性文件及期后支付进行检查。确保其符合被审计单位的会计政策和适用的财务报告编制基础。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 福利费项目 | 文本 | 明细账 | 非空 |
| 计提基数 | 金额 | 工资总额 | 与工资费用一致 |
| 计提比例 | 百分比 | 会计政策 | 与政策一致 |
| 应计提额 | 金额 | provision_calc 测算 | = 基数 × 比例 |
| 本期实际计提 | 金额 | 明细账 | 与总账一致 |
| 本期实际使用 | 金额 | 明细账 | 与凭证一致 |
| 期末余额 | 金额 | 期初 + 计提 − 使用 | = 期初 + 提 − 用 |
| 是否超税前扣除限额 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明 | 文本 | 人工填写 | 差异或超限项必有 |

## 质量门

- 计提基数与工资总额勾稽一致，计提比例符合公司政策
- 福利费使用凭证齐备且经审批
- 超税前扣除限额部分已识别并评估纳税调整

## 升级路径

- 计提基数或比例与政策不符 → 升级项目经理，评估对损益与应付职工薪酬的影响
- 福利费使用无凭证或与员工福利无关 → 升级，评估真实性与税务风险
