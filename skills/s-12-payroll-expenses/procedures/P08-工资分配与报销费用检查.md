# P08 工资分配与报销费用检查

> 来源：S6604 程序库 其他9、其他10｜认定：E、A、P｜产出：S-12-08
> 执行方式：自动（分配重算+抽样）｜确定性工具：recalc_check、sampling_draw

## 输入

- 工资分配表（按部门与成本费用项目）
- 各部门人数与工时统计
- 报销费用明细与审批记录
- 报销收据与发票
- 公司报销制度

## Steps

1. 【规则】工资的分配
   - 检查工资的分配，与支持性文件进行核对 （例如，行政人员的工资计入管理费用），确保工资费用在财务报表中得到适当分类。
2. 【规则】报销费用
   - （1）核对相关收据和发票的金额和摘要。核实报销的费用与被审计单位的活动有关。
   - （2）获取费用报告的副本，并验证报告已适当批准(可能为双重目的测试-如果被审计单位的控制有效运行，可能能够获取一些TOC保证)。
   - （3）核对总账金额，并核实报销费用是否记录于正确的总账账户，并分配至适当的项目。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 项目 | 文本 | 明细账 | 枚举（工资分配/报销费用） |
| 受益部门或人员 | 文本 | 分配表/报销单 | 非空 |
| 分配依据 | 文本 | 人数或工时统计 | 有依据 |
| 分配金额 | 金额 | 分配表 | 与总账一致 |
| 归集科目 | 文本 | 账务记录 | 枚举（生产成本/销售费用/管理费用/在建工程） |
| 分配合计核对 | 金额 | 分配合计 − 工资总额 | = 0 或列示差异 |
| 报销审批 | 文本 | 审批记录 | 枚举（齐备/不齐备） |
| 报销与经营相关性 | 文本 | 人工判断 | 枚举（相关/不相关） |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 工资分配合计与工资总额勾稽一致，分配依据可验证
- 报销费用 100% 核对至收据发票，金额与摘要相符
- 报销与被审计单位活动相关且经适当批准

## 升级路径

- 工资分配依据不充分或分配比例异常 → 升级项目经理，评估对成本与费用的影响
- 报销费用与经营活动无关或审批缺失 → 升级，评估真实性与内控缺陷
