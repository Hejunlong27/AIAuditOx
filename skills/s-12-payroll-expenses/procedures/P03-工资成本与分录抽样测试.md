# P03 工资成本与分录抽样测试

> 来源：S6604 程序库 其他2、其他3｜认定：E、A｜产出：S-12-03
> 执行方式：自动（抽样+重算）｜确定性工具：sampling_draw、recalc_check

## 输入

- 本期工资费用详细清单
- 月度或周度工资单
- 员工档案与劳动合同
- 抽样参数（样本量与固定 seed）

## Steps

1. 【规则】工资成本测试
   - （1）获取本期工资费用的详细清单，执行程序测试IPE的可靠性；
   - （2）选取样本执行下列工作：
   - （3）记录样本规模和选样依据。
   - ①检查劳动合同确认该员工确为被审计单位的员工，并检查其身份证明文件（如驾照、纳税单。；核实员工档案中是否存在缺失的信息（如出生日期、税务证明、编号等）
   - ②将工资/薪金金额与已劳动合同或已批准的工资清单进行核对；
   - ③获取有关工时的支持性证据（如考勤记录）；
   - ④重新计算测试期间的工资费用，包括任何相关的税金，并与总账进行核对，对差异进行调查；
   - ⑤核实工资成本是否按照适用的财务报告编制基础进行了适当分类。
2. 【规则】抽样检查工资分录
   - （1）获取周/月度工资单，并执行程序测试IPE的可靠性。记录样本量和选样依据；
   - （2）针对选出的分录样本，执行下列工作：
   - ①将工资信息与支持性文件（工时单/劳动合同等）进行核对；
   - ②调查异常调整项目并与支持性文件进行核对；
   - ③核实通过工资支付的其他成本（佣金、奖金、长期激励、辞退补偿等）已得到恰当记录。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 样本类型 | 文本 | 抽样来源 | 枚举（工资成本/工资分录） |
| 凭证号或工资单号 | 文本 | 工资单 | 非空 |
| 员工姓名 | 文本 | 员工档案 | 与人事记录一致 |
| 应发工资 | 金额 | 工资单 | 与工资单一致 |
| 代扣款项 | 金额 | 工资单 | 合计与工资单一致 |
| 实发工资 | 金额 | 工资单/银行流水 | = 应发 − 代扣 |
| 入账金额 | 金额 | 明细账 | 与总账一致 |
| 重算差异 | 金额 | 重算 − 账面 | = 差额 |
| 追查结论 | 文本 | 人工填写 | 枚举（相符/不符） |

## 质量门

- 抽样样本量由 sampling_draw 以固定 seed 生成，可复现，并记录选样依据
- 每笔样本 100% 核对至员工档案与工资单，实发与银行流水匹配
- 不符项均有说明

## 升级路径

- 样本中发现虚构员工或无档案人员 → 立即升级项目经理，按舞弊事项处理
- 实发与银行流水不匹配 → 升级，扩大抽样范围并评估内控缺陷
