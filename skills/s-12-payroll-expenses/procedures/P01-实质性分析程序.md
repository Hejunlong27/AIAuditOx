# P01 实质性分析程序

> 来源：S6604 程序库 分析1、分析2、分析3、分析4｜认定：C、E、A｜产出：S-12-01
> 执行方式：自动（工资成本预期测算）+人工判断｜确定性工具：recalc_check、threshold_flag

## 输入

- 工资费用明细账（按部门、按月、按项目）
- 员工名册（人数、职位、工资率、入离职日期）
- 销售佣金与奖金计算表及销售收入数据
- 上年度数与本期预算数
- 实际执行的重要性水平

## Steps

1. 【规则】将销售佣金或奖金与相关销售收入进行比较
   - （1）对销售佣金或奖金与相关销售收入之间的关系作出预期；
   - （2）将实际关系与预期值进行比较；
   - （3）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。考虑是否需要计划并实施追加工作及/或记录识别出的任何差错。
2. 【规则】按照〔部门/生产线/月份〕复核工资成本
   - （1）对下列数据作出预期：
   - （2）将实际值与预期值进行比较；
   - （3）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。考虑是否需要计划并实施追加工作及/或记录识别出的任何差错。
   - ①各部门或生产线的人工和福利成本；
   - ②选定工资期间的人工和福利成本；
   - ③按日、周或月支付的薪资；
   - ④各部门或生产线的员工人数；
   - ⑤有资格获得福利计划的员工人数；
   - ⑥不同级别的员工平均工资；
3. 【规则】将工资成本与上期/预算进行比较
   - （1）对本期工资成本与上期和/或本期预算作出预期；
   - （2）将实际值与预期值进行比较；
   - （3）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。考虑是否需要计划并实施追加工作及/或记录识别出的任何差错。
4. 【脚本】根据员工人数计算的工资成本
   - （1）根据员工人数和工资率，对本期工资成本作出预期；
   - （2）将实际值与预期值进行比较；
   - （3）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。考虑是否需要计划并实施追加工作及/或记录识别出的任何差错。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析维度名称 | 非空 |
| 本期实际数 | 金额 | 明细账 | 与总账一致 |
| 上期数 | 金额 | 上年明细账 | 与上年审定数一致 |
| 预算数 | 金额 | 预算表 | 有依据 |
| 员工人数 | 整数 | 员工名册 | 与人事记录一致 |
| 人均工资 | 金额 | 本期实际数 ÷ 员工人数 | = 比值 |
| 佣金奖金占收入比率 | 百分比 | 佣金奖金 ÷ 销售收入 | = 比值 |
| 差异 | 金额 | 实际 − 预期 | = 差额 |
| 是否超重要性水平 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明与证据 | 文本 | 人工填写 | 超限项必有 |

## 质量门

- 按部门、按生产线、按月份三个维度全覆盖复核，无遗漏
- 佣金奖金与销售收入的关系经测算验证，偏离已说明
- 按员工人数与工资率测算的工资成本与实际差异超重要性水平项均有解释

## 升级路径

- 工资成本与人数、工资率测算严重背离且无法解释 → 升级项目经理，转 P03/P04/P05 扩大检查
- 发现虚构员工或虚列工资迹象 → 立即升级，按舞弊事项处理
