# P07 服务机构工资检查

> 来源：S6604 程序库 其他8｜认定：C、E、A｜产出：S-12-07
> 执行方式：自动（清单校验）+人工判断｜确定性工具：rule_check

## 输入

- 服务机构协议（劳务派遣或代发工资）
- 服务机构提供的工资明细与结算单
- 本公司与服务机构的往来对账
- 用工名单与岗位安排

## Steps

1. 【规则】服务机构—工资
   - 如果被审计单位在处理工薪的过程中使用服务机构，完成服务机构问卷。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 服务机构 | 文本 | 协议 | 非空 |
| 用工形式 | 文本 | 协议 | 枚举（劳务派遣/代发工资/其他） |
| 本期结算金额 | 金额 | 结算单 | 与协议一致 |
| 已入账金额 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 结算 − 入账 | = 差额 |
| 列报是否恰当 | 文本 | rule_check 校验 | 枚举（恰当/不恰当） |
| 说明 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 服务机构结算金额与入账金额 100% 核对
- 劳务派遣与正式用工的列报界限清晰，符合准则要求
- 差异项均有说明

## 升级路径

- 结算与入账差异无法解释 → 升级项目经理
- 存在以劳务派遣规避用工责任或虚列人员 → 升级，评估合规与舞弊风险
