## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：所有工资费用均已记录（含未列示于账面者）；存在（E）：记录的工资费用于资产负债表日存在且归被审计单位拥有或控制；准确性（A）：金额正确计算、适当加总且准确记录；列报（P）：分类、披露恰当 |
| 所需资料 | 工资费用明细表与明细账（按部门、按月）、员工名册与劳动合同（职位、工资率、入离职日期）、月度或周度工资单、工时卡与考勤记录、销售佣金与奖金计算表、应付福利费明细账、社保与公积金缴纳记录、个人所得税申报记录、董事会决议与薪酬委员会文件、服务机构（劳务派遣）协议、公司报销制度与报销单、报表附注 |
| 所需数据 | 各月工资费用发生额、员工人数与人均工资、工资率与工时、佣金奖金与销售收入的对应关系、代扣代缴金额、实发工资与银行发放流水、福利费计提基数与比例、社保与公积金缴费基数、董事与关键管理人员薪酬构成、税前扣除限额、实际执行的重要性水平 |
| 核对逻辑 | 1. 实质性分析程序（将销售佣金或奖金与相关销售收入进行比较）；2. 工资费用明细表编制与核对（获取工资费用明细表，复核加计是否正确，并与报表数、总账数及明细账合计数核对是否相符。）；3. 工资成本与分录抽样测试（工资成本测试）；4. 授薪员工工资确认（工资确认——授薪员工）；5. 计时员工与节假日工资检查（计时员工）；6. 应付福利费复核（复核并验证应付福利费）；7. 服务机构工资检查（服务机构—工资）；8. 工资分配与报销费用检查（工资的分配）；9. 舞弊风险应对—工薪循环职责分离测试（舞弊—针对与工薪循环相关的职责分离不充分的测试）；10. 董事与关键管理人员薪酬检查（检查董事和关键管理人员的薪酬） |
| 底稿编制内容 | 见「产出清单」，全部底稿采用四段式制式：底稿名称与表头（项目基本信息）→ 审计目标和程序说明 → 审计程序执行结果 → 审计说明。共 10 张底稿。 |
| 输出格式 | xlsx 工作簿（模板见 templates/S-12工资费用审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/S-12工资费用/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性（见六要素「所需资料」）；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → P02 → P03 → P04 → P05 → P06 → P07 → P08 → P09 → P10；人工程序标记待办并跟踪完成状态。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：按各程序卡「升级路径」处理，发现异常事项逐级升级。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P10 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：明细表合计数 = 总账数 = 报表数；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源；差异事项均有解释与支持文件。
- 异常闭环：所有异常事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料 只读）；跳过强制程序。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 工资费用的完整性依赖员工名册的完整性；须取得董事会与管理层对授薪员工清单的签署确认书，仅核对工资单无法发现幽灵员工
- 离职人员继续发放、同一银行账号对应多个员工，是典型的舞弊信号，须专项比对
- 工资分配至生产成本、销售费用、管理费用、在建工程的依据（人数或工时）须可验证，分配比例异常会同时扭曲存货与损益
- 应付福利费的计提基数应为工资总额，基数或比例与政策不符会低估负债
- 劳务派遣与正式用工的列报界限须清晰；以劳务派遣规避用工责任同时可能影响费用归集
- 董事与关键管理人员薪酬属于关联方交易，披露要求高于普通员工，须与关联方清单交叉核对
- 社保与公积金缴费基数低于工资总额可能隐含少缴风险，须评估是否需计提补缴准备
