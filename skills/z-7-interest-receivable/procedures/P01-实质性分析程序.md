# P01 实质性分析程序

> 来源：Z1132 程序库 分析1、分析2｜认定：C、E、A｜产出：Z-7-01
> 执行方式：自动（利率/利息预期测算）｜确定性工具：interest_calc、threshold_flag

## 输入

- 债券/理财产品明细及持有期间
- 银行基准利率或与银行签订的协议利率
- 应收利息明细账本期发生额
- 实际执行的重要性水平（TE）

## Steps

1. 【脚本】根据（如债券、理财产品）银行基准利率/与银行签订的协议,对计算利息收入的实际利率作出预期：
   - ①将实际值与预期值进行比较；
   - ②检查 xxxx以上（实际执行的重要性水平的%， 特定金额）相对于预期值的差异，并获取相关说明和证据；
   - ③在无适当的说明或确切的证据可以证明差异时，考虑是否需要计划并实施额外工作及/或记录发现的任何差错。
2. 【规则】对本年应收利息作出预期：
   - ①将实际利息收入与预期利息收入进行比较；
   - ②检查 xxxx以上（实际执行的重要性水平的%， 特定金额）相对于预期值的差异，并获取相关说明和证据；
   - ③在无适当的说明或确切的证据可以证明差异时，考虑是否需要计划并实施额外工作及/或记录发现的任何差错。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 金融资产名称 | 非空 |
| 本金/摊余成本 | 金额 | 投资台账 | 与总账一致 |
| 年利率 | 百分比 | 协议利率/基准利率 | 有书面依据 |
| 起息日 | 日期 | 投资合同 | 非空 |
| 止息日 | 日期 | 投资合同/资产负债表日 | 不早于起息日 |
| 计息天数口径 | 文本 | 合同约定 | 枚举（actual/365、30/360 等） |
| 预期利息 | 金额 | interest_calc 测算 | 重算一致 |
| 实际利息 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 预期 − 实际 | = 差额 |
| 是否超重要性水平 | 文本 | threshold_flag 判定（TE） | 超限标注「是」 |
| 说明 | 文本 | 人工填写 | 超限项必有 |

## 质量门

- 全部计息金融资产 100% 纳入分析
- 计息天数口径与合同一致，并在底稿中显式声明
- 差异超 TE 项均有说明与证据

## 升级路径

- 差异无法解释 → 升级项目经理，转 P03 扩大检查范围
- 发现未计提利息的金融资产 → 升级，按完整性/准确性错报处理
