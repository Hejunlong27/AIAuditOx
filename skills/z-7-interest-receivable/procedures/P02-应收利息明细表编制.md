# P02 应收利息明细表编制

> 来源：Z1132 程序库 其他1｜认定：A、V｜产出：Z-7-02
> 执行方式：自动（脚本核对）｜确定性工具：recalc_check、balance_confirm

## 输入

- 应收利息明细表（按金融资产/对手方）
- 总账 1132 余额及明细账合计数
- 资产负债表日即期汇率表（存在外币时）
- 上年审定数

## Steps

1. 【规则】获取或编制应收利息明细表：
   - （1）复核加计正确，并与总账数和明细账合计数核对是否相符；结合坏账准备科目与报表数核对是否相符；
   - （2）检查非记账本位币应收利息的折算汇率及折算是否正确；
   - （3）关注到期一次还本付息债券投资的应收利息是否包含在应收利息明细表中，如有，则调整至持有至到期投资科目。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 金融资产/对手方 | 文本 | 明细表 | 非空 |
| 币种 | 文本 | 明细表 | 枚举（CNY/USD/HKD 等） |
| 原币金额 | 金额 | 明细表 | 与凭证一致 |
| 折算汇率 | 汇率 | 即期汇率表 | 资产负债表日汇率 |
| 本位币金额 | 金额 | 原币金额 × 折算汇率 | = 乘积 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数
- 外币项目汇率 100% 校验
- 差异项均有初步说明

## 升级路径

- 与总账差异无法解释 → 升级 Z-7 助理，联动 P03
- 存在未入账应收利息 → 升级项目经理，按完整性错报处理
