# P03 应收利息增减变动检查

> 来源：Z1132 程序库 其他2｜认定：C、E、A｜产出：Z-7-03
> 执行方式：自动（抽样+利息重算）｜确定性工具：interest_calc、sampling_draw

## 输入

- 应收利息明细账本期借贷方发生额
- 债权投资/交易性金融资产审计底稿
- 利息计算表、结息单、收款凭证

## Steps

1. 【规则】检查应收利息增减变动：
   - （1）与金融资产（如以公允价值计量且其变动计入当期损益的金融资产、持有至到期投资、可供出售金融资产等）的相关审计结合, 验证确定应收利息的计算是否充分、正确，检查会计处理是否正确；
   - （2）对于重大的应收利息项目，审阅相关文件,复核其计算的准确性。必要时，向有关单位函证并记录。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 金融资产/对手方 | 文本 | 明细账 | 非空 |
| 期初余额 | 金额 | 明细账 | 与上年审定数衔接 |
| 本期增加 | 金额 | 明细账借方 | 与总账一致 |
| 本期减少 | 金额 | 明细账贷方 | 与总账一致 |
| 期末余额 | 金额 | 期初 + 增加 − 减少 | = 期初 + 增 − 减 |
| 利息重算 | 金额 | interest_calc 测算 | 与账面一致 |
| 重算差异 | 金额 | 重算 − 账面 | 超限标注 |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 重大应收利息项目 100% 重算利息并留痕
- 减少额与收款记录匹配
- 与金融资产审计结论交叉核对一致

## 升级路径

- 利息重算差异超重要性水平 → 升级项目经理
- 减少无收款记录支持 → 升级，评估舞弊风险
