# P05 应收利息披露检查

> 来源：Z1132 程序库 其他4｜认定：P｜产出：Z-7-05
> 执行方式：自动（schema 校验）+人工确认｜确定性工具：rule_check

## 输入

- 财务报表附注中应收利息相关披露文本
- 应收利息明细表
- 关联方清单（涉及关联方利息时）

## Steps

1. 【规则】审计应收利息的披露
   - 检查相关财务报表附注披露的准确性和完整性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 披露事项 | 文本 | 准则要求清单 | 枚举（分类/账龄/减值/关联方 等） |
| 附注披露内容 | 文本 | 报表附注 | 非空 |
| 是否完整 | 文本 | rule_check 校验 | 缺项标注「否」 |
| 与底稿一致性 | 文本 | 与明细表比对 | 枚举（一致/不符） |
| 说明 | 文本 | 人工填写 | 缺项或不符必有 |

## 质量门

- 准则要求的披露事项逐项核对，无遗漏
- 附注金额与底稿明细表金额一致

## 升级路径

- 披露缺项 → 升级项目经理，提请管理层补充披露
- 附注与底稿金额不符 → 退回 P02 核实后重新比对
