# 06 · 报告模板库

> 由 Skill 06（`roles/report-generator`）加载。四套模板按交付对象选用，不得混用结构。

## 选用规则

| 模板 | 何时用 | 篇幅 |
|---|---|---|
| T1 一页纸高管摘要 | 模式 A、高层会议、快速了解 | ≤1 页 |
| T2 标准财务分析报告 | 模式 B、月/季/年度分析、经营复盘 | 8–20 页 |
| T3 深度财务尽调报告 | 模式 C、投融资、并购、债务排查 | 20 页以上 |
| T4 董事会汇报版本 | 用户要求"给董事长/董事会看" | 3–5 页 |

**通用要求**：开头声明公司、口径（合并/单体）、币种、单位、期间、数据来源；结尾附数据缺口说明。

## T2 · 标准财务分析报告

```markdown
# <公司全称> 财务分析报告（<期间>）

**编制口径**：<合并/单体> | **币种/单位**：人民币/万元 | **是否经审计**：<是/否>
**数据来源**：<报表、附注、台账清单> | **分析模式**：标准分析

## 一、执行摘要
### 1.1 总体经营状态
<规模、结构、所处周期位置>
### 1.2 盈利情况
### 1.3 现金流情况
### 1.4 资产质量
### 1.5 债务风险
### 1.6 核心优势（≤3 条）
### 1.7 核心问题（≤3 条）
### 1.8 一句话结论
> <结论>

## 二、经营情况
- 业务结构与收入构成（分板块/分区域）
- 关键经营数据（房开：销售/回款/去化；矿业：产量/销量/价格）
- 经营数据与财务数据的交叉验证结果（含背离提示）

## 三、收入及盈利能力
- 收入规模与增长（同比、CAGR，3 年/5 年）
- 毛利率、EBITDA 率、净利率趋势
- 主营利润占比与非经常性损益影响
- **利润变动归因**：量 / 价 / 成本 / 费用 各自影响
- 结论：主营盈利能力是否可持续

## 四、资产质量
- 资产结构（重资产程度、流动性）
- 应收 / 存货 / 长期资产质量
- 受限资产与减值情况
- 资产周转效率趋势
- 结论：资产是否产生收入与现金

## 五、负债及偿债能力
- 负债结构（有息/无息、短/长期）
- 杠杆指标（资产负债率、净负债率、有息负债率）
- 偿债指标（流动比率、速动比率、现金短债比、EBITDA/利息）
- 债务期限墙与集中到期分析
- 结论：偿债能力与再融资压力

## 六、现金流
- 三类现金流结构与趋势
- 净现比、收现比、CAPEX 覆盖率、自由现金流
- 现金流缺口测算（现金来源 → 用途 → 缺口）
- 结论：现金安全边际

## 七、营运资金
- 应收/存货/应付周转天数、现金转换周期
- 增长带来的资金占用变化
- 结论：增长是否在消耗现金

## 八、行业专项分析
> 房地产或矿业自动切换；其他行业写明"行业专项模型尚未覆盖"

### 8.A 房地产
- 土地储备（面积、货值、区域结构、去化周期）
- 项目分析（项目盈利矩阵 + 四类分类）
- 销售与回款（去化率、回款率）
- 杠杆与监管口径（三道红线）
- 行业风险清单

### 8.B 矿业
- 资源与储量（储量、品位、剩余服务年限、储采比）
- 产能与产量（利用率、产销率、回收率）
- 成本（吨矿/吨产品/现金成本、成本结构）
- 盈利与归因（量价本分解，谁影响最大）
- CAPEX（维持性/扩张性、回报）
- 价格敏感性（七档情景 + 盈亏平衡价、现金平衡价、偿债临界价）
- 行业风险清单

## 九、重大风险
> 每条：风险事项 → 数据证据 → 原因 → 影响 → 建议动作 → 评级

| 编号 | 风险事项 | 数据证据 | 原因 | 影响 | 建议动作 | 评级 |
|---|---|---|---|---|---|---|
| | | | | | | 🟡/🔴 |

## 十、企业优势
<基于数据支撑的优势，每条附证据；不得空泛>

## 十一、未来展望
- 未来 12 个月关键变量（价格/去化/融资/政策）
- 基准情景与压力情景下的现金流与偿债表现
- 明确不确定性来源

## 十二、管理建议
| 优先级 | 建议 | 依据 | 责任方向 | 时间窗 |
|---|---|---|---|---|
| 高 | | | | |

## 附录
- A. 数据缺口与不可计算指标
- B. 关键指标全表（3 年）
- C. 数据来源与口径说明
```

## T3 · 深度财务尽调报告

在 T2 结构基础上增加/强化以下章节（顺序固定）：

```markdown
# <公司全称> 财务尽调报告

## 0. 尽调摘要
- 尽调范围与局限
- 核心发现（事实 / 判断 / 风险 三分列示）
- 尽调结论与主要保留意见

## 1. 数据基础与质量
- 资料来源清单与可信度分级
- 勾稽复核结果（含差额与未解释项）
- 数据缺口清单及对结论的影响
- **未经核实事项清单**（明确声明）

## 2. 盈利质量穿透
- 收入确认政策与口径（房开：交付确认；矿业：产量/长协）
- 关联交易与关联方依赖
- 非经常性损益与一次性收益
- 会计政策变更影响
- 结论：可持续盈利能力

## 3. 资产质量穿透
- 应收账款账龄、坏账计提充分性、保理/出表还原
- 存货跌价测试（按项目/按产品）
- 长期资产（在建工程转固、无形资产/采矿权摊销）
- 商誉减值测试
- 受限资产清单
- 结论：资产是否高估

## 4. 负债与表外事项
- 有息负债明细与真实成本
- 债务期限墙（按年、按渠道、按利率）
- 担保、承诺事项、未决诉讼
- 明股实债与表外融资穿透
- 结论：真实杠杆水平

## 5. 现金流真实性
- 三类现金流质量与可持续性
- 经营现金流与收入/利润的匹配度
- 现金流向与关联方资金往来
- 结论：现金创造能力真实性

## 6. 压力测试
- 6 个标准情景 + 定制情景
- 偿债缺口、触发红色条件、临界点
- 结论：极端情况下的生存能力

## 7. 行业与经营验证
- 经营数据与财务数据交叉验证（房开：去化/回款/结算；矿业：产量/价格/成本）
- 行业周期位置判断（含外部数据来源与年份）
- 结论：经营与财务是否自洽

## 8. 风险清单与评级
> 全量风险表，含"无法验证事项"单独列示

## 9. 尽调结论与交易建议
- 估值调整因素（如适用，仅列因素，不给证券买卖建议）
- 交割前条件（Conditions Precedent）
- 投后监控指标清单
```

**尽调特有硬约束**：
1. 每个关键数字标注来源；无法核实的一律列入"未经核实事项"。
2. 不允许"看起来合理"式推断；推断必须标注为「推算结果」并写明假设。
3. 差额不得调平；须列示并解释。

## 写作规范（全部模板通用）

1. **结论先行**：每章第一句就是该章结论，之后才是数据与论证。
2. **数据说话**：每个判断后面跟数值；禁止"较大""偏高""良好"等无数值修饰。
3. **事实/判断/风险分离**：可用小标题或加粗标签区分。
4. **表格优先**：指标、风险、建议用表格；叙述只用于解释因果。
5. **单位统一**：正文万元，重大金额可括注亿元。
6. **缺口显性**：无法计算的指标集中在附录，写明缺什么、影响哪条结论。
7. **建议可执行**：动作 + 责任方向 + 时间窗，缺一不可。
8. **不新增结论**：Skill 06 只整合上游结果，不得引入未经验证的新判断。
