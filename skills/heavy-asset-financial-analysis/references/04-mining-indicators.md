# 04 · 矿业与资源型专项指标库

> 由 Skill 04（`roles/mining`）加载。适用：金属矿、非金属矿、煤炭、油气及其他资源型能源企业。

## 1. 经营闭环（分析主线）

```
资源储量 → 可采储量 → 设计产能 → 实际产量 → 回收率 → 销量
   → 销售价格 → 单位成本 → 单位毛利 → 经营现金流 → CAPEX → 自由现金流 → 储量消耗
```

**核心判断**：矿业是"**价格 × 产量 − 成本**"的生意，且必须用 CAPEX 和储量消耗来"续命"。因此分析必须同时回答：
1. 当前盈利是价格给的还是成本控出来的？
2. 现有储量还能支撑几年？
3. 维持产量需要多少 CAPEX，现金流能不能覆盖？

## 2. 资源与储量指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 资源储量 | 探明+控制+推断资源量 | 地质报告汇总 | 地质/储量报告 | 家底总量 | 无储量报告 → 相关结论无法判断 |
| 可采储量 | 经济可采部分 | 资源储量 × 设计回采率 | 储量报告 | 真实可采 | 可采/资源 < 50% → 经济性偏弱 |
| 品位 | 矿石中有用组分含量 | 金属量 / 矿石量 | 地质报告 | 单位矿石价值 | 品位下滑 → 单位成本被动上升 |
| 剩余服务年限 | 矿山寿命 | 可采储量 / 年产量 | 储量+产量 | 持续经营能力 | <5 年 → 红色（除非有接续资源） |
| 储采比 | 储量消耗速度 | 可采储量 / 年产量 | 储量+产量 | 资源续接 | <8 年 → 黄色；<5 年 → 红色 |
| 储量消耗率 | 年度储量净减少 | (采出量 − 新增探明量)/年初储量 | 储量报告 | 是否"吃老本" | >3% 且无新增 → 黄色 |
| 采矿权/探矿权账面价值 | 权利资产 | 无形资产中采矿权余额 | 附注 | 摊销负担 | 与剩余年限对比判断摊销是否充分 |
| 单位储量获取成本 | 补储成本 | 年度勘探/收购支出 / 新增可采储量 | 现金流量表+储量报告 | 扩张经济性 | 高于单吨毛利 → 扩张不经济 |
| 资源集中度 | 单一矿山依赖 | 最大矿山产量 / 总产量 | 生产台账 | 单点风险 | >50% → 黄色；>70% → 红色 |

## 3. 产能与产量指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 设计产能 | 核定生产能力 | 设计文件 | 生产台账 | 上限 | — |
| 实际产量 | 报告期产出 | 生产台账 | 生产台账 | 真实供给 | 连续下滑 → 追因（品位/检修/政策） |
| 产能利用率 | 产能发挥程度 | 实际产量 / 设计产能 | 生产台账 | 效率与需求 | <70% → 黄色；<50% → 红色 |
| 销量 | 实际销售数量 | 销售台账 | 销售台账 | 变现体量 | 产量升销量降 → 库存积压 |
| 产销率 | 产销匹配 | 销量 / 产量 | 生产+销售台账 | 库存压力 | <90% → 黄色；<80% → 红色 |
| 回收率 | 选矿回收水平 | 精矿金属量 / 原矿金属量 | 生产台账 | 工艺水平 | 同比下滑 >3pct → 黄色 |
| 剥采比（露天） | 剥离与采矿比 | 剥离量 / 采矿量 | 生产台账 | 成本驱动 | 上升 → 单位成本将上升 |
| 品位达标率 | 实际品位与设计差 | 实际入选品位 / 设计品位 | 生产台账 | 资源质量 | <90% → 黄色 |

## 4. 成本指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 吨矿成本 | 单位原矿成本 | 采矿总成本 / 原矿产量 | 成本台账 | 采选效率 | 同比上升 >10% → 追因 |
| 吨产品成本 | 单位精矿/金属成本 | 产品成本 / 产品产量 | 成本台账 | 单位经济性 | 与售价对比看安全边际 |
| 现金成本（C1） | 不含折旧摊销的现金支出 | (材料+能源+人工+运输+税费)/产量 | 成本台账 | 抗跌能力 | 价格跌至现金成本 → 停产临界 |
| 完全成本 | 含折旧摊销与期间费用 | 现金成本 + 折旧摊销/产量 + 期间费用/产量 | 成本台账 | 真实盈利门槛 | 价格低于完全成本 → 亏损 |
| 单位毛利 | 每吨赚钱能力 | 单位售价 − 单位完全成本 | 计算 | 核心盈利指标 | 连续收窄 → 黄色 |
| 折旧摊销占比 | 固定成本刚性 | 折旧摊销 / 营业成本 | 两表 | 成本刚性 | >30% → 减产时成本难降 |
| 能源成本占比 | 能耗敏感度 | 能源成本 / 营业成本 | 成本台账 | 能源价格敞口 | >30% → 能源涨价敏感 |
| 人工成本占比 | 人力密集度 | 人工成本 / 营业成本 | 成本台账 | 刚性成本 | 高占比 + 产量降 → 单位成本升 |
| 运输成本占比 | 物流半径 | 运输成本 / 营业成本 | 成本台账 | 区位劣势 | >15% → 价格竞争力弱 |
| 资源税/权益金率 | 税费负担 | 资源税 / 收入 | 两表/附注 | 政策敞口 | 政策变动需单独提示 |
| 单位成本同比 | 成本趋势 | (本期单位成本 − 上期)/上期 | 计算 | 成本控制 | 连续 2 年上升 >5% → 黄色 |

## 5. 盈利与价格指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 销售单价 | 单位售价 | 销售收入 / 销量 | 两表 | 价格水平 | 与市场价对比判断折价 |
| 单吨收入 | 单位收入 | 同上（按产品分） | 两表 | 变现能力 | 下滑 → 量价齐跌风险 |
| 单吨毛利 | 单位毛利 | 单吨收入 − 吨产品成本 | 计算 | 核心盈利 | <0 → 红色 |
| 毛利率 | 产品盈利水平 | 毛利 / 收入 | 利润表 | 盈利空间 | 同比下滑 >5pct → 黄色 |
| EBITDA 率 | 现金盈利水平 | EBITDA / 收入 | 计算 | 重资产关键 | <20%（矿业）→ 黄色 |
| 单矿利润 | 单矿山盈利 | 矿山收入 − 矿山成本费用 | 分部数据 | 资产质量 | 单矿长期亏损 → 减值风险 |
| 单矿现金流 | 单矿山现金贡献 | 矿山 EBITDA − 维持性 CAPEX | 分部数据 | 真实造血 | <0 → 靠其他矿补贴 |
| 价格实现率 | 售价与市场价之比 | 实际售价 / 市场均价 | 两表+外部 | 销售能力 | <90% → 长协折价或品位折价 |
| 价格-成本剪刀差 | 盈利驱动方向 | 售价同比变化 − 单位成本同比变化 | 计算 | 利润归因 | 为负 → 利润被成本侵蚀 |
| 利润归因分解 | 量价本三因素 | 分别测算量、价、成本对利润的影响 | 计算 | 解释利润变动 | 必须出结论：谁影响最大 |

### 5.1 量价本归因公式（必须计算）

设基期销量 Q0、单价 P0、单位成本 C0；本期 Q1、P1、C1。

```
销量影响 = (Q1 − Q0) × (P0 − C0)
价格影响 = (P1 − P0) × Q1
成本影响 = (C0 − C1) × Q1
利润变动 ≈ 销量影响 + 价格影响 + 成本影响
```

**输出要求**：明确回答「**矿价变化和成本变化，谁对利润影响更大？**」，并给出三项影响金额与占比。

## 6. CAPEX 与自由现金流指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 维持性 CAPEX | 保产所需投入 | 维持现有产能的支出 | 现金流量表/管理报表 | 生存成本 | 无法区分时须声明按比例估算 |
| 扩张性 CAPEX | 新增产能投入 | 新矿建设/扩产/技改 | 同上 | 增长投入 | 回报不明确 → 黄色 |
| CAPEX/收入 | 投资强度 | CAPEX / 收入 | 现金流量表 | 资本密集度 | >30% → 黄色 |
| CAPEX/产量 | 单位产能投入 | CAPEX / 产量 | 计算 | 投资效率 | 持续上升 → 边际回报下降 |
| CAPEX 现金覆盖率 | 内生投资能力 | CFO / CAPEX | 现金流量表 | 融资依赖 | <1 → 依赖融资；连续 3 年 <1 → 红色 |
| 单位产能投资额 | 新建成本 | 项目投资额 / 新增产能 | 项目资料 | 投资经济性 | 高于行业经验值 → 需说明 |
| 自由现金流 FCF | 可自由支配现金 | CFO − CAPEX | 现金流量表 | 真实回报 | 连续为负 → 红色 |
| CAPEX 回报率 | 投入产出 | 新增 EBITDA / 累计 CAPEX | 计算 | 投资效果 | <10% → 黄色 |

## 7. 价格敏感性模型（有产量与成本数据时必须生成）

对基准情景按 **−30% / −20% / −10% / 基准 / +10% / +20% / +30%** 七档价格情景测算。

**测算口径（固定）**

| 项目 | 处理方式 |
|---|---|
| 收入 | 销量 × 价格（销量假设不变，除非用户指定弹性） |
| 成本 | 单位成本不变（刚性成本假设）；若用户提供成本弹性，按弹性调整 |
| 折旧摊销 | 不变 |
| 税费 | 资源税按收入比例同步变动；所得税按 25%（或用户指定税率） |
| EBITDA | 收入 − 现金成本 |
| 净利润 | (EBITDA − 折旧摊销 − 利息支出) × (1 − 税率) |
| 经营现金流 | 净利润 + 折旧摊销（简化口径，须声明） |
| 自由现金流 | 经营现金流 − CAPEX |
| 偿债能力 | EBITDA/利息、现金短债比、FCF 是否为正 |

**输出表（固定）**

| 价格情景 | 收入 | EBITDA | 净利润 | 经营现金流 | 自由现金流 | EBITDA/利息 | 结论 |
|---|---:|---:|---:|---:|---:|---:|---|
| −30% | | | | | | | |
| −20% | | | | | | | |
| −10% | | | | | | | |
| 基准 | | | | | | | |
| +10% | | | | | | | |
| +20% | | | | | | | |
| +30% | | | | | | | |

**必须给出的结论**：
1. **盈亏平衡价格**：使净利润 = 0 的价格。
2. **现金平衡价格**：使经营现金流 = 0 的价格（即现金成本线）。
3. **偿债临界价格**：使 EBITDA/利息 = 1 的价格。
4. 当前价格距离上述三条线各有多少缓冲（百分比）。

## 8. 矿业核心风险清单（自动识别）

| 风险 | 触发判据 | 证据要求 |
|---|---|---|
| 价格周期风险 | 价格处于历史低位或同比下滑 >20% | 价格数据来源与年份 |
| 成本刚性风险 | 单位成本连续上升 >2 年 | 成本台账趋势 |
| 储量枯竭风险 | 剩余服务年限 <5 年或储采比 <8 | 储量报告 |
| 补储不足 | 储量消耗率 >3% 且无新增探明 | 储量报告 |
| 产能利用不足 | 产能利用率 <70% | 生产台账 |
| 产销失衡 | 产销率 <90% | 生产/销售台账 |
| 品位下滑 | 入选品位同比下降 >5% | 生产台账 |
| CAPEX 过度 | CAPEX/收入 >30% 且 FCF 为负 | 现金流量表 |
| 维持性投入不足 | 维持性 CAPEX 低于折旧摊销的 60% | 现金流量表+管理报表 |
| 单点依赖 | 最大矿山产量占比 >50% | 生产台账 |
| 政策与合规 | 采矿权到期、环保/安全处罚、资源税调整 | 公告/附注；无证据须声明 |
| 减值风险 | 单矿长期亏损或价格低于完全成本 | 分部数据 |
