# 03 · 房地产专项指标库

> 由 Skill 03（`roles/real-estate`）加载。适用：房地产开发、城市更新/土地开发、产业园区（含开发销售部分）。

## 1. 经营闭环（分析主线）

```
拿地 → 土地成本 → 开发建设 → 形成货值 → 销售 → 回款 → 结算 → 利润 → 再投资
```

**核心判断**：这条链条上任何一环的节奏变化，都会在 6–18 个月后反映到报表。分析必须按链条顺序推进，而不是先看利润表。

| 环节 | 关键问题 | 对应指标 |
|---|---|---|
| 拿地 | 拿地强度是否与回款匹配？ | 拿地金额/销售金额、土储去化周期 |
| 土地成本 | 地价是否吃掉未来毛利？ | 土地成本率、地货比 |
| 开发建设 | 在建规模是否可控？ | 在建面积/在建工程、CAPEX |
| 货值 | 可售资源是否足够？ | 土储货值、货值覆盖倍数 |
| 销售 | 去化是否健康？ | 销售额、去化率、销售均价 |
| 回款 | 回款是否跟得上？ | 回款率、收现比 |
| 结算 | 结算与销售是否匹配？ | 已售未结、合同负债 |
| 利润 | 毛利是否被地价侵蚀？ | 项目毛利率、结算毛利率 |
| 再投资 | 是否靠融资滚动？ | 融资依赖度、净负债率 |

## 2. 土地储备指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 土地储备面积 | 可开发土地总量 | Σ 各项目未开发+未售建面 | 土储台账 | 未来可售资源 | 与销售规模对比判断可持续性 |
| 土地储备货值 | 按现价估算可售总额 | Σ 未售面积 × 区域可比售价 | 土储台账+市场价 | 未来销售池 | 货值下降 → 规模收缩 |
| 货值覆盖倍数 | 土储对年度销售的支撑 | 土储货值 / 当年销售额 | 土储+销售 | 可持续年限 | <2 年 → 黄色；<1 年 → 红色 |
| 土储去化周期 | 卖完现有土储所需年数 | 土储面积 / 年销售面积 | 土储+销售 | 资源周转 | >5 年 → 黄色；>8 年 → 红色 |
| 土地成本率 | 地价占售价比重 | 土地成本 / 预计售价 | 项目台账 | 利润空间 | >40% → 毛利率承压；>50% → 红色 |
| 地货比 | 地价与货值比 | 拿地金额 / 对应货值 | 项目台账 | 拿地纪律 | >0.4 → 黄色 |
| 拿地强度 | 扩张节奏 | 当年拿地金额 / 当年销售额 | 土储+销售 | 现金流匹配 | >0.4 且回款率下滑 → 红色 |
| 土储区域集中度 | 区域敞口 | 单一城市群土储货值 / 总货值 | 土储台账 | 区域周期风险 | >50% → 黄色；>70% → 红色 |
| 土储城市能级结构 | 一二线 vs 三四线占比 | 分类货值 / 总货值 | 土储台账 | 去化质量 | 三四线占比 >60% → 去化风险上升 |
| 项目进入时间结构 | 土储新旧 | 各年份获取土储占比 | 土储台账 | 地价水位 | 高价年份土储占比高 → 潜在减值 |

## 3. 销售与回款指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 销售额（全口径/权益） | 签约规模 | Σ 签约金额 | 销售台账 | 规模与排名 | 全口径与权益口径差距大 → 合作开发依赖 |
| 销售面积 | 签约面积 | Σ 签约面积 | 销售台账 | 去化体量 | 面积增而金额降 → 均价下行 |
| 销售均价 | 单位售价 | 销售额 / 销售面积 | 销售台账 | 产品结构与价格 | 同比下滑 >10% → 黄色 |
| 去化率 | 可售资源售出比例 | 累计已售面积 / 可售面积 | 项目台账 | 需求强度 | <50%（首开一年内）→ 黄色；<30% → 红色 |
| 回款率 | 签约到回款的转化 | 回款额 / 销售额 | 回款台账 | 现金质量 | <80% → 黄色；<60% → 红色 |
| 权益比 | 归属本公司的比例 | 权益货值 / 全口径货值 | 项目台账 | 真实规模 | <60% → 规模含水分 |
| 已售未结 | 已卖未确认收入 | 合同负债 + 已售未结明细 | 资产负债表/附注 | 未来收入池 | 与未来 12 个月收入比对 |
| 结算收入/销售额比 | 结算节奏 | 当年结算收入 / 上年销售额 | 两表 | 收入确认节奏 | 长期 <0.5 → 收入滞后或交付困难 |
| 单方销售费用 | 获客成本 | 销售费用 / 销售面积 | 两表 | 营销效率 | 持续上升 → 去化难度加大 |

## 4. 存货与开发指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 存货构成 | 开发成本/开发产品/拟开发 | 各明细 / 存货合计 | 附注 | 沉淀结构 | 开发产品占比高 → 已建成未售，去化差 |
| 存货周转率/天数 | 存货变现速度 | 360 / (营业成本 / 平均存货) | 两表 | 周转效率 | >1000 天 → 黄色；>1500 天 → 红色 |
| 存货跌价准备率 | 减值计提强度 | 存货跌价准备 / 存货原值 | 附注 | 资产高估程度 | 低计提但售价下行 → 潜在减值 |
| 在建规模 | 开发投入强度 | 在建面积 / 销售面积 | 项目台账 | 资金占用 | >3 倍且回款放缓 → 资金链风险 |
| 开发成本率 | 建安占售价比 | 建安成本 / 售价 | 项目台账 | 成本控制 | 上升 >3pct → 毛利率承压 |
| 单方土地+建安成本 | 单位成本合计 | (土地+建安)/可售面积 | 项目台账 | 成本竞争力 | 与区域售价对比判断安全边际 |
| 已完工未售货值 | 现房库存 | Σ 完工未售货值 | 项目台账 | 变现压力 | 占总货值 >30% → 黄色 |

## 5. 项目盈利与现金流指标

| 指标 | 中文解释 | 计算公式 | 数据来源 | 指标意义 | 风险判断方式 |
|---|---|---|---|---|---|
| 项目货值 | 项目可售总额 | 可售面积 × 预计售价 | 项目台账 | 项目规模 | — |
| 项目毛利率 | 项目盈利能力 | (货值 − 土地 − 建安 − 其他)/货值 | 项目台账 | 单项目质量 | <10% → 黄色；<5% → 红色 |
| 项目净利率 | 扣除费用与税后 | (货值 − 全成本 − 税费 − 费用)/货值 | 项目台账 | 真实回报 | <5% → 黄色 |
| 项目 IRR | 项目内部收益率 | 现金流折现 | 项目台账 | 投资回报 | <融资成本 → 毁灭价值 |
| 项目现金流峰值缺口 | 最大资金占用 | min(累计净现金流) | 项目台账 | 资金需求 | 缺口大且融资未落实 → 红色 |
| 项目回收期 | 现金回正时间 | 累计净现金流首次转正时点 | 项目台账 | 周转效率 | >4 年 → 黄色 |
| 项目资金回正率 | 自有资金回收程度 | 累计回款 / 累计自有投入 | 项目台账 | 资本效率 | <1 且临近完工 → 红色 |
| 未来资金需求 | 后续开发缺口 | Σ 后续开发支出 − 预计回款 | 项目台账 | 融资需求 | 与可用融资额度对比 |

## 6. 房地产杠杆与监管口径

| 指标 | 中文解释 | 计算公式 | 风险判断方式 |
|---|---|---|---|
| 剔除预收款后资产负债率 | 监管"三道红线"之一 | (总负债 − 预收/合同负债)/总资产 | >70% → 踩线（黄） |
| 净负债率 | 监管"三道红线"之二 | (有息负债 − 现金)/所有者权益 | >100% → 踩线（黄） |
| 现金短债比 | 监管"三道红线"之三 | 现金 / 短期有息负债 | <1 → 踩线（黄） |
| 三道红线档位 | 综合档位 | 按踩线数：0 绿 / 1 黄 / 2 橙 / 3 红 | 橙色及以上 → 融资受限，红色 → 高度依赖非标 |
| 少数股东权益占比 | 明股实债嫌疑 | 少数股东权益 / 所有者权益 | 高占比 + 少数股东损益长期为负/极小 → 需穿透核查 |
| 合作方往来 | 联营合营资金占用 | 其他应收款中合作方往来 | 金额大 → 核查是否存在资金占用 |
| 表外负债线索 | 隐性债务 | 明股实债、担保、代建垫资 | 有线索必须列示，标注无法验证 |

## 7. 项目盈利矩阵（有项目数据时必须生成）

**列定义（固定）**

| 项目 | 货值 | 成本 | 销售额 | 毛利 | 毛利率 | 去化率 | 回款 | 未来资金需求 | 风险 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---|

**分类标准（四类）**

| 类别 | 判据（同时满足） | 建议动作 |
|---|---|---|
| 优质项目 | 毛利率 ≥ 20% 且 去化率 ≥ 70% 且 回款率 ≥ 85% | 保持节奏，优先保障资源 |
| 正常项目 | 毛利率 10%–20%，去化率 50%–70% | 盯紧去化与回款节奏 |
| 低利润项目 | 毛利率 5%–10%，或去化率 30%–50% | 压降成本、加快去化，评估退出 |
| 高风险项目 | 毛利率 < 5% 或 去化率 < 30% 或 未来资金需求 > 可用融资 | 专项处置，考虑合作方让利/降价/整体转让 |

> 阈值可按企业所在城市能级调整，但**必须在报告中声明调整依据**，不得静默改动。

## 8. 房地产核心风险清单（自动识别）

| 风险 | 触发判据 | 证据要求 |
|---|---|---|
| 高库存 | 存货/总资产 > 60% 且 周转天数 > 1000 | 存货明细 + 周转趋势 |
| 去化缓慢 | 去化率 < 50% 或同比下滑 >15pct | 项目去化台账 |
| 高土地成本 | 土地成本率 > 40% | 项目成本明细 |
| 毛利率下降 | 毛利率同比下滑 >3pct | 结算毛利率趋势 |
| 销售回款下降 | 回款率 < 80% 或回款额同比下滑 >20% | 回款台账 |
| 项目延期 | 计划交付 vs 实际交付偏差 >6 个月 | 项目节点表 |
| 高杠杆 | 净负债率 > 100% 或 资产负债率 > 80% | 报表 + 有息负债明细 |
| 短债集中 | 一年内到期债务 / 有息负债 > 40% | 借款台账 |
| 土储质量下降 | 三四线货值占比 > 60% 或 高价年土储占比 > 50% | 土储台账 |
| 区域集中 | 单一城市群货值占比 > 50% | 土储/销售区域拆分 |
| 明股实债 | 少数股东权益占比高且损益异常 | 附注 + 合作方明细 |
| 表外风险 | 存在担保/代建/明股实债线索 | 附注；无法验证须声明 |
