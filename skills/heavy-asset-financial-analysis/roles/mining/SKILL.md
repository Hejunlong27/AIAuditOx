# 角色 · 矿产（资源型）企业经营与财务分析（Mining）

> 由顶层 `heavy-asset-financial-analysis` 在【环节 3 行业专项】调用（企业类型 = 矿产 / 矿山 / 资源型能源）。子技能 04。

## 1. 定位与适用场景

**定位**：把财务报表翻译成"**资源—产能—产量—价格—成本**"的经营语言，判断这家矿业公司的**盈利来源、成本韧性、储量续接与投资强度**。

**适用场景**
- 矿山单位成本与盈利能力分析
- 价格敏感性 / 盈亏平衡价测算
- 储量与矿山寿命评估
- CAPEX 合理性与投资回报分析
- 矿业财务尽调中的经营专项部分

**前置**：必须先有 Skill 02（三表及经营分析）的输出。

## 2. 输入 / 输出

| | 内容 |
|---|---|
| **输入** | `standard_dataset.json` + 生产台账 / 储量报告 / 成本台账 / 销售台账 / 商品价格数据 |
| **输出** | `03-industry/mining-analysis.md`、`sensitivity.csv`（七档价格敏感性）、三级盈利（矿山→产品→公司）、三条价格临界线 |
| **降级** | 缺储量报告 → 储采比与矿山寿命无法计算；缺分产品成本 → 三级盈利降为二级 |

## 3. Instructions（执行步骤）

1. 读标准数据集与经营台账，确认 `meta.industry` 属资源型。
2. 按**经营闭环**顺序分析：
   `资源储量 → 可采储量 → 设计产能 → 实际产量 → 回收率 → 销量 → 销售价格 → 单位成本 → 单位毛利 → 经营现金流 → CAPEX → 自由现金流 → 储量消耗`
3. 出资源与储量指标（储量、品位、剩余服务年限、储采比、储量消耗率）。
4. 出产能与产量指标（利用率、产销率、回收率、剥采比）。
5. 出成本分析（吨矿成本、吨产品成本、现金成本 C1、完全成本、成本结构占比）。
6. 做**量价本归因**，明确回答"矿价与成本谁对利润影响更大"。
7. 出 CAPEX 分析（维持性 vs 扩张性、强度、回报、覆盖率）。
8. 生成**七档价格敏感性表** + 三条临界线（盈亏平衡价、现金平衡价、偿债临界价）。
9. 逐条跑第 6 节风险清单，输出结论。

## 4. 计算逻辑

指标与公式见 `references/04-mining-indicators.md`。核心必算：

```
吨矿成本   = 采矿总成本 ÷ 原矿产量
吨产品成本 = 产品成本 ÷ 产品产量
现金成本C1 = (材料 + 能源 + 人工 + 运输 + 税费) ÷ 产量
完全成本   = 现金成本 + 折旧摊销÷产量 + 期间费用÷产量
单位毛利   = 销售单价 − 单位完全成本
储采比     = 可采储量 ÷ 年产量
储量消耗率 = (采出量 − 新增探明量) ÷ 年初储量
产能利用率 = 实际产量 ÷ 设计产能
产销率     = 销量 ÷ 产量
```

**量价本归因（必须计算）**

```
销量影响 = (Q1 − Q0) × (P0 − C0)
价格影响 = (P1 − P0) × Q1
成本影响 = (C0 − C1) × Q1
利润变动 ≈ 三项之和
```

**价格敏感性口径**

| 项目 | 处理 |
|---|---|
| 收入 | 销量 × 价格（销量不变，除非用户指定弹性） |
| 成本 | 单位成本不变（刚性成本假设）；用户提供弹性时按弹性调整 |
| 折旧摊销 | 不变 |
| 税费 | 资源税按收入比例同步；所得税按 25%（或用户指定） |
| EBITDA | 收入 − 现金成本 |
| 净利润 | (EBITDA − 折旧摊销 − 利息支出) × (1 − 税率) |
| 经营现金流 | 净利润 + 折旧摊销（简化口径，须声明） |
| 自由现金流 | 经营现金流 − CAPEX |
| 偿债 | EBITDA/利息、FCF 是否为正 |

## 5. 分析逻辑

**三级盈利**：矿山 → 产品 → 公司。逐级回答：
1. 哪座矿在赚钱，哪座在亏？
2. 哪个产品在贡献毛利？
3. 公司层面利润是主业给的还是副产品/投资收益给的？

**成本韧性四问**：
1. 单位成本是涨还是跌？涨的原因是什么（品位、剥采比、能源、人工）？
2. 成本里多少是刚性（折旧、人工）？减产时能不能降下来？
3. 现金成本距离售价还有多少缓冲？
4. 完全成本线在哪里？现价能否覆盖？

**CAPEX 三问**：
1. 维持性 CAPEX 够不够（对比折旧摊销的 60%）？
2. 扩张性 CAPEX 回报如何（新增 EBITDA ÷ 累计 CAPEX）？
3. CFO 能不能覆盖 CAPEX？

## 6. 风险规则（自动识别）

| 风险 | 触发判据 | 证据要求 |
|---|---|---|
| 价格周期风险 | 价格同比下滑 >20% 或处历史低位 | 价格数据来源与年份 |
| 成本刚性风险 | 单位成本连续上升 >2 年 | 成本台账趋势 |
| 储量枯竭风险 | 剩余服务年限 <5 年 或 储采比 <8 年 | 储量报告 |
| 补储不足 | 储量消耗率 >3% 且无新增探明 | 储量报告 |
| 产能利用不足 | 产能利用率 <70% | 生产台账 |
| 产销失衡 | 产销率 <90% | 生产/销售台账 |
| 品位下滑 | 入选品位同比 −5% | 生产台账 |
| CAPEX 过度 | CAPEX/收入 >30% 且 FCF <0 | 现金流量表 |
| 维持性投入不足 | 维持性 CAPEX < 折旧摊销 ×60% | 管理报表 + 现金流量表 |
| 单点依赖 | 最大矿山产量占比 >50% | 生产台账 |
| 政策与合规 | 采矿权到期、环保/安全处罚、资源税调整 | 公告/附注；无证据须声明 |
| 减值风险 | 单矿长期亏损或价格低于完全成本 | 分部数据 |

## 7. 示例任务

**用户**：「帮我分析这个矿山的单位成本和盈利能力。」

**示例输出（节选）**

```markdown
# 某矿业 矿业专项分析（2024–2025）
口径：合并 | 单位：万元 / 万吨 / 元/吨 | 来源：2025 审计报告、生产台账、储量报告

## 一句话结论
2025 年利润下滑 **76% 来自价格**，而非成本失控；成本控制基本达标，
但**储采比已降至 6.8 年**、维持性 CAPEX 仅占折旧摊销的 52%，
公司真正的风险不是当期盈利，而是**三年后的资源续接与产能维持**。

## 一、量价本归因（2024 → 2025）
| 因素 | 影响金额（万元） | 占比 | 说明 |
|---|---:|---:|---|
| 价格影响 | −24,300 | 76% | 均价 4,850 → 4,120 元/吨（−15.1%） |
| 销量影响 | −3,900 | 12% | 销量 42.0 → 40.5 万吨（−3.6%） |
| 成本影响 | −3,800 | 12% | 单位成本 3,180 → 3,240 元/吨（+1.9%） |
| **合计** | **−32,000** | 100% | 毛利 70,140 → 38,140 万元 |
**结论**：矿价变化对利润的影响是成本的 **6.4 倍**。成本控制不是主要矛盾，价格敞口才是。

## 二、成本分析
| 指标 | 2023 | 2024 | 2025 | 判断 |
|---|---:|---:|---:|---|
| 吨矿成本（元/吨） | 152 | 158 | 161 | 温和上升 |
| 吨产品成本（元/吨） | 3,120 | 3,180 | 3,240 | +1.9% |
| 现金成本 C1（元/吨） | 2,760 | 2,810 | 2,860 | 抗跌线 |
| 完全成本（元/吨） | 3,120 | 3,180 | 3,240 | 盈利门槛 |
| 单位毛利（元/吨） | 1,980 | 1,670 | 880 | 🔴 两年 −55.6% |
| 折旧摊销占营业成本 | 24% | 26% | 27% | 刚性偏高 |
| 能源成本占营业成本 | 31% | 33% | 34% | 🟡 能源敞口大 |

## 三、资源与储量
| 指标 | 2023 | 2024 | 2025 | 判断 |
|---|---:|---:|---:|---|
| 可采储量（万吨） | 342 | 320 | 276 | 两年 −19.3% |
| 入选品位（%） | 1.42 | 1.38 | 1.31 | 🟡 品位下滑 |
| 年产量（万吨） | 40.8 | 42.0 | 40.5 | 基本稳定 |
| 储采比（年） | 8.4 | 7.6 | 6.8 | 🔴 <8 |
| 储量消耗率 | +1.2% | +1.9% | +2.6% | 🟡 净消耗 |
| 剩余服务年限 | 8.4 | 7.6 | 6.8 | 🔴 无接续资源 |
**结论**：品位下滑与储量净消耗同时发生，若 2028 年前无新增探明储量，产量将被动下滑。

## 四、CAPEX
| 指标 | 2023 | 2024 | 2025 |
|---|---:|---:|---:|
| 维持性 CAPEX | 4,200 | 3,900 | 3,600 |
| 扩张性 CAPEX | 2,100 | 3,400 | 2,800 |
| CAPEX 合计 | 6,300 | 7,300 | 6,400 |
| CAPEX/收入 | 11.0% | 11.5% | 10.6% |
| CFO/CAPEX | 1.42 | 1.08 | 0.86 |
| 自由现金流 | 2,650 | 600 | −880 |
**结论**：维持性 CAPEX（3,600）低于折旧摊销（5,180）的 60%（3,108）… 实为 69%，尚可；
但 CFO/CAPEX 已降至 0.86，自由现金流转负，投资开始依赖融资。

## 五、价格敏感性（基准：销量 40.5 万吨，单位现金成本 2,860 元/吨）
| 价格情景 | 单价(元/吨) | 收入 | EBITDA | 净利润 | 经营现金流 | 自由现金流 | EBITDA/利息 | 结论 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| −30% | 2,884 | 116,802 | 972 | −4,910 | −1,220 | −7,620 | 0.2 | 🔴 亏损+现金断裂 |
| −20% | 3,296 | 133,488 | 17,658 | 6,110 | 9,800 | 3,400 | 1.4 | 🔴 接近现金平衡 |
| −10% | 3,708 | 150,174 | 34,344 | 18,130 | 21,820 | 15,420 | 3.2 | 🟡 |
| 基准 | 4,120 | 166,860 | 51,030 | 30,140 | 33,830 | 27,430 | 5.4 | 🟢 |
| +10% | 4,532 | 183,546 | 67,716 | 42,150 | 45,840 | 39,440 | 7.6 | 🟢 |
| +20% | 4,944 | 200,232 | 84,402 | 54,160 | 57,850 | 51,450 | 9.8 | 🟢 |
| +30% | 5,356 | 216,918 | 101,088 | 66,170 | 69,860 | 63,460 | 12.0 | 🟢 |

**三条临界线**
| 临界线 | 价格（元/吨） | 相对现价缓冲 |
|---|---:|---:|
| 盈亏平衡价（净利润=0） | 3,412 | −17.2% |
| 现金平衡价（经营现金流=0） | 3,152 | −23.5% |
| 偿债临界价（EBITDA/利息=1） | 2,988 | −27.5% |
**结论**：现价距盈亏平衡价仅 17.2% 缓冲；若矿价回到 2023 年低位（约 3,900 元/吨），公司仍在盈利，
但自由现金流将转负，需提前安排融资。

## 六、核心风险清单
| 风险 | 证据 | 评级 |
|---|---|---|
| 储量枯竭 | 储采比 6.8 年，无接续资源 | 🔴 |
| 品位下滑 | 入选品位 1.42% → 1.31% | 🟡 |
| 价格周期 | 均价 −15.1%，利润 −76% 归因于价格 | 🟡 |
| 自由现金流转负 | FCF −880 万元，CFO/CAPEX 0.86 | 🟡 |
| 能源成本敞口 | 能源占营业成本 34% | 🟡 |

## 七、建议动作
1. 2026 年 Q2 前完成接续资源方案（新增探明或收购矿权），否则 2028 年产量将被动下滑。
2. 对能源成本（占 34%）签订长协或做套保，锁定价差。
3. 在矿价 >4,300 元/吨时优先偿还短债，为 2027 年 FCF 转负预留缓冲。
4. 品位下滑需技改配矿方案，目标把入选品位稳定在 1.35% 以上。
```

## 8. 边界

- **不做偿债评级与压力测试**（归 Skill 05），只提供价格敏感性中的偿债临界价。
- 无储量报告时，不得估算储量、品位、矿山寿命。
- 外部价格数据必须标注来源与年份；无来源标为"经验参考值"。
- 不做大宗商品走势预测，只做情景测算。
- 不做证券估值与买卖建议。
