# 角色 · 重资产企业三表及经营财务分析（Statement Analysis）

> 由顶层 `heavy-asset-financial-analysis` 在【环节 2 财务分析】调用。子技能 02。

## 1. 定位与适用场景

**定位**：回答"**这家公司整体财务状态如何**"。五维分析：盈利能力 + 资产质量 + 营运效率 + 现金流 + 经营质量。

**适用场景**
- 财务概览、三表分析、年度/季度复盘
- 尽调中的通用财务部分
- 作为行业专项（Skill 03/04）与风险分析（Skill 05）的前置

## 2. 输入 / 输出

| | 内容 |
|---|---|
| **输入** | `01-standard/standard_dataset.json`（缺则先要求跑 Skill 01） |
| **输出** | `02-statements/statement-analysis.md`、`02-statements/metrics.json` |
| **必含** | 五维结论、3 年趋势（数据允许则 5 年 / 4 季）、财务质量背离清单、异常变动追因 |

## 3. Instructions（执行步骤）

1. 读取标准数据集，确认 `meta` 与 `qc.status`；`fail` 则停止。
2. 跑指标：`python scripts/fin_metrics.py --input standard_dataset.json --industry <类型> --out metrics.json`。
3. 按 **资产负债表 → 利润表 → 现金流量表 → 营运资金 → 财务趋势 → 财务质量** 顺序分析。
4. 对每个变动 >20% 或与经营逻辑相悖的科目，**先追因再下结论**。
5. 执行第 8 节的 5 条交叉验证链条，逐条给"通/断"结论。
6. 输出五维结论 + 趋势 + 背离清单 + 异常追因。
7. 自检：每条结论是否都有 `数据 → 指标 → 趋势 → 原因 → 风险 → 结论` 链条。

## 4. 计算逻辑

### 4.1 资产负债表

**资产端**（关注结构、流动性、重资产程度、周转、质量、减值、沉淀）
货币资金、应收账款、其他应收款、存货、固定资产、在建工程、投资性房地产、长期股权投资、无形资产、商誉、受限资产。

**负债端**（关注有息负债、期限、结构、杠杆、短期压力、融资依赖）
应付账款、其他应付款、短期借款、长期借款、一年内到期非流动负债、公司债、租赁负债、其他有息负债。

### 4.2 利润表

收入 / 收入增长 / 毛利 / 毛利率 / EBITDA / EBITDA 率 / 营业利润 / 净利润 / 净利率 / ROA / ROE / 期间费用率 / 财务费用 / 利息支出 / 资产减值 / 信用减值 / 投资收益 / 公允价值变动 / 非经常性损益。

**必须识别"真正的主营盈利能力"**：
```
主营利润 = 营业利润 − 投资收益 − 公允价值变动收益 − 其他收益 − 资产处置收益
主营利润占比 = 主营利润 / 营业利润
```
占比 < 50% → 盈利不可持续（黄色）。

### 4.3 现金流量表

CFO / CFI / CFF / 净现比（CFO÷净利润）/ 收现比（销售收现÷收入）/ 现金流收入比（CFO÷收入）/ CAPEX / CAPEX 覆盖率（CFO÷CAPEX）/ 自由现金流（CFO − CAPEX）。

**必须回答**："企业到底有没有把利润转化为现金。"

### 4.4 营运资金

应收周转天数、存货周转天数、应付周转天数、现金转换周期 CCC。
**必须识别**："增长是否带来更多资金占用。"

### 4.5 财务趋势

- 年度默认 **3 年**，数据允许扩展到 **5 年**；季度默认 **4 季**（同比优先）。
- 计算：同比、环比、CAGR。
- 口径变更（合并范围变化）时标注不可比。

公式细节见 `references/02-indicator-library.md`。

## 5. 分析逻辑（五维展开顺序）

| 维度 | 先问什么 | 再答什么 |
|---|---|---|
| 1 盈利 | 赚不赚钱？赚的是不是主营？ | 毛利率趋势、主营利润占比、ROE 是否靠杠杆 |
| 2 资产 | 资产是什么？能不能变现？ | 结构、周转、受限、减值 |
| 3 效率 | 增长有没有带来资金占用？ | 周转天数、CCC、总资产周转率 |
| 4 现金流 | 利润有没有变成钱？ | 净现比、收现比、FCF |
| 5 质量 | 增长是否健康？ | 收入/利润/资产/现金流四者增速是否同向 |

**分析优先级固定**：现金安全 > 偿债能力 > 资产质量 > 盈利质量 > 盈利规模 > 增长速度。

## 6. 风险规则（财务质量背离，必须逐条检查）

| 编号 | 背离 | 判据 | 含义 |
|---|---|---|---|
| QA-01 | 收入与现金流背离 | 收入增长但收现比 < 0.9 或 CFO 下滑 | 收入靠赊销 |
| QA-02 | 利润与现金流背离 | 净利润 > 0 且 CFO < 0，或净现比 < 0.5 持续 2 年 | 利润不含金 |
| QA-03 | 资产与收入背离 | 总资产增速 > 收入增速持续 2 年 | 扩张无效 |
| QA-04 | 借款增长过快 | 有息负债增速 − 收入增速 > 20pct | 杠杆扩张 |
| QA-05 | 应收增长过快 | 应收增速 > 收入增速，周转天数 +30 天 | 回款恶化 |
| QA-06 | 存货增长过快 | 存货增速 > 收入增速，周转天数上升 | 积压 |
| QA-07 | CAPEX 异常 | CAPEX/收入 > 30% 且 CFO/CAPEX < 1 | 现金被投资吞掉 |
| QA-08 | 减值异常 | 连续 2 年计提减值 | 存量资产高估 |
| QA-09 | 主营虚化 | 主营利润占比 < 50% | 利润不可持续 |

## 7. 示例任务

**用户**：「帮我分析这家公司近三年的财务情况。」（提供 2023–2025 三表 + 附注）

**执行**：读标准数据集 → 跑 `fin_metrics.py` → 五维分析 → 5 条链条验证 → 输出。

**示例输出（节选）**

```markdown
# 某某控股 三表及经营财务分析（2023–2025）
口径：合并 | 单位：万元 | 来源：2023–2025 审计报告

## 一句话结论
规模仍在增长但现金创造能力持续弱于账面利润，杠杆扩张速度已明显快于收入，
公司当前的主要约束不是盈利能力，而是**现金流与短期偿债能力**。

## 一、盈利
- **事实**：营业收入 2023/2024/2025 分别为 48.2 / 51.6 / 54.1 亿元，3 年 CAGR 6.0%。
- **事实**：毛利率 21.4% → 18.9% → 16.2%，两年累计下滑 5.2pct。
- **事实**：2025 年营业利润 6.8 亿元，其中投资收益 3.1 亿元，主营利润占比 54.4%。
- **判断**：毛利率连续两年下滑，且近半利润来自投资收益，主营盈利能力在弱化。
- **风险**：若投资收益不可持续，利润存在下行风险。

## 二、资产质量
- 存货占总资产 61.3%，存货周转天数 1,180 天（上年 1,020 天）。
- 受限资金 4.2 亿元，占货币资金 38%。
- **判断**：资产高度沉淀在存货，且账面现金近四成不可自由动用。

## 三、现金流
| 指标 | 2023 | 2024 | 2025 |
|---|---:|---:|---:|
| 经营现金流净额 | 8,900 | 2,100 | −1,800 |
| 净现比 | 0.52 | 0.12 | −0.09 |
| CAPEX | 12,400 | 15,800 | 18,600 |
| 自由现金流 | −3,500 | −13,700 | −20,400 |
| 收现比 | 0.94 | 0.88 | 0.81 |
- **事实**：2025 年经营现金流净额转为 −1,800 万元，自由现金流连续三年为负。
- **判断**：利润未转化为现金，经营现金流已不足以覆盖资本开支，增长依赖融资。
- **风险**：若融资收紧，在建项目资金链将承压。

## 四、营运资金
| 指标 | 2023 | 2024 | 2025 |
|---|---:|---:|---:|
| 应收账款周转天数 | 86 | 104 | 137 |
| 存货周转天数 | 890 | 1,020 | 1,180 |
| 现金转换周期 | 612 | 748 | 906 |
- **判断**：增长确实在带来更多资金占用，CCC 两年拉长 294 天。

## 五、财务质量背离清单
| 编号 | 背离 | 证据 | 评级 |
|---|---|---|---|
| QA-01 | 收入与现金流背离 | 收入 +4.8%，收现比降至 0.81 | 🟡 |
| QA-02 | 利润与现金流背离 | 净利 2.0 亿元，CFO −1,800 万元 | 🔴 |
| QA-03 | 资产与收入背离 | 总资产 +12.4%，收入 +4.8% | 🟡 |
| QA-04 | 借款增长过快 | 有息负债 +26%，收入 +4.8% | 🔴 |
| QA-07 | CAPEX 异常 | CAPEX/收入 34.4%，CFO/CAPEX < 0 | 🔴 |

## 六、交叉验证链条
| 链条 | 结果 | 中断环节 |
|---|---|---|
| 收入→应收→回款→CFO | **断** | 回款（收现比 0.81） |
| 净利润→CFO→FCF | **断** | CFO 与 FCF |
| 资产增长→收入增长→利润→现金流 | **断** | 资产扩张未带来收入同步增长 |
| 债务→利息→EBITDA→CFO | **断** | CFO 转负 |
| CAPEX→资产→产能→收入→EBITDA→FCF | **断** | 投资未转化为收入与现金 |
```

## 8. 边界

- **不做行业专项结论**（土地储备、去化率、单吨成本等归 Skill 03/04）。
- **不做偿债能力评级与压力测试**（归 Skill 05）。
- 不做证券估值与买卖建议。
- 缺少经营台账时，只做纯财务分析并声明"未经经营数据验证"。
