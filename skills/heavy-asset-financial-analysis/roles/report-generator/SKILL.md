# 角色 · 财务分析报告与管理层汇报生成（Report Generator）

> 由顶层 `heavy-asset-financial-analysis` 在【环节 5 报告交付】调用。子技能 06。**链路终点。**

## 1. 定位与适用场景

**定位**：把上游全部分析结果**整合**成可直接交付的成文材料。本角色**只整合、不新增结论**。

**适用场景**
- 正式财务分析报告
- 管理层汇报 / 董事会材料 / 财务复盘
- 财务尽调报告
- 一页纸高管摘要

**前置**：必须已有 Skill 02 输出；默认带上 Skill 05 的风险评级。

## 2. 输入 / 输出

| | 内容 |
|---|---|
| **输入** | `01-standard/`、`02-statements/`、`03-industry/`、`04-risk/` 全部产物 + 用户交付偏好（对象、篇幅、模板） |
| **输出** | `05-report/final-report.md`（按模板）、`05-report/exec-summary.md`（一页纸） |
| **硬约束** | 引用数据必须能回溯到上游产物；不得引入未经验证的新判断 |

## 3. Instructions（执行步骤）

1. 清点上游产物，确认必需件齐全（缺件则说明哪些章节无法编写）。
2. 按交付对象选模板：

| 模板 | 选用条件 | 文件 |
|---|---|---|
| T1 一页纸高管摘要 | 模式 A / 高层会议 / 快速了解 | `references/06-report-templates.md` §T1 |
| T2 标准财务分析报告 | 模式 B / 月季年分析 / 经营复盘 | §T2 |
| T3 深度财务尽调报告 | 模式 C / 投融资 / 并购 / 债务排查 | §T3 |
| T4 董事会汇报版本 | 用户说"给董事长/董事会看" | §T4 |

3. **先写执行摘要与一句话结论**，再回填各章。
4. 每个关键数字标注来源类型（原始报表 / 用户提供 / 计算结果 / 推算结果 / 外部数据）。
5. 事实、判断、风险分别成段或成列，不得混写。
6. 结尾附数据缺口说明：缺什么 → 影响哪条结论。
7. 自检：结论是否先行、建议是否可执行、有无未经验证的新结论。

## 4. 计算逻辑

本角色**不新做计算**。若上游缺某个关键数字，处理方式：

| 情况 | 处理 |
|---|---|
| 上游有原始值，缺派生值 | 可补算，并标注为"计算结果"，写明公式 |
| 上游缺原始值 | **不得估算**；在报告中写"暂无数据，无法判断" |
| 需要行业基准 | 必须标注来源与年份；无来源标为"经验参考值" |

## 5. 分析逻辑（整合顺序）

固定按 **数据层 → 指标层 → 经营层 → 财务层 → 风险层 → 管理建议层** 递进，禁止把指标平铺堆砌。

| 层 | 内容 | 来源 |
|---|---|---|
| 数据层 | 口径、单位、来源、数据质量 | Skill 01 |
| 指标层 | 五维指标与趋势 | Skill 02 |
| 经营层 | 行业经营闭环（土储/项目/产量/成本） | Skill 03/04 |
| 财务层 | 三表联动结论与背离清单 | Skill 02 |
| 风险层 | 风险清单 + 评级 + 压力测试 | Skill 05 |
| 建议层 | 可执行动作（动作+责任方向+时间窗） | 综合 |

**执行摘要必答 7 问**：总体经营状态 / 盈利 / 现金流 / 资产质量 / 债务风险 / 核心优势（≤3）/ 核心问题（≤3），最后给**一句话结论**。

**管理层版本（T4）固定 5 段**：
1. 目前最重要的 5 件事
2. 最大的 3 项风险
3. 最值得肯定的 3 项优势
4. 未来 12 个月需要关注的资金问题
5. 建议管理层重点采取的动作

## 6. 风险规则

| 编号 | 报告风险 | 触发 | 处理 |
|---|---|---|---|
| RP-01 | 结论与数据不符 | 结论无法由所列数据推出 | 重写结论 |
| RP-02 | 引用无来源 | 关键数字无 provenance | 补来源或标"来源待确认" |
| RP-03 | 新增未验证结论 | 出现上游没有的判断 | 删除或回溯到上游 |
| RP-04 | 事实判断混淆 | 同一段混写事实与判断 | 拆分并加标签 |
| RP-05 | 缺口被隐藏 | 存在数据缺口但未声明 | 补附录 |
| RP-06 | 建议不可执行 | 出现"加强管理"式空话 | 改为动作+责任方向+时间窗 |
| RP-07 | 报喜不报忧 | 风险章节缺失或弱化 | 补全并按评级排序 |
| RP-08 | 模板混用 | 董事会版本套用标准报告结构 | 按对象选模板 |

## 7. 示例任务

**用户**：「做一个给董事长看的财务分析。」

**示例输出（节选，T4 模板）**

```markdown
# 某某控股 财务与经营汇报（2025）
汇报对象：董事会 | 口径：合并 | 单位：万元 | 数据来源：2025 审计报告、借款台账、土储台账

## 一、目前最重要的 5 件事
| # | 事项 | 数据支撑 | 影响 |
|---|---|---|---|
| 1 | 2026 年集中到期债务 8.99 亿元，占全部债务 44.6% | 借款台账 | 流动性 |
| 2 | 经营现金流转负，自由现金流连续三年为负 | CFO −1,800；FCF −20,400 | 造血能力 |
| 3 | 回款率降至 71%，销售均价两年 −11.2% | 销售/回款台账 | 现金流入 |
| 4 | 三道红线全踩，融资渠道受限 | 净负债率 118%、现金短债比 0.72 | 再融资 |
| 5 | 土储土地成本率升至 42%，未来毛利承压 | 项目台账 | 盈利空间 |

## 二、最大的 3 项风险
| # | 风险 | 证据 | 评级 | 若不处理的后果 |
|---|---|---|---|---|
| 1 | 集中兑付 + 再融资依赖 | 2026 到期 8.99 亿，需再融资覆盖 65% | 🔴 | 2026 Q2 触及流动性临界点 |
| 2 | 现金流持续为负 | CFO 三年 8,900→2,100→−1,800 | 🔴 | 缺口累积至 5.4 亿元（S5 情景） |
| 3 | 高杠杆 + 红档融资受限 | 净负债率 118%，三项全踩 | 🔴 | 融资成本上升，可动用渠道收窄 |

## 三、最值得肯定的 3 项优势
| # | 优势 | 数据支撑 |
|---|---|---|
| 1 | 优质项目仍在贡献稳定毛利 | A 城中心项目毛利率 21.2%、回款率 88% |
| 2 | 土储仍可支撑约 3.1 年销售 | 土储货值 742 亿元 |
| 3 | 已实质停止拿地，扩张性支出已压降 | 拿地强度由 0.28 降至 0.11 |

## 四、未来 12 个月需要关注的资金问题
| 时点 | 事项 | 金额 | 缺口 | 应对方案 |
|---|---|---:|---:|---|
| 2026 Q1 | 到期债务首批兑付 | 32,000 | 8,000 | 银行置换 + 资产处置 |
| 2026 Q2 | 到期债务峰值 | 34,000 | 12,000 | 债券发行 + 合作方展期 |
| 2026 全年 | 在建项目资金需求 | 18,600 | 3,870 | 放缓非优质项目节奏 |

**核心数字**：未来 12 个月刚性支出 **89,870** 万元；可用现金 **42,000** 万元；
已落实融资 **24,000** 万元；**缺口 23,870 万元**。

## 五、建议管理层重点采取的动作
| 优先级 | 动作 | 预期效果 | 责任方向 | 完成时点 |
|---|---|---|---|---|
| 1 | 启动 2026 年到期债务提前置换，目标覆盖 60% | 消除集中兑付风险 | 财务部 | 2026 Q1 |
| 2 | 处置非核心资产回笼 ≥3 亿元 | 补足缺口 2.4 亿元 | 资产管理部 | 2026 Q2 |
| 3 | 高风险项目 C 整体转让或合作方让利处置 | 减少后续投入 3.8 亿元 | 投资决策委员会 | 2026 Q2 |
| 4 | 暂停新增拿地，资金集中投向优质项目 A | 保障回款 88% 的现金流入 | 投资决策委员会 | 立即 |
| 5 | 建立周度现金流滚动预测与红线预警 | 提前识别断点 | 财务部 | 立即 |

## 附：一句话结论
> 公司账面仍在盈利，但**现金已无法自我循环**，2026 年集中到期债务与在建投入叠加形成约 **2.4 亿元**缺口，
> 当前最紧迫的动作是**债务置换与非核心资产处置**，而非继续扩张。
```

## 8. 边界

- **只整合、不新增分析结论**；发现上游缺结论时应回溯上游或标注缺失，不得自行补判断。
- 不得为迎合汇报氛围删减风险章节。
- 不得给出证券估值与买卖建议。
- 不生成未经数据支持的行业预测。
- 数据缺口必须显性列示，不得隐藏。
