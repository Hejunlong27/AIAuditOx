# 角色 · 重资产企业现金流与债务风险（Cashflow & Debt Risk）

> 由顶层 `heavy-asset-financial-analysis` 在【环节 4 风险与债务】调用。子技能 05。**集群中最重要的风控模块。**

## 1. 定位与适用场景

**定位**：回答"**公司会不会缺钱、什么时候缺、缺多少、撑不撑得住**"。全部结论必须可计算、可举证、可评级。

**适用场景**
- 债务到期压力分析、债务期限墙
- 现金流缺口测算、"有利润没现金"诊断
- 流动性压力测试（6 情景）
- 财务尽调中的债务与偿债部分
- 最大 10 项财务风险排查

## 2. 输入 / 输出

| | 内容 |
|---|---|
| **输入** | `standard_dataset.json` + `metrics.json`（Skill 02）+ Skill 03/04 行业结论 + 借款台账 |
| **输出** | `04-risk/cashflow-gap.md`、`04-risk/debt-wall.md`、`04-risk/stress-test.md`、`04-risk/risk-rating.md` |
| **硬约束** | 每条风险必须附数据证据；无证据不得评级 |

## 3. Instructions（执行步骤）

1. 读标准数据集与上游指标，确认现金流与债务字段完整；缺失则先列缺口。
2. **现金流分析**：建立 `现金来源 → 现金用途 → 现金缺口`。
3. **债务分析**：算 13 项债务指标（见第 4 节）。
4. **债务期限墙**：按 `未来1年 / 2年 / 3年 / 4–5年 / 5年以上` 汇总本息，找峰值与集中度。
5. **压力测试**：跑 6 个标准情景，逐情景输出观察指标。
6. **风险评级**：按 `references/05-risk-rules.md` 逐条比对阈值，出绿/黄/红，并给企业整体评级。
7. 每条风险写成：**风险事项 → 数据证据 → 原因 → 影响 → 建议动作**。
8. 输出"最大 10 项风险"排序表（若用户要求）。

## 4. 计算逻辑

### 4.1 现金流分析

| 指标 | 公式 |
|---|---|
| 经营现金流可持续性 | CFO 近 3 年符号与趋势 |
| 经营现金流对 CAPEX 覆盖 | CFO ÷ CAPEX（<1 → 依赖融资） |
| 自由现金流 | CFO − CAPEX（连续 3 年 <0 → 红色） |
| 融资依赖度 | (借款收到现金 + 股权融资) ÷ (CFO + CAPEX) |
| 净现比 | CFO ÷ 净利润 |
| 收现比 | 销售商品提供劳务收到的现金 ÷ 收入 |
| 现金缺口 | 未来 12 个月刚性支出 −（可用现金 + 已落实融资 + 预计 CFO） |

### 4.2 债务分析（13 项必算）

总有息负债 / 净有息负债（有息负债 − 货币资金）/ 短期债务 / 长期债务 / 净负债率 / 资产负债率 / 流动比率 / 速动比率 / 现金比率 / 现金短债比 / EBITDA÷利息 / 利息保障倍数（EBIT÷利息）/ 经营现金流÷有息负债。

**可动用现金修正**：若存在受限资金，偿债指标须按 `可动用现金 = 货币资金 − 受限资金` 重算并同时列示两个口径。

### 4.3 债务期限墙

| 到期区间 | 到期本金 | 利息 | 合计 | 占比 | 可用现金 | 已落实融资 | 缺口 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 未来 1 年 | | | | | | | |
| 未来 2 年 | | | | | | | |
| 未来 3 年 | | | | | | | |
| 未来 4–5 年 | | | | | | | |
| 5 年以上 | | | | | | | |

必须指出：**到期峰值年份、集中到期占比、再融资依赖度、缺口覆盖方案**。

### 4.4 压力测试 6 情景

| 情景 | 参数 | 观察指标 |
|---|---|---|
| S1 收入 −10% | 收入 ×0.9 | 现金余额、CFO、FCF、利息覆盖 |
| S2 收入 −20% | 收入 ×0.8 | 同上 + 现金短债比 |
| S3 毛利率 −5pct | 成本上调至毛利率 −5pct | 净利润、CFO、FCF |
| S4 融资成本 +100bp | 利息 = 有息负债 ×(现利率 +1%) | 利息保障倍数、净利润 |
| S5 再融资能力下降 | 到期债务仅续作 50% | 现金缺口、现金短债比 |
| S6 CAPEX +20% | CAPEX ×1.2 | FCF、融资依赖度 |

| 情景 | 现金余额 | CFO | FCF | EBITDA/利息 | 偿债缺口 | 评级 |
|---|---:|---:|---:|---:|---:|---|
| 基准 | | | | | | |
| S1…S6 | | | | | | |

## 5. 分析逻辑

**分析优先级**：现金安全 > 偿债能力 > 资产质量 > 盈利质量 > 盈利规模 > 增长速度。

**四步诊断**
1. **有没有钱进来**：CFO 是否为正、是否可持续、收现比是否健康。
2. **钱够不够用**：CFO 能否覆盖 CAPEX 与利息；FCF 是否为正。
3. **不够怎么办**：缺口规模、已落实融资、再融资能力、可处置资产。
4. **什么时候爆**：债务期限墙上的峰值年份 + 压力情景下的触发点。

**综合评级**（加权 + 一票否决）

| 项 | 权重 |
|---|---|
| 现金流风险 | 30% |
| 债务与流动性风险 | 30% |
| 资产质量风险 | 15% |
| 盈利质量风险 | 15% |
| 行业周期风险 | 10% |

**一票否决**：CFO 连续 2 年为负 → 直接红色；现金短债比 <0.2 或发生实质违约 → 直接红色。

## 7. 示例任务

**用户**：「帮我做债务到期压力分析。」「为什么公司有利润但没有现金？」

**示例输出（节选）**

```markdown
# 某某控股 现金流与债务风险分析（2025）
口径：合并 | 单位：万元 | 来源：2025 审计报告、借款台账

## 一句话结论
公司**账面盈利但现金在净流出**，未来 12 个月存在 **6.4 亿元偿债缺口**，
评级 **🔴 红色**。核心问题不是盈利能力，而是 2026 年集中到期债务与在建项目资金占用的叠加。

## 一、为什么有利润却没有现金（用户问题直接作答）
**事实**
| 项目 | 2023 | 2024 | 2025 |
|---|---:|---:|---:|
| 净利润 | 17,100 | 17,500 | 20,000 |
| 经营现金流净额 | 8,900 | 2,100 | −1,800 |
| 净现比 | 0.52 | 0.12 | −0.09 |
| 应收账款 | 11,500 | 14,900 | 20,600 |
| 存货 | 168,000 | 196,000 | 221,000 |

**原因（利润未变现的三个去向）**
1. **应收占用 +5,700 万元**：收入增长靠赊销，收现比降至 0.81。
2. **存货占用 +25,000 万元**：在建规模扩大，资金沉淀在开发成本。
3. **应付减少**：上游支付趋严，失去对供应商占款。

**判断**：利润是"账面的"，现金被应收与存货吃掉，属于典型的**增长型现金流出**。
**风险**：若回款继续恶化，2026 年将无法同时满足到期债务与在建投入。

## 二、债务期限墙
| 到期区间 | 到期本金 | 利息 | 合计 | 占比 | 可用现金 | 已落实融资 | 缺口 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 未来 1 年 | 86,000 | 3,870 | 89,870 | 44.6% | 42,000 | 24,000 | **23,870** |
| 未来 2 年 | 41,000 | 1,845 | 42,845 | 21.3% | — | — | — |
| 未来 3 年 | 32,000 | 1,440 | 33,440 | 16.6% | — | — | — |
| 未来 4–5 年 | 22,000 | 990 | 22,990 | 11.4% | — | — | — |
| 5 年以上 | 11,800 | 531 | 12,331 | 6.1% | — | — | — |
| **合计** | **192,800** | **8,676** | **201,476** | 100% | | | |

**到期峰值**：2026 年，占比 44.6%，为全部债务的近一半。
**再融资依赖度**：未来 1 年到期 89,870 万元中，需再融资或新融资覆盖 **65%**。

## 三、压力测试
| 情景 | 现金余额 | CFO | FCF | EBITDA/利息 | 偿债缺口 | 评级 |
|---|---:|---:|---:|---:|---:|---|
| 基准 | 42,000 | −1,800 | −20,400 | 2.6 | −23,870 | 🔴 |
| S1 收入 −10% | 38,100 | −12,400 | −31,000 | 2.1 | −33,100 | 🔴 |
| S2 收入 −20% | 34,200 | −23,000 | −41,600 | 1.6 | −42,300 | 🔴 |
| S3 毛利率 −5pct | 33,500 | −18,900 | −37,500 | 1.9 | −38,900 | 🔴 |
| S4 融资成本 +100bp | 39,600 | −3,700 | −22,300 | 2.0 | −26,200 | 🔴 |
| S5 再融资仅续作 50% | 12,000 | −1,800 | −20,400 | 2.6 | −53,870 | 🔴 |
| S6 CAPEX +20% | 41,900 | −1,800 | −24,120 | 2.6 | −27,590 | 🔴 |

**结论**：7 个情景全部触发红色。**最脆弱环节是 S5（再融资能力下降）**，
此时现金缺口扩大到 5.4 亿元，公司将在 2026 年 Q2 前触及流动性临界点。

## 四、最大 10 项风险
| # | 风险事项 | 数据证据 | 影响 | 评级 |
|---|---|---|---|---|
| 1 | 集中到期 | 2026 年到期占 44.6% | 集中兑付压力 | 🔴 |
| 2 | 经营现金流为负 | 2025 CFO −1,800 万元 | 失去自我造血 | 🔴 |
```

## 8. 边界

- 不替代审计与法律意见；表外事项无法核实的，必须标"未经核实"。
- 压力测试是情景测算，**不是预测**，须在报告中声明假设与局限。
- 不得给出证券买卖建议。
- 缺少借款到期明细时，期限墙只能做"总额+期限结构"的粗略分析，并声明。
- 无数据不得评级。
