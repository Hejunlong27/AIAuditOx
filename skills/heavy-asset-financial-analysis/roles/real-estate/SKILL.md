# 角色 · 房地产企业经营与财务分析（Real Estate）

> 由顶层 `heavy-asset-financial-analysis` 在【环节 3 行业专项】调用（企业类型 = 房地产 / 城市更新 / 土地开发 / 产业园区开发）。子技能 03。

## 1. 定位与适用场景

**定位**：把财务报表翻译成"**土地—项目—销售—回款**"的经营语言，判断这家房企的**资源质量、去化能力、利润空间与资金缺口**。

**适用场景**
- 土地储备分析、项目盈利能力分析
- 销售与回款质量诊断
- 房企年度经营复盘、项目组合优化
- 房企财务尽调中的经营专项部分

**前置**：必须先有 Skill 02（三表及经营分析）的输出。

## 2. 输入 / 输出

| | 内容 |
|---|---|
| **输入** | `standard_dataset.json` + 土储台账 / 项目台账 / 销售台账 / 回款台账 / 开发计划 |
| **输出** | `03-industry/real-estate-analysis.md`、`project-matrix.csv`（项目盈利矩阵）、项目四类分类结论 |
| **降级** | 缺项目级数据 → 只做公司级指标（存货结构、周转、回款率、杠杆），并声明项目级结论无法给出 |

## 3. Instructions（执行步骤）

1. 读标准数据集与经营台账，确认 `meta.industry` 属于房地产类。
2. 按**经营闭环**顺序分析，不跳步：
   `拿地 → 土地成本 → 开发建设 → 形成货值 → 销售 → 回款 → 结算 → 利润 → 再投资`
3. 出土地储备指标（面积、货值、去化周期、成本率、区域结构）。
4. 出项目级分析表 → 生成**项目盈利矩阵** → 四类分类。
5. 出销售与回款指标（去化率、回款率、均价、已售未结）。
6. 出杠杆与监管口径（三道红线 + 明股实债线索）。
7. 逐条跑第 6 节核心风险清单。
8. 输出结论：资源够不够、卖得动不动、赚不赚钱、缺多少钱。

## 4. 计算逻辑

核心指标与公式见 `references/03-real-estate-indicators.md`。必算清单：

**土地**：土储面积 / 土储货值 / 货值覆盖倍数（土储货值÷年销售额）/ 土储去化周期（土储面积÷年销售面积）/ 土地成本率（土地成本÷预计售价）/ 地货比 / 拿地强度（当年拿地金额÷销售额）/ 区域与城市能级集中度。

**项目**：货值 / 已售金额 / 已售面积 / 去化率（累计已售面积÷可售面积）/ 回款率（回款额÷销售额）/ 土地成本 / 开发成本 / 项目毛利 / 项目毛利率 / 未来资金需求。

**公司级**：销售额 / 销售面积 / 销售均价 / 存货周转率与天数 / 项目毛利率 / 土地成本率 / 建安成本率 / 销售费用率 / 管理费用率 / 财务费用率 / 净负债率 / 现金短债比。

**监管口径**：剔除预收款后资产负债率 =（总负债 − 预收/合同负债）÷ 总资产；净负债率 =（有息负债 − 现金）÷ 所有者权益；现金短债比 = 现金 ÷ 短期有息负债。

## 5. 分析逻辑

**闭环诊断四问**：
1. **资源够不够**：货值覆盖倍数、土储去化周期、区域与能级结构。
2. **卖得动不动**：去化率、销售均价趋势、单方销售费用。
3. **赚不赚钱**：土地成本率、项目毛利率、结算毛利率与签约毛利率的差。
4. **缺多少钱**：在建规模 vs 回款、未来资金需求 vs 可用融资、拿地强度 vs 回款。

**项目盈利矩阵（有项目数据时必须生成）**

| 项目 | 货值 | 成本 | 销售额 | 毛利 | 毛利率 | 去化率 | 回款 | 未来资金需求 | 风险 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---|

**四类分类标准**

| 类别 | 判据 | 动作 |
|---|---|---|
| 优质项目 | 毛利率 ≥20% 且 去化率 ≥70% 且 回款率 ≥85% | 保障资源，保持节奏 |
| 正常项目 | 毛利率 10–20%，去化率 50–70% | 盯紧去化与回款 |
| 低利润项目 | 毛利率 5–10% 或 去化率 30–50% | 压降成本、加快去化、评估退出 |
| 高风险项目 | 毛利率 <5% 或 去化率 <30% 或 资金需求 > 可用融资 | 专项处置 |

> 阈值可按城市能级调整，但必须声明调整依据。

## 6. 风险规则（自动识别）

| 风险 | 触发判据 | 证据要求 |
|---|---|---|
| 高库存 | 存货/总资产 >60% 且 周转天数 >1,000 | 存货明细 + 周转趋势 |
| 去化缓慢 | 去化率 <50% 或同比下滑 >15pct | 项目去化台账 |
| 高土地成本 | 土地成本率 >40% | 项目成本明细 |
| 毛利率下降 | 毛利率同比下滑 >3pct | 结算毛利率趋势 |
| 销售回款下降 | 回款率 <80% 或回款额同比 −20% | 回款台账 |
| 项目延期 | 计划 vs 实际交付偏差 >6 个月 | 项目节点表 |
| 高杠杆 | 净负债率 >100% 或 资产负债率 >80% | 报表 + 有息负债明细 |
| 短债集中 | 一年内到期债务/有息负债 >40% | 借款台账 |
| 土储质量下降 | 三四线货值占比 >60% 或 高价年土储占比 >50% | 土储台账 |
| 区域集中 | 单一城市群货值占比 >50% | 土储/销售区域拆分 |
| 明股实债 | 少数股东权益占比高且损益异常 | 附注 + 合作方明细 |
| 表外风险 | 担保/代建垫资/明股实债线索 | 附注；无法验证须声明 |

## 7. 示例任务

**用户**：「帮我分析这家房地产公司的土地储备和项目盈利能力。」

**示例输出（节选）**

```markdown
# 某置业 房地产专项分析（2025）
口径：合并 | 单位：万元 / 万平方米 | 来源：2025 审计报告、土储台账、项目台账

## 一句话结论
土储总量可支撑约 3.1 年销售，但**三四线货值占比 64%**、在建规模是年销售的 3.4 倍，
叠加回款率降至 71%，公司当前的核心矛盾是**去化与资金缺口**，而非利润水平。

## 一、土地储备
| 指标 | 2023 | 2024 | 2025 | 判断 |
|---|---:|---:|---:|---|
| 土储面积（万㎡） | 620 | 585 | 540 | 持续收缩 |
| 土储货值（亿元） | 892 | 810 | 742 | 两年 −16.8% |
| 货值覆盖倍数（年） | 3.6 | 3.4 | 3.1 | 接近 3 年临界 |
| 土储去化周期（年） | 3.6 | 3.4 | 3.1 | 尚可 |
| 土地成本率 | 34% | 38% | 42% | 🔴 已过 40% |
| 拿地强度 | 0.28 | 0.19 | 0.11 | 已实质停止拿地 |
| 三四线货值占比 | 52% | 58% | 64% | 🟡 结构下沉 |

- **事实**：土地成本率由 34% 升至 42%，两年上升 8pct。
- **判断**：存量土储的地价水位偏高，未来结算毛利率将被持续压制。
- **风险**：若区域房价继续下行，高价年获取的土储存在减值风险。

## 二、项目盈利矩阵（节选）
| 项目 | 货值 | 成本 | 销售额 | 毛利 | 毛利率 | 去化率 | 回款 | 未来资金需求 | 风险 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---|
| A 城中心 | 42.0 | 30.1 | 36.8 | 8.9 | 21.2% | 82% | 88% | 2.1 | 优质 |
| B 新区 | 28.5 | 24.0 | 15.2 | 2.6 | 9.1% | 48% | 73% | 5.4 | 低利润 |
| C 县域 | 19.8 | 18.6 | 4.1 | 0.4 | 2.0% | 21% | 61% | 3.8 | 高风险 |
| D 合作盘 | 33.0 | 26.4 | 24.6 | 5.2 | 15.8% | 66% | 80% | 1.2 | 正常 |

**分类结果**：优质 1 个、正常 1 个、低利润 1 个、高风险 1 个。
高风险与低利润项目合计货值 48.3 亿元，占存量货值 22.8%，合计未来资金需求 9.2 亿元。

## 三、销售与回款
| 指标 | 2023 | 2024 | 2025 |
|---|---:|---:|---:|
| 销售额（亿元） | 248 | 238 | 239 |
| 销售均价（元/㎡） | 13,400 | 12,600 | 11,900 |
| 去化率 | 68% | 59% | 51% |
| 回款率 | 87% | 79% | 71% |

- **事实**：销售额基本持平，但均价两年下滑 11.2%，回款率下滑 16pct。
- **判断**：规模靠降价维持，回款质量同步恶化。
- **风险**：回款率若继续下行，在建项目资金缺口将扩大。

## 四、杠杆与监管口径
| 指标 | 2025 | 三道红线 |
|---|---:|---|
| 剔除预收款后资产负债率 | 73.4% | 踩线（>70%） |
| 净负债率 | 118% | 踩线（>100%） |
| 现金短债比 | 0.72 | 踩线（<1） |
**档位**：三项全踩 → **红档**，融资渠道受限，需依赖销售回款与资产处置。

## 五、核心风险清单
| 风险 | 证据 | 评级 |
|---|---|---|
| 高土地成本 | 土地成本率 42% | 🔴 |
| 去化缓慢 | 去化率 51%，同比 −8pct | 🟡 |
| 回款下降 | 回款率 71%，同比 −8pct | 🔴 |
| 土储质量下降 | 三四线货值占比 64% | 🟡 |
| 高杠杆 | 净负债率 118%，红档 | 🔴 |
| 短债集中 | 一年内到期/有息负债 46% | 🟡 |

## 六、建议动作
1. 高风险项目 C 启动整体转让或合作方让利处置（6 个月内出方案）。
2. 低利润项目 B 压缩建安标准并加快推盘，目标去化率提升至 60%。
3. 暂停新增拿地，把资金集中到优质项目 A 的交付回款。
4. 提前 9 个月启动 2026 年 46% 到期债务的置换安排。
```

## 8. 边界

- **不做偿债评级与压力测试**（归 Skill 05），只给杠杆事实与监管档位。
- 项目 IRR、净利率等需完整现金流模型的数据，缺失时不硬算。
- 不得用行业平均去化率替代企业实际去化率。
- 缺土储台账 → 明确写"土地储备相关结论无法判断"。
