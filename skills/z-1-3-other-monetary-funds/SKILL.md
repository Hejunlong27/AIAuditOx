## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 存在性/完整性（E/C）：各类其他货币资金真实存在且记录完整；准确性/计价（A/V）：金额正确、外币折算正确；列报（P）：按性质分类披露恰当 |
| 所需资料 | 其他货币资金明细账（按款项性质）、银行对账单/保证金对账单、银行承兑汇票协议/授信审批文件、信用证开立协议、第三方支付平台协议与流水、证券账户资料、询证函回函、财务报表附注 |
| 所需数据 | 各款项性质余额（外埠存款/银行承兑汇票保证金/银行汇票/银行本票/信用卡/信用证保证金/存出投资款）、应付票据规模与保证金比例、大额支出明细、期末前后收支明细 |
| 核对逻辑 | ① 明细加计↔总账/日记账核对+外币折算；② 保证金与应付票据/信用证规模勾稽（协议比例×规模 vs 账面）；③ 全类函证；④ 第三方支付平台流水↔账面核对+大额抽查；⑤ 存出投资款批准文件+证券户名+流水抽查；⑥ 大额支出原始凭证抽查；⑦ 期末前后截止测试；⑧ 披露核对 |
| 底稿编制内容 | 见「产出清单」，全部底稿采用 auditox-wp-standard 四段式制式 |
| 输出格式 | xlsx 工作簿（模板见 templates/Z-1-3其他货币资金审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已指定（未指定拒绝启动）；基于模板在 `02_工作底稿/Z-1-3其他货币资金/` 创建工作簿副本。
2. 校验输入：明细账必输；按款项性质判断适用程序（无第三方支付/投资款则对应程序标「不适用+理由」）。
3. 分派顺序：P01 → （P02、P03 并行）→ P04（含 P05 附区）→ P06（含 P07 附区）→ P08。
4. 副本先行 + 修订记录伴随。
5. 异常激活：P02 保证金与应付票据规模明显不匹配 → 升级助理并联动应付票据科目审计；P04 平台流水与账面不符 → 激活 P06 扩大抽查；P03 未回函 → 替代程序（期后对账单/流水核验）。
6. 汇总执行一级复核（完整性/勾稽/证据/异常闭环/制式合规），通过后提交人工二级复核。

## 一级复核清单

- P01~P08 均有底稿或「不适用+理由」；索引号连续；
- 明细合计=总账数；保证金勾稽差异已解释；函证覆盖全部款项性质或替代程序齐备；
- 四段式制式完整、七要素齐全、修订记录同步。

## 边界与禁止事项

- 仅项目工作目录内操作；禁止物理删除、外发数据；禁止代替人工执行函证寄发与平台登录查询（技能做数据准备与核对计算）；
- 数字核对脚本精确匹配；差异说明标注「待人工确认」。

## Pitfalls

- 保证金规模与应付票据/信用证余额的勾稽是本科目核心程序，比例须取自协议约定而非估算；
- 第三方支付平台款项须获取发生额及余额明细或直接登录查询，仅凭被审计单位导出文件不足以验证；
- 存出投资款关注证券账户户名是否与被审计单位相符；
- 外币其他货币资金折算与银行存款适用同一汇率口径。

## Verification

- 工作簿公式重算无错误；保证金勾稽表「应有余额 vs 账面余额」差异结论明确；
- 每张底稿四段式完整、修订记录对应。
