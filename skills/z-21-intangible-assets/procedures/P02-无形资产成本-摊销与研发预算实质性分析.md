# P02 无形资产成本、摊销与研发预算实质性分析

> 来源：Z1701+Z1702+Z1703 程序库 Z1701 分析1、Z1701 分析2、Z1702 分析1、Z1702 分析2、Z1702 分析3｜认定：C、E、A｜产出：Z-21-02
> 执行方式：自动（预期值、差异和阈值）+人工调查｜确定性工具：recalc_check、threshold_flag

## 输入

- 分无形资产类别原值与摊销、会计政策、研发计划与预算、本期研发投入/完成/终止项目、上期比较数据

## Steps

1. 【规则】对无形资产成本与摊销变动情况执行分析程序：
   - （1）计算无形资产成本与摊销变动的预期值；
   - （2）将实际值与预期值进行比较；
   - （3）调查超过实际执行重要性水平既定比例或特定金额的差异，并针对这些差异获取解释和佐证证据。
2. 【规则】将企业董事会审议决定的研发计划与研发预算，本期投入研发、完成研发或终止研发项目的名称、实际发生额与董事会决议和预算进行对比分析，检查研发计划与预算的执行情况。
3. 【规则】将实际值与预期值进行比较。
4. 【规则】检查超过实际执行重要性水平既定比例或特定金额的差异，并获取相关说明和证据。
5. 【规则】在无适当说明或确切证据证明差异时，考虑是否需要计划并实施额外工作及/或记录发现的任何差错。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析表 | 按类别/项目拆分 |
| 预期值 | 数值 | 审计模型 | 模型依据留痕 |
| 实际值 | 数值 | 总账/明细账 | 与账面核对 |
| 差异 | 金额 | 计算表 | 实际-预期 |
| 差异率 | 百分比 | 计算表 | 差异/预期，除零保护 |
| 重要性阈值 | 金额 | 计划阶段 | 记录实际执行重要性 |
| 是否超阈值 | 文本 | 规则判断 | 超阈值须调查 |
| 原因与证据 | 文本 | 访谈/支持文件 | 不能仅凭解释 |
| 结论 | 文本 | 审计判断 | 记录追加程序或调整 |

## 质量门

- 重要类别和分析项目均建立预期；预算执行差异和超阈值差异有解释与证据

## 升级路径

- 资本化比例异常、预算重大偏离或无解释差异时升级项目经理。
