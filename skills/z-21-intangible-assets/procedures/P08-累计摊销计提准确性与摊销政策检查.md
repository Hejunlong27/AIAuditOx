# P08 累计摊销计提准确性与摊销政策检查

> 来源：Z1701+Z1702+Z1703 程序库 Z1702 程序2、Z1702 程序3、Z1702 程序4｜认定：C、E、A、V、P｜产出：Z-21-08
> 执行方式：自动重算+人工复核政策｜确定性工具：recalc_check、threshold_flag

## 输入

- 无形资产原值及变动、会计政策、使用寿命和残值、累计摊销明细账、摊销费用分配表

## Steps

1. 【规则】检查使用寿命有限的无形资产的摊销
   - （1）按照无形资产的类别，用财务报表中会计政策规定的年摊销率乘以无形资产原值/公允价值/账面价值，验证本期摊销额；
   - （2）确保本期使用的摊销率与上期一致且是适当的（考虑剩余使用寿命、财务报告编制基础等）。若使用的摊销率存在差异，获取存在差异的理由，并确保任何会计变更（估计、政策或差错）已得到正确地处理和披露；
   - （3）复核重新计算后的金额与实际金额之间的差异。如必要，获取对差异的解释及佐证证据。
2. 【规则】抽样检查并复核使用寿命有限的无形资产的摊销费用
   - （1）获取无形资产及相关摊销费用的清单；
   - （2）记录样本量和选样依据。(考虑选取100%项目的必要性）；
   - （3）将本期无形资产原值与上期财务报表或支持性文件进行核对，佐证是否存在变动或差异；
   - （4）检查摊销费用的计算准确性；
   - （5）针对下列两项，检查摊销政策是否与上期一致并具有合理性：
   - ①残值；
   - ②使用经济寿命。
3. 【规则】评价使用寿命有限的无形资产的摊销率
   - （1）评价被审计单位使用的摊销率并结合下列方面考虑其合理性：
   - （2）与管理层讨论存在的重大差异，并针对这些差异获取解释和佐证证据。
   - ①资产寿命；
   - ②关于该类资产处置损益的经验；
   - ③无形资产残值的确定；
   - ④适用的财务报告编制基础的要求；
   - ⑤考虑利用专家工作的必要性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产类别/项目 | 文本 | 折旧/摊销清单 | 类别完整 |
| 原值 | 金额 | 资产台账 | 与总账核对 |
| 折旧/摊销方法 | 文本 | 会计政策 | 前后期一致 |
| 预计使用寿命/残值率 | 文本 | 会计政策/评估 | 估计合理 |
| 本期应计折旧/摊销 | 金额 | 审计重算 | 按政策独立重算 |
| 账面折旧/摊销 | 金额 | 明细账 | 贷方发生额 |
| 差异 | 金额 | 计算表 | 应计-账面 |
| 分配核对 | 金额 | 成本费用明细账 | 折旧分配额勾稽 |
| 结论 | 文本 | 审计判断 | 差异是否需调整 |

## 质量门

- 重要无形资产独立重算；摊销率与上期一致或变更处理正确；摊销费用分配勾稽

## 升级路径

- 摊销率明显偏离资产寿命、残值不合理或差异重大时升级项目经理。
