# P06 无形资产完整性检查

> 来源：Z1701+Z1702+Z1703 程序库 Z1701 程序5｜认定：C｜产出：Z-21-06
> 执行方式：规则筛异常+人工判断｜确定性工具：rule_check、threshold_flag

## 输入

- 无形资产台账、采购/研发/政府补助资料、许可和特许经营资料、同行业与业务访谈信息、期后事项

## Steps

1. 【规则】考虑所有重要无形资产的完整性
   - 根据我们对被审计单位的了解，考虑是否所有重要无形资产都已按照被审计单位的会计政策和适用的财务报告编制基础的要求包含在财务报表中。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析表 | 按类别/项目拆分 |
| 预期值 | 数值 | 审计模型 | 模型依据留痕 |
| 实际值 | 数值 | 总账/明细账 | 与账面核对 |
| 差异 | 金额 | 计算表 | 实际-预期 |
| 差异率 | 百分比 | 计算表 | 差异/预期，除零保护 |
| 重要性阈值 | 金额 | 计划阶段 | 记录实际执行重要性 |
| 是否超阈值 | 文本 | 规则判断 | 超阈值须调查 |
| 原因与证据 | 文本 | 访谈/支持文件 | 不能仅凭解释 |
| 结论 | 文本 | 审计判断 | 记录追加程序或调整 |

## 质量门

- 结合业务了解评价重要无形资产是否均已入账；账外无形资产线索逐项调查

## 升级路径

- 发现重大账外无形资产或完整性无法确认时升级项目经理并扩大程序。
