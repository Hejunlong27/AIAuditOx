# P09 无形资产减值迹象与减值测试

> 来源：Z1701+Z1702+Z1703 程序库 Z1703 程序2、Z1703 程序3、Z1703 程序4、Z1703 程序5｜认定：C、A、V、P｜产出：Z-21-09
> 执行方式：人工主导（减值判断）+自动重算｜确定性工具：recalc_check｜**必须留人**（Agent 不得代替执行）

## 输入

- 减值迹象清单、使用寿命不确定资产测试、资产组划分、可收回金额模型、折现率与第三方数据、专家报告

## Steps

1. 【规则】考虑对使用寿命不确定或尚未使用的无形资产进行减值的必要性
   - （1）评价每年按照财务报告编制基础计算的可收回金额，通常涉及考虑模型、假设、原始数据和结果，对管理层作出的估计进行审计。考虑使用“4.获取审计证据”文件夹中EG示例文件夹内的减值模板。
   - （2）记录如何运用职业怀疑态度。
   - （3）考虑是否需要利用专家的工作；
   - （4）检查账面金额并确定是否需要计提减值准备。如果需要，检查减值准备的计算并确保减值准备已按照适用的财务报告编制基础予以处理。
2. 【规则】考虑使用寿命有限的无形资产是否需要减值
   - （1）按照财务报告编制基础考虑是否存在减值迹象（例如，企业改变其资产用途、市场价值缩水、经营亏损等）；
   - （2）审慎评价管理层对无形资产是否存在减值迹象作出的评估（如适用），并获取管理层对于减值迹象得出结论的佐证证据（包括管理层得出存在和不存在减值迹象的结论）；
   - （3）按照财务报告编制基础评价计算的可收回金额，通常涉及考虑模型、假设、原始数据和结果，对管理层作出的估计进行审计。考虑使用“3.获取证据”文件夹内的减值模板。
   - （4）记录如何运用职业怀疑态度。
   - （5）考虑是否需要利用专家的工作；
   - （6）检查账面金额并确定是否需要计提减值准备。如果需要，检查减值准备的计算并确保减值准备已按照适用的财务报告编制基础予以处理。
3. 【规则】无形资产是否恰当分摊至资产组（CGUs）并确定评估减值的层面
   - （1）评价管理层对无形资产划分至资产组（CGUs）的确定是否合理；
   - （2）评价分配至每个资产组的资产和相关账面价值的适当性；
   - （3）确定是否可以在单项资产层面评估减值，或是否必须在资产组层面评估减值。
   - 考虑使用减值模板——资产组层面文件进行减值评估。
4. 【脚本】复核计算减值的使用价值所采用的折现率
   - （1）计算中采用的所有假设都是合理的，不存在高估或低估；
   - （2）充分考虑计算对每个因素的敏感性，针对高度敏感的因素执行更多工作；
   - （3）用于计算相关折现率的所有数据（如β系数等）与第三方文件（比如，市场统计数据、参考文献及专家建议等）核对一致；
   - （4）确保被审计单位现金产出单元的使用价值与下列数据相比是合理的：
   - 重新计算折现率（比如，加权平均资本成本），确保下列事项：
   - ①市场资本；
   - ②净资产价值。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产/资产组 | 文本 | 减值测试表 | 资产组划分合理 |
| 账面价值 | 金额 | 明细账 | 与总账核对 |
| 可收回金额 | 金额 | 评估报告/模型 | 公允价值减处置费用与使用价值孰高 |
| 现有准备 | 金额 | 准备明细账 | 期初+计提-核销 |
| 应有准备 | 金额 | 审计重算 | 账面价值-可收回金额且不低于零 |
| 本期计提/核销 | 金额 | 计算表 | 会计分录正确 |
| 减值迹象 | 文本 | 管理层评估/外部证据 | 迹象须有支持 |
| 关键假设/专家 | 文本 | 模型/专家报告 | 假设合理性已评价 |
| 结论 | 文本 | 审计判断 | 充分/不足/需调整 |

## 质量门

- 减值迹象逐项评价；资产组划分合理；折现率和关键假设有依据；准备不得转回

## 升级路径

- 可收回金额重大不确定、专家工作不足或发现准备转回时升级项目经理。
