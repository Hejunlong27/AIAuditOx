# P04 无形资产新增检查

> 来源：Z1701+Z1702+Z1703 程序库 Z1701 程序3｜认定：C、E、A、P｜产出：Z-21-04
> 执行方式：自动筛样+人工核单｜确定性工具：sampling_draw

## 输入

- 本期新增无形资产清单、付款凭证、发票、合同、验收/投入使用资料、研发资本化资料、使用寿命分析

## Steps

1. 【规则】抽样检查新增无形资产：
   - 获取本期新增无形资产清单，执行程序测试IPE的可靠性：
   - 记录样本规模和选样依据；
   - 通过确认无形资产正在产生现金流量，确定该资产是否存在；
   - 将新增无形资产的交易与支持性文件(例如，付款凭证、发票）进行核对或实施实地检查；
   - 确保资产得以正确分类为无形资产（例如，满足开发成本的确认标准）并根据适用的财务报告编制基础适当的计价；
   - 考虑无形资产使用寿命计算的适当性；
   - 如果需要计提减值准备，检查计算，并确保按照适用的财务报告编制基础进行会计处理和披露。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 样本编号 | 文本 | 抽样表 | 样本量与依据已记录 |
| 项目/合同名称 | 文本 | 明细账/台账 | 与账面一致 |
| 账面金额 | 金额 | 明细账 | 金额精确匹配 |
| 支持文件日期 | 日期 | 发票/合同/凭证 | 日期在审计期间内 |
| 支持文件编号 | 文本 | 发票/合同/凭证 | 可回溯 |
| 核对内容 | 文本 | 程序表 | 覆盖授权、存在、计价 |
| 独立证据 | 文本 | 外部/现场证据 | 必要时取得外部证据 |
| 异常事项 | 文本 | 审计判断 | 异常不得留空 |
| 结论 | 文本 | 审计判断 | 支持/不支持账面记录 |

## 质量门

- 新增样本存在、分类、计价和使用寿命均有支持；资本化条件已评价

## 升级路径

- 研发资本化依据不足、分类错误或使用寿命明显不合理时升级项目经理。
