# P07 内部开发无形资产资本化与会计政策检查

> 来源：Z1701+Z1702+Z1703 程序库 Z1701 程序6、Z1701 程序7｜认定：E、P｜产出：Z-21-07
> 执行方式：自动重算+人工评价资本化条件｜确定性工具：recalc_check

## 输入

- 研发项目立项与可行性报告、开发支出明细、工时/领料/试验记录、资本化政策、会计政策变更资料

## Steps

1. 【规则】内部开发无形资产的资本化
   - 针对重要的内部开发无形资产，复核成本金额，确定是否包含了财务报告编制基础允许的项目（例如，开发无形资产使用或消耗的材料和服务成本、内部开发无形资产生的人员工资费用、登记法定权利的费用等），未包含其他成本（例如，广告费、在新地点开展业务、管理成本等）。
2. 【规则】资本化政策
   - （1）与适当人员讨论被审计单位的无形资产资本化和摊销政策；
   - （2）考虑该政策的适当性及其与被审计单位无形资产的关系；
   - （3）评价会计变更是否构成会计政策与会计估计变更或差错。
   - （4）考虑是否需要在财务报表中披露这些变更。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 研发项目 | 文本 | 研发项目台账 | 项目完整 |
| 研究/开发阶段 | 文本 | 立项/可行性报告 | 阶段划分有依据 |
| 本期投入 | 金额 | 研发支出明细账 | 与总账核对 |
| 资本化金额 | 金额 | 开发支出明细账 | 五项资本化条件逐项支持 |
| 费用化金额 | 金额 | 研发费用明细账 | 研究阶段及不满足条件支出费用化 |
| 结转/减少 | 金额 | 明细账 | 转无形资产/费用化正确 |
| 截止日期 | 日期 | 凭证/验收单 | 资产负债日前后截止 |
| 支持证据 | 文本 | 立项/工时/领料/验收 | 证据链完整 |
| 结论 | 文本 | 审计判断 | 资本化/费用化是否恰当 |

## 质量门

- 资本化成本范围正确；五项条件逐项支持；资本化政策适当且一贯

## 升级路径

- 资本化条件证据不足或政策变更处理错误时升级项目经理并考虑专家工作。
