# P03 无形资产权属、存在性与受益期限检查

> 来源：Z1701+Z1702+Z1703 程序库 Z1701 程序2｜认定：E｜产出：Z-21-03
> 执行方式：自动筛样+人工检查权属｜确定性工具：sampling_draw

## 输入

- 无形资产台账、权属证书原件、非专利技术保密资料、协议、董事会纪要、使用状况和受益期限分析

## Steps

1. 【规则】.检查无形资产的权属证书原件、非专利技术的持有和保密状况等，并获取有关协议和董事会纪要等文件、资料，检查无形资产的性质、构成内容、计价依据、使用状况和受益期限，确定无形资产是否存在，并由被审计单位拥有或控制。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 样本编号 | 文本 | 抽样表 | 样本量与依据已记录 |
| 项目/合同名称 | 文本 | 明细账/台账 | 与账面一致 |
| 账面金额 | 金额 | 明细账 | 金额精确匹配 |
| 支持文件日期 | 日期 | 发票/合同/凭证 | 日期在审计期间内 |
| 支持文件编号 | 文本 | 发票/合同/凭证 | 可回溯 |
| 核对内容 | 文本 | 程序表 | 覆盖授权、存在、计价 |
| 独立证据 | 文本 | 外部/现场证据 | 必要时取得外部证据 |
| 异常事项 | 文本 | 审计判断 | 异常不得留空 |
| 结论 | 文本 | 审计判断 | 支持/不支持账面记录 |

## 质量门

- 重要无形资产权属清晰；性质、计价依据、使用状况和受益期限有证据

## 升级路径

- 权属不清、被质押/许可限制或受益期限依据不足时升级项目经理。
