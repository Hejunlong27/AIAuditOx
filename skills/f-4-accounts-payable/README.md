## 程序库映射完整性

F2202 共 5 项实质性分析程序 + 12 项其他实质性程序，全部映射：分析1-5→P02；程序1→P01；程序2→P03；程序3、4→P04；程序5、6、11→P05；程序7→P06；程序8、9→P07；程序10、12→P08。

## 模板要点（含公式）

| 表 | 内置公式/机制 |
|----|-------------|
| F-4-01 明细表 | 本位币=原币；合计加总；借方余额/预付同挂/关联方/暂估标注列 |
| F-4-02 分析程序 | 差异+超阈值 IF（比率行百分比格式） |
| F-4-03 对账单调节 | 差异=IF(对账单-账面)；异常类型下拉（折扣/退回/红字冲销/异常处理/缺凭证/暂估） |
| F-4-04 函证 | 回函差异 IF；中期前推公式=发函日余额+采购+折扣−付款 |
| F-4-05 未入账负债 | 三来源区（未入账发票/货到票未到/期后付款）+ **SUMIF 建议补提合计**（只汇总"需补提=是"行） |
| F-4-06 截止测试 | 双向测试区+归属期间/跨期下拉 |

## 跨科目联动

- 未入账负债（完整性核心）→ Z-5 存货入库资料、F-6 应付职工薪酬、F-7 应交税费；
- 预付双挂账 → Z-3 预付账款技能（镜像联动）；
- 供应商疑似关联方 → A-5 关联方技能（强制升级）；
- 债务重组或有应付 → F-15 预计负债；
- 期后付款核对 → Z-1 货币资金组。

## 制式遵循

强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录）。
