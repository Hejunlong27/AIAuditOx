# F-4 应付账款技能组（助理级主技能）

> **【技能来源与使用声明】**
> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。
> **作者与许可**：何小疯27 · 免费开源 · 禁止商用转售
> **技能主页**：aiauditox.l.cd ｜ **开发动态**：公众号‘小小审计员日记’
> **使用声明**：本技能输出内容仅供学习与工作参考，不构成任何审计意见或专业建议；请勿将客户敏感数据用于公开的 AI 服务。

> 技能库分组：负债类 F → F-4 应付账款（对应所内科目编号 2202 / 程序库 F2202）
> 角色：本技能由「F-4 应付账款助理」持有并调度，程序卡 P01~P08 由实习生级执行，一级复核由助理执行（编制-复核分离）。
> 程序来源：《审计程序库——F2202应付账款》（立信技术标准部 2022/10 版，编号 F2202）。
> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：负债完整记录（未入账负债是本科目核心风险）；存在性（E）：已记录负债真实；准确性/计价（A/V）：金额准确、外币折算正确、现金折扣与债务重组处理正确；列报（P）：披露恰当 |
| 所需资料 | 应付账款明细账（按供应商）、供应商对账单、函证工作簿及回函、期后付款清单、验收报告/入库单（期后收货）、采购合同、债务重组协议与批文（如有）、主要供应商工商资料、财务报表附注 |
| 所需数据 | 分供应商期末余额、本期采购额、期初余额与上年数、账龄分布、供应商对账单差异调节事项、期后付款额、暂估入账（货到票未到）清单、前十供应商采购额与合同额 |
| 核对逻辑 | ① 明细加计↔总账/报表核对+外币折算+借方余额重分类+预付账款双挂账排查；② 分析程序五项（采购比率/周转天数/分供应商余额预期/月度采购量季节性/账龄预期）超阈值调查；③ 供应商对账单调节复核（大额购货折扣/退回/红字冲销/异常交易）；④ 函证+中期前推；⑤ 暂挂账户分析；⑥ 查找未入账负债（未入账发票/货到票未到/期后付款三来源+结合存货监盘入库资料）；⑦ 采购截止测试（收货清单→负债入账双向）；⑧ 现金折扣全额入账检查；⑨ 债务重组10项子程序；⑩ 负债完整性考虑（薪酬/服务/税费）；⑪ 主要供应商核查（名单变动/工商资料/访谈/合同匹配）；⑫ 披露核对 |
| 底稿编制内容 | 见「产出清单」，全部底稿采用 auditox-wp-standard 四段式制式 |
| 输出格式 | xlsx 工作簿（模板见 templates/F-4应付账款审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已指定（未指定拒绝启动）；基于模板在 `02_工作底稿/F-4应付账款/` 创建工作簿副本。
2. 校验输入：应付账款明细账必输；供应商对账单、期后付款清单、期后收货资料（P05/P06 需要）缺失列明缺口挂起。
3. 分派顺序：P01 → P02 → （P03、P04 并行）→ P05（未入账负债，核心）→ P06 → （P07、P08 视情况并行）。
4. 副本先行 + 修订记录伴随。
5. 异常激活：P02 采购比率/周转天数异常 → 激活 P05 未入账负债查找与 P06 截止测试扩样；P03 对账单差异重大 → 检查支持性文件并考虑计提额外负债；P05 发现货到票未到未暂估 → 提请补提负债（联动 Z-5 存货入库资料）；P06 采购跨期 → 升级助理评估调整；P08 供应商与被审计单位疑似关联 → 升级项目经理并联动 A-5；P04 未回函 → 替代程序（期后付款/对账单核对）。
6. 汇总执行一级复核（完整性/勾稽/证据/异常闭环/制式合规），通过后提交人工二级复核。

## 一级复核清单（独立于编制上下文）

- P01~P08 均有底稿或「不适用+理由」；索引号连续；
- 明细合计=总账数=报表数；借方余额重分类、预付双挂账排查有结论；
- 未入账负债查找三来源齐备且记录选样依据；期后收货资料与暂估勾稽；
- 函证样本量与选样依据记录，回函差异与替代程序闭环；
- 现金折扣按全额入账核实；债务重组事项（如有）10 项子程序执行完整；
- 主要供应商核查有工商资料与访谈记录；
- 四段式制式完整、七要素齐全、修订记录同步。

## 边界与禁止事项

- 仅项目工作目录内操作；禁止物理删除、外发数据；禁止代替人工执行函证寄发与供应商实地走访/电话访谈；
- 数字核对脚本精确匹配；是否计提额外负债的建议标注「待人工确认」；
- 供应商疑似关联方发现后必须升级项目经理（联动 A-5），不得仅作底稿记录。

## Pitfalls

- 应付账款的核心风险是完整性（少计负债），查找未入账负债必须覆盖三来源：未入账发票、货到票未到、资产负债表日后付款；并须结合存货监盘的期前后入库资料；
- 借方余额项目须查明原因重分类至预付账款；与预付账款同一供应商双挂账须排查（与 Z-3 技能互为镜像）；
- 现金折扣应按发票全额入账、实际获得时冲减财务费用，按净额入账是常见错误；
- 债务重组涉及关联方的，重组利得会计处理须符合关联方披露规定；
- 中期函证须前推至期末（+采购+折扣−付款），不能直接采用中期余额。

## Verification

- 工作簿公式重算无错误；分析程序区所有「预期vs实际」均有阈值判定结论；
- 未入账负债区三来源齐备；截止测试双向执行；
- 每张底稿四段式完整、修订记录对应。
