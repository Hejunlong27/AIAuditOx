## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：所有工程物资均已记录（含未列示于账面者）；存在（E）：记录的工程物资于资产负债表日存在且归被审计单位拥有或控制；准确性（A）：金额正确计算、适当加总且准确记录；计价（V）：按恰当金额计价（含减值、摊销、公允价值等调整）；列报（P）：分类、披露恰当 |
| 所需资料 | 工程物资明细账与仓库台账、总账与报表、采购合同/订单、发票、入库验收单、领用单、工程完工资料、增值税资料、关联方清单、减值测试、财务报表附注 |
| 所需数据 | 物资名称/规格、供应商、数量、单价、金额、入库日期、存放地点、领用项目、呆滞状态、可变现净值、关联方标识、减值准备 |
| 核对逻辑 | 1. 工程物资明细表编制与核对（获取或编制工程物资明细表，复核加计是否正确，并与总账数和明细账合计数核对是否相符，结合工程物资减值准备与报表数核对是否相符。）；2. 工程物资实地检查与呆滞物资识别（实地检查工程物资，确定其是否存在，并观察是否有呆滞、积压物资。）；3. 工程物资采购授权与原始凭证检查（抽查若干工程物资采购合同、发票、货物验收单等原始凭证，检查其是否经过授权审批，会计处理是否正确。）；4. 完工剩余工程物资转存货及增值税检查（检查工程完工后剩余的工程物资在转入存货时，是否将其所含的增值税进项税额进行了正确的分离。）；5. 工程物资关联交易与减值检查（检查有无与关联方的工程物资购销业务，是否经过适当授权，是否按正常交易价格结算。）；6. 工程物资披露检查（审计工程物资的披露） |
| 底稿编制内容 | 共 6 张底稿：P01 工程物资明细表编制与核对、P02 工程物资实地检查与呆滞物资识别、P03 工程物资采购授权与原始凭证检查、P04 完工剩余工程物资转存货及增值税检查、P05 工程物资关联交易与减值检查、P06 工程物资披露检查。全部采用 auditox-wp-standard 四段式制式。 |
| 输出格式 | xlsx 工作簿（模板见 templates/Z-18工程物资审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/Z-18工程物资/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性（见六要素「所需资料」）；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → P02 → P03 → P04 → P05 → P06；人工程序标记待办并跟踪完成状态。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：按各程序卡「升级路径」处理，发现异常事项逐级升级。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P06 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：明细表合计数 = 总账数 = 报表数；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源；差异事项均有解释与支持文件。
- 异常闭环：所有异常事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料 只读）；跳过强制程序。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 工程物资长期未领用或项目已完工后仍挂账，可能已无使用价值或应转存货。
- 剩余工程物资转存货时增值税进项税额未正确分离，可能影响存货成本。
- 采购无授权、验收数量与发票不符或供应商异常，可能表明虚构采购。
- 关联方购销和减值迹象容易漏披露，须与关联方程序交叉核对。

- 工作簿公式重算无错误；合计数与总账/报表数核对一致。
- 每张底稿「审计程序执行结果」与「审计说明」均有实质内容或明确的不适用声明。
- 修订记录 .md 与工作簿版本一一对应。
