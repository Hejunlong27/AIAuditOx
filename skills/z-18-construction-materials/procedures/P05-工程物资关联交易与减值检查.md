# P05 工程物资关联交易与减值检查

> 来源：Z1605 程序库 Z1605 程序5、Z1605 程序6｜认定：C、E、A、V｜产出：Z-18-05
> 执行方式：规则筛异常+人工检查｜确定性工具：rule_check、threshold_flag

## 输入

- 关联方清单、购销合同与价格依据、减值测试、管理层判断说明、物资状态

## Steps

1. 【规则】检查有无与关联方的工程物资购销业务，是否经过适当授权，是否按正常交易价格结算。
2. 【规则】检查当期计提的工程物资减值准备是否充分、合理，累计减值准备额是否以恰当的金额列示。获取管理层在资产负债表日就工程物资是否存在可能发生减值的迹象的判断的说明。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产/资产组 | 文本 | 减值测试表 | 资产组划分合理 |
| 账面价值 | 金额 | 明细账 | 与总账核对 |
| 可收回金额 | 金额 | 评估报告/模型 | 公允价值减处置费用与使用价值孰高 |
| 现有准备 | 金额 | 准备明细账 | 期初+计提-核销 |
| 应有准备 | 金额 | 审计重算 | 账面价值-可收回金额且不低于零 |
| 本期计提/核销 | 金额 | 计算表 | 会计分录正确 |
| 减值迹象 | 文本 | 管理层评估/外部证据 | 迹象须有支持 |
| 关键假设/专家 | 文本 | 模型/专家报告 | 假设合理性已评价 |
| 结论 | 文本 | 审计判断 | 充分/不足/需调整 |

## 质量门

- 关联交易经授权且价格公允；减值判断有依据并正确入账

## 升级路径

- 关联交易价格异常或减值准备不足时升级项目经理并联动关联方程序。
