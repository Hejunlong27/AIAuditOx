# P02 工程物资实地检查与呆滞物资识别

> 来源：Z1605 程序库 Z1605 程序2｜认定：E｜产出：Z-18-02
> 执行方式：人工主导（现场检查）+自动比对｜确定性工具：sampling_draw｜**必须留人**（Agent 不得代替执行）

## 输入

- 工程物资盘点表、仓库现场、物资标签、台账、项目进度资料

## Steps

1. 【人工】实地检查工程物资，确定其是否存在，并观察是否有呆滞、积压物资。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产编号 | 文本 | 资产标签/台账 | 编号唯一 |
| 资产名称 | 文本 | 台账/铭牌 | 名称规格一致 |
| 存放/工程地点 | 文本 | 现场记录 | 与台账地址一致 |
| 账面价值 | 金额 | 明细账 | 与盘点清单一致 |
| 现场状态 | 文本 | 监盘记录 | 存在/毁损/闲置等 |
| 使用/完工状态 | 文本 | 现场观察/访谈 | 与账面状态一致 |
| 权属/标识 | 文本 | 产权证/铭牌 | 权属清晰 |
| 差异 | 文本 | 核对表 | 账实差异逐项说明 |
| 结论 | 文本 | 审计判断 | 是否需调整/减值 |

## 质量门

- 重要存放地点均检查；账实差异和呆滞积压物资逐项记录并评价减值

## 升级路径

- 账实差异重大、物资不存在或大量呆滞时升级项目经理。
