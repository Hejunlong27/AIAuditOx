# P05 借款费用资本化与在建工程项目成本测试

> 来源：Z1604 程序库 Z1604 程序6、Z1604 程序7｜认定：C、E、A、V、P｜产出：Z-17-05
> 执行方式：自动重算+人工复核资本化条件｜确定性工具：recalc_check、threshold_flag

## 输入

- 借款合同、借款费用明细、资本化率、资产支出加权平均数、资本化开始/暂停/停止依据、项目成本明细、验收记录

## Steps

1. 【脚本】检查利息资本化是否正确。复核计算资本化利息的借款费用、资本化率、实际支出数以及资本化的开始和停止时间。
2. 【规则】测试在建工程
   - （1）获取在建工程清单并执行审计程序测试IPE的可靠性；
   - （2）记录样本量和选样依据：
   - （3）确认该在建工程尚未投入使用，且未计提折旧；
   - （4）确保该在建工程的披露和会计处理是适当的，且符合被审计单位的会计政策及适用的财务报告编制基础；
   - （5）如果在建工程在本期完工，确保在建成本已结转至资产账户并相应摊销，确认剩余成本已停止资本化并在发生时计入费用。
   - ①获取已选取资产的详细信息，将其账面价值与佐证文件进行核对；
   - ②确定成本是否符合资本化标准；
   - ③如果对相关长期借款的利息予以资本化，确认资本化金额计算正确；
   - ④根据下列方面考虑资产账面价值的可收回性：
   - a）资产市场价值的变化；
   - b）资产的状况；
   - c）影响资产使用寿命或产量的未来计划；

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析表 | 按类别/项目拆分 |
| 预期值 | 数值 | 审计模型 | 模型依据留痕 |
| 实际值 | 数值 | 总账/明细账 | 与账面核对 |
| 差异 | 金额 | 计算表 | 实际-预期 |
| 差异率 | 百分比 | 计算表 | 差异/预期，除零保护 |
| 重要性阈值 | 金额 | 计划阶段 | 记录实际执行重要性 |
| 是否超阈值 | 文本 | 规则判断 | 超阈值须调查 |
| 原因与证据 | 文本 | 访谈/支持文件 | 不能仅凭解释 |
| 结论 | 文本 | 审计判断 | 记录追加程序或调整 |

## 质量门

- 资本化金额独立重算；资本化期间和资产支出依据充分；项目成本符合资本化范围

## 升级路径

- 资本化率、期间或项目成本归集错误时升级项目经理并评估重分类/调整。
