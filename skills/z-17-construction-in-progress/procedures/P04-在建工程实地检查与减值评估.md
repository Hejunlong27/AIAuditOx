# P04 在建工程实地检查与减值评估

> 来源：Z1604 程序库 Z1604 程序4、Z1604 程序5｜认定：C、E、A、V、P｜产出：Z-17-04
> 执行方式：人工主导（实地检查）+自动重算｜确定性工具：recalc_check｜**必须留人**（Agent 不得代替执行）

## 输入

- 项目现场、工程进度记录、监理报告、未安装设备清单、停建/缓建说明、减值测试模型

## Steps

1. 【人工】实施在建工程实地检查程序（全部或部分）。实地勘察在建工程建造情况，了解工程项目的实际完工进度，查看未安装设备的实际存在。
2. 【规则】检查在建工程减值准备，关注停建工程：
   - （1）检查在建工程是否出现减值情形，是否应确认减值准备，并从以下角度考虑资产账面价值的可收回性：
   - （2）检查在建工程减值准备计提的方法是否符合规定，前后期是否一致，计提数是否恰当，相关会计处理是否正确，依据是否充分，并作出记录；
   - （3）检查减值计提所依据的确定可收回金额的方法。对以市价确定可收回金额的在建工程，复核管理层使用的市价的取得方法；对以现值确定的可收回金额，复核计算现值的假设、方法是否合理。获取管理层在资产负债表日就在建工程是否存在可能发生减值迹象的判断的说明；
   - （4）检查实际发生的在建工程损失核销的金额及会计处理是否正确。
   - ①资产市场价值发生改变；
   - ②资产的状况；
   - ③影响资产使用寿命或产量的未来计划；

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产编号 | 文本 | 资产标签/台账 | 编号唯一 |
| 资产名称 | 文本 | 台账/铭牌 | 名称规格一致 |
| 存放/工程地点 | 文本 | 现场记录 | 与台账地址一致 |
| 账面价值 | 金额 | 明细账 | 与盘点清单一致 |
| 现场状态 | 文本 | 监盘记录 | 存在/毁损/闲置等 |
| 使用/完工状态 | 文本 | 现场观察/访谈 | 与账面状态一致 |
| 权属/标识 | 文本 | 产权证/铭牌 | 权属清晰 |
| 差异 | 文本 | 核对表 | 账实差异逐项说明 |
| 结论 | 文本 | 审计判断 | 是否需调整/减值 |

## 质量门

- 重要项目均实地查看；完工程度与账面一致；停建和减值迹象逐项评价

## 升级路径

- 项目不存在、长期停建、进度严重滞后或减值不足时升级项目经理并考虑专家工作。
