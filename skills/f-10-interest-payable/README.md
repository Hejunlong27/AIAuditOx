## 程序库映射完整性

《审计程序库——F2231应付利息》全部程序条目映射如下：

| 程序库条目 | 条目名称 | 落地位置 |
|-----------|---------|---------|
| 分析1 | 复核利息支出的平均实际利率，根据本年度平均借款余额及利率对本期平均实际利率作出预 | P01 |
| 分析2 | 检查应付利息的计算是否正确 | P01 |
| 其他1 | 获取或编制应付利息明细表 | P02 |
| 其他2 | 结合短期借款、长期借款、分期付息到期还本的长期借款、应付债券、以公允价值计量且其 | P02 |
| 其他3 | 审计应付利息的披露 | P03 |

## 底稿制式（四段式）

每张底稿统一结构：

1. 底稿名称与表头——一、项目基本信息：被审计单位、审计期间、编制人、编制日期、审核人、审核日期、索引号
2. 二、审计目标和程序说明——审计目标段 + 程序表（序号/程序/认定/是否已实施/执行结果）
3. 三、审计程序执行结果——数据表（含公式自动计算）
4. 四、审计说明——编号说明行 + 编制/审核签字行 + 修订记录伴随声明

模板中灰色斜体行为示例行，实际使用时删除。
