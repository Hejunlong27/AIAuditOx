# P03 应付利息披露检查

> 来源：F2231 程序库 其他3｜认定：P｜产出：F-10-03
> 执行方式：自动（schema 校验）+人工确认｜确定性工具：rule_check

## 输入

- 报表附注中应付利息或借款费用相关披露文本
- 应付利息明细表
- 借款费用资本化披露

## Steps

1. 【规则】审计应付利息的披露
   - 检查相关财务报表附注披露的准确性和完整性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 披露事项 | 文本 | 准则要求清单 | 枚举（分类/借款费用资本化/关联方借款 等） |
| 附注披露内容 | 文本 | 报表附注 | 非空 |
| 是否完整 | 文本 | rule_check 校验 | 缺项标注「否」 |
| 与底稿一致性 | 文本 | 与明细表比对 | 枚举（一致/不符） |
| 说明 | 文本 | 人工填写 | 缺项或不符必有 |

## 质量门

- 准则要求的披露事项逐项核对，无遗漏
- 附注金额与底稿明细表金额一致
- 借款费用资本化金额已按准则披露

## 升级路径

- 披露缺项 → 升级项目经理，提请管理层补充披露
- 附注与底稿金额不符 → 退回 P02 核实后重新比对
