# P01 实质性分析程序

> 来源：F2231 程序库 分析1、分析2｜认定：C、E、A、V｜产出：F-10-01
> 执行方式：自动（利率与利息测算）｜确定性工具：interest_calc、threshold_flag

## 输入

- 借款与债券台账（本金、票面或合同利率、起止日）
- 市场平均利率参考
- 平均借款余额计算表
- 应付利息明细账
- 上年数据
- 实际执行的重要性水平

## Steps

1. 【规则】复核利息支出的平均实际利率，根据本年度平均借款余额及利率对本期平均实际利率作出预期：
   - （1）将实际值与预期值进行比较；
   - （2）检查xxxx以上（实际执行的重要性水平的%，特定金额）相对于预期值的差异，并获取相关说明和证据；
   - （3）在无适当的说明或确切的证据可以证明差异时，考虑是否需要计划并实施额外工作及/或记录发现的任何差错。
2. 【脚本】检查应付利息的计算是否正确：
   - （1）计算借款、债券等平均利率（票面或合同利率）并同以前年度及市场平均利率相比较；
   - （2）根据借款、债券等平均余额、平均利率测算当期应付或应计利息，并与账面记录进行比较。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 借款或债券项目 | 非空 |
| 平均借款余额 | 金额 | 按月加权计算 | 重算一致 |
| 平均实际利率 | 百分比 | 利息支出 ÷ 平均借款余额 | 脚本计算 |
| 市场平均利率 | 百分比 | 市场数据或基准利率 | 有依据 |
| 测算应计利息 | 金额 | interest_calc 测算 | 重算一致 |
| 账面应付利息 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 测算 − 账面 | = 差额 |
| 是否超重要性水平 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明与证据 | 文本 | 人工填写 | 超限项必有 |

## 质量门

- 全部借款与债券项目 100% 纳入分析，无遗漏
- 平均实际利率与市场平均利率及以前年度已比较，偏离已说明
- 测算应计利息与账面差异超实际执行的重要性水平的项目均有解释与佐证

## 升级路径

- 测算与账面差异重大 → 升级项目经理，转 P02 逐笔核查完整性
- 平均利率显著偏离市场水平 → 升级，评估是否存在未披露的关联方借款或利率异常安排
