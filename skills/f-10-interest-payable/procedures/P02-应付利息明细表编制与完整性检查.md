# P02 应付利息明细表编制与完整性检查

> 来源：F2231 程序库 其他1、其他2｜认定：C、E、A、V｜产出：F-10-02
> 执行方式：自动（脚本核对+漏记测算）｜确定性工具：recalc_check、balance_confirm、interest_calc

## 输入

- 应付利息明细表（按借款或债券项目）
- 总账 2231 余额及明细账合计数
- 借款与债券台账
- 融资租赁合同
- 固定资产借款资料
- 资产负债表日即期汇率表
- 上年审定数

## Steps

1. 【规则】获取或编制应付利息明细表：
   - （1）复核加计是否正确，并与报表数、总账数和明细账合计数核对是否相符；
   - （2）检查非记账本位币应付利息的折算汇率及折算是否正确。
2. 【规则】结合短期借款、长期借款、分期付息到期还本的长期借款、应付债券、以公允价值计量且其变动计入当期损益的金融负债、固定资产、租赁费用的审计，检查应付利息有无漏记。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 借款或债券项目 | 文本 | 明细表 | 非空 |
| 币种 | 文本 | 明细表 | 枚举（CNY/USD/HKD 等） |
| 原币金额 | 金额 | 明细表 | 与凭证一致 |
| 折算汇率 | 汇率 | 即期汇率表 | 资产负债表日汇率 |
| 本位币金额 | 金额 | 原币金额 × 折算汇率 | = 乘积 |
| 年利率 | 百分比 | 借款合同 | 与合同一致 |
| 计息期间 | 文本 | 借款合同 | 非空 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数（四方相符）
- 外币项目 100% 有折算汇率且为资产负债表日即期汇率
- 已结合短期借款、长期借款、应付债券、融资租赁、固定资产等科目的审计检查应付利息有无漏记

## 升级路径

- 与借款、债券科目交叉核对发现漏记 → 升级项目经理，按完整性错报处理
- 外币折算汇率使用错误 → 升级，评估对财务费用的影响
