## 使用方式

对话触发：「执行 Z-22 商誉审计程序」「编制商誉底稿」。

执行顺序：工作目录门禁 → 资料清单校验 → 按程序分派表执行 → 异常升级 → 一级复核 → 底稿归档。

## 跨科目联动

- 固定资产、在建工程、工程物资和固定资产清理之间应交叉核对转固、领用和处置链条。
- 无形资产应与研发支出、政府补助、借款费用和所得税程序交叉核对。
- 使用权资产应与租赁负债、固定资产和长期待摊费用程序交叉核对。
- 商誉应与企业合并、资产减值损失和所得税程序交叉核对。

## 制式遵循

强制遵循全局标准技能 auditox-wp-standard。所有 Excel 模板中的合计行均使用公式，示例行使用时删除。
