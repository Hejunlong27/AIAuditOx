# P04 企业合并形成商誉检查

> 来源：Z1711 程序库 Z1711 程序4｜认定：C｜产出：Z-22-04
> 执行方式：自动勾稽+人工复核合并资料｜确定性工具：recalc_check、threshold_flag

## 输入

- 企业合并协议、购买日确定资料、可辨认资产/负债公允价值、合并对价、合并审计底稿

## Steps

1. 【规则】针对本期所有企业合并，通过对企业合并进行审计，确定是否形成商誉

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析表 | 按类别/项目拆分 |
| 预期值 | 数值 | 审计模型 | 模型依据留痕 |
| 实际值 | 数值 | 总账/明细账 | 与账面核对 |
| 差异 | 金额 | 计算表 | 实际-预期 |
| 差异率 | 百分比 | 计算表 | 差异/预期，除零保护 |
| 重要性阈值 | 金额 | 计划阶段 | 记录实际执行重要性 |
| 是否超阈值 | 文本 | 规则判断 | 超阈值须调查 |
| 原因与证据 | 文本 | 访谈/支持文件 | 不能仅凭解释 |
| 结论 | 文本 | 审计判断 | 记录追加程序或调整 |

## 质量门

- 本期所有企业合并均已确定是否形成商誉；购买日和对价分摊正确

## 升级路径

- 合并对价分摊不完整或商誉计算异常时升级项目经理并联动企业合并程序。
