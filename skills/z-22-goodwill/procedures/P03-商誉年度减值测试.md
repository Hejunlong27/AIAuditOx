# P03 商誉年度减值测试

> 来源：Z1711 程序库 Z1711 程序3｜认定：A、V｜产出：Z-22-03
> 执行方式：人工主导（会计估计审计）+自动重算｜确定性工具：recalc_check｜**必须留人**（Agent 不得代替执行）

## 输入

- 减值测试模型、现金流预测、预算、折现率、长期增长率、处置成本、评估报告、专家报告、行业数据

## Steps

1. 【规则】评估商誉年度减值测试
   - （1）获取被审计单位进行减值评估的详细资料，并确定审计会计估计的方法（审计管理层的计算，作出注册会计师的点估计或区间估计等）；
   - （2）评价模型在适用的财务报告编制基础下的适当性，包括现金产出单元和用于确定公允价值减去处置成本和使用价值的模型的适当性；考虑使用GFSA财务报表编制示例文件夹下内的减值模板；
   - （3）评价模型中使用的数据的可靠性；
   - （4）评价用于确定可收回金额的假设的合理性（如现金流量、折现率、处置成本等）；
   - （5）考虑是否需要利用专家的工作；
   - （6）检查商誉的账面价值和确认的减值损失；
   - （7）根据适用的财务报告编制基础，检查相关披露是否完整、准确；                                                       （8）确保遵守《中国注册会计师审计准则第1321号——审计估计估计（包括公允价值会计估计）和相关披露》的所有要求；
   - （9）记录如何在审计过程中保持职业怀疑以及对所有佐证证据实施的检查。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产/资产组 | 文本 | 减值测试表 | 资产组划分合理 |
| 账面价值 | 金额 | 明细账 | 与总账核对 |
| 可收回金额 | 金额 | 评估报告/模型 | 公允价值减处置费用与使用价值孰高 |
| 现有准备 | 金额 | 准备明细账 | 期初+计提-核销 |
| 应有准备 | 金额 | 审计重算 | 账面价值-可收回金额且不低于零 |
| 本期计提/核销 | 金额 | 计算表 | 会计分录正确 |
| 减值迹象 | 文本 | 管理层评估/外部证据 | 迹象须有支持 |
| 关键假设/专家 | 文本 | 模型/专家报告 | 假设合理性已评价 |
| 结论 | 文本 | 审计判断 | 充分/不足/需调整 |

## 质量门

- 模型和资产组划分适当；关键假设有证据；独立重算/敏感性分析和专家工作已评价

## 升级路径

- 可收回金额接近账面价值、假设高度敏感或专家工作不足时升级项目经理。
