> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。

> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式：一、项目基本信息/二、审计目标和程序说明/三、审计程序执行结果/四、审计说明 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

> 程序来源：《审计程序库——S6603财务费用》

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：所有财务费用均已记录（含未列示于账面者）；存在（E）：记录的财务费用于资产负债表日存在且归被审计单位拥有或控制；准确性（A）：金额正确计算、适当加总且准确记录；计价（V）：按恰当金额计价（含减值、摊销、公允价值等调整）；列报（P）：分类、披露恰当 |
| 所需资料 | 财务费用明细表与明细账、借款与债券台账及合同、融资租赁合同、利息计算表与结息单、含息投资台账、外币账户与外币债权债务明细、资产负债表日即期汇率表、结汇购汇凭证、金融机构手续费协议与发票、资本化资产台账与资本化计算表、报表附注 |
| 所需数据 | 各借款与投资项目的本金或摊余成本、年利率、计息起止日、平均借款余额与实际利率、利息支出与利息收入本期发生额、外币金额与折算汇率、汇兑损益金额、金融机构手续费金额、资本化金额与资本化率、实际执行的重要性水平 |
| 核对逻辑 | 1. 实质性分析程序（复核利息收入的平均实际利率）；2. 财务费用明细表编制与核对（获取或编制财务费用明细表，复核其加计数是否正确，并与报表数、总账数和明细账合计数核对是否相符。）；3. 利息支出检查（检查利息支出明细账）；4. 利息收入检查（检查利息收入明细账）；5. 汇兑损益与手续费检查（检查汇兑损益明细账，检查汇兑损益计算方法是否正确，核对所用汇率是否正确，前后期是否一致。）；6. 财务费用披露检查（检查财务费用是否已按照企业会计准则的规定在财务报表中作出恰当的列报和披露。） |
| 底稿编制内容 | 见「产出清单」，全部底稿采用四段式制式：底稿名称与表头（项目基本信息）→ 审计目标和程序说明 → 审计程序执行结果 → 审计说明。共 6 张底稿。 |
| 输出格式 | xlsx 工作簿（模板见 templates/S-11财务费用审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/S-11财务费用/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性（见六要素「所需资料」）；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → P02 → P03 → P04 → P05 → P06；人工程序标记待办并跟踪完成状态。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：按各程序卡「升级路径」处理，发现异常事项逐级升级。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P06 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：明细表合计数 = 总账数 = 报表数；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源；差异事项均有解释与支持文件。
- 异常闭环：所有异常事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料 只读）；跳过强制程序。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 利息支出须逐笔测算并检查期末应计利息是否漏记，账面与测算差异不能仅以「已核对」了结
- 购建或生产符合资本化条件资产期间的借款费用应资本化，费用化与资本化划分错误会同时影响资产与损益
- 融资租赁未确认融资费用摊销、购入资产超过正常信用条件延期付款的利息摊销，均须按实际利率法核算，勿简化为直线法
- 应收票据贴现息、弃置费用利息容易被遗漏，须专项核查
- 外币折算须统一采用资产负债表日即期汇率；汇率前后期不一致会系统性扭曲汇兑损益
- 利息收入的确认应与应收利息余额调节一致，两科目差异须查明
