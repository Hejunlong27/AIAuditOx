# P06 财务费用披露检查

> 来源：S6603 程序库 其他7｜认定：P｜产出：S-11-06
> 执行方式：自动（schema 校验）+人工确认｜确定性工具：rule_check

## 输入

- 报表附注中财务费用相关披露文本
- 财务费用明细表
- 借款费用资本化披露
- 关联方资金往来披露

## Steps

1. 【规则】检查财务费用是否已按照企业会计准则的规定在财务报表中作出恰当的列报和披露。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 披露事项 | 文本 | 准则要求清单 | 枚举（费用构成/借款费用资本化/关联方资金往来 等） |
| 附注披露内容 | 文本 | 报表附注 | 非空 |
| 是否完整 | 文本 | rule_check 校验 | 缺项标注「否」 |
| 与底稿一致性 | 文本 | 与明细表比对 | 枚举（一致/不符） |
| 说明 | 文本 | 人工填写 | 缺项或不符必有 |

## 质量门

- 准则要求的披露事项逐项核对，无遗漏
- 附注金额与底稿明细表金额一致
- 借款费用资本化金额及资本化率已按准则披露

## 升级路径

- 披露缺项 → 升级项目经理，提请管理层补充披露
- 附注与底稿金额不符 → 退回 P02 核实后重新比对
