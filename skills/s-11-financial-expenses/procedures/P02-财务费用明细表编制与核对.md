# P02 财务费用明细表编制与核对

> 来源：S6603 程序库 其他1、其他2｜认定：A、P｜产出：S-11-02
> 执行方式：自动（脚本核对+核算范围校验）｜确定性工具：recalc_check、balance_confirm、rule_check

## 输入

- 财务费用明细表（按构成项目）
- 总账 6603 余额及明细账合计数
- 财务费用核算内容与范围规定
- 上年审定数

## Steps

1. 【脚本】获取或编制财务费用明细表，复核其加计数是否正确，并与报表数、总账数和明细账合计数核对是否相符。
2. 【规则】检查财务费用明细项目的设置是否符合规定的核算内容与范围，是否划清财务费用与其他费用的界限。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 费用构成项目 | 文本 | 明细表 | 枚举（利息支出/利息收入/汇兑损益/金融机构手续费/其他） |
| 本期发生额 | 金额 | 明细账 | 与总账一致 |
| 上年同期数 | 金额 | 上年明细账 | 与上年审定数一致 |
| 变动率 | 百分比 | (本期 − 上年同期) ÷ 上年同期 | 脚本计算 |
| 核算范围是否恰当 | 文本 | rule_check 校验 | 枚举（恰当/不恰当） |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数
- 明细项目设置符合财务费用核算内容与范围，与其他费用界限清晰
- 差异项均有初步说明

## 升级路径

- 存在财务费用与管理费用或制造费用混记 → 升级，评估重分类调整
- 与总账差异无法解释 → 升级 S-11 助理，联动 P03/P04 逐项核查
