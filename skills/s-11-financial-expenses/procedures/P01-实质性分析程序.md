# P01 实质性分析程序

> 来源：S6603 程序库 分析1、分析2、分析3、分析4、分析5｜认定：C、E、A｜产出：S-11-01
> 执行方式：自动（利息收支与费用构成测算）+人工判断｜确定性工具：interest_calc、threshold_flag

## 输入

- 借款与债券台账（本金、利率、起止日）
- 财务费用明细账（利息支出/利息收入/汇兑损益/手续费）
- 上年度数与本期预算数
- 市场平均利率参考
- 实际执行的重要性水平

## Steps

1. 【规则】复核利息收入的平均实际利率：
   - （1）将实际值与预期值进行比较；
   - （2）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。
   - 根据银行基准利率、与银行签订的协议、应收贷款协议等,对计算利息收入的实际利率作出预期：
2. 【规则】比较本年、上年以及预算的利息收入：
   - （1）将实际利息收入与预期利息收入进行比较；
   - （2）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。
   - 对本年应收利息作出预期：
3. 【规则】复核利息支出的平均实际利率：
   - （1）将实际值与预期值进行比较；
   - （2）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。
   - 根据本年度平均借款余额及利率对本期平均实际利率作出预期：
4. 【规则】比较本年、上年以及预算的实际利息支出：
   - （1）将实际利息支出与预期利息支出进行比较；
   - （2）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。
   - 根据本期每月借款余额及月利率，对本期利息费用作出预期：
5. 【规则】了解并核查公司财务费用构成项目是否存在异常或变动幅度较大的情况及其合理性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 费用构成项目 | 非空 |
| 本金或摊余成本 | 金额 | 借款或投资台账 | 与总账一致 |
| 实际利率 | 百分比 | 利息支出 ÷ 平均借款余额 | 脚本计算 |
| 预期利率 | 百分比 | 合同利率或市场平均利率 | 有依据 |
| 本期实际数 | 金额 | 明细账 | 与总账一致 |
| 上期数 | 金额 | 上年明细账 | 与上年审定数一致 |
| 预算数 | 金额 | 预算表 | 有依据 |
| 差异 | 金额 | 实际 − 预期 | = 差额 |
| 是否超重要性水平 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明与证据 | 文本 | 人工填写 | 超限项必有 |

## 质量门

- 利息支出与利息收入分别按实际利率复核，测算过程由脚本产出
- 财务费用构成项目中变动幅度异常或性质异常的项目已全部识别并说明
- 超实际执行的重要性水平的差异均有解释与佐证

## 升级路径

- 实际利率显著偏离合同利率或市场水平 → 升级项目经理，转 P03/P04 逐笔核查
- 发现应资本化的借款费用被费用化 → 升级，评估对在建工程与损益的连带影响
