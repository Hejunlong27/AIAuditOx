# P04 利息收入检查

> 来源：S6603 程序库 其他4｜认定：C、E、A、V、P｜产出：S-11-04
> 执行方式：自动（利息测算）+人工确认｜确定性工具：interest_calc、recalc_check

## 输入

- 含息投资台账（面值、利率、计息期间）
- 利息计算表与结息单
- 现金收据与银行流水
- 预提利息调整记录

## Steps

1. 【规则】检查利息收入明细账：
   - （1）确认利息收入的真实性及正确性；
   - （2）通过将各类含息投资的面值总额与相关利率相乘来证明利息收入；
   - （3）通过现金收据和预提利息的调整获取应收利息余额的明细；
   - （4）检查从其他企业或非银行金融机构取得的利息收入是否按规定计缴营业税。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 投资项目 | 文本 | 投资台账 | 非空 |
| 面值或本金 | 金额 | 投资台账 | 与总账一致 |
| 年利率 | 百分比 | 投资合同 | 与合同一致 |
| 计息期间 | 文本 | 投资合同 | 非空 |
| 测算利息收入 | 金额 | interest_calc 测算 | 重算一致 |
| 账面利息收入 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 测算 − 账面 | = 差额 |
| 收款核对 | 文本 | 现金收据/银行流水 | 枚举（相符/不符） |
| 说明 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 含息投资 100% 测算利息收入，测算过程由脚本产出
- 利息收入与应收利息余额调节一致
- 利息收入 100% 核对至收款凭据

## 升级路径

- 利息收入显著高于测算且无收款支持 → 升级项目经理，评估虚构收入风险
- 存在未计提利息的投资 → 升级，按完整性或准确性错报处理
