# P05 汇兑损益与手续费检查

> 来源：S6603 程序库 其他5、其他6｜认定：C、E、A、V、P｜产出：S-11-05
> 执行方式：自动（汇率/重算）+人工确认｜确定性工具：recalc_check、threshold_flag

## 输入

- 外币账户与外币债权债务明细
- 资产负债表日即期汇率表
- 结汇与购汇凭证
- 金融机构手续费明细与协议

## Steps

1. 【脚本】检查汇兑损益明细账，检查汇兑损益计算方法是否正确，核对所用汇率是否正确，前后期是否一致。
2. 【规则】检查“财务费用––其他”明细账，注意检查大额金融机构手续费的真实性与正确性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 项目 | 文本 | 明细账 | 枚举（汇兑损益/金融机构手续费/其他） |
| 外币金额 | 金额 | 外币账户明细 | 与明细账一致 |
| 折算汇率 | 汇率 | 即期汇率表 | 资产负债表日汇率 |
| 本位币金额 | 金额 | 外币金额 × 折算汇率 | = 乘积 |
| 本期损益或费用 | 金额 | 明细账 | 与总账一致 |
| 重算金额 | 金额 | recalc_check 重算 | 重算一致 |
| 差异 | 金额 | 重算 − 账面 | = 差额 |
| 是否异常 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明 | 文本 | 人工填写 | 差异或异常项必有 |

## 质量门

- 汇率前后期一致，采用资产负债表日即期汇率折算，折算金额由脚本重算
- 汇兑损益计算方法正确，与外币账户余额变动勾稽一致
- 大额金融机构手续费 100% 核对至协议与发票

## 升级路径

- 汇率使用前后期不一致或非即期汇率 → 升级项目经理，评估对损益的整体影响
- 大额手续费无协议或无实质服务支持 → 升级，评估真实性与舞弊风险
