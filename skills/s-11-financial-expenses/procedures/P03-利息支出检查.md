# P03 利息支出检查

> 来源：S6603 程序库 其他3｜认定：C、E、A、V、P｜产出：S-11-03
> 执行方式：自动（利息重算+资本化判断辅助）+人工判断｜确定性工具：interest_calc、recalc_check

## 输入

- 借款、债券、融资租赁台账
- 利息计算表与结息单
- 资本化资产（在建工程等）台账与资本化计算表
- 应收票据贴现记录
- 弃置费用义务资产清单

## Steps

1. 【规则】检查利息支出明细账：
   - （1）审查各项借款期末应计利息有无预计入账；
   - （2）审查现金折扣的会计处理是否正确；
   - （3）结合长短期借款、应付债券等的审计，检查财务费用中是否包括为购建或生产满足资本化条件的资产发生的应予资本化的借款费用；
   - （4）检查融资租入的固定资产、购入有关资产超过正常信用条件延期支付价款、实质上具有融资性质的，采用实际利率法分期摊销未确认融资费用时计入财务费用数是否正确，实施以下程序：
   - （1）该租赁被合理认定为融资租赁；
   - （2）该资产金额与租赁合同核对相符；
   - （5）检查应收票据贴现息的计算与会计处理是否正确；
   - （6）检查存在资产弃置费用义务的固定资产或油气资产，在其使用寿命内，是否按期计算确定应负担的利息费用。
   - ①复核租赁信息，以确保：
   - ②检查租赁费用的计算准确性；
   - ③核实租赁会计处理符合客户的会计政策及企业会计准则的规定；
   - ④确保租赁事项在财务报表中正确披露，包括对现金和非现金交易金额的现金流量进行恰当的分类和披露；

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 借款或负债项目 | 文本 | 借款台账 | 非空 |
| 本金或摊余成本 | 金额 | 借款台账 | 与总账一致 |
| 年利率 | 百分比 | 借款合同 | 与合同一致 |
| 计息起止日 | 文本 | 借款合同 | 非空 |
| 应计利息（测算） | 金额 | interest_calc 测算 | 重算一致 |
| 账面利息支出 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 测算 − 账面 | = 差额 |
| 是否应资本化 | 文本 | 人工判断 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 差异或资本化项必有 |

## 质量门

- 全部借款与负债项目 100% 测算应计利息，期末应计利息无漏记
- 资本化与费用化划分符合准则，资本化金额有计算表支持
- 现金折扣、票据贴现息、未确认融资费用摊销、弃置费用利息的计算与处理均已核查

## 升级路径

- 期末应计利息漏记金额重大 → 升级项目经理，按完整性错报处理并联动应付利息程序
- 资本化金额计算错误 → 升级，评估对在建工程与损益的双向影响
