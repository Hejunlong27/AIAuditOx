# P02 库存现金监盘

> 来源：Z1001 程序2（监盘库存现金）｜认定：C、E、A｜产出：Z-1-1-02 库存现金盘点核对表

## 输入

- 期末库存现金存放地点及预期金额清单（执行 IPE 可靠性测试）
- 被审计单位盘点计划/盘点表；盘点日未记账传票

## Steps（人工主导监盘，技能做计算与记录）

1. 【人工+规则】确定监盘地点与选样依据；制定监盘计划与时间；IPE 测试记录。
2. 【脚本】盘点日账面应有金额 = 上一日账面余额 + 未记账传票收入 − 未记账传票付出。
3. 【人工】按面额清点实存现金（人民币/外币分列），监盘人/出纳/主管会计签字。
4. 【脚本】差异 = 应有 − 实存；差异追查原因记录。
5. 【脚本】非报表日监盘倒推：报表日应有余额 = 盘点日应有 + 报表日至盘点日付出 − 收入；与报表日账面核对。
6. 结果写入 Z-1-1-02（检查核对记录区 + 面额盘点区 + 差异分析 + 倒推区），同步修订记录。

## 质量门

- 勾稽链完整：账面→应有→实存→差异→倒推报表日；
- 差异 100% 有原因与处理结论；监盘人员签字齐全。

## 升级路径

- 差异超阈值且无法解释 → 升级 Z-1 助理并激活 P03 扩大抽查；疑似白条抵库/账外现金 → 升级项目经理。
