# P04 日常余额合理性分析

> 来源：Z1001 程序4（余额合理性）+ 分析程序1（现金交易比例分析）｜认定：E、C、A｜产出：Z-1-1-04 库存现金余额合理性分析表

## 输入

- 各月库存现金余额（或日记账月度数据）
- 现金交易比例数据（现金收支占收支总额比例，如适用）
- 业务循环相关报表项目审计结果（联动）

## Steps

1. 【脚本】月度余额趋势分析：均值/峰值/波动，标注超常月份；与业务规模比较判断合理性。
2. 【规则】关注大额未缴存库存现金：日记账收现后久未解缴银行的记录（收现日期与缴存日期间隔超阈值）。
3. 【脚本】现金交易比例分析（分析程序1）：现金交易比例较高时，结合生产/采购/销售/工薪循环审计结果，分析评价现金交易合理性，输出与各循环的联动索引。
4. 结果写入 Z-1-1-04（发生额分析区 + 余额趋势区 + 结论），同步修订记录。

## 质量门

- 分析区间覆盖全年；异常月份/大额未缴存 100% 有调查记录；现金比例分析的联动索引完整。

## 升级路径

- 大额未缴存现金或现金比例异常 → 激活 P03 关注相关收支；升级 Z-1 助理评估库存现金坐支/白条风险。
