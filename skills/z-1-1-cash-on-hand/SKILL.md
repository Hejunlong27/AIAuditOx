## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 存在性（E）：库存现金于资产负债表日实存；完整性（C）：均已记录；准确性/计价（A/V）：金额正确、外币折算正确；列报（P）：披露恰当 |
| 所需资料 | 库存现金日记账、总账（1001）、现金盘点计划与盘点表、资产负债表日即期汇率（外币现金）、大额收支原始单据、财务报表附注 |
| 所需数据 | 各币种日记账余额、盘点金额（按面额）、盘点日至资产负债表日收支、大额收支明细（日期/凭证/对方/金额/摘要）、现金交易比例（如适用） |
| 核对逻辑 | ① 日记账↔总账核对+外币重新折算；② 监盘：盘点实存 vs 账面应有（含未记账传票调整），非报表日监盘倒推至报表日；③ 大额收支核对原始单据（收付款方/金额/合同/订单/出入库单一致）；④ 日常余额合理性+大额未缴存关注；⑤ 附注披露核对 |
| 底稿编制内容 | 见「产出清单」，全部底稿采用 auditox-wp-standard 四段式制式 |
| 输出格式 | xlsx 工作簿（模板见 templates/Z-1-1库存现金审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已指定（未指定拒绝启动）；在 `02_工作底稿/Z-1-1库存现金/` 下基于模板创建工作簿副本。
2. 校验输入：库存现金日记账、总账必输；缺失列明缺口挂起。
3. 分派顺序：P01 → （P02 与 P03/P04 可并行）→ P05；P02 为人工主导（监盘），技能负责台账、倒推计算与差异记录。
4. 副本先行 + 修订记录伴随（每次生成/修订同步登记）。
5. 异常激活：P02 盘点差异超阈值且无法解释 → 升级助理并扩大 P03 抽查；P04 发现大额未缴存现金或现金比例异常 → 激活 P03 关注相关收支；P03 发现收付款方与合同/订单不一致 → 升级项目经理。
6. 汇总产出执行一级复核（完整性/勾稽/证据/异常闭环/制式合规五项），通过后提交人工二级复核。

## 一级复核清单（独立于编制上下文）

- P01~P05 均有底稿或「不适用+理由」；索引号连续；
- 日记账合计=总账数=审定数；监盘倒推至报表日金额勾稽 P01；
- 盘点差异、大额异常均有处理记录；外币折算正确；
- 四段式制式完整、七要素齐全、修订记录同步。

## 边界与禁止事项

- 仅项目工作目录内操作；禁止物理删除、外发数据；禁止代替人工执行监盘动作（技能仅做计算与记录）；
- 数字核对脚本精确匹配，禁止模型估算；差异说明可模型起草但标注「待人工确认」。

## Pitfalls

- 非资产负债表日监盘必须倒推（+报表日至盘点日付出 − 收入），遗漏倒推是常见错误；
- 未记账传票收入/付出须先调整出「盘点日账面应有金额」再比较；
- 外币现金按报表日即期汇率重折算，与账面差异须调整；
- 现金交易比例高的企业，须结合业务循环审计结果分析现金交易合理性（分析程序1）。

## Verification

- 工作簿公式重算无错误；监盘表勾稽链完整（账面→应有→实存→差异→倒推报表日）；
- 每张底稿四段式完整、修订记录对应。
