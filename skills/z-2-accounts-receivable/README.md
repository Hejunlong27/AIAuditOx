## 程序库映射完整性

《审计程序库——Z1122应收账款》共 7 项实质性分析程序 + 12 项其他实质性程序，全部映射：分析1→P02；分析2、3、4→P02；分析5、7→P03；分析6（期中账龄比较）→P06 备注项；程序1→P01；程序2→P04；程序3、8→P05；程序4、5→P06；程序6→P07；程序7→P03；程序9→P08；程序10、11→P09；程序12→P10。

## 模板要点（含公式）

| 表 | 内置公式/机制 |
|----|-------------|
| Z-2-01 明细表 | 本位币=原币×汇率；合计加总；贷方余额/关联方标注列 |
| Z-2-02 分析程序 | 差异=IF(实际-预期)；超阈值判定=IF(ABS(差异)>阈值,"超阈值，需调查","范围内")；月度滚动余额=期初+增加-回笼 |
| Z-2-03 坏账复核 | 应有坏账=账龄段余额×计提比例；差异=应有-账面；合计勾稽；逾期样本四要素评价区 |
| Z-2-05 函证 | 回函差异=IF(回函-账面)；回函状态下拉；中期前推=发函日余额+销售-收款-核销 |
| Z-2-09 截止期后 | 归属期间/是否跨期下拉；期后未支付余额=IF(期末余额-期后收款) |

## 使用方式

对话触发：「执行 Z1122 应收账款审计程序」「编制应收账款底稿」。技能按 SKILL.md 调度：工作目录门禁 → 资料校验 → P01 →（P02、P03 并行）→ P04 → P05（强制函证）→ P06 →（P07/P08/P09）→ P10 → 一级复核。

## 制式遵循

强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录）。
