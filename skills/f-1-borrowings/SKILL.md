# F-1 借款技能组（助理级主技能）

> **【技能来源与使用声明】**
> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。
> **作者与许可**：何小疯27 · 免费开源 · 禁止商用转售
> **技能主页**：aiauditox.l.cd ｜ **开发动态**：公众号‘小小审计员日记’
> **使用声明**：本技能输出内容仅供学习与工作参考，不构成任何审计意见或专业建议；请勿将客户敏感数据用于公开的 AI 服务。

> 技能库分组：负债类 F → F-1 借款（对应所内科目 2001 借款合并口径，含短期/长期 / 程序库 F2001）
> 角色：本技能由「F-1 借款助理」持有并调度，程序卡 P01~P09 由实习生级执行，一级复核由助理执行（编制-复核分离）。
> 程序来源：《审计程序库——F2001借款》（立信技术标准部 2022/10 版）。利息重算与限制条款违约检查为本科目两大确定性重算点。
> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：借款全部入账（银行回函要求列示所有贷款）；存在性（E）：真实负债；准确性/计价（A/V）：利息与摊余成本计算正确；列报（P）：限制条款/违约/抵押/重组披露 |
| 所需资料 | 借款清单与借款合同、银行询证函回函、企业信用报告、银行对账单（期前后）、董事会决议（新融资/条款修改）、抵押资产权证、债务重组协议、财务报表附注 |
| 所需数据 | 分笔借款：贷款行、金额、起止日、利率、付息方式、抵押/担保；本期新增与归还明细；利息计提记录；摊余成本计算表（如有折溢价）；限制条款指标值 |
| 核对逻辑 | ① 清单加计↔总账/报表核对+外币折算+银行回函逐笔核对（完整性）+调节表；② 余额预期（融资政策/上期/预算）；③ 利息重算=本金×利率×期限；④ 摊余成本重算（实际利率法）；⑤ 限制条款重计算与违约检查（持续经营联动）；⑥ 增减变动与现金流量表勾稽；⑦ 新融资授权与条款核对；⑧ 合同条款修改（CAS 22 终止确认判断）；⑨ 抵押资产与债务重组；⑩ 企业信用报告核对（含对外担保信息）；⑪ 披露 |
| 底稿编制内容 | 见「产出清单」，全部底稿采用 auditox-wp-standard 四段式制式 |
| 输出格式 | xlsx 工作簿（模板见 templates/F-1借款审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已指定；基于模板在 `02_工作底稿/F-1借款/` 创建工作簿副本。
2. 校验输入：借款清单、借款合同、银行询证函回函必输；缺失列明缺口挂起。
3. 分派顺序：P01 → P02 → P03（函证，联动 Z-1-2 银行函证）→ （P04、P05 并行）→ P06 → （P07、P08 视情况）→ P09。
4. 副本先行 + 修订记录伴随。
5. 异常激活：P01 清单与回函差异（回函多出借款）→ 完整性缺口，升级项目经理；P04 利息差异超阈值 → 提请调整（联动 F-8 应付利息/S-4 财务费用）；P05 限制条款违约 → 升级项目经理并联动 A-6 持续经营与披露；P08 信用报告显示账外借款或大额对外担保 → 升级（联动 A-7 或有事项）；P07 条款修改终止确认判断复杂 → 升级技术部门。
6. 汇总执行一级复核，通过后提交人工二级复核。

## 一级复核清单

- P01~P09 均有底稿或「不适用+理由」；清单加计=总账数=报表数；
- 回函覆盖全部借款（未函证项有批准理由）；清单与回函差异 100% 有调节表与解释；
- 利息/摊余成本重算无误；限制条款指标重算齐备、违约事项披露闭环；
- 信用报告差异分析（含对外担保）有结论；四段式制式完整、修订记录同步。

## 边界与禁止事项

- 仅项目工作目录内操作；禁止物理删除、外发数据；禁止代替人工执行函证寄发；
- 利息与摊余成本重算用脚本精确计算；终止确认判断与违约定性的结论须人工（标注「待人工确认」）。

## Pitfalls

- 银行询证函必须要求银行列示所有贷款——这是借款完整性的关键证据，回函金额比清单多出的就是账外借款线索；
- 借款的完整性风险高于存在性：账外借款常经股东/关联方账户流转，信用报告核对是重要兜底；
- 限制条款（资产负债率/净资产等财务指标）违约即使获银行豁免也须披露，且评估对持续经营的影响；
- 摊余成本借款（折溢价/发行费用）的利息不能按票面利率简单计算，须实际利率法重算；
- 新增借款须确认金额计入现金流量表筹资活动（与 Z-1-2 银行流水勾稽）。

## Verification

- 工作簿公式重算无错误（利息=本金×利率×期限、摊余成本滚动表）；
- 回函核对区与调节表齐备；条款指标重算有依据；每张底稿四段式完整、修订记录对应。
