## 模板要点（含公式）

F-1-01 明细表：回函差异 IF 公式 + 回函双向核对区（回函多出借款=账外借款线索升级）；F-1-03：利息重算 = 本金×利率×天数/360 + 摊余成本滚动区；F-1-04：限制条款指标重算（合同要求值 vs 期末实际值）。
