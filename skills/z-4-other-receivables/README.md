## 程序库映射完整性

Z1221 共 1 项实质性分析程序 + 6 项其他实质性程序，全部映射：分析1→P03；程序1→P01；程序2→P02；程序3→P04；程序4→P05；程序5（11 项子程序）→P06；程序6→P07。

## 模板要点（含公式）

| 表 | 内置公式/机制 |
|----|-------------|
| Z-4-01 明细表 | 本位币=原币；合计加总；期后收款列合计；款项性质/关联方/贷方余额标注 |
| Z-4-02 特殊项目 | 五类迹象下拉打标（关联占用/变相拆借/隐形投资/误用科目/或有损失）+ 多科目双挂账交叉区 |
| Z-4-03 分析程序 | 差异+超阈值 IF 判定 |
| Z-4-04 函证 | 回函差异 IF；回函状态下拉；调节项目细节确认列 |
| Z-4-05 账龄 | 分布占比公式 + 账龄表更新确认行 + 抽样测试区 |
| Z-4-06 坏账复核 | 账龄分段测算+个别认定区（比例可自定义）+ 计提勾稽减值损失 + 核销五要素检查区 |

## 跨科目联动

- 关联方占用 → A-5 关联方技能（监管红线，强制升级）；
- 双挂账 → Z-2 应收账款 / F-10 其他应付款 / Z-3 预付账款；
- 坏账体系 → Z-2 坏账准备模式复用；
- 核销税务手续 → F-7 应交税费（未获批调整应纳税所得额）；
- 期后收款核对 → Z-1 货币资金组。

## 制式遵循

强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录）。
