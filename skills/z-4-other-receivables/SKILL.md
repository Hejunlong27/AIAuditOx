# Z-4 其他应收款技能组（助理级主技能）

> **【技能来源与使用声明】**
> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。
> **作者与许可**：何小疯27 · 免费开源 · 禁止商用转售
> **技能主页**：aiauditox.l.cd ｜ **开发动态**：公众号‘小小审计员日记’
> **使用声明**：本技能输出内容仅供学习与工作参考，不构成任何审计意见或专业建议；请勿将客户敏感数据用于公开的 AI 服务。

> 技能库分组：资产类 Z → Z-4 其他应收款（对应所内科目编号 1221 / 程序库 Z1221）
> 角色：本技能由「Z-4 其他应收款助理」持有并调度，程序卡 P01~P07 由实习生级执行，一级复核由助理执行（编制-复核分离）。
> 程序来源：《审计程序库——Z1221其他应收款》（立信技术标准部 2022/10 版，编号 Z1221）。
> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 存在性（E）：真实存在、归属被审计单位；完整性（C）：均已记录；准确性/计价（A/V）：金额准确、坏账准备充分（关联方占用与长期挂账的可收回性）；列报（P）：坏账政策、关联方款项披露恰当 |
| 所需资料 | 其他应收款明细账（按款项性质/对象）、应收账款与其他应付款明细账（双挂账排查）、账龄分析表、坏账准备计算表、函证回函、期后收款记录、董事会批准的坏账政策、税务审批文件（核销）、财务报表附注 |
| 所需数据 | 分对象期末余额、款项性质分类（往来/备用金/保证金/代垫款等）、账龄分布、坏账准备余额与计提比例、期后收款额、关联方身份标注 |
| 核对逻辑 | ① 明细加计↔总账/报表核对；② 特殊项目检查：关联企业/实际控制人资金占用、变相拆借、隐形投资、误用科目、或有损失迹象；与应收账款/其他应付款双挂账排查；③ 余额预期比较（超阈值调查）；④ 函证+期后收款/发货证据替代；⑤ 账龄划分测试；⑥ 坏账准备 11 项子程序（政策复核/计提勾稽减值损失/账龄跟进/个别认定/核销批准与税务/关联方核销披露/重新收回处理）；⑦ 披露核对 |
| 底稿编制内容 | 见「产出清单」，全部底稿采用 auditox-wp-standard 四段式制式 |
| 输出格式 | xlsx 工作簿（模板见 templates/Z-4其他应收款审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已指定（未指定拒绝启动）；基于模板在 `02_工作底稿/Z-4其他应收款/` 创建工作簿副本。
2. 校验输入：其他应收款明细账、坏账准备计算表必输；应收账款/其他应付款明细账（P02 双挂账）缺失列明缺口挂起。
3. 分派顺序：P01 → （P02、P03 并行）→ P04（人工为主）→ P05 → P06 → P07。
4. 副本先行 + 修订记录伴随。
5. 异常激活：P02 发现关联方大额占用/变相拆借迹象 → 立即升级项目经理并联动 A-5 关联方技能与披露检查；P02 双挂账 → 联动 Z-2 应收账款/F-10 其他应付款技能；P06 坏账测算差异超阈值 → 联动 P05 账龄复核；P04 未回函 → 期后收款核对（联动 Z-1 组），仍未清偿 → 与发货证据核对；P06 核销涉及关联方 → 联动 P07 披露。
6. 汇总执行一级复核（完整性/勾稽/证据/异常闭环/制式合规），通过后提交人工二级复核。

## 一级复核清单（独立于编制上下文）

- P01~P07 均有底稿或「不适用+理由」；索引号连续；
- 明细合计=总账数=报表数；款项性质分类完整，关联方项目全部标注；
- 双挂账排查、贷方余额重分类有结论；函证替代程序闭环；
- 坏账准备：计提数与资产减值损失明细勾稽、政策与上年一致、个别认定有还款能力证据、核销批准与税务手续齐备、关联方核销已披露；
- 四段式制式完整、七要素齐全、修订记录同步。

## 边界与禁止事项

- 仅项目工作目录内操作；禁止物理删除、外发数据；禁止代替人工执行函证寄发；
- 数字核对脚本精确匹配；坏账计提充分性与关联方占用定性结论须人工（标注「待人工确认」）；
- 涉及关联方资金占用的迹象发现后，不得仅作底稿记录，必须升级项目经理（监管红线事项）。

## Pitfalls

- 其他应收款是关联方资金占用最常见的藏身处：单笔大额、长期不动、对手为关联方/个人/非经营性主体是典型特征，程序2(1) 必须逐项做性质分析；
- 双挂账排查方向是三向的：应收账款、其他应付款、预付账款都可能与其他应收款重复挂账；
- 坏账计提数须与资产减值损失（或信用减值损失）明细发生额双向勾稽，只看余额表会漏；
- 核销坏账的税务审批手续是程序5(8)(9)的硬性要求，未获批须调整应纳税所得额；
- 账龄分析表要求被审计单位按资产负债表日后收款情况更新后再测试。

## Verification

- 工作簿公式重算无错误；坏账计提测算表与账龄分布、减值损失明细三方勾稽；
- 每张底稿四段式完整、修订记录对应。
