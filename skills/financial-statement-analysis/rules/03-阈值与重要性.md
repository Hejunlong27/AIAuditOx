# 阈值与重要性

## 重要性水平

优先由使用人提供。未提供时按下表测算，并以**税前利润为建议基准**，其余基准供参考。建议值一律标记"待人工确认"：

| 基准 | 比例 | 适用情形 |
| --- | --- | --- |
| 税前利润（利润总额） | 5% | 营利性企业常用基准（首选） |
| 营业收入 | 0.5% | 收入规模大或利润波动大时使用 |
| 资产总计 | 0.5% | 资产规模大或重资产行业使用 |

税前利润为零或为负时，程序自动退到营业收入、资产总计。非营利组织、亏损企业等特殊情形需自行调整基准。程序不替使用人决定重要性水平。

## 可容忍差异

`可容忍差异 = max(重要性水平 × 50%, |期望值| × 容差率)`

容差率：

| 科目性质 | 容差率 | 理由 |
| --- | --- | --- |
| 收入 | 5% | 收入确认为舞弊与错报高风险区 |
| 成本 | 5% | 与收入配比，异常需解释 |
| 费用 | 8% | 波动性相对较高 |
| 资产负债类 | 10% | 存量科目，年度间正常波动较大 |

## 异常分级

| 等级 | 判定 |
| --- | --- |
| L1 提示 | `50% × 可容忍差异 < |差异| ≤ 可容忍差异` |
| L2 需解释 | `可容忍差异 < |差异| < 重要性水平` |
| L3 高风险 | `|差异| ≥ 重要性水平`，或方向指向高估资产/利润且超可容忍差异 |

### 模型置信度对分级的影响

期望值模型的驱动关系有强弱之分。使用资产总计增长率等**低置信度**驱动关系的项目（如货币资金、其他应收款），其结果等级封顶为 L2，并在备注中说明。低置信度模型只作方向提示，不足以支撑高风险定级。

## 变动率阈值

用于两年对比的初筛，仅用于决定是否进入人工关注范围，不作为结论：

| 报表 | 变动率阈值 |
| --- | --- |
| 资产负债表 | 30% |
| 利润表 | 20% |
| 现金流量表 | 30% |

同时要求变动绝对额达到 `重要性水平 × 10%`，避免小额科目的百分比噪声。变动率绝对值超过阈值且变动额达标时才列为关注项。

## 结构分析阈值

项目占总计比重（资产负债表按资产总计、利润表按营业收入）的变动超过 **3 个百分点**，且金额变动达到 `重要性水平 × 10%`，列为关注项。

## 跨科目一致性检查阈值

| 检查项 | 触发条件 |
| --- | --- |
| 收入与应收账款背离 | 应收账款增长率 − 收入增长率 > 20 个百分点 |
| 利润与经营现金流背离 | 净利润增长率 − 经营现金流净额增长率 > 30 个百分点 |
| 毛利率异常变动 | 毛利率变动 > 3 个百分点 |
| 存货与收入背离 | 存货增长率 − 收入增长率 > 20 个百分点 |
| 其他应收款异常增长 | 增幅 > 50% 且金额达到重要性水平 |
| 偿债能力恶化 | 资产负债率上升 > 10 个百分点 |
| 盈利质量不足 | 净利润 > 0 且 净利润现金含量 < 0.5 |
| 回款质量不足 | 收现比 < 0.9 |
| 回款周期恶化 | 应收账款周转天数增幅 > 30% |

## 变动的方向口径

对资产负债表与利润表项目，判断差异方向时统一按"是否倾向于增加资产或利润"标注：增加记为正向，减少记为负向。该标注帮助使用人判断高估或低估风险，本身不是结论。
