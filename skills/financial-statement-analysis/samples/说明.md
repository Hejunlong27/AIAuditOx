# 样例数据说明

`示例-四张报表.xlsx` 由 `scripts/make_sample.py` 生成，是一家虚构制造业公司（示例制造有限公司）2025 年度与 2024 年度的四张报表。所有数据均为编造，与任何真实主体无关。

## 样例中刻意埋入的现象

用于验证程序能否识别，也便于你对照检查输出结果：

| 现象 | 数据表现 | 程序应有的反应 |
| --- | --- | --- |
| 利润大幅增长 | 净利润由 10,740,000 增至 20,700,000（+92.7%） | 两年对比提示，纳入成长性分析 |
| 应收账款增长快于收入 | 应收账款 +59.6%，收入 +30.0% | 一致性检查"收入与应收账款背离"触发；期望值模型测算应收账款高于期望值 |
| 毛利率上升 | 由 30.00% 升至 33.97% | 一致性检查"毛利率异常变动"触发 |
| 成本低于配比测算 | 期望成本 109,200,000，实际 103,000,000 | 期望值模型识别为高风险差异 |
| 其他应收款异常增长 | 由 2,400,000 增至 6,800,000（+183%） | 一致性检查与期望值模型同时关注，指向资金占用 |
| 盈利质量下降 | 净利润增长 92.7%，经营现金流由 20,000,000 降至 13,500,000 | 一致性检查"利润与经营现金流背离"触发 |
| 回款质量不足 | 收现比 0.88，低于 0.90 | 一致性检查"回款质量不足"触发 |
| 未映射项目 | 所有者权益变动表的"一、上年年末余额""三、本年增减变动金额" | 列入未映射清单，由人工确认，不做猜测 |

## 已知的勾稽关系

样例数据已保证下列关系成立，可用于验证程序的数据校验功能没有误报：资产总计 = 负债和所有者权益总计；期末现金 = 期初现金 + 净增加额；权益变动表年末余额 = 年初余额 + 综合收益总额 − 利润分配；权益变动表净利润 = 利润表净利润。

## 换成真实数据

把你的报表整理成与样例相同的布局即可：每个工作表第一行放编制单位与单位说明，第二行放表头（项目列 + 本期/上期金额列），之后逐行放数据。程序会自动识别单位、表头与科目名称，识别不了的项目会列出来而不是丢弃。
