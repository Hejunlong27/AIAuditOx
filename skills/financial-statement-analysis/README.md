# 财务报表分析程序

面向会计师事务所审计人员的分析性程序底稿生成器。输入四张报表的本期与上期数据，输出可复算、可追溯的分析底稿。

## 快速开始

```bash
python scripts/make_sample.py
python scripts/run_analysis.py --input samples/示例-四张报表.xlsx --outdir output --entity "示例有限公司" --period "2025年度" --materiality 500000
```

输出在 `output/` 下：Excel 分析工作簿、Word 分析底稿草稿、异常清单 CSV、运行日志。

`output/` 里已放了一份用样例数据跑出来的结果，可直接打开查看底稿长什么样；样例数据埋入的现象与预期结果见 `samples/说明.md`。

## 输出格式（固定制式）

每次运行的版式完全一致，只有内容随输入变化。

Excel 分析工作簿按事务所底稿制式（四段式）输出，共 11 张表，页签以索引号命名：`A-9-01 说明与参数`、`A-9-02 数据校验`、`A-9-03 结构分析`、`A-9-04 两年对比`、`A-9-05 比率分析`、`A-9-06 期望值模型`、`A-9-07 一致性检查`、`A-9-08 异常汇总`、`A-9-09 未映射清单`、`A-9-10 行业对比（待填）`、`A-9-11 图表`。每张表为"标题／副标题 + 一、项目基本信息 + 二、审计目标和程序说明 + 三、审计程序执行结果 + 四、审计说明"结构；全表宋体，节标题 12pt 加粗带 `E8E8E8` 底纹，表头 10pt 加粗带 `D9D9D9` 底纹，金额 `#,##0.00`、百分比 `0.00%`；可计算的列写入 Excel 公式不硬编码；A4 横向打印、跨页重复标题行与前两列。运行同时生成同路径的《-修订记录.md》。

Word 分析底稿为 A4 纵向、固定十个章节：项目基本信息、分析目的与依据、数据来源与口径说明、执行的程序、数据校验结果、主要财务比率、异常事项汇总、待向被审计单位询问的问题、分析结论（留空）、复核记录。

## 运行测试

```bash
python -m pytest tests -q
```

## 目录说明

| 路径 | 说明 |
| --- | --- |
| `SKILL.md` | 方法论、适用范围、专业规则、质检清单 |
| `rules/` | 指标定义、阈值口径、科目映射、成因库、建议程序库（人工可读） |
| `scripts/fs_analysis/` | 分析引擎源码 |
| `scripts/run_analysis.py` | 命令行入口 |
| `scripts/make_sample.py` | 生成脱敏样例数据 |
| `samples/` | 样例数据与样例输出 |
| `tests/` | 自动化测试 |

## 数据安全

程序只在本机读取与写出文件，不联网、不上传任何数据。请在脱敏数据上验证流程后再用于真实项目。
