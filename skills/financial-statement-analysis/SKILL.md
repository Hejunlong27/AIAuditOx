# 财务报表分析程序

> **【技能来源与使用声明】**
> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。
> **作者与许可**：何小疯27 · 免费开源 · 禁止商用转售
> **技能主页**：aiauditox.l.cd ｜ **开发动态**：公众号‘小小审计员日记’
> **使用声明**：本技能输出内容仅供学习与工作参考，不构成任何审计意见或专业建议；请勿将客户敏感数据用于公开的 AI 服务。

## 使命

把审计准则要求执行的分析程序，从"算一堆比率、写一句无重大异常"变成一份可复算、可追溯、带异常线索和建议程序的分析底稿。

使用者是执行财务报表审计的审计人员。本 Skill 负责计算、比对、找差异、给线索；**结论、定性和审计意见始终由签字人作出**。

## 适用范围

适用：

- 已取得被审计单位已定稿的四张报表（资产负债表、利润表、现金流量表、所有者权益变动表），且至少包含本期与上期两期数据。
- 需要形成风险评估阶段的分析程序底稿，或期末总体分析性复核底稿。
- 需要快速定位异常科目、编制待询问客户问题清单。

不适用：

- 编制、重编或调整财务报表本身。
- 替代函证、监盘、抽样检查等实质性程序。
- 合并报表抵销、合并范围判断。
- 审计意见类型判断、舞弊定性。
- 只有科目余额表但没有成表报表的场景（需要先转换格式，见"输入格式"）。

## 输入格式

主输入为一个 Excel 文件，包含按标准报表格式排列的四张表，工作表名称可识别（如"资产负债表"）。每张表的表头需包含项目列与两期金额列，列名中带"本期/期末/年末/本年"与"上期/期初/年初/上年"字样。

运行 `python scripts/make_sample.py` 可生成一份符合格式的脱敏样例，建议先用样例验证流程再换成真实数据。

必须提供或确认的参数：

| 参数 | 说明 | 缺省处理 |
| --- | --- | --- |
| 重要性水平 | 整体重要性水平（元） | 未提供时按税前利润 5% / 资产总计 0.5% / 营业收入 0.5% 测算并给出建议值，标记"待人工确认" |
| 期间标签 | 如"2025 年度" | 取默认值并提示 |
| 被审计单位名称 | 底稿抬头 | 留空待填 |
| 可容忍差异比例 | 默认重要性水平的 50% | 使用默认值 |

输入质量要求：金额单位一致（会自动识别"单位：元/千元/万元"并统一换算为元）；两期科目名称可比；报表内部勾稽成立。不满足时程序会记录在"数据校验"页，不中断运行。

## 工作方法

按顺序执行，每一步的结果都落到输出文件：

1. **加载与映射**：识别四张表、定位表头、解析项目与两期金额、按别名表映射到标准项目，未识别的项目全部记录，不做静默丢弃。
2. **数据校验**：勾稽关系、期间完整性、零分母与负值、映射缺失率。差异超出容忍额时标注"注意"或"不符"。
3. **结构分析**：各项目占总额（资产负债表按资产总计、利润表按营业收入）的比重及两期变动（百分点）。
4. **两年对比**：同比变动额、变动率；上期为零或为负时变动率不适用并明确标注。
5. **比率分析**：偿债、营运、盈利、现金流质量、成长性五组比率，加杜邦分解。周转率使用两期平均余额。每项比率给出本期、上期、变动与方向判断。
6. **期望值模型**：按驱动关系测算"应该有多少"，而非只看变动率。收入与成本配比、费用率配比、资产负债表科目按业务量驱动测算；差异与可容忍差异比较。
7. **跨科目一致性检查**：识别互相矛盾的现象，如收入增长而应收账款增长更快、净利润增长而经营现金流下降、毛利率异常变动等。
8. **异常分级与汇总**：合并所有异常，按 L1/L2/L3 分级，附可能成因与建议程序。
9. **出报告**：Excel 分析工作簿、Word 分析底稿草稿、异常清单 CSV、运行日志。

## 专业规则

### 异常分级口径

分级表示关注强度，不是审计结论。

| 等级 | 判定 | 处理含义 |
| --- | --- | --- |
| L1 提示 | 差异介于可容忍差异的 50% 与 100% 之间 | 记录即可，可结合其他证据 |
| L2 需解释 | 差异超过可容忍差异但未达重要性水平 | 需向客户询问并取得解释 |
| L3 高风险 | 差异达到或超过重要性水平，或方向明显指向高估资产/利润 | 需扩大程序、取得支持性证据 |

### 可容忍差异

`可容忍差异 = max(重要性水平 × 比例, |期望值| × 容差率)`

容差率按科目性质区分：收入与成本 5%，费用 8%，资产负债类 10%。收入类科目的容差更紧，因为收入确认是舞弊与错报的高风险区域。

### 变动率的适用条件

上期金额为零或为负时，变动率在数学上不成立或无意义，一律标记"变动率不适用"，改用绝对额变动与重要性水平比较。不要输出会误导的百分比。

### 两年期的能力边界

只有两期数据时，不具备做时间序列统计离群（波动率、回归残差）的条件。本版本用变动率法、结构变动法和跨科目一致性检查替代，并在底稿中说明这一限制。若客户提供分月或分季度数据，可另行扩展。

### 事实与推测分离

底稿中，"本期金额""差异额""差异率"是事实；"可能成因""建议程序"是线索与建议，必须分列在不同栏位。"人工结论"栏一律留空。

## 输出结构

Excel 分析工作簿：

| 页签 | 内容 |
| --- | --- |
| 说明与参数 | 输入文件、期间、单位、重要性水平、阈值、运行时间与版本 |
| 数据校验 | 勾稽检查、边界情况、未映射项目 |
| 结构分析 | 各项目占总计比重及两期变动 |
| 两年对比 | 变动额与变动率 |
| 比率分析 | 五组比率与杜邦分解 |
| 期望值模型 | 期望值、差异、可容忍差异、分级 |
| 一致性检查 | 跨科目矛盾现象 |
| 异常汇总 | 全部异常按等级排序，含成因、建议程序、人工结论栏 |
| 行业对比（待填） | 预留行业中位数与四分位列，由使用人填列 |
| 图表 | 关键项目两期对比图 |

Word 分析底稿：项目信息表、分析目的与依据、数据来源与口径说明、执行程序清单、数据校验结果、主要比率、异常事项汇总表、待向客户询问的问题清单、分析结论（留空）、复核记录。

另外输出异常清单 CSV 与运行日志 TXT。

### 固定制式约定（每次输出一致，不随项目变化）

**Excel 分析工作簿**严格对齐事务所底稿制式（AuditOx 四段式），每次输出格式完全一致：

- **索引号与页签命名**：索引号为 `A-9-nn`（A＝通用辅助类，9＝报表分析），工作表名＝`索引号 + 空格 + 底稿名称`，共 11 张表，顺序固定为：`A-9-01 说明与参数`、`A-9-02 数据校验`、`A-9-03 结构分析`、`A-9-04 两年对比`、`A-9-05 比率分析`、`A-9-06 期望值模型`、`A-9-07 一致性检查`、`A-9-08 异常汇总`、`A-9-09 未映射清单`、`A-9-10 行业对比（待填）`、`A-9-11 图表`。
- **四段式结构**：每张底稿表固定为——标题（宋体 16pt 加粗居中）与副标题（9pt 灰字）；`一、项目基本信息`（被审计单位、审计期间、索引号、编制人、编制日期、审核人、审核日期七要素）；`二、审计目标和程序说明`；`三、审计程序执行结果`（数据表）；`四、审计说明`（编号说明 + 编制/审核签字行 + 修订记录伴随声明）。
- **字体与填充**：全表宋体；节标题 12pt 加粗、`E8E8E8` 底纹；表头 10pt 加粗、`D9D9D9` 底纹、居中换行；数据行 10pt，文本左对齐换行、数字右对齐。
- **数字格式**：金额 `#,##0.00`；百分比 `0.00%`；倍数/次数/天 `0.00`；占比变动单列"百分点"。
- **真公式**：可计算的列（差异、变动额、变动率、占比、占比变动、偏离程度等）写入 Excel 公式，不硬编码结果，打开时自动重算。
- **列宽**：按表内各列内容登记期望宽度并取最大值，最小 3 字符，保证金额列不出现 `####`。
- **打印设置**：A4 横向、按内容适配页宽（1～3 页宽）、跨页重复标题行与前两列、水平居中。
- **伴随文件**：每次运行同步生成《<工作簿名>-修订记录.md》，按版本登记修订内容。

**Word 分析底稿**（自建制式，A4 纵向，正文宽约 16.8cm，表格宽度不超过 15.9cm）固定十个章节，顺序为：`一、项目基本信息`、`二、分析目的与依据`、`三、数据来源与口径说明`、`四、执行的程序`、`五、数据校验结果`、`六、主要财务比率`、`七、异常事项汇总`、`八、待向被审计单位询问的问题`、`九、分析结论`（留空待填）、`十、复核记录`。节标题 12pt 加粗带底纹，表头 `D9D9D9` 底纹，表格行设置"允许跨页断行"关闭、表头跨页重复，页脚含页码域。

制式是固定的：同一版本每次运行输出的版式相同，只有内容随输入数据变化。如确需调整版式，应在 `scripts/fs_analysis/reports.py` 中统一样式常量，而不是逐次手改单个文件。

## 使用步骤

```bash
# 1. 生成脱敏样例（仅首次或需要验证流程时）
python scripts/make_sample.py

# 2. 正式运行
python scripts/run_analysis.py \
  --input samples/示例-四张报表.xlsx \
  --outdir output \
  --entity "XX有限公司" \
  --period "2025年度" \
  --materiality 500000

# 3. 不知道重要性水平时，先要建议值
python scripts/run_analysis.py --input samples/示例-四张报表.xlsx --outdir output --suggest-materiality
```

运行后先看"说明与参数"页确认单位与重要性水平，再看"数据校验"页确认没有未识别的科目，最后看"异常汇总"。

## 质量检查清单

出稿前逐项确认：

- 四张表全部被识别，未映射项目已逐条看过，不是静默丢弃。
- 金额单位识别正确，"万元"没有被当成"元"。
- 数据校验页的重大勾稽差异已查明原因。
- 随机抽取 10 个异常，手工复算差异额与差异率，结果一致。
- 每个异常都能追溯到具体报表、项目与期间。
- 上期为零或为负的项目，变动率列显示"不适用"而不是空白或错误百分比。
- 结论栏为空，没有代写结论；事实与推测分列。
- 行业对比页留空并标注数据来源由使用人填列。
- 底稿能直接并入现有工作底稿，不需要重新排版。

## 不确定时的处理

- 科目名称无法映射：不猜测，记入未映射清单，并在校验页提示"需人工确认对应关系"。
- 表头无法识别：报告失败原因并提示改用样例模板格式，不静默按位置乱猜。
- 重要性水平未提供：给出测算建议值，全部结果标注"基于建议重要性水平，待人工确认"。
- 关键项目缺失（如营业收入）：相关比率标记"无法计算 - 缺少 X"，不中断整体运行。

## 已知限制

本版本只支持两期对比。行业对比为空白模板，需人工填列。期望值模型依赖业务驱动关系，对被审计单位商业模式特殊、或科目口径发生变动的项目，测算结果只作参考并已标注置信度。程序不做舞弊定性，不判断审计意见类型。
