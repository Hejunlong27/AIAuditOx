# P04 预收账款披露检查

> 来源：F2203 程序库 其他5｜认定：P｜产出：F-8-04
> 执行方式：自动（schema 校验）+人工确认｜确定性工具：rule_check

## 输入

- 报表附注中预收账款或合同负债相关披露文本
- 预收账款明细表
- 合同负债与预收款项划分依据

## Steps

1. 【规则】审计预收账款的披露
   - 检查相关财务报表附注披露的准确性和完整性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 披露事项 | 文本 | 准则要求清单 | 枚举（分类/账龄/合同负债划分 等） |
| 附注披露内容 | 文本 | 报表附注 | 非空 |
| 是否完整 | 文本 | rule_check 校验 | 缺项标注「否」 |
| 与底稿一致性 | 文本 | 与明细表比对 | 枚举（一致/不符） |
| 说明 | 文本 | 人工填写 | 缺项或不符必有 |

## 质量门

- 准则要求的披露事项逐项核对，无遗漏
- 附注金额与底稿明细表金额一致
- 合同负债与预收款项的划分及披露符合准则

## 升级路径

- 披露缺项 → 升级项目经理，提请管理层补充披露
- 附注与底稿金额不符 → 退回 P01 核实后重新比对
