# P01 预收账款明细表编制与核对

> 来源：F2203 程序库 其他1｜认定：A、V｜产出：F-8-01
> 执行方式：自动（脚本核对）+人工确认｜确定性工具：recalc_check、balance_confirm、rule_check

## 输入

- 预收账款明细表（按客户）
- 总账 2203 余额及明细账合计数
- 销售合同（含预收条款）
- 应收账款明细（用于两方挂账检查）
- 上年审定数

## Steps

1. 【规则】获取或编制预收账款明细表：
   - （1）将期初余额与上年财务报表进行核对；
   - （2）复核加计是否正确，并与报表数、总账数和明细账合计数核对是否相符；
   - （3）确保会计政策得到一贯运用，或会计政策的变更得到正确处理、列报和披露;当存在对上年的调整时，确保相关分录已正确录入总账；
   - （4）检查是否存在借方余额，必要时进行重分类调整；
   - （5）结合应收账款等往来款项目的明细余额，检查是否存在应收、预收两方挂账的项目，必要时做出调整。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 客户名称 | 文本 | 明细表 | 非空 |
| 期初余额 | 金额 | 明细账 | 与上年审定数衔接 |
| 本期增加 | 金额 | 明细账贷方 | 与总账一致 |
| 本期减少 | 金额 | 明细账借方 | 与总账一致 |
| 期末余额 | 金额 | 期初 + 增加 − 减少 | = 期初 + 增 − 减 |
| 其中借方余额 | 金额 | 明细账 | 非空时须查明原因 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异或借方余额必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数（四方相符）
- 会计政策得到一贯运用，上年调整分录已正确录入总账
- 借方余额项目已查明原因并评估是否需重分类调整
- 已结合应收账款明细检查是否存在应收预收两方挂账

## 升级路径

- 借方余额无法解释或金额重大 → 升级项目经理，评估重分类调整
- 存在同一客户应收预收两方挂账 → 升级，评估是否需抵销列报及对收入的影响
