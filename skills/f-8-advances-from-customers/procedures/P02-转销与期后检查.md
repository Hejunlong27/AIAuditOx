# P02 转销与期后检查

> 来源：F2203 程序库 其他2、其他4｜认定：C、E、A｜产出：F-8-02
> 执行方式：自动（抽样+截止）+人工核对单据｜确定性工具：sampling_draw、cutoff_test

## 输入

- 销货合同与订单
- 仓库发货记录与货运单据
- 收款凭证
- 期末前后转销明细
- 记账凭证与销货发票
- 至审计时已转销款项清单

## Steps

1. 【规则】抽查预收账款有关的销货合同、仓库发货记录、货运单据和收款凭证，检查已实现销售的商品是否及时转销预收账款，确定预收账款期末余额的正确性和合理性。
2. 【规则】请被审计单位协助，在预收账款明细表上标出至审计时已转销的预收账款，对已转销金额较大的款项进行常规检查，如核对记账凭证、仓库发货单、销货发票等，并注意凭证发生日期及转销日期的合理性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 客户名称 | 文本 | 明细表 | 非空 |
| 合同号 | 文本 | 销货合同 | 非空 |
| 预收金额 | 金额 | 明细账 | 与总账一致 |
| 转销金额 | 金额 | 明细账借方 | 与凭证一致 |
| 发货日期 | 日期 | 仓库发货记录 | 非空 |
| 转销日期 | 日期 | 记账凭证 | 非空 |
| 转销期间合理性 | 文本 | 人工判断 | 枚举（合理/不合理） |
| 是否跨期 | 文本 | cutoff_test 判定 | 跨期时标注 |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 已实现销售的商品 100% 及时转销预收账款，无长期挂账未转销
- 转销日期不早于发货日期，转销金额与合同及发货金额一致
- 至审计时已转销的大额款项 100% 有常规检查记录（核对记账凭证、仓库发货单、销货发票）
- 记录选样依据，抽样可复现

## 升级路径

- 存在长期挂账未转销的预收账款 → 升级项目经理，评估是否应确认收入或存在退款义务
- 转销日期早于发货日期 → 升级，评估提前确认收入的风险
- 转销金额与合同不符 → 升级，联动收入确认程序核查
