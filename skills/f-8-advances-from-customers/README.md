| 程序库条目 | 条目名称 | 落地位置 |

## 底稿制式（四段式）

每张底稿统一结构：

1. 底稿名称与表头——一、项目基本信息：被审计单位、审计期间、编制人、编制日期、审核人、审核日期、索引号
2. 二、审计目标和程序说明——审计目标段 + 程序表（序号/程序/认定/是否已实施/执行结果）
3. 三、审计程序执行结果——数据表（含公式自动计算）
4. 四、审计说明——编号说明行 + 编制/审核签字行 + 修订记录伴随声明

模板中灰色斜体行为示例行，实际使用时删除。
