# S-1 营业收入技能组（助理级主技能）

> **【技能来源与使用声明】**
> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。
> **作者与许可**：何小疯27 · 免费开源 · 禁止商用转售
> **技能主页**：aiauditox.l.cd ｜ **开发动态**：公众号‘小小审计员日记’
> **使用声明**：本技能输出内容仅供学习与工作参考，不构成任何审计意见或专业建议；请勿将客户敏感数据用于公开的 AI 服务。

> 技能库分组：损益类 S → S-1 营业收入（对应所内科目 6001 主营业务收入 + 6051 其他业务收入 / 程序库 S6001 + S6051）
> 角色：本技能由「S-1 营业收入助理」持有并调度，程序卡 P01~P12 由实习生级执行，一级复核由助理执行（编制-复核分离）。
> 程序来源：《审计程序库——S6001主营业务收入》（2023/10 版，10 项分析程序 + 54 项实质性程序）+《审计程序库——S6051其他业务收入》（2022/10 版，7 项实质性程序）。
> **特别提示：收入存在推定的舞弊风险（准则假定），舞弊专项程序（P10）为必经环节，不可因控制测试结论良好而省略。**
> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 发生（E）：已记录收入真实发生（本科目核心认定，与资产负债表科目方向相反）；完整性（C）：收入无漏记（双向风险）；准确性（A）：金额与期间正确；计价（V）：可变对价/退款/返利等估计恰当；列报（P）：收入分解与政策披露 |
| 所需资料 | 收入明细账（按收入类别）、销售清单与销售增值税销项清单、销售合同及变更、发货日志/出库单/客户签收联、退货通知单与期后退货清单、经销商/代理商协议、出口报关单与货运提单、客户工商资料与走访记录、期后收款记录、非财务信息（产能/水电能耗/运输数量）、财务报表附注 |
| 所需数据 | 分收入类别发生额、毛利率（分产品线）、月度收入、销售折扣与折让、退货金额与比例、重要客户销售与回款、出口收入、合同履约进度（时段法适用时）、返利/折让估计 |
| 核对逻辑 | ① 明细加计↔总账/报表/销项清单核对；② 十项分析程序（毛利率/月度/上期比较/期末前后/折扣/退货/存货配比/费用率/非财务信息/行业市场）超阈值调查；③ 客户核查（名单变动/工商/股权穿透/走访/合同匹配）+货款回收测试（第三方回款）；④ 特殊模式评价（经销商/代理商/出口/委托代销/售后代管）；⑤ CAS 14 专项（五步法：合同识别/履约义务/交易价格/分摊/确认时点；政策衔接/合并合同/单独售价/时段进度/主要责任人/融资成分/合同变更）；⑥ 双向测试（凭证→支持文件、发货→收入）；⑦ 截止测试（发货/签收/确认三日期）；⑧ 退货退款（期后退回/准备金/退款负债重算）；⑨ 可变对价（限制/返利/折让）；⑩ 合同成本（增量成本资本化/履约成本/减值）；⑪ 现金收入舞弊（第三方回款/现金抵消/挪用）；⑫ 收入函证；⑬ 披露（含收入分解） |
| 底稿编制内容 | 见「产出清单」，全部底稿采用 auditox-wp-standard 四段式制式 |
| 输出格式 | xlsx 工作簿（模板见 templates/S-1营业收入审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已指定（未指定拒绝启动）；基于模板在 `02_工作底稿/S-1营业收入/` 创建工作簿副本。
2. 校验输入：收入明细账、销售合同样本、发货日志必输；销项税清单（P01）、非财务信息（P02）缺失列明缺口挂起。
3. 分派顺序：P01 → P02（分析先行定风险）→ （P03、P05、P06 并行）→ P07 → P08 → P10（舞弊必经）→ （P04、P09、P11 视业务模式启用）→ P11/P12。
4. 副本先行 + 修订记录伴随。
5. 异常激活（收入科目的高频触发链）：P02 毛利率/月度波动异常 → 激活 P06 扩样+P07 截止扩窗；P02 期末前后交易占比异常 → 激活 P07 加密期末样本；P03 第三方/员工/个人账户回款 → 立即升级项目经理（P10 舞弊专项）并联动 Z-2 应收账款；P02 退货率异动 → 激活 P08 期后退货复核；P07 跨期 → 升级评估管理层偏向；P05 发现政策与准则不符 → 升级技术部门；P04 经销商频繁进退/囤货迹象 → 升级项目经理（压货风险）。
6. 汇总执行一级复核（完整性/勾稽/证据/异常闭环/制式合规），通过后提交人工二级复核。

## 一级复核清单（独立于编制上下文）

- P01~P12 均有底稿或「不适用+理由」；索引号连续；
- 主营+其他业务收入合计与利润表「营业收入」勾稽；销项清单核对结论；
- P10 舞弊专项必经（不可「不适用」），现金收入三查（第三方回款/现金抵消/挪用）有记录；
- 截止测试双向执行；退货与期后退回勾稽；
- CAS 14 专项按业务模式覆盖（不适用项有理由）；
- 四段式制式完整、七要素齐全、修订记录同步。

## 边界与禁止事项

- 仅项目工作目录内操作；禁止物理删除、外发数据；禁止代替人工执行客户走访与海关函证；
- 数字核对脚本精确匹配；可变对价估计、退款负债、履约进度等会计估计结论须人工（标注「待人工确认」）；
- 发现舞弊迹象（第三方回款、期末突击销售、现金抵消）必须升级项目经理并保留证据链，不得自行删除或弱化记录。

## Pitfalls

- 收入认定的核心是「发生」而非「存在」——警惕多记收入（虚构、提前、压货），同时双向测试不可偏废（发货→收入查完整性）；
- 收入舞弊为准则推定风险，P10 不可省略；期末突击确认、期后大额冲回、经销商压货是三大典型信号；
- 五步法判断错误是一切收入错报之源：识别合同→识别履约义务→确定交易价格→分摊→确认收入，P05 逐层评价；
- 退货权利未完全转移风险报酬的，需按历史与行业数据测试退货准备金假设；
- 出口销售须核对报关单/提单/发票三单一致，注意汇率与期间配比；
- 新收入准则首次执行年关注衔接方法一致性（程序13）。
