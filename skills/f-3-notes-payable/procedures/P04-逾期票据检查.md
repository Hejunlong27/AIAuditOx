# P04 逾期未兑付票据检查

> 来源：F2201 程序4｜认定：E、A、V｜产出：F-3-04 逾期票据检查表

## Steps

1. 【脚本】逾期筛查：到期日晚于资产负债表日且未兑付的票据清单。
2. 【规则】逾期处理核查（硬规则，逐项判定）：
   - 逾期银行承兑汇票 → 是否已转入短期借款（联动 F-1）；
   - 逾期商业承兑汇票 → 是否已转入应付账款（联动 F-4）；
   - 带息票据 → 是否已停止计息（联动 P05）；
   - 是否存在抵押票据情形（披露联动 P06）。
3. 【规则】逾期原因查明记录。
4. 结果写入 F-3-04（逾期清单+转科目判定区），同步修订记录。

## 质量门

- 逾期票据 100% 有原因与转科目结论（未转提请调整，结论待人工确认）。

## 升级路径

- 大额逾期长期未转科目 → 升级 F-3 助理（负债性质掩盖）。
