# F-3 应付票据技能组（助理级主技能）

> **【技能来源与使用声明】**
> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。
> **作者与许可**：何小疯27 · 免费开源 · 禁止商用转售
> **技能主页**：aiauditox.l.cd ｜ **开发动态**：公众号‘小小审计员日记’
> **使用声明**：本技能输出内容仅供学习与工作参考，不构成任何审计意见或专业建议；请勿将客户敏感数据用于公开的 AI 服务。

> 技能库分组：负债类 F → F-3 应付票据（对应所内科目编号 2201 / 程序库 F2201）
> 角色：本技能由「F-3 应付票据助理」持有并调度，程序卡 P01~P06 由实习生级执行，一级复核由助理执行（编制-复核分离）。
> 程序来源：《审计程序库——F2201应付票据》（立信技术标准部 2022/10 版）。无分析程序。
> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：应付票据无漏记（期后偿付/贷款卡核对）；存在性（E）：真实交易支持；准确性/计价（A/V）：票面与利息计算正确、逾期转科目正确；列报（P）：种类/质押/到期未兑付披露 |
| 所需资料 | 应付票据明细账与备查簿、交易合同/发票/收货单、承兑保证金对账单（联动其他货币资金）、贷款卡（企业信用报告）信息、询证函回函、期后付款记录 |
| 所需数据 | 票据明细（种类/号数/出票日/到期日/票面金额/交易合同号/收款人/付款日期金额）、带息票据利率、保证金余额与比例、逾期票据清单 |
| 核对逻辑 | ① 明细加计↔总账/报表核对+备查簿逐要素核对+带息利息复核+外币折算；② 备查簿检查：交易真实性（合同发票收货单）、承兑保证金与其他货币资金勾稽、期后已偿付票据（查未入账）、注销票据资产负债表日前偿付确认、贷款卡信息三方核对；③ 函证+替代程序；④ 逾期未兑付：银行承兑→短期借款、商业承兑→应付账款、带息停息、抵押票据情形；⑤ 利息足额计提复核；⑥ 披露 |
| 底稿编制内容 | 见「产出清单」，全部底稿采用 auditox-wp-standard 四段式制式 |
| 输出格式 | xlsx 工作簿（模板见 templates/F-3应付票据审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已指定；基于模板在 `02_工作底稿/F-3应付票据/` 创建工作簿副本。
2. 校验输入：明细账与备查簿必输；缺失列明缺口挂起。
3. 分派顺序：P01 → （P02、P03 并行）→ P04 → P05 → P06。
4. 副本先行 + 修订记录伴随。
5. 异常激活：P02 贷款卡信息与账面不符（贷款卡多出票据）→ 完整性缺口升级项目经理；P02 保证金与应付票据余额不匹配 → 联动 Z-1-3 保证金勾稽；P04 逾期银行承兑未转短期借款 / 商业承兑未转应付账款 → 提请调整（联动 F-1/F-4）；P05 利息计提不足 → 调整建议（联动 F-8/S-4）；P03 未回函 → 替代程序（期后偿付核对，联动 P02）。
6. 汇总执行一级复核，通过后提交人工二级复核。

## 一级复核清单

- P01~P06 均有底稿或「不适用+理由」；明细合计=总账数=报表数=贷款卡信息；
- 备查簿逐要素核对完整；保证金勾稽闭环；期后偿付核对查未入账；
- 逾期票据转科目处理 100% 有结论；带息票据利息重算无误；
- 四段式制式完整、修订记录同步。

## 边界与禁止事项

- 仅项目工作目录内操作；禁止物理删除、外发数据；禁止代替人工执行函证寄发与贷款卡打印；
- 利息重算用脚本精确计算；逾期转科目定性结论须人工确认。

## Pitfalls

- 逾期票据的转科目处理是硬规则：银行承兑逾期→短期借款、商业承兑逾期→应付账款、带息票据逾期停止计息——长期挂应付票据会掩盖负债性质与融资成本；
- 贷款卡（企业信用报告）信息与账面三方核对是完整性关键兜底（与 F-1 借款同源逻辑）；
- 承兑保证金须与其他货币资金科目勾稽（联动 Z-1-3 P02 的反向核对）；
- 期后已偿付票据追查是查找未入账应付票据的重要路径（与 F-4 未入账负债逻辑同源）。

## Verification

- 工作簿公式重算无错误（利息重算）；保证金勾稽区与 Z-1-3 联动；
- 每张底稿四段式完整、修订记录对应。
