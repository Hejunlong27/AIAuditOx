# P04 研发支出截止测试

> 来源：Z5301 程序库 Z5301 程序4｜认定：C、E｜产出：Z-25-04
> 执行方式：自动筛截止样本+人工核凭证｜确定性工具：sampling_draw

## 输入

- 资产负债表日前后研发支出明细账、凭证、发票、工时/领料记录、验收单

## Steps

1. 【规则】对研发支出实施截止测试，检查资产负债表日前后天内开发支出明细账和凭证，确定有无跨期现象。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 样本编号 | 文本 | 抽样表 | 样本量与依据已记录 |
| 项目/合同名称 | 文本 | 明细账/台账 | 与账面一致 |
| 账面金额 | 金额 | 明细账 | 金额精确匹配 |
| 支持文件日期 | 日期 | 发票/合同/凭证 | 日期在审计期间内 |
| 支持文件编号 | 文本 | 发票/合同/凭证 | 可回溯 |
| 核对内容 | 文本 | 程序表 | 覆盖授权、存在、计价 |
| 独立证据 | 文本 | 外部/现场证据 | 必要时取得外部证据 |
| 异常事项 | 文本 | 审计判断 | 异常不得留空 |
| 结论 | 文本 | 审计判断 | 支持/不支持账面记录 |

## 质量门

- 截止日前后样本归属期间正确；跨期项目已调整或记录

## 升级路径

- 跨期金额重大或截止控制失效时升级项目经理并扩大截止测试。
