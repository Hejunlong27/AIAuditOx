# P05 研发支出资本化条件与内容合理性检查

> 来源：Z5301 程序库 Z5301 程序5｜认定：C、E、A｜产出：Z-25-05
> 执行方式：人工主导（资本化判断）+自动重算｜确定性工具：recalc_check、threshold_flag｜**必须留人**（Agent 不得代替执行）

## 输入

- 研究/开发阶段划分依据、五项资本化条件证据、项目预算与进度、技术可行性报告、经济利益分析、成本归集表

## Steps

1. 【规则】应关注研发支出的内容是否合理，研发支出资本化的依据是否充分，具体包括：（1）检查被审计单位对研究阶段和开发阶段的确认时点是否合理，研究阶段支出是否全部费用化；
   - （2）对于开发阶段的资本化支出，是否已满足资本化条件；
   - （3）对于无法区分研究阶段和开发阶段的支出，是否已全部费用化。
   - 对于研发支出资本化，应获取充分的支持性证据，必要时可利用外部专家工作。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 研发项目 | 文本 | 研发项目台账 | 项目完整 |
| 研究/开发阶段 | 文本 | 立项/可行性报告 | 阶段划分有依据 |
| 本期投入 | 金额 | 研发支出明细账 | 与总账核对 |
| 资本化金额 | 金额 | 开发支出明细账 | 五项资本化条件逐项支持 |
| 费用化金额 | 金额 | 研发费用明细账 | 研究阶段及不满足条件支出费用化 |
| 结转/减少 | 金额 | 明细账 | 转无形资产/费用化正确 |
| 截止日期 | 日期 | 凭证/验收单 | 资产负债日前后截止 |
| 支持证据 | 文本 | 立项/工时/领料/验收 | 证据链完整 |
| 结论 | 文本 | 审计判断 | 资本化/费用化是否恰当 |

## 质量门

- 研究阶段全部费用化；开发阶段五项条件逐项有证据；无法区分阶段全部费用化

## 升级路径

- 资本化条件证据不足或资本化金额重大时升级项目经理并考虑专家工作。
