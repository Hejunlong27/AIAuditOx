# P07 租赁折现率与租赁负债摊销检查

> 来源：Z1641 程序库 Z1641 程序11｜认定：A、V｜产出：Z-20-07
> 执行方式：自动重算+人工评价折现率｜确定性工具：recalc_check、threshold_flag

## 输入

- 租赁内含利率证据、增量借款利率计算、同期银行贷款/抵押贷款利率、租赁负债摊销表

## Steps

1. 【规则】租赁的计量–折现率
   - （1）评价折现率的估计不确定性的程度。如果不确定性程度较高，评价管理层的应对措施（如使用替代性假设）。
   - （2）获取租赁内含利率的证据（支持性和/或相矛盾），并考虑利率的可确定性。
   - （3）如果使用增量借款利率作为折现率，获取无法确定租赁内含利率的证据。
   - （4）获取管理层计算增量借款利率的支持性文件。考虑折现率和同期银行贷款利率、资产抵押贷款利率的相似性，检查管理层作出的假设，并进行重新计算。
   - （5）核实租赁负债是否按照适用的财务报告编制基础进行摊销。
   - 选取本年度内新签订的租赁协议，实施下列程序以核实计量租赁负债时使用的折现率是否适当：

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 租赁合同/资产 | 文本 | 租赁台账/合同 | 合同已完整识别 |
| 租赁期开始日 | 日期 | 合同 | 与起租证据一致 |
| 租赁期 | 整数 | 合同 | 含续租/终止选择权判断 |
| 租赁付款额 | 金额 | 合同/付款计划 | 固定及实质固定付款额完整 |
| 折现率 | 百分比 | 增量借款利率依据 | 与市场数据比较 |
| 使用权资产初值 | 金额 | 计算表 | 独立重算 |
| 本期折旧 | 金额 | 折旧表 | 按剩余使用寿命/租赁期孰短 |
| 期末账面价值 | 金额 | 计算表 | 初值-折旧-减值+变更 |
| 结论 | 文本 | 审计判断 | 计量/分类是否恰当 |

## 质量门

- 折现率依据与市场数据一致；租赁负债利息和摊销独立重算正确

## 升级路径

- 折现率偏离市场、无法取得依据或摊销错误时升级项目经理。
