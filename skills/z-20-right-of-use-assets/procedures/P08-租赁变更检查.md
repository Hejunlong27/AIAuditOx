# P08 租赁变更检查

> 来源：Z1641 程序库 Z1641 程序12｜认定：C、E、A、V｜产出：Z-20-08
> 执行方式：自动筛变更+人工复核合同｜确定性工具：threshold_flag、sampling_draw

## 输入

- 租赁付款额明细、租赁变更清单、补充协议、终止/续租记录、会计处理凭证

## Steps

1. 【规则】租赁变更
   - 向管理层询问报告期内是否存在租赁变更。获取租赁付款额的明细清单，检查经常性付款是否发生变化，识别可能发生变更的租赁。将识别出的可能发生变更的租赁与管理层提供的租赁变更清单进行比较，评估完整性。复核更新的合同和其他往来函件，验证租赁变更。评估被审计单位是否恰当应用了新租赁准则中对租赁变更的会计处理的相关规定。（注意：如果增加的使用权扩大了租赁范围或延长了租赁期间，租赁变更可能作为一项单独租赁。）

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析表 | 按类别/项目拆分 |
| 预期值 | 数值 | 审计模型 | 模型依据留痕 |
| 实际值 | 数值 | 总账/明细账 | 与账面核对 |
| 差异 | 金额 | 计算表 | 实际-预期 |
| 差异率 | 百分比 | 计算表 | 差异/预期，除零保护 |
| 重要性阈值 | 金额 | 计划阶段 | 记录实际执行重要性 |
| 是否超阈值 | 文本 | 规则判断 | 超阈值须调查 |
| 原因与证据 | 文本 | 访谈/支持文件 | 不能仅凭解释 |
| 结论 | 文本 | 审计判断 | 记录追加程序或调整 |

## 质量门

- 租赁变更完整识别；单独租赁与重新计量判断正确；会计处理符合准则

## 升级路径

- 变更未识别或应作单独租赁却调整原合同，升级项目经理。
