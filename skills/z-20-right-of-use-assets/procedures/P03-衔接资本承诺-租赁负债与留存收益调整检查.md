# P03 衔接资本承诺、租赁负债与留存收益调整检查

> 来源：Z1641 程序库 Z1641 程序5、Z1641 程序6｜认定：C、E、A、V｜产出：Z-20-03
> 执行方式：自动勾稽+人工复核｜确定性工具：recalc_check、threshold_flag

## 输入

- 经营租赁资本承诺、首次执行日租赁负债调节表、留存收益调整明细、租赁付款计划、会计处理凭证

## Steps

1. 【规则】审计新租赁准则的衔接-核对经营租赁资本承诺和租赁负债
   - 获取和评估管理层对经营租赁资本承诺（执行新租赁准则前）和首次执行日租赁负债的调节，包括考虑调节项和异常项的恰当性。
2. 【规则】审计新租赁准则的衔接 - 审计首次执行日对年初留存收益的调整
   - 选取样本测试交易细节，验证对年初留存收益的调整是否符合新租赁准则的要求。考虑在备忘录中记录如何验证留存收益及其他相关FSA的调整和相关披露的完整性、存在性、准确性和计价。可能的情况下，在测试历史交易及核对租赁条款和支持性文件是否一致时，使用以前年度执行的审计工作。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析表 | 按类别/项目拆分 |
| 预期值 | 数值 | 审计模型 | 模型依据留痕 |
| 实际值 | 数值 | 总账/明细账 | 与账面核对 |
| 差异 | 金额 | 计算表 | 实际-预期 |
| 差异率 | 百分比 | 计算表 | 差异/预期，除零保护 |
| 重要性阈值 | 金额 | 计划阶段 | 记录实际执行重要性 |
| 是否超阈值 | 文本 | 规则判断 | 超阈值须调查 |
| 原因与证据 | 文本 | 访谈/支持文件 | 不能仅凭解释 |
| 结论 | 文本 | 审计判断 | 记录追加程序或调整 |

## 质量门

- 承诺与租赁负债调节完整；留存收益调整可追溯且符合准则

## 升级路径

- 调节项异常、留存收益调整无依据时升级项目经理。
