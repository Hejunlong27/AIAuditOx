## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 存在（E）：记录的长期待摊费用于资产负债表日存在且归被审计单位拥有或控制；准确性（A）：金额正确计算、适当加总且准确记录；计价（V）：按恰当金额计价（含减值、摊销、公允价值等调整）；列报（P）：分类、披露恰当 |
| 所需资料 | 长期待摊费用明细账、总账与报表、装修/改良/租赁等原始合同与发票、受益期分析、摊销政策、付款凭证、验收资料、财务报表附注 |
| 所需数据 | 项目名称、发生日期、原始金额、累计摊销、本期摊销、期末余额、摊销期限、剩余摊销期、受益对象、一年内到期金额、实际执行的重要性水平 |
| 核对逻辑 | 1. 长期待摊费用明细表编制与核对（获取或编制长期待摊费用明细表，复核加计是否正确，并与总账数和明细账合计数核对是否相符，减去将于一年内（含一年）摊销的数额后与报表数核对是否相符。）；2. 长期待摊费用摊销政策与重算（检查摊销政策是否符合会计制度的规定，复核计算摊销额及相关的会计处理是否正确，前后期是否保持一致，是否存在随意调节利润的情况。）；3. 长期待摊费用抽样检查（抽样检查待摊费用）；4. 长期待摊费用披露检查（审计待摊费用的披露） |
| 底稿编制内容 | 共 4 张底稿：P01 长期待摊费用明细表编制与核对、P02 长期待摊费用摊销政策与重算、P03 长期待摊费用抽样检查、P04 长期待摊费用披露检查。全部采用 auditox-wp-standard 四段式制式。 |
| 输出格式 | xlsx 工作簿（模板见 templates/Z-23长期待摊费用审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/Z-23长期待摊费用/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性（见六要素「所需资料」）；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → P02 → P03 → P04；人工程序标记待办并跟踪完成状态。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：按各程序卡「升级路径」处理，发现异常事项逐级升级。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P04 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：明细表合计数 = 总账数 = 报表数；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源；差异事项均有解释与支持文件。
- 异常闭环：所有异常事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料 只读）；跳过强制程序。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 将应费用化或应资本化为固定资产/无形资产的支出计入长期待摊费用。
- 摊销期限超过合同租赁期或预计受益期，或随意延长摊销期调节利润。
- 项目已无未来经济利益但仍挂账，未及时转销或计提减值。
- 一年内到期的长期待摊费用未在一年内到期的非流动资产项目列报。

## Verification

- 工作簿公式重算无错误；合计数与总账/报表数核对一致。
- 每张底稿「审计程序执行结果」与「审计说明」均有实质内容或明确的不适用声明。
- 修订记录 .md 与工作簿版本一一对应。
