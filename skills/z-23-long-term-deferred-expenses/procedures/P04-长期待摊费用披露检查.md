# P04 长期待摊费用披露检查

> 来源：Z1801 程序库 Z1801 程序4｜认定：P｜产出：Z-23-04
> 执行方式：自动核对+人工确认｜确定性工具：rule_check

## 输入

- 长期待摊费用附注、审定表、摊销政策、一年内到期金额

## Steps

1. 【规则】审计待摊费用的披露
   - 检查相关财务报表附注披露的准确性和完整性，同时，请注意剩余摊销期1年以内的长期待摊费用是否在财务报表内一年内到期的非流动资产项目反映。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 披露项目 | 文本 | 报表附注 | 披露要求逐项覆盖 |
| 附注表述/金额 | 文本 | 报表附注 | 与附注原文一致 |
| 审定数 | 金额 | 审定表 | 与底稿勾稽 |
| 差异 | 金额 | 计算表 | 附注-审定数 |
| 披露要求 | 文本 | 会计准则/格式 | 引用依据 |
| 完整性 | 文本 | 规则核对 | 完整/缺失/不适用 |
| 证据索引 | 文本 | 底稿索引 | 可回溯 |
| 结论 | 文本 | 审计判断 | 是否需补充披露 |

## 质量门

- 披露数=审定数；摊销政策和一年内到期列报正确

## 升级路径

- 应披露未披露或列报错误时升级项目经理。
