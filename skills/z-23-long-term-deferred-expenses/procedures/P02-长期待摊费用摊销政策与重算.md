# P02 长期待摊费用摊销政策与重算

> 来源：Z1801 程序库 Z1801 程序2｜认定：V｜产出：Z-23-02
> 执行方式：自动重算+人工评价政策｜确定性工具：recalc_check、threshold_flag

## 输入

- 摊销政策、各项目原始金额、开始摊销日期、合同/受益期、本期摊销明细、以前期间政策

## Steps

1. 【脚本】检查摊销政策是否符合会计制度的规定，复核计算摊销额及相关的会计处理是否正确，前后期是否保持一致，是否存在随意调节利润的情况。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产类别/项目 | 文本 | 折旧/摊销清单 | 类别完整 |
| 原值 | 金额 | 资产台账 | 与总账核对 |
| 折旧/摊销方法 | 文本 | 会计政策 | 前后期一致 |
| 预计使用寿命/残值率 | 文本 | 会计政策/评估 | 估计合理 |
| 本期应计折旧/摊销 | 金额 | 审计重算 | 按政策独立重算 |
| 账面折旧/摊销 | 金额 | 明细账 | 贷方发生额 |
| 差异 | 金额 | 计算表 | 应计-账面 |
| 分配核对 | 金额 | 成本费用明细账 | 折旧分配额勾稽 |
| 结论 | 文本 | 审计判断 | 差异是否需调整 |

## 质量门

- 摊销期限与受益期/租赁期匹配；本期摊销独立重算；政策前后期一致

## 升级路径

- 摊销期限不合理、政策不一致或差异重大时升级项目经理。
