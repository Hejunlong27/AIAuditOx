# P03 长期待摊费用抽样检查

> 来源：Z1801 程序库 Z1801 程序3｜认定：E、A｜产出：Z-23-03
> 执行方式：自动筛样+人工核单｜确定性工具：sampling_draw

## 输入

- 长期待摊费用台账、合同、发票、付款凭证、验收/受益资料、摊销计算表

## Steps

1. 【规则】抽样检查待摊费用
   - （1）获取待摊费用余额明细表并执行其他程序测试IPE的可靠性；
   - （2）记录样本量和选样依据；
   - （3）针对待摊费用样本，执行下列工作：
   - ①检查支持性文件，确认会计处理的有效性；
   - ②确保待摊费用的核算依据与前期一致，并符合适用的财务报告编制基础；
   - ③如果对未来经济利益作出的预期看似合理，根据经营成果、当前经济状况等因素评价该收益的可收回性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 样本编号 | 文本 | 抽样表 | 样本量与依据已记录 |
| 项目/合同名称 | 文本 | 明细账/台账 | 与账面一致 |
| 账面金额 | 金额 | 明细账 | 金额精确匹配 |
| 支持文件日期 | 日期 | 发票/合同/凭证 | 日期在审计期间内 |
| 支持文件编号 | 文本 | 发票/合同/凭证 | 可回溯 |
| 核对内容 | 文本 | 程序表 | 覆盖授权、存在、计价 |
| 独立证据 | 文本 | 外部/现场证据 | 必要时取得外部证据 |
| 异常事项 | 文本 | 审计判断 | 异常不得留空 |
| 结论 | 文本 | 审计判断 | 支持/不支持账面记录 |

## 质量门

- 样本性质符合长期待摊费用定义；支持文件完整；可收回性有评价

## 升级路径

- 支出性质错误、支持文件不足或未来经济利益存疑时升级项目经理。
