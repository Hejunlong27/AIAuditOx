# P03 纳税申报表核对

> 来源：F2221 程序库 其他2｜认定：C、E、A、V｜产出：F-9-03
> 执行方式：自动（申报表解析+重算）+人工确认｜确定性工具：recalc_check、excel_read、sheet_to_csv

## 输入

- 各税种纳税申报表
- 完税凭证与银行对账单
- 上年提交的税费计算单
- 税费支出与税费抵扣调节表
- 税务机关记录

## Steps

1. 【规则】获取有关税种纳税申报表
   - （1）将付款/收款凭证与银行对账单核对；
   - （2）检查税款是否已及时交款，如果未及时缴付，则确保任何罚金和返还已被正确会计处理；；
   - （3）将期初余额与上年财务报表及上年提交的税费计算单核对；
   - （4）获取财务报表中的税费支出与税费抵扣计算单的调节表，评估任何差异以及由此实施的处理方法的合理性；
   - （5）核对纳税申报表中的税费支出数与账户中披露的金额；
   - （6）确保应交税费账户中的所有数字与税费计算单一致；
   - （7）评估税费账户的所有变动的合理性。例如：选取部分汇款样本与银行对账单或者税务机关记录进行核对，并调节税费支出与利润表中税费支出数的差异；
   - （8）考虑各项税费负债的应税时间。查看上年年末的应交税费是否已经缴纳，评估客户在本年税费应税日支付税费的能力，由此评估是否需要对延期支付的税费计提利息。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 税种 | 文本 | 纳税申报表 | 非空 |
| 申报表金额 | 金额 | 纳税申报表 | 与申报表一致 |
| 账面金额 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 申报表 − 账面 | = 差额 |
| 已缴金额 | 金额 | 完税凭证 | 与凭证一致 |
| 银行流水匹配 | 文本 | 银行对账单 | 枚举（相符/不符） |
| 是否及时缴付 | 文本 | 完税凭证日期 | 枚举（是/否） |
| 是否需计提延期利息 | 文本 | 人工判断 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 差异或未及时缴付必有 |

## 质量门

- 各税种申报表金额与账面金额 100% 核对，差异已查明
- 已缴税款 100% 与银行对账单核对一致
- 未及时缴付的税款已确保罚金与返还被正确会计处理
- 各项税费负债的应税时间已考虑，评估是否需要为延期支付计提利息

## 升级路径

- 申报表与账面差异无法解释 → 升级项目经理，评估是否存在未申报或错报
- 存在欠缴税款 → 升级，评估滞纳金、罚金与披露要求
- 税费支出与利润表金额无法调节 → 升级，联动所得税费用程序
