# P07 税收减免与返还检查

> 来源：F2221 程序库 其他13｜认定：E、A、V｜产出：F-9-07
> 执行方式：自动（依据齐备性校验）+人工确认｜确定性工具：rule_check、recalc_check

## 输入

- 税收减免或返还的批准文件
- 减免申请材料
- 税务机关批复
- 会计处理记录
- 政府补助准则要求

## Steps

1. 【规则】检查税收减免与返还
   - （1）如果有特殊的税收项目（如税收减免等），确保已遵守相关的税收法律法规并已按照要求对有关税费进行了调整；
   - （2）检查被审计单位获得税费减免或返还时的依据是否充分、合法和有效，会计处理是否正确。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 减免或返还项目 | 文本 | 批准文件 | 非空 |
| 依据文件 | 文本 | 税务机关批复 | 非空 |
| 批准金额 | 金额 | 批准文件 | 与文件一致 |
| 本期确认金额 | 金额 | 明细账 | 与总账一致 |
| 会计处理方法 | 文本 | 账务记录 | 枚举（冲减税金及附加/计入其他收益/计入递延收益） |
| 是否符合准则 | 文本 | 人工判断 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 税收减免或返还的依据充分、合法、有效
- 会计处理符合政府补助准则，与税收相关的补助处理方法恰当
- 与递延收益科目交叉核对，摊销进度一致

## 升级路径

- 依据不充分或不合法 → 升级项目经理，评估冲回及相关税务风险
- 会计处理与准则不符 → 升级，联动递延收益与税金及附加程序
