# P11 境外公司税费检查

> 来源：F2221 程序库 其他15｜认定：E、A、V｜产出：F-9-11
> 执行方式：人工为主（需利用专家/外币折算核对）｜**必须留人**（Agent 不得代替执行）

## 输入

- 境外公司纳税申报表
- 境外税务法规或当地税务专家意见
- 外币财务报表折算资料
- 境外公司财务报表
- 资产负债表日即期汇率表

## Steps

1. 【规则】检查在境外注册公司的税费
   - （1）考虑是否需要利用专家的工作；
   - （2）确保资产负债表的年末外币折算符合企业会计准则；
   - （3）获取纳税申报表的复印件并确认相关的现金流动。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 境外公司 | 文本 | 境外公司清单 | 非空 |
| 所在国家或地区 | 文本 | 境外公司清单 | 非空 |
| 税种 | 文本 | 纳税申报表 | 非空 |
| 申报表金额（原币） | 金额 | 纳税申报表 | 与申报表一致 |
| 折算汇率 | 汇率 | 即期汇率表 | 资产负债表日汇率 |
| 折算后金额 | 金额 | 原币 × 折算汇率 | = 乘积 |
| 账面金额 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 折算后 − 账面 | = 差额 |
| 是否需利用专家 | 文本 | 人工判断 | 枚举（是/否） |
| 结论 | 文本 | 人工填写 | 非空 |

## 质量门

- 境外公司纳税申报表 100% 获取并与账面核对
- 外币折算符合企业会计准则，采用资产负债表日即期汇率
- 必要时利用专家的工作并完成相关专家工作模板
- 本卡必须人工执行（涉及境外法规判断），Agent 仅可整理与折算

## 升级路径

- 境外税务处理存在重大不确定性 → 升级项目经理，考虑利用当地税务专家
- 外币折算错误 → 升级，评估对所得税费用与外币报表折算差额的影响
- 境外公司存在未申报税种 → 升级，评估或有负债与合规风险
