# P10 税收会计政策复核

> 来源：F2221 程序库 其他18｜认定：C、E、A、V｜产出：F-9-10
> 执行方式：自动（政策清单校验）+人工判断｜确定性工具：rule_check

## 输入

- 财务报表中的税收会计政策披露
- 适用财务报告编制基础
- 企业会计准则第18号等准则要求清单

## Steps

1. 【规则】复核税收会计政策
   - （1）复核财务报表中的税收会计政策，确定其运用是否正确；
   - （2）考虑税收会计政策是否完整、准确，符合适用的财务报告编制基础。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 政策事项 | 文本 | 准则要求清单 | 非空 |
| 公司政策 | 文本 | 财务报表附注 | 非空 |
| 准则要求 | 文本 | 适用编制基础 | 非空 |
| 是否符合 | 文本 | rule_check 校验 | 枚举（是/否） |
| 差异影响 | 金额 | 人工测算 | 不符时必有 |
| 说明 | 文本 | 人工填写 | 不符项必有 |

## 质量门

- 税收会计政策 100% 逐项与适用财务报告编制基础核对
- 政策运用正确，且完整、准确地反映了准则要求
- 与集团税收会计政策的一致性已考虑（存在集团时）

## 升级路径

- 政策与准则不符 → 升级项目经理，评估是否需追溯调整
- 政策披露不完整 → 升级，提请管理层补充披露
