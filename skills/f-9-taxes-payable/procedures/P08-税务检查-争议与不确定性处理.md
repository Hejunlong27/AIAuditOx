# P08 税务检查、争议与不确定性处理

> 来源：F2221 程序库 其他14、其他19、其他20、其他21｜认定：C、E、A、V｜产出：F-9-08
> 执行方式：人工为主（需税务专家/管理层分析）+控制表自动｜确定性工具：rule_check｜**必须留人**（Agent 不得代替执行）

## 输入

- 税务机关近期检查结论文件
- 税务争议资料与往来函件
- 外部税务咨询意见
- 管理层对不确定税务处理的详细分析文件
- 法院对以前税务案件的裁决
- 税务机关既往评估与意见
- 诉讼时效相关资料

## Steps

1. 【规则】税务检查与税务争议
   - （1）如果有税务机关的近期检查，获取税务检查结论或一份对相关事项评估及复核的副本。确保任何额外付款（包括罚金和返还）已正确处理；
   - （2）复核是否遵守税务机关的规定，并询问是否存在实际或者可能的争议事项——考虑是否需要为尚未支付的税费或者罚金计提任何准备。
2. 【规则】确定是否存在具有不确定性的税务处理
   - 向管理层获取对其具有不确定性的税务处理的详细分析文件，包括来自外部咨询师的税务处理建议。
   - 确认这些被归类为“具有不确定性”的项目与应纳税所得额（或损失）、税务亏损、税款抵减和税率等的确定相关。
   - 评估是否识别出重大（单独或汇总起来）的税务处理及评价税务处理是否符合恰当的会计准则。
   - 确认《企业会计准则第18号——所得税》范围内规范的与具有不确定性的税务处理相关的利息和罚款也已考虑。
   - 确认客户计提/减少负债或资产或增加/减少递延所得税负债/资产的具有不确定性的税务处理是否代表其税务申报中的真是情况。
   - 在UTE问卷中，在复杂性领域的问题下选择“具有不确定性的税务处理”，将自动生成其他与具有不确定性的税务处理相关的默认测试。
3. 【规则】验证具有不确定性的税务处理的完整性
   - 为了评估被审计单位具有不确定性的税务处理的完整性，考虑是否在与被审计单位相关的领域对税收法律法规有重要解释。这可能需要咨询税务专家。
   - 例如，考虑税法中的重要解释是否适用于被审计单位进行的下列交易：
   - 重大关联方交易（转让定价研究应用中可能产生具有不确定性的税务处理）。
   - 重大研究和开发索赔（对于索赔或索赔的某些部分是否有资格出于税务目的进行扣除或抵免，可能会产生具有不确定性的税务处理）。
   - 重大业务重组或交易（如果存在资产处置，且资产处置的税务处理方式和税率具有不确定性，则可能产生具有不确定性的税务处理）。
   - 税务机关的任何调查或审计活动（税务机关正在调查的领域可能存在具有不确定性的税务处理）。
   - 还要考虑管理层的分析中是否遗漏了任何税务处理，因为管理层认为它们不相关。在这些情况下，获取并复核管理层关于为什么这些税务处理不被认为具有不确定性的解释。
4. 【规则】具有不确定性的税务处理的计价
   - 对于管理层汇总的具有不确定性的税务处理的重要项目：
   - 评价用于计算具有不确定性的税务处理的方法（如最可能金额法与预期价值法）是否适用于具体情况。
   - 评价用于计算具有不确定性的税务处理的金额值（如税务影响的结果）是否恰当确定及反应了适当的估值技术，如适用。如必要考虑利用注册会计师的专家并完成相关利用专家的工作模板。
   - 评价是否恰当确定具有不确定性的税务处理被税务机关接受的可能性并确定计算具有不确定性的税收处理时使用的每种结果的相关概率是否合理。咨询税务专家以确定可能需要的税务处理的概率；如果需要，请填写相关利用专家工作模板。支持不同可能性的证据可从法院对以前税务案件的裁决、税务机关以前的评估和意见的经验等中获取。
   - 确认税务机关审查客户税务处理的可能性未包含在不确定性性的计量中。
   - 验证在计算中使用的税率是正确的税率。
   - 验证相关税务机关检查和质疑具有不确定性的税收处理的诉讼时效已被考虑，且所有时效期内的都包含在分析中。
   - 如果具有不确定性的税务处理与时间安排相关（如项目抵免的时间），考虑对本期所得税和递延所得税的影响。
   - 如果具有不确定性的税务处理与转让定价研究相关，考虑获取有关不同司法管辖区税务机关如何评估被审计单位的税务处理的信息。
   - 评价客户是否在财务报表中适当反映了情况和事实的任何变化所产生的影响，这些变化会导致之后的税务处理的确认、取消确认或计量变更。
   - 考虑与税务处理相关的不确定性是否在年末和报告日前得到解决。例如，税务事项已通过协商或诉讼解决，有关税务机关检查和质疑税务处理的诉讼时效已过等。
   - 测试计算的数学准确性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 事项类型 | 文本 | 检查结论/管理层分析 | 枚举（税务检查/争议事项/不确定税务处理/转让定价） |
| 事项描述 | 文本 | 支持性文件 | 非空 |
| 涉及税种 | 文本 | 管理层分析 | 非空 |

| 接受可能性 | 百分比 | 人工判断 | 0%–100% |

| 是否已计提 | 文本 | 账务记录 | 枚举（是/否） |
| 会计处理 | 文本 | 账务记录 | 枚举（已处理/未处理/处理不当） |
| 结论 | 文本 | 人工填写 | 非空 |

## 质量门

- 具有不确定性的税务处理识别完整，已考虑重大关联方交易、研发索赔、业务重组、税务调查四类高发领域
- 计价方法（最可能金额法或预期价值法）适用于具体情况，接受可能性与相关概率合理
- 税务机关审查的可能性未包含在不确定性计量中；所用税率正确；诉讼时效已考虑
- 税务机关近期检查结论 100% 获取并复核，额外付款（含罚金、返还）已正确处理
- 本卡必须人工执行（必要时咨询税务专家），Agent 仅可整理底稿

## 升级路径

- 存在未计提的不确定税务处理负债 → 升级项目经理，评估对所得税费用与递延所得税的影响
- 税务机关调查或争议正在进行 → 升级，评估或有负债的确认与披露
- 涉及转让定价且缺乏支持性研究 → 升级，考虑利用税务专家并完成专家工作模板
