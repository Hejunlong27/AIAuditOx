# P05 各税种计算与凭证检查

> 来源：F2221 程序库 其他4、其他5、其他6、其他7、其他8、其他9、其他11、其他12、其他16｜认定：E、A、V｜产出：F-9-05
> 执行方式：自动（逐税种重算+抽样）+人工确认｜确定性工具：recalc_check、sampling_draw、rule_check

## 输入

- 各税种计税依据（应税消费品销售额、课税数量、预售房产预收款）
- 适用税率或单位税额
- 完税凭证
- 土地增值税清算鉴证报告
- 自有车船与房屋资料
- 固定资产明细账
- 抽样参数

## Steps

1. 【规则】检查应交消费税
   - （1）根据审定的应税消费品销售额（或数量），检查消费税的计税依据是否正确。适用税率（或单位税额）是否符合税法规定，是否按规定进行了会计处理；
   - （2）分项复核本期应交消费税税额；3.抽查本期已交消费税资料，确定已交数的正确性。
2. 【规则】检查应交资源税
   - 检查应交资源税的计算是否正确，是否按规定进行了会计处理。
3. 【规则】检查应交土地增值税
   - （1）根据审定的预售房地产的预收账款，复核预交税款是否准确；
   - （2）对符合项目清算条件的房地产开发项目，检查被审计单位是否按规定进行土地增值税清算；如果被审计单位已聘请中介机构办理土地增值税清算鉴证的，应检查、核对相关鉴证报告；
   - （3）如果被审计单位被主管税务机关核定征收土地增值税的，应检查、核对相关的手续；
   - （4）检查土地增值税会计处理是否正确。
4. 【规则】检查城市维护建设税
   - （1）结合各项流转税的审计，检查应交城市维护建设税的计算是否正确；
   - （2）抽查本期已交城市维护建设税资料，确定已交数的正确性；
   - （3）检查会计处理是否正确。
5. 【规则】检查应交车船使用税和房产税
   - （1）获取被审计单位自有车船数量、吨位（或座位）及自有房屋建筑面积、用途、造价（购入原价）、购建年月等资料，并与固定资产（含融资租入固定资产）明细账复核一致；
   - （2）了解其使用、停用时间及其原因等情况；
   - （3）通过审核本期完税单，检查其是否如实申报和按期缴纳；
   - （4）是否按规定进行了会计处理。
6. 【规则】检查应交土地使用税
   - 检查应交土地使用税的计算是否正确，是否按规定进行了会计处理。
7. 【规则】检查教育费附加
   - 检查教育费附加、矿产资源补偿费等的计算是否正确，是否按规定进行了会计处理。
8. 【规则】检查其他税项处理
   - 检查除上述税项外的其他税项及代扣税项的计算是否正确，是否按规定进行了会计处理。
9. 【规则】抽样检查应交税费样本
   - 抽查x笔应交税费相关的凭证，检查是否有合法依据，会计处理是否正确。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 税种 | 文本 | 纳税申报表 | 枚举（消费税/资源税/土地增值税/城建税/车船税/房产税/土地使用税/教育费附加/其他） |
| 计税依据 | 金额 | 已审定销售额或数量 | 与审定数一致 |
| 适用税率或单位税额 | 数值 | 税收政策 | 与政策一致 |
| 重算应纳税额 | 金额 | 计税依据 × 税率 | = 乘积 |
| 账面计提额 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 重算 − 账面 | = 差额 |
| 已缴金额 | 金额 | 完税凭证 | 与凭证一致 |
| 凭证抽查结论 | 文本 | 人工填写 | 枚举（相符/不符） |
| 说明 | 文本 | 人工填写 | 差异或异常项必有 |

## 质量门

- 各税种 100% 重算，差异已查明
- 车船税与房产税的资产基础与固定资产明细账复核一致，使用与停用时间已了解
- 土地增值税对符合清算条件的项目已按规定清算，鉴证报告已核对
- 抽样检查应交税费凭证有合法依据，会计处理正确

## 升级路径

- 重算差异重大 → 升级项目经理，评估补提或申请退税
- 土地增值税未按规定清算 → 升级，评估或有负债与披露
- 发现以核定征收方式规避税款 → 升级，评估税务合规风险
