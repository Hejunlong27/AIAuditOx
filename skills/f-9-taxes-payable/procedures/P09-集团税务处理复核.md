# P09 集团税务处理复核

> 来源：F2221 程序库 其他3｜认定：C、E、A、V｜产出：F-9-09
> 执行方式：自动（纳税调节表核对）+人工判断｜确定性工具：recalc_check、excel_read

## 输入

- 集团纳税调节表
- 各公司财务报表或报告
- 合并调整分录
- 集团与子公司税收会计政策
- 集团税收减免文件

## Steps

1. 【规则】复核集团审计的税务处理
   - （1）获取本年度的集团纳税调节表，检查计算是否准确，并确保电子表格公式是完整且正确的；
   - （2）将各公司的金额与该公司的财务报表/报告进行核对；
   - （3）考虑所有合并及企业会计准则调整的税务处理；
   - （4）核对纳税调节表中的数字与集团财务报表中披露的金额是否一致；
   - （5）考虑集团会计政策与公司会计政策不一致而导致需要进行任何调整时的税务处理；
   - （6）确保任何集团税收减免已经被正确扣除，并且集团税收减免（如有）已经进行了正确的会计处理；
   - （7）复核集团税收的会计政策，如果集团税收的会计政策与子公司税收的会计政策不一致，考虑差异的调整对合并的影响。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 项目 | 文本 | 纳税调节项目 | 非空 |
| 集团纳税调节表金额 | 金额 | 集团调节表 | 公式完整正确 |
| 各公司报表合计 | 金额 | 各公司财务报表 | 与报表一致 |
| 差异 | 金额 | 调节表 − 各公司合计 | = 差额 |
| 合并调整税务处理 | 文本 | 合并调整分录 | 枚举（已处理/未处理） |
| 是否符合准则 | 文本 | 人工判断 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 集团纳税调节表计算准确，电子表格公式完整且正确
- 各公司金额与该公司财务报表或报告核对一致
- 所有合并及企业会计准则调整的税务处理已考虑
- 集团与子公司税收会计政策不一致导致的调整影响已评估，集团税收减免已正确扣除与处理

## 升级路径

- 集团与子公司税收政策不一致且影响重大 → 升级项目经理，评估合并层面错报
- 集团税收减免处理错误 → 升级，联动所得税费用与递延所得税程序
- 纳税调节表公式存在错误 → 升级，要求管理层修正后重新复核
