# P02 应交税费明细表编制与核对

> 来源：F2221 程序库 其他1｜认定：C、E、A｜产出：F-9-02
> 执行方式：自动（脚本核对）｜确定性工具：recalc_check、balance_confirm、rule_check

## 输入

- 应交税费明细表（分税种）
- 总账 2221 余额及明细账合计数
- 上年审定数

## Steps

1. 【规则】获取应交税费明细表
   - （1）复核加计是否正确，并与报表数、总账数和明细账合计数核对是否相符；
   - （2）注意印花税、耕地占用税以及其他不需要预计应缴数的税金有无误入应交税费项目（应缴未缴除外）；
   - （3）分析存在借方余额的项目，查明原因，判断是否由被审计单位预缴税款引起。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 税种 | 文本 | 明细表 | 非空 |
| 期初余额 | 金额 | 明细账 | 与上年审定数衔接 |
| 本期增加 | 金额 | 明细账贷方 | 与总账一致 |
| 本期减少 | 金额 | 明细账借方 | 与总账一致 |
| 期末余额 | 金额 | 期初 + 增加 − 减少 | = 期初 + 增 − 减 |
| 其中借方余额 | 金额 | 明细账 | 非空时须查明原因 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异或借方余额必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数（四方相符）
- 已检查印花税、耕地占用税等不需预计应缴数的税金有无误入应交税费项目
- 借方余额项目已查明原因，判断是否由预缴税款引起

## 升级路径

- 借方余额无法解释 → 升级项目经理，评估是否需重分类为其他流动资产
- 存在不需预计应缴数的税金误入 → 升级，评估重分类及对税金及附加的影响
