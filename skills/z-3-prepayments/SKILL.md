> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。

> 技能库分组：资产类 Z → Z-3 预付款项（对应所内科目编号 1123 / 程序库 Z1123）
> 角色：本技能由「Z-3 预付账款助理」持有并调度，程序卡 P01~P07 由实习生级执行，一级复核由助理执行（编制-复核分离）。

> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 存在性（E）：预付账款真实、系按购货合同支付的款项；完整性（C）：期后收货转销完整、无虚构；准确性/计价（A/V）：金额准确、长期未核销与坏账风险恰当处理；列报（P）：披露准确完整 |
| 所需资料 | 预付账款明细账（按供应商）、应付账款明细账（重复挂账排查）、采购合同/订单、银行支付凭证、函证回函、期后存货/在建工程明细账及入库凭证、财务报表附注 |
| 所需数据 | 分供应商期末余额、账龄（1年以内/1-2年/2-3年/3年以上）、期初余额与上年数、合同约定的付款进度与条件、期后收货转销额、红字冲销记录 |
| 核对逻辑 | ① 明细加计↔总账/报表核对+应付账款双向查重+贷方余额重分类；② 余额波动分析+预期比较（超阈值调查）；③ 账龄构成分析：是否按合同支付、一年以上未核销原因与坏账可能、性质不符/供应商破产撤销的转其他应收款；④ 函证+替代程序；⑤ 期后收货转销核实+红字冲销检查（防虚构）；⑥ 样本核对银行支付凭证与合同付款条件；⑦ 披露核对 |
| 底稿编制内容 | 见「产出清单」，全部底稿采用 auditox-wp-standard 四段式制式 |
| 输出格式 | xlsx 工作簿（模板见 templates/Z-3预付账款审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已指定（未指定拒绝启动）；基于模板在 `02_工作底稿/Z-3预付账款/` 创建工作簿副本。
2. 校验输入：预付账款明细账必输；应付账款明细账（P01 查重需要）、采购合同（P06 需要）缺失时列明缺口挂起。
3. 分派顺序：P01 → （P02、P03 并行）→ P04（人工为主，与 P05/P06 并行跟踪）→ P05 → P06 → P07。
4. 副本先行 + 修订记录伴随。
5. 异常激活：P02 余额波动超阈值且无法解释 → 激活 P06 扩样；P03 一年以上未核销或供应商破产 → 联动转其他应收款建议与坏账评估（Z-2/Z-4 坏账体系）并升级助理；P01 发现预付/应付同一供应商双挂账 → 联动 F-4 应付账款技能；P05 红字冲销异常（虚构预付迹象）→ 升级项目经理；P04 回函差异 → 检查支持性文件，未回函 → 替代程序（期后收货/合同核对，联动 P05）。
6. 汇总执行一级复核（完整性/勾稽/证据/异常闭环/制式合规），通过后提交人工二级复核。

## 一级复核清单（独立于编制上下文）

- P01~P07 均有底稿或「不适用+理由」；索引号连续；
- 明细合计=总账数=报表数；预付/应付查重与贷方余额重分类有结论；
- 函证样本量与选样依据记录，回函差异与替代程序闭环；
- 一年以上预付账款 100% 有未核销原因分析；期后转销与红字冲销检查有记录；
- 四段式制式完整、七要素齐全、修订记录同步。

## 边界与禁止事项

- 仅项目工作目录内操作；禁止物理删除、外发数据；禁止代替人工执行函证寄发；
- 数字核对脚本精确匹配；坏账/转销建议可模型起草但标注「待人工确认」。

## Pitfalls

- 预付账款与应付账款同一供应商双挂账是本科目核心风险（重复付款/错挂），必须双向核对；
- 一年以上预付账款须评估性质：不符合预付性质或供应商破产撤销的应转入其他应收款并计提坏账，不能长期挂账；
- 红字冲销可能是虚构预付后再冲回的痕迹，须检查冲销依据与资金流向；
- 期后转销核实是存在性的关键证据：核对期后存货/在建工程明细账的入库与转销记录。

## Verification

- 工作簿公式重算无错误；账龄分布合计=明细合计；函证汇总勾稽明细表；
- 每张底稿四段式完整、修订记录对应。
