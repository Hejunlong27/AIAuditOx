# P05 期后转销与红字冲销检查

> 来源：Z1123 程序4（检查资产负债表日后的转销与红字冲销）｜认定：C、A｜产出：Z-3-05 期后转销检查表

## 输入

- 期后预付账款、存货、在建工程明细账
- 期后入库凭证/工程进度单据、红字冲销记录

## Steps

1. 【脚本】筛选期后转销记录：预付账款贷方发生额对应的收货/转销明细，与存货、在建工程明细账核对。
2. 【人工+脚本】检查相关凭证（入库单/验收单），核实期后已收到实物并转销，分析资产负债表日预付账款的真实性与完整性。
3. 【脚本】红字冲销检查：筛出全部红字冲销记录，检查冲销依据与资金流向，确保不存在虚构增加预付账款的情况（虚构预付→期后冲回是典型舞弊痕迹）。
4. 结果写入 Z-3-05（期后转销区+红字冲销区），同步修订记录。

## 质量门

- 期后转销核对有凭证索引；红字冲销 100% 有依据检查结论；
- 期末大额预付且期后冲回的记录单独标注并升级。

## 升级路径

- 无实物支持的大额期后冲销、虚构预付迹象 → 升级项目经理（资金占用/舞弊风险）。
