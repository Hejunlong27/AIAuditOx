# P04 预付账款函证

> 来源：Z1123 程序3（实施函证程序）｜认定：E、C、A｜产出：Z-3-04 函证结果汇总表

## 输入

- 预付账款余额清单（选取供应商样本）、询证函模板、回函

## Steps（人工主导，技能做数据准备与核对）

1. 【脚本】生成函证样本清单（大额供应商全覆盖+账龄长+异常项+随机），记录样本量与选样依据。
2. 【人工】寄发询证函；技能跟踪发函与回函状态。
3. 【脚本】编制函证结果汇总表，回函确认金额与账面比较，不符事项输出清单。
4. 【规则】调查不符事项，确定是否表明存在错报（检查合同/付款凭证支持性文件）。
5. 【规则】未回函实施替代程序（期后收货核对/采购合同与付款凭证检查，联动 P05/P06），保持关注并调整进一步程序。
6. 结果写入 Z-3-04（发函清单/回函核对/不符调查/替代程序区），同步修订记录。

## 质量门

- 函证样本覆盖与选样依据记录；不符事项 100% 有调查结论；未回函替代程序齐备。

## 升级路径

- 回函差异重大或发现函证舞弊迹象 → 升级项目经理（参照函证舞弊风险迹象核对表）。
