## 程序库映射完整性

Z1123 共 1 项实质性分析程序 + 6 项其他实质性程序，全部映射：分析1→P02；程序1→P01；程序2→P03；程序3→P04；程序4→P05；程序5→P06；程序6→P07。

## 模板要点（含公式）

| 表 | 内置公式/机制 |
|----|-------------|
| Z-3-01 明细表 | 本位币=原币；合计加总；应付账款同挂/贷方余额/关联方标注列 + 双挂账排查区 |
| Z-3-02 分析程序 | 差异+波动率（除零保护）+超阈值 IF 判定 |
| Z-3-03 账龄构成 | 账龄分布占比公式（联动合计行）+ 一年以上逐项分析区 |
| Z-3-04 函证 | 回函差异 IF；回函状态下拉 |
| Z-3-05 期后转销 | 期后转销合计与占期末余额比例公式 + 红字冲销检查区 |

## 跨科目联动

- 预付/应付双挂账 → 联动 F-4 应付账款技能；
- 转其他应收款/坏账 → 联动 Z-4 其他应收款与 Z-2 坏账体系；
- 期后转销收货 → 联动 Z-5 存货 / Z-12 在建工程；
- 付款真实性 → 联动 Z-1 货币资金组（银行支付凭证）。

## 制式遵循

强制遵循全局标准技能 auditox-wp-standard（四段式制式 + 副本先行 + 修订记录）。
