# P04 期后付款与未入账负债检查

> 来源：F2241 程序库 其他4｜认定：C、A｜产出：F-12-04
> 执行方式：自动（期后付款匹配+截止）+人工确认｜确定性工具：cutoff_test、sampling_draw

## 输入

- 财务报表日后付款记录
- 期后收到的供应商发票
- 期后会议纪要
- 期后银行流水
- 抽样参数

## Steps

1. 【规则】复核期后付款、发票及会议纪要
   - （1）分析财务报表日后的付款并与支持性文件核对；
   - （2）复核财务报表日后的会议纪要及收到的发票，以确认是否存在未入账的负债，并检查年末存在的所有负债是否均已记录在财务报表中；
   - （3）记录选样依据。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 凭证号或发票号 | 文本 | 期后付款/发票 | 非空 |
| 业务发生日 | 日期 | 发票或合同 | 非空 |
| 入账期间 | 文本 | 明细账 | 格式 YYYY-MM |
| 金额 | 金额 | 发票或明细账 | 与凭证一致 |
| 期后付款日期 | 日期 | 银行流水 | 非空 |
| 期后付款金额 | 金额 | 银行流水 | 与流水一致 |
| 是否跨期 | 文本 | cutoff_test 判定 | 跨期时标注 |
| 是否存在未入账负债 | 文本 | 人工判断 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 期后付款 100% 与支持性文件核对，财务报表日后会议纪要与发票已复核
- 期末存在的所有负债已确认均已记录在财务报表中，未入账负债已识别
- 记录选样依据，抽样可复现

## 升级路径

- 存在重大未入账负债 → 升级项目经理，按完整性错报累积并提请调整
- 跨期呈系统性偏差 → 升级，评估采购与费用入账控制缺陷
- 期后会议纪要显示重大承诺或诉讼 → 升级，联动或有事项与预计负债程序
