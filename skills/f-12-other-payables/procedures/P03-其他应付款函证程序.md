# P03 其他应付款函证程序

> 来源：F2241 程序库 其他2｜认定：C、E、A｜产出：F-12-03
> 执行方式：人工为主（函证寄发/跟函）+控制表自动｜**必须留人**（Agent 不得代替执行）

## 输入

- 其他应付款明细表
- 对方单位名称与地址清单
- 函证控制表
- 回函
- 替代程序资料（支持性发票、对账单）

## Steps

1. 【人工】实施函证程序：
   - （1）编制其他应付款函证结果汇总表，检查回函真实性；
   - （2）调查不符事项，获取相关支持性证据，确定是否表明存在错报，并对可能显示舞弊的迹象保持职业怀疑；
   - （3）对未作回复的函证，将XXX与相关支持性发票和证据，或者对账单进行核对。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 对方单位 | 文本 | 明细表 | 非空 |
| 函证金额 | 金额 | 明细表 | 与总账一致 |
| 发函日期 | 日期 | 函证控制表 | 非空 |
| 回函日期 | 日期 | 回函 | 非空 |
| 回函金额 | 金额 | 回函 | 与回函一致 |
| 差异 | 金额 | 账面 − 回函 | = 差额 |
| 差异原因 | 文本 | 人工填写 | 有差异时必有 |
| 替代程序 | 文本 | 人工填写 | 未回函时必有 |
| 结论 | 文本 | 人工填写 | 非空 |

## 质量门

- 大额及异常余额 100% 发函，函证范围与样本量记录在函证控制表
- 未回函项目 100% 实施替代程序
- 回函不符事项已调查并获取支持性证据，对可能显示舞弊的迹象保持职业怀疑
- 函证寄发与跟函由人工执行，Agent 不得代为执行

## 升级路径

- 回函差异无法解释且金额重大 → 升级项目经理，评估是否存在未入账负债或错报
- 发现可能显示舞弊的迹象 → 立即升级，按舞弊事项处理
- 回函率显著偏低 → 升级，扩大替代程序范围
