# P07 预提费用会计估计评价

> 来源：F2241 程序库 其他6｜认定：C、E、A、V｜产出：F-12-07
> 执行方式：人工为主（估计流程与假设评价）｜确定性工具：provision_calc｜**必须留人**（Agent 不得代替执行）

## 输入

- 管理层对预提费用估计的流程说明
- 估计所依据的数据与假设
- 历史数据与行业数据
- 估计模型
- 专家工作资料
- 审计会计估计工作簿

## Steps

1. 【规则】通过复核和测试管理层对预提费用作出估计的流程，评价对预提费用作出估计的合理性。
   - （1）识别作出估计所依据的数据。考虑其是否相关、可靠、足以达到目的；
   - （2）评价假设是否合理，是否与支持性证据、相关历史数据、行业数据以及当前趋势相符。记录职业怀疑态度；
   - （3）考虑管理层使用的模型的适当性；
   - （4）考虑利用专家的工作；
   - （5）测试管理层依据假设和数据对预提费用作出估计的计算过程；
   - （6）评价估计的总体合理性。
   - 请使用《3.EG.05 审计会计估计工作簿》或《3.EG.06 审计会计估计模板》记录对估计的合理性实施的工作。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 估计事项 | 文本 | 管理层估计清单 | 非空 |
| 依据数据 | 文本 | 管理层说明 | 非空 |
| 数据是否相关可靠充分 | 文本 | 人工判断 | 枚举（是/否） |
| 关键假设 | 文本 | 管理层说明 | 非空 |
| 假设是否合理 | 文本 | 人工判断 | 枚举（合理/不合理） |
| 与历史及行业数据是否相符 | 文本 | 人工判断 | 枚举（相符/不符） |
| 模型是否适当 | 文本 | 人工判断 | 枚举（适当/不适当） |
| 计算过程复核 | 金额 | recalc_check 重算 | = 重算结果 |
| 总体合理性 | 文本 | 人工填写 | 枚举（合理/不合理） |

## 质量门

- 估计所依据的数据已识别并评价其相关性、可靠性与充分性
- 假设的合理性已评价，并与支持性证据、历史数据、行业数据及当前趋势相符，已记录职业怀疑态度
- 管理层使用模型的适当性已考虑，必要时已利用专家的工作
- 管理层依据假设和数据作出的计算过程已测试，估计的总体合理性已评价
- 已使用《审计会计估计工作簿》或模板记录，本卡必须人工判断

## 升级路径

- 假设与历史或行业数据严重不符且无合理解释 → 升级项目经理，评估估计错报
- 管理层拒绝提供估计依据或流程不透明 → 升级，评估管理层凌驾控制之上的风险
- 估计涉及专门领域 → 升级，考虑利用专家并完成专家工作模板
