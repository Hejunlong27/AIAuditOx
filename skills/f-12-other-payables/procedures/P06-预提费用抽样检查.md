# P06 预提费用抽样检查

> 来源：F2241 程序库 其他5｜认定：E、A、V｜产出：F-12-06
> 执行方式：自动（抽样+验算）+人工确认｜确定性工具：sampling_draw、provision_calc

## 输入

- 其他应付或预提费用清单
- 预提计算表与支持性文件
- 费用合同或协议
- 期后付款记录
- 抽样参数

## Steps

1. 【规则】从其他应付或预提费用清单中选取样本（确信已执行程序测试IPE的可靠性）。记录样本量和选样依据，检查其他应付或预提的支持性文件：
   - （1）确定预提费用的计算基础和计算方法，确信该基础和方法与以前年度以及适用的财务报告编制基础保持一致；
   - （2）验算预提费用的金额；
   - （3）复核预提费用的合理性；
   - （4）如可能，将预提费用与期后付款进行比较以确定其合理性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 项目 | 文本 | 预提清单 | 非空 |
| 对方单位 | 文本 | 合同或发票 | 非空 |
| 预提金额 | 金额 | 明细账 | 与总账一致 |
| 计算基础与方法 | 文本 | 预提计算表 | 非空 |
| 与以前年度是否一致 | 文本 | 人工判断 | 枚举（是/否） |
| 验算金额 | 金额 | recalc_check 重算 | = 重算结果 |
| 差异 | 金额 | 验算 − 账面 | = 差额 |
| 与期后付款比较 | 金额 | 期后付款记录 | 差异超容差须说明 |
| 合理性 | 文本 | 人工填写 | 枚举（合理/不合理） |

## 质量门

- 抽样样本量由 sampling_draw 以固定 seed 生成，可复现，并记录选样依据与样本量
- 预提费用的计算基础与方法与以前年度及适用财务报告编制基础保持一致
- 验算金额正确，已与期后付款比较以确定其合理性
- 已执行程序测试 IPE（被审计单位提供的信息）的可靠性

## 升级路径

- 计算基础或方法变更无依据 → 升级项目经理，评估对损益的影响
- 验算差异重大或与期后付款严重不符 → 升级，评估预提不足或虚增负债
- 预提长期未使用且无对应义务 → 升级，评估转回及对损益的影响
