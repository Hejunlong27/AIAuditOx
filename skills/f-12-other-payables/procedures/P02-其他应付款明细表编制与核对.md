# P02 其他应付款明细表编制与核对

> 来源：F2241 程序库 其他1｜认定：E、A｜产出：F-12-02
> 执行方式：自动（脚本核对）｜确定性工具：recalc_check、balance_confirm、rule_check

## 输入

- 其他应付款明细表（按项目或对方单位）
- 总账 2241 余额及明细账合计数
- 上年审定数
- 上年调整分录

## Steps

1. 【规则】获取其他应付款明细表，并执行下列程序：
   - （1）将期初余额与上年财务报表进行核对；
   - （2）复核加计是否正确，并与报表数、总账数及明细账合计数核对是否相符；
   - （3）确保会计政策得到一贯运用，或会计政策的变更得到正确处理、列报和披露；
   - （4）当存在对上年的调整时，确保相关分录已正确录入总账；
   - （5）分析有借方余额的项目，查明原因，必要时，作重分类调整。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 项目或对方单位 | 文本 | 明细表 | 非空 |
| 款项性质 | 文本 | 明细表 | 非空 |
| 期初余额 | 金额 | 明细账 | 与上年审定数衔接 |
| 本期增加 | 金额 | 明细账贷方 | 与总账一致 |
| 本期减少 | 金额 | 明细账借方 | 与总账一致 |
| 期末余额 | 金额 | 期初 + 增加 − 减少 | = 期初 + 增 − 减 |
| 其中借方余额 | 金额 | 明细账 | 非空时须查明原因 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异或借方余额必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数（四方相符）
- 会计政策得到一贯运用，上年调整分录已正确录入总账
- 借方余额项目已查明原因并评估是否需重分类调整

## 升级路径

- 借方余额无法解释 → 升级项目经理，评估重分类为其他应收款
- 上年调整分录未正确录入 → 升级，评估期初余额与本期损益的影响
