# P05 售后回购融入资金检查

> 来源：F2241 程序库 其他3｜认定：C、E、A｜产出：F-12-05
> 执行方式：自动（利息分摊重算）+人工判断｜确定性工具：recalc_check、rule_check

## 输入

- 售后回购协议
- 回购价格与原销售价格
- 回购期间
- 账务记录与凭证

## Steps

1. 【规则】检查售后回购方式融入资金：
   - （1）检查售后回购方式融入资金的会计处理是否正确；
   - （2）回购价格与原销售价格之间的差额，是否在回购期间内按期计提利息费用；
   - （3）按照合同约定回购该项商品时，是否借记该科目。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 交易对方 | 文本 | 协议 | 非空 |
| 原销售价格 | 金额 | 协议 | 与协议一致 |
| 回购价格 | 金额 | 协议 | 与协议一致 |
| 差额 | 金额 | 回购价格 − 原销售价格 | = 差额 |
| 回购期间 | 文本 | 协议 | 非空 |
| 按期计提利息费用 | 金额 | recalc_check 重算 | 按期间分摊正确 |
| 会计处理是否正确 | 文本 | 人工判断 | 枚举（是/否） |
| 回购时是否按约定借记该科目 | 文本 | 账务记录 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 售后回购按融资业务处理，回购价格与原销售价格的差额在回购期间内按期计提利息费用
- 回购该项商品时已按合同约定借记其他应付款科目
- 会计处理符合准则，未错误确认为销售收入

## 升级路径

- 错误确认为销售收入 → 升级项目经理，评估收入与负债的双向错报
- 未按期计提利息费用 → 升级，评估对财务费用与负债余额的影响
- 回购条款实质为销售且风险报酬已转移 → 升级，评估收入确认时点
