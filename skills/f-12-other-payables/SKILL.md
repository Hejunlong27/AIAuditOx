> **【技能来源与使用声明】**
> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。
> **作者与许可**：何小疯27 · 免费开源 · 禁止商用转售
> **技能主页**：aiauditox.l.cd ｜ **开发动态**：公众号‘小小审计员日记’

> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式：一、项目基本信息/二、审计目标和程序说明/三、审计程序执行结果/四、审计说明 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：所有其他应付款均已记录（含未列示于账面者）；存在（E）：记录的其他应付款于资产负债表日存在且归被审计单位拥有或控制；准确性（A）：金额正确计算、适当加总且准确记录；计价（V）：按恰当金额计价（含减值、摊销、公允价值等调整）；列报（P）：分类、披露恰当 |
| 所需资料 | 其他应付款明细表与明细账（含预提费用）、总账与报表、其他应付或预提费用清单与支持性文件、预提计算表、费用合同或协议、期后付款记录与期后收到的发票、期后会议纪要、售后回购协议、管理层对预提费用估计的流程说明与依据、历史与行业数据、估计模型、专家工作资料、关联方往来清单、报表附注 |
| 所需数据 | 各项目期初与期末余额、本期增减发生额、借方余额项目、预提金额与计算基础、验算金额、期后付款金额与日期、售后回购的原销售价格与回购价格及回购期间、估计所依据的数据与关键假设、关联方往来金额、实际执行的重要性水平 |
| 核对逻辑 | 1. 实质性分析程序（将实际值与预期值进行比较；）；2. 其他应付款明细表编制与核对（获取其他应付款明细表，并执行下列程序）；3. 其他应付款函证程序（实施函证程序）；4. 期后付款与未入账负债检查（复核期后付款、发票及会议纪要）；5. 售后回购融入资金检查（检查售后回购方式融入资金）；6. 预提费用抽样检查（从其他应付或预提费用清单中选取样本（确信已执行程序测试IPE的可靠性）。记录样本量和选样依据，检查其他应付或预提的支持性文件）；7. 预提费用会计估计评价（通过复核和测试管理层对预提费用作出估计的流程，评价对预提费用作出估计的合理性。）；8. 其他应付款披露检查（审计其他应付款的披露） |
| 底稿编制内容 | 见「产出清单」，全部底稿采用四段式制式：底稿名称与表头（项目基本信息）→ 审计目标和程序说明 → 审计程序执行结果 → 审计说明。共 8 张底稿。 |
| 输出格式 | xlsx 工作簿（模板见 templates/F-12其他应付款审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/F-12其他应付款/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性（见六要素「所需资料」）；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → P02 → P03 → P04 → P05 → P06 → P07 → P08；人工程序标记待办并跟踪完成状态。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：按各程序卡「升级路径」处理，发现异常事项逐级升级。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P08 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：明细表合计数 = 总账数 = 报表数；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源；差异事项均有解释与支持文件。
- 异常闭环：所有异常事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料 只读）；跳过强制程序。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 其他应付款是「杂项负债」，最容易藏未入账负债与跨期费用，期后付款与期后发票检查是本卡的核心程序，不可省略
- 预提费用的会计估计评价属于审计会计估计范畴，须评价数据、假设、模型与计算过程，并记录职业怀疑；不能只验算金额
- 预提费用的计算基础与方法应与以前年度及适用财务报告编制基础保持一致，方法变更无依据会导致损益跨期
- 售后回购融入资金属于融资业务，回购价与原售价的差额应在回购期间按期计提利息费用，错误确认为销售收入会同时虚增收入与负债
- 借方余额应重分类为其他应收款，长期挂账的借方余额可能是资金占用甚至舞弊信号
- 期后会议纪要常揭示未入账的承诺、诉讼或担保，须与或有事项程序联动
