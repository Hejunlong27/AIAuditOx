# P08 弃置费用与固定资产重估检查

> 来源：Z1601+Z1602+Z1603 程序库 Z1601 程序10、Z1601 程序11｜认定：C、E、A、V｜产出：Z-16-08
> 执行方式：自动重算+人工评价假设｜确定性工具：recalc_check

## 输入

- 弃置义务合同/法规、弃置费用估算、折现率、资产重估报告、评估师资质、账面价值与累计折旧资料

## Steps

1. 【脚本】检查固定资产是否存在弃置费用，如果存在弃置费用，检查弃置费用的估计方法和弃置费用现值的计算是否合理，会计处理是否正确。
2. 【规则】评价资产重估价值
   - 对于本期进行的资产重估，确定进行重估是否符合适用的财务报告编制基础的规定。
   - 检查资产重估的支持性文件，确保基于现有资产用途（如适用）进行重估。
   - 确定数据的可靠性、估值模型的适当性以及提供给估值人员的假设或用于确定价值的输入的合理性。
   - 记录如何保持职业怀疑，以及是否遵守了《中国注册会计师审计准则1321号—审计会计估计》的相关要求。
   - 如果利用了管理层的专家和/或注册会计师的专家的工作，确保适当记录了与该专家相关的工作。
   - 根据租金收益率考虑房地产估值的适当性（如适用）。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产/资产组 | 文本 | 减值测试表 | 资产组划分合理 |
| 账面价值 | 金额 | 明细账 | 与总账核对 |
| 可收回金额 | 金额 | 评估报告/模型 | 公允价值减处置费用与使用价值孰高 |
| 现有准备 | 金额 | 准备明细账 | 期初+计提-核销 |
| 应有准备 | 金额 | 审计重算 | 账面价值-可收回金额且不低于零 |
| 本期计提/核销 | 金额 | 计算表 | 会计分录正确 |
| 减值迹象 | 文本 | 管理层评估/外部证据 | 迹象须有支持 |
| 关键假设/专家 | 文本 | 模型/专家报告 | 假设合理性已评价 |
| 结论 | 文本 | 审计判断 | 充分/不足/需调整 |

## 质量门

- 弃置费用现值重算正确；重估模型、假设和评估师工作已评价；会计处理符合准则

## 升级路径

- 弃置义务金额重大、假设缺乏依据或重估增值异常时升级项目经理并考虑专家工作。
