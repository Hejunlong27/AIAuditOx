# P12 固定资产披露检查

> 来源：Z1601+Z1602+Z1603 程序库 Z1601 程序16｜认定：P｜产出：Z-16-12
> 执行方式：自动核对+人工确认｜确定性工具：rule_check

## 输入

- 固定资产附注、审定表、折旧政策、减值准备、抵押担保、持有待售及关联交易披露

## Steps

1. 【规则】审计固定资产的披露
   - 检查相关财务报表附注披露的准确性和完整性。
   - 获取固定资产明细表，并执行下列程序：
   - （1）将期初余额与上年财务报表进行核对；
   - （2）复核加计是否正确，并与报表数、总账数及明细账合计数核对是否相符，结合固定资产减值准备、资产减值损失科目与报表数核对是否相符；
   - （3）确保会计政策得到一贯运用，或会计政策的变更得到正确处理、列报和披露；
   - （4）当存在对上年的调整时，确保相关分录已正确录入总账。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 披露项目 | 文本 | 报表附注 | 披露要求逐项覆盖 |
| 附注表述/金额 | 文本 | 报表附注 | 与附注原文一致 |
| 审定数 | 金额 | 审定表 | 与底稿勾稽 |
| 差异 | 金额 | 计算表 | 附注-审定数 |
| 披露要求 | 文本 | 会计准则/格式 | 引用依据 |
| 完整性 | 文本 | 规则核对 | 完整/缺失/不适用 |
| 证据索引 | 文本 | 底稿索引 | 可回溯 |
| 结论 | 文本 | 审计判断 | 是否需补充披露 |

## 质量门

- 披露数=审定数；会计政策、增减变动、受限资产和减值信息完整

## 升级路径

- 应披露未披露或披露口径与准则不符时升级项目经理并提出补充披露。
