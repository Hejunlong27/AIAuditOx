# P07 持有待售、资产变更会议记录与维修费测试

> 来源：Z1601+Z1602+Z1603 程序库 Z1601 程序7、Z1601 程序8、Z1601 程序9｜认定：C、E、A｜产出：Z-16-07
> 执行方式：自动筛样+人工判断｜确定性工具：sampling_draw、threshold_flag

## 输入

- 持有待售资产清单及出售计划、董事会/管理层会议纪要、维修费总账及发票、工程/服务内容说明

## Steps

1. 【规则】检查持有待售固定资产
   - 获取持有待售固定资产的相关证明文件，并作相应记录，检查对其预计净残值调整是否正确、会计处理是否正确：
   - 考虑关于售价和完工成本的假设，并与之前的评估对比；
   - 了解企业过往的预测能力和准确预测的相关经验，据此评价采用完工百分比法来计算以及收入成本预测的合理性；
   - 若发现资产有损坏，考虑是否需要计提减值；
   - 对于占所有资产比重较大的或者具有特殊性的不动产，与管理层讨论，验证所获取解释的真实性；
   - 考虑滞销资产是否表明可能存在减值；
   - 将转出的成本与存货清单核对；
   - 对销售成本抽样，并追查至发票。
2. 【规则】复核有关固定资产变更的会议记录
   - （1）本期新增/处置的重大资产；
   - （2）期后取得资产的授权情况；
   - （3）闲置资产或未达到产能的资产。
   - 复核董事会/管理层会议的会议记录，了解下列详细信息：
   - 确保财务报表中的数字和披露支持发现的这些情况。
3. 【规则】维护修理费测试
   - （1）获取被审计单位本期维护修理费总账的详细信息。
   - （2）记录选样依据，选取维护修理费项目进行测试。
   - （3）复核发票，评估维护修理费金额是否得到准确记录。
   - （4）复核维护修理的相关工作、提供的服务或对固定资产实施的改进的性质，确定相关支出是否符合资本化条件，或者是否作为费用予以正确记录。如必要，对任何应当资本化的费用提出调整建议，或记录于错报汇总表。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 样本编号 | 文本 | 抽样表 | 样本量与依据已记录 |
| 项目/合同名称 | 文本 | 明细账/台账 | 与账面一致 |
| 账面金额 | 金额 | 明细账 | 金额精确匹配 |
| 支持文件日期 | 日期 | 发票/合同/凭证 | 日期在审计期间内 |
| 支持文件编号 | 文本 | 发票/合同/凭证 | 可回溯 |
| 核对内容 | 文本 | 程序表 | 覆盖授权、存在、计价 |
| 独立证据 | 文本 | 外部/现场证据 | 必要时取得外部证据 |
| 异常事项 | 文本 | 审计判断 | 异常不得留空 |
| 结论 | 文本 | 审计判断 | 支持/不支持账面记录 |

## 质量门

- 持有待售分类与计量有依据；会议决议已勾稽报表；维修费资本化/费用化判断有证据

## 升级路径

- 疑似应资本化支出被费用化、持有待售分类错误或重大资产变动未披露时升级项目经理。
