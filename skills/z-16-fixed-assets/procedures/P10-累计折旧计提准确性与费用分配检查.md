# P10 累计折旧计提准确性与费用分配检查

> 来源：Z1601+Z1602+Z1603 程序库 Z1602 程序2、Z1602 程序4、Z1602 程序5｜认定：A｜产出：Z-16-10
> 执行方式：自动重算+人工复核政策｜确定性工具：recalc_check、threshold_flag

## 输入

- 折旧清单、固定资产原值及增减变动、会计政策、预计使用寿命/残值、累计折旧明细账、成本费用折旧分配表

## Steps

1. 【规则】抽样检查折旧费用
   - （1）获取折旧清单;
   - （2）记录样本量和选样依据：
   - （1）被审计单位制定的折旧政策和方法是否符合相关会计准则的规定；
   - （2）确定其所采用的折旧方法能否在固定资产预计使用寿命内合理分摊其成本，前后期是否一致；
   - （3）确定的预计使用寿命和预计净残值是否合理。
   - ①将计提折旧资产的原值与支持性文件进行核对；
   - ②检查折旧费用计算的准确性；
   - ③检查本期折旧率/折旧政策与上期的一致性，并判断以下数值的合理性：
   - i估计的残值；
   - ii剩余使用寿命，对于使用权资产，如果承租人能够合理确定租赁期届满时取得租赁资产所有权的；
   - iii租赁期与租赁资产剩余使用寿命两者孰短，如果承租人无法合理确定租赁期届满时能够取得租赁资产所有权。
   - ④复核利润表中折旧费用分类的恰当性。
   - 注意固定资产增减变动时，有关折旧的会计处理是否符合规定，查明通过更新改造、接受捐赠或融资租入而增加的固定资产的折旧费用计算是否正确。对已经交付使用但尚未办理竣工结算等手续的固定资产，检查其是否按规定计提折旧。对未使用、不需用固定资产是否已按规定计提折旧，追溯调整依据是否充分，计算是否正确。检查全额计提减值准备的固定资产是否不再计提折旧，计提减值准备后重新计算折旧是否正确，对于已提足折旧仍继续使用的固定资产，获取相关证明文件。
   - 检查折旧政策：
2. 【规则】检查累计折旧的减少是否合理，会计处理是否正确。
3. 【规则】将“累计折旧”账户贷方的本期计提折旧额与相应的成本费用中的折旧费用明细账户的借方相比较，检查本期所计提折旧金额是否已全部摊入本期产品成本或费用。若存在差异，应追查原因，并考虑是否应建议作适当调整。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产类别/项目 | 文本 | 折旧/摊销清单 | 类别完整 |
| 原值 | 金额 | 资产台账 | 与总账核对 |
| 折旧/摊销方法 | 文本 | 会计政策 | 前后期一致 |
| 预计使用寿命/残值率 | 文本 | 会计政策/评估 | 估计合理 |
| 本期应计折旧/摊销 | 金额 | 审计重算 | 按政策独立重算 |
| 账面折旧/摊销 | 金额 | 明细账 | 贷方发生额 |
| 差异 | 金额 | 计算表 | 应计-账面 |
| 分配核对 | 金额 | 成本费用明细账 | 折旧分配额勾稽 |
| 结论 | 文本 | 审计判断 | 差异是否需调整 |

## 质量门

- 重要类别独立重算；折旧分配额=累计折旧贷方发生额；政策变更处理正确

## 升级路径

- 折旧差异重大、折旧年限明显偏长或费用分配异常时升级项目经理并评估错报。
