# P09 闲置资产、保险、关联交易与抵押担保检查

> 来源：Z1601+Z1602+Z1603 程序库 Z1601 程序12、Z1601 程序13、Z1601 程序14、Z1601 程序15｜认定：C、E、A、V、P｜产出：Z-16-09
> 执行方式：规则筛异常+人工检查｜确定性工具：rule_check、threshold_flag

## 输入

- 闲置/停用资产清单、保险单与保额、关联方清单及交易台账、借款合同、抵押/担保登记文件、资产明细账

## Steps

1. 【规则】检查停用与闲置固定资产：
   - （1）获取暂时闲置固定资产的相关证明文件，并观察其实际状况，检查是否已按规定计提折旧，相关的会计处理是否正确；
   - （2）检查因修理、更新改造而停止使用的固定资产的会计处理是否正确。
2. 【规则】检查固定资产保险情况，复核保险范围是否足够。
3. 【规则】检查有无与关联方的固定资产购售活动，是否经适当授权，交易价格是否公允。对于合并范围内的购售活动，记录应予合并抵销的金额。
4. 【规则】检查固定资产的抵押、担保情况。结合对银行借款等的检查，了解固定资产是否存在重大的抵押、担保情况。如存在，应取证，并作相应的记录，同时提请被审计单位作恰当披露。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产/资产组 | 文本 | 减值测试表 | 资产组划分合理 |
| 账面价值 | 金额 | 明细账 | 与总账核对 |
| 可收回金额 | 金额 | 评估报告/模型 | 公允价值减处置费用与使用价值孰高 |
| 现有准备 | 金额 | 准备明细账 | 期初+计提-核销 |
| 应有准备 | 金额 | 审计重算 | 账面价值-可收回金额且不低于零 |
| 本期计提/核销 | 金额 | 计算表 | 会计分录正确 |
| 减值迹象 | 文本 | 管理层评估/外部证据 | 迹象须有支持 |
| 关键假设/专家 | 文本 | 模型/专家报告 | 假设合理性已评价 |
| 结论 | 文本 | 审计判断 | 充分/不足/需调整 |

## 质量门

- 闲置资产均评价减值；保险范围与资产风险匹配；关联交易和受限资产完整披露

## 升级路径

- 重大资产受限、关联交易价格异常或保险明显不足时升级项目经理并联动关联方/借款程序。
