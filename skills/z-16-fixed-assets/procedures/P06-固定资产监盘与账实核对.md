# P06 固定资产监盘与账实核对

> 来源：Z1601+Z1602+Z1603 程序库 Z1601 程序6｜认定：C、E、V｜产出：Z-16-06
> 执行方式：人工主导（现场监盘）+自动比对｜确定性工具：sampling_draw｜**必须留人**（Agent 不得代替执行）

## 输入

- 监盘计划、固定资产盘点表、资产标签、现场照片/记录、固定资产台账

## Steps

1. 【人工】抽样监盘固定资产并追查至固定资产台账
   - （1）从选取的固定资产追查至固定资产台账；
   - （2）对于发现的闲置或低使用率资产，确定固定资产减值准备计提是否充分；
   - （3）与固定资产的性质和状况进行比较，评价其账面价值是否合理；
   - 从现场监盘的固定资产的清单测试下列内容，记录样本量和选样依据：

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产编号 | 文本 | 资产标签/台账 | 编号唯一 |
| 资产名称 | 文本 | 台账/铭牌 | 名称规格一致 |
| 存放/工程地点 | 文本 | 现场记录 | 与台账地址一致 |
| 账面价值 | 金额 | 明细账 | 与盘点清单一致 |
| 现场状态 | 文本 | 监盘记录 | 存在/毁损/闲置等 |
| 使用/完工状态 | 文本 | 现场观察/访谈 | 与账面状态一致 |
| 权属/标识 | 文本 | 产权证/铭牌 | 权属清晰 |
| 差异 | 文本 | 核对表 | 账实差异逐项说明 |
| 结论 | 文本 | 审计判断 | 是否需调整/减值 |

## 质量门

- 监盘覆盖重要地点和重要资产；账实差异100%追查；闲置/低使用率资产已评价减值

## 升级路径

- 账实差异重大、资产不存在或监盘范围受限时升级项目经理并评估审计意见影响。
