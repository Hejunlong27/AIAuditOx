# P03 固定资产新增检查

> 来源：Z1601+Z1602+Z1603 程序库 Z1601 程序3｜认定：E、A、P｜产出：Z-16-03
> 执行方式：自动筛样+人工核单｜确定性工具：sampling_draw

## 输入

- 本期固定资产增加明细、采购合同、发票、验收单、付款凭证、授权审批、资产启用记录

## Steps

1. 【规则】抽样检查固定资产的新增情况：
   - （1）获取固定资产明细表，确保期初余额和期末余额与总账核对一致。
   - （2）从固定资产增加明细中抽样选取新增项目（根据样本量工作表，如适用）。针对选取的每个项目，获取支持性文件（发票，授权文件，付款单等），检查新增项目的存在，固定资产启用日期与可使用年限的准确性，以及根据复核文件描述的资产性质，固定资产的分类是否恰当。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 样本编号 | 文本 | 抽样表 | 样本量与依据已记录 |
| 项目/合同名称 | 文本 | 明细账/台账 | 与账面一致 |
| 账面金额 | 金额 | 明细账 | 金额精确匹配 |
| 支持文件日期 | 日期 | 发票/合同/凭证 | 日期在审计期间内 |
| 支持文件编号 | 文本 | 发票/合同/凭证 | 可回溯 |
| 核对内容 | 文本 | 程序表 | 覆盖授权、存在、计价 |
| 独立证据 | 文本 | 外部/现场证据 | 必要时取得外部证据 |
| 异常事项 | 文本 | 审计判断 | 异常不得留空 |
| 结论 | 文本 | 审计判断 | 支持/不支持账面记录 |

## 质量门

- 新增样本覆盖大额及异常项目；存在、启用日期、分类和使用寿命均有证据

## 升级路径

- 资本化支出无依据、验收或付款对象异常时升级项目经理并联动采购与资金程序。
