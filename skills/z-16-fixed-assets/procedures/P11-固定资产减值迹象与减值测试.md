# P11 固定资产减值迹象与减值测试

> 来源：Z1601+Z1602+Z1603 程序库 Z1603 程序2、Z1603 程序3、Z1603 程序4、Z1603 程序5｜认定：V｜产出：Z-16-11
> 执行方式：人工主导（减值判断）+自动重算｜确定性工具：recalc_check｜**必须留人**（Agent 不得代替执行）

## 输入

- 减值迹象清单、管理层减值测试、资产组划分、可收回金额模型、评估报告、专家报告、减值准备明细账、核销审批

## Steps

1. 【规则】考虑固定资产减值迹象并确定是否需要计提减值准备
   - （1）根据适用的财务报告编制基础，考虑是否存在减值迹象（例如，被审计单位改变其固定资产使用方式、市场价值缩水、资产损毁、经营亏损等）；
   - （2）如果存在减值迹象，评价根据适用的财务报告编制基础计算的可收回金额。通常涉及考虑模型、假设、原始数据和结果，对管理层作出的估计进行审计。记录如何运用职业怀疑态度。考虑使用注册会计师专家的必要性；                                                                    （3）检查账面价值并确定是否需要计提减值准备；
   - （4）如果需要计提减值准备，检查计算并确保已按照适用的财务报告编制基础对减值准备进行了会计处理。
2. 【规则】检查固定资产减值准备计提和核销的批准程序，取得书面报告等证明文件。实际发生的固定资产损失转销是否符合有关法规的规定完成审批手续，会计处理是否正确。
3. 【规则】对于存在减值迹象的固定资产，实施以下审计程序：
   - （1）评价管理层对资产组（CGUs）的确定是否合理；
   - （2）评价分配至每个资产组的资产和相关账面价值的适当性；
   - （3）确定是否可以在单项资产层面评估减值，或是否必须在资产组层面评估减值。考虑使用减值模板——资产组层面文件进行减值评估。
   - （4）检查计提固定资产减值准备的依据是否充分，会计处理是否正确。
4. 【规则】检查是否存在转回固定资产减值准备的情况，确定减值准备在以后会计期间没有转回。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 资产/资产组 | 文本 | 减值测试表 | 资产组划分合理 |
| 账面价值 | 金额 | 明细账 | 与总账核对 |
| 可收回金额 | 金额 | 评估报告/模型 | 公允价值减处置费用与使用价值孰高 |
| 现有准备 | 金额 | 准备明细账 | 期初+计提-核销 |
| 应有准备 | 金额 | 审计重算 | 账面价值-可收回金额且不低于零 |
| 本期计提/核销 | 金额 | 计算表 | 会计分录正确 |
| 减值迹象 | 文本 | 管理层评估/外部证据 | 迹象须有支持 |
| 关键假设/专家 | 文本 | 模型/专家报告 | 假设合理性已评价 |
| 结论 | 文本 | 审计判断 | 充分/不足/需调整 |

## 质量门

- 减值迹象逐项评价；资产组划分合理；关键假设和折现率有依据；准备不得转回

## 升级路径

- 可收回金额重大不确定、专家工作不足或发现准备转回时升级项目经理并考虑审计意见影响。
