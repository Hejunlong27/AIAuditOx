# P02 固定资产原值、折旧及减值率实质性分析

> 来源：Z1601+Z1602+Z1603 程序库 Z1601 分析1、Z1601 分析2、Z1601 分析3、Z1602 分析1、Z1602 分析2、Z1603 分析1｜认定：C、E、A、V｜产出：Z-16-02
> 执行方式：自动（预期值、差异和阈值）+人工调查｜确定性工具：recalc_check、threshold_flag

## 输入

- 分资产类别期初期末原值、增减变动、折旧政策、本期折旧、减值准备、上期比较数据、预算/产能等预期依据

## Steps

1. 【规则】根据资产类别、预算、产能及上期数据对固定资产原值/估值变动作出预期；
2. 【规则】将实际值与预期值进行比较；
3. 【规则】调查超过实际执行重要性水平既定比例或特定金额的差异，并针对这些差异获取解释和佐证证据。
   - 复核并说明固定资产原值/估值的变动：
4. 【规则】根据固定资产原值、增减变动和会计政策，按资产类别对折旧变动作出预期：
   - （1）将实际值与预期值进行比较；
   - （2）调查超过实际执行重要性水平既定比例或特定金额的差异，并针对这些差异获取解释和佐证证据。
5. 【脚本】比较各类别资产的实际折旧额与计算的折旧额：
   - （1）使用财务报表中会计政策规定的固定资产折旧率乘以调整本期新增/处置/已全额计提折旧的固定资产之后的账面价值，对本期的资产折旧额（按照资产类别）作出预期；
   - （2）将实际值与预期值进行比较；
   - （3）检查超过实际执行重要性水平既定比例或特定金额的差异，并获取相关说明和证据；
   - （4）确保本期使用的折旧率与上期一致。如果折旧率有差异，获取存在差异的理由，确保会计估计方面的任何变化都已得到正确处理/披露。
6. 【脚本】计算本期末固定资产减值准备占期末固定资产原值的比率，并与期初该比率比较，分析固定资产的质量状况。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析表 | 按类别/项目拆分 |
| 预期值 | 数值 | 审计模型 | 模型依据留痕 |
| 实际值 | 数值 | 总账/明细账 | 与账面核对 |
| 差异 | 金额 | 计算表 | 实际-预期 |
| 差异率 | 百分比 | 计算表 | 差异/预期，除零保护 |
| 重要性阈值 | 金额 | 计划阶段 | 记录实际执行重要性 |
| 是否超阈值 | 文本 | 规则判断 | 超阈值须调查 |
| 原因与证据 | 文本 | 访谈/支持文件 | 不能仅凭解释 |
| 结论 | 文本 | 审计判断 | 记录追加程序或调整 |

## 质量门

- 每个重要类别均建立预期并有依据；超阈值差异100%取得解释和佐证
