# P05 固定资产重要项目与权属检查

> 来源：Z1601+Z1602+Z1603 程序库 Z1601 程序5｜认定：E｜产出：Z-16-05
> 执行方式：自动筛样+人工检查权属｜确定性工具：sampling_draw

## 输入

- 固定资产台账、采购合同/发票、房地产权证、车辆登记证、融资租赁合同、留置/抵押文件、律师证明或公开登记查询

## Steps

1. 【规则】从固定资产台账中抽样检查重要项目
   - （1）获取固定资产台账并执行其他程序测试IPE的可靠性。
   - （2）记录样本量和选样依据：
   - （1）对外购的机器设备等固定资产，审核采购发票、采购合同等；
   - （2）对于房地产类固定资产，查阅有关的合同、产权证明、财产税单、抵押借款的还款凭据、保险单等书面文件，必要时，通过函证确认房契归属于律师、担保财产受益人（如抵押贷款银行）还是客户；
   - （3）对融资租入的固定资产，检查有关融资租赁合同；
   - （4）对汽车等运输设备，检查有关所有权证件等；
   - （5）对受留置权限制的固定资产，结合有关负债项目进行检查；
   - （6）对于正在办理权属证明的大额资产，应了解权属证明办理情况，确认是否存在权属纠纷或实质性障碍。
   - 对各类固定资产，获取、收集不同的证据以确定其是否归被审计单位所有：如适当，以上文件考虑通过公开渠道向登记机关核实相关信息，如不能核实，提请律师出具相关证明意见：

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 样本编号 | 文本 | 抽样表 | 样本量与依据已记录 |
| 项目/合同名称 | 文本 | 明细账/台账 | 与账面一致 |
| 账面金额 | 金额 | 明细账 | 金额精确匹配 |
| 支持文件日期 | 日期 | 发票/合同/凭证 | 日期在审计期间内 |
| 支持文件编号 | 文本 | 发票/合同/凭证 | 可回溯 |
| 核对内容 | 文本 | 程序表 | 覆盖授权、存在、计价 |
| 独立证据 | 文本 | 外部/现场证据 | 必要时取得外部证据 |
| 异常事项 | 文本 | 审计判断 | 异常不得留空 |
| 结论 | 文本 | 审计判断 | 支持/不支持账面记录 |

## 质量门

- 重要资产权属证据齐全；受限资产与负债程序勾稽；未办证资产逐项评估障碍

## 升级路径

- 权属不清、权证不在被审计单位名下或存在实质障碍时升级项目经理并评估减值/披露。
