# P04 固定资产清理长期挂账检查

> 来源：Z1606 程序库 Z1606 程序4｜认定：E｜产出：Z-19-04
> 执行方式：自动账龄筛选+人工调查｜确定性工具：threshold_flag

## 输入

- 清理明细账、挂账起始日期、处置进度说明、期后转销记录

## Steps

1. 【规则】检查固定资产清理是否长期挂账，如有，应作出记录，必要时建议作适当调整。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 分析表 | 按类别/项目拆分 |
| 预期值 | 数值 | 审计模型 | 模型依据留痕 |
| 实际值 | 数值 | 总账/明细账 | 与账面核对 |
| 差异 | 金额 | 计算表 | 实际-预期 |
| 差异率 | 百分比 | 计算表 | 差异/预期，除零保护 |
| 重要性阈值 | 金额 | 计划阶段 | 记录实际执行重要性 |
| 是否超阈值 | 文本 | 规则判断 | 超阈值须调查 |
| 原因与证据 | 文本 | 访谈/支持文件 | 不能仅凭解释 |
| 结论 | 文本 | 审计判断 | 记录追加程序或调整 |

## 质量门

- 长期挂账项目逐项说明原因；必要时提出调整或重分类建议

## 升级路径

- 长期挂账且无合理原因时升级项目经理并评估错报。
