# P02 递延收益明细表编制与核对

> 来源：F2401 程序库 其他1｜认定：A、V｜产出：F-13-02
> 执行方式：自动（脚本核对）｜确定性工具：recalc_check、balance_confirm

## 输入

- 递延收益明细表（按补助项目）
- 总账 2401 余额及明细账合计数
- 政府补助批准文件
- 上年审定数

## Steps

1. 【脚本】获取或编制递延收益明细表，复核加计正确并与总账数、报表数和明细账合计数核对是否相符。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 补助项目 | 文本 | 明细表 | 非空 |
| 批准文件号 | 文本 | 政府补助文件 | 非空 |
| 补助性质 | 文本 | 政府补助文件 | 枚举（与资产相关/与收益相关） |
| 期初余额 | 金额 | 明细账 | 与上年审定数衔接 |
| 本期增加 | 金额 | 明细账贷方 | 与批准文件一致 |
| 本期摊销 | 金额 | 明细账借方 | 与摊销政策一致 |
| 期末余额 | 金额 | 期初 + 增加 − 摊销 | = 期初 + 增 − 摊 |
| 摊销年限 | 数值 | 摊销政策 | 与政策一致 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数（四方相符）
- 补助金额、性质与批准文件核对一致
- 摊销年限与摊销政策一致，与资产相关与与收益相关的补助分类正确

## 升级路径

- 与批准文件不符 → 升级项目经理，评估补助确认与摊销错报
- 摊销年限与政策不一致 → 升级，评估对损益的影响
- 补助分类错误（与资产相关误列为与收益相关）→ 升级，评估摊销方法影响
