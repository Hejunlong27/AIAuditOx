# P03 递延收益余额抽样与追溯检查

> 来源：F2401 程序库 其他2、其他3｜认定：C、E、A｜产出：F-13-03
> 执行方式：自动（抽样）+人工确认｜确定性工具：sampling_draw、rule_check

## 输入

- 递延收益余额明细表
- 政府补助文件与收款凭证
- 摊销计算表
- 首次接受委托时的年初余额资料
- 抽样参数

## Steps

1. 【规则】抽样检查递延收益余额：
   - （1）获取递延收益余额的明细表，并执行程序测试IPE的可靠性；
   - （2）对于选定的样本，确认递延收益的基础与往年一致，符合适用的财务报告编制基础：
   - ①检查支持性文件以验证会计处理是否正确；
   - ②通过确定对未来收益作出的预期是否合理（考虑经营成果及当前经济状况等因素），评价递延收益余额的合理性；
   - ③记录样本量和选样依据。
2. 【规则】对首次接受委托的单位，应对年初递延收益进行追溯查验，原始发生额入账依据是否充分，入账金额是否正确。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 补助项目 | 文本 | 明细表 | 非空 |
| 期末余额 | 金额 | 明细账 | 与总账一致 |
| 本期摊销额 | 金额 | 明细账 | 与摊销政策一致 |
| 摊销依据 | 文本 | 摊销计算表 | 非空 |
| 摊销是否与往年一致 | 文本 | 人工判断 | 枚举（是/否） |
| 是否符合编制基础 | 文本 | 人工判断 | 枚举（是/否） |
| 年初余额追溯查验结论 | 文本 | 人工填写 | 首年审计时必有 |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 抽样样本量由 sampling_draw 以固定 seed 生成，可复现
- 递延收益的确认基础与往年一致，符合适用的财务报告编制基础
- 已执行程序测试 IPE（被审计单位提供的信息）的可靠性
- 首次接受委托时，年初递延收益已追溯查验，原始发生额入账依据充分、入账金额正确

## 升级路径

- 摊销基础与往年不一致且无依据 → 升级项目经理，评估对损益的影响
- 年初余额无法追溯查验 → 升级，考虑对期初余额及审计意见的影响
- 补助确认依据不充分（如仅有收款无批准文件）→ 升级，评估负债确认是否恰当
