# P01 实质性分析程序

> 来源：F2401 程序库 分析1、分析2｜认定：C、E、A｜产出：F-13-01
> 执行方式：自动（预期值测算）+人工判断｜确定性工具：threshold_flag、recalc_check

## 输入

- 递延收益明细账
- 政府补助文件（金额、补助性质）
- 摊销政策与摊销年限
- 上期数与本期预算数
- 实际执行的重要性水平

## Steps

1. 【规则】将实际值与预期值进行比较。
2. 【规则】调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。
   - 了解被审计单位是如何对收益进行递延确认的，并据此对本期递延收益作出预期：

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 补助项目名称 | 非空 |
| 期初余额 | 金额 | 明细账 | 与上年审定数一致 |
| 本期增加 | 金额 | 明细账贷方 | 与批准文件一致 |
| 本期摊销 | 金额 | 明细账借方 | 与摊销政策一致 |
| 期末余额 | 金额 | 期初 + 增加 − 摊销 | = 期初 + 增 − 摊 |
| 预期摊销额 | 金额 | 按摊销年限测算 | 重算一致 |
| 差异 | 金额 | 本期摊销 − 预期摊销 | = 差额 |
| 是否超重要性水平 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明与证据 | 文本 | 人工填写 | 超限项必有 |

## 质量门

- 主要补助项目 100% 纳入分析，无遗漏
- 摊销进度与摊销政策及补助文件约定的受益期间一致
- 差异超实际执行的重要性水平的项目均有解释与佐证

## 升级路径

- 摊销进度异常（过快或过慢）→ 升级项目经理，转 P03 抽样检查摊销依据
- 存在已满足确认条件但未摊销的补助 → 升级，评估对损益的影响
