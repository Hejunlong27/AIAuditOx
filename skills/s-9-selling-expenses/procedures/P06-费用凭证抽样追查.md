# P06 费用凭证抽样追查

> 来源：S6601 程序库 其他9｜认定：E、A｜产出：S-9-06
> 执行方式：自动（抽样）+人工追查至发票｜确定性工具：sampling_draw、rule_check

## 输入

- 本期发生的费用或采购清单
- 供应商发票
- 货物入库单或服务验收单
- 抽样参数（样本量与固定 seed）

## Steps

1. 【规则】从总账中选取费用样本并追查至供应商发票及收到的货物/服务
   - （1）获取本期发生的费用/采购清单，执行程序测试IPE的可靠性；
   - （2）选取样本执行下列工作：
   - ①将供应商发票、入库单等文件与会计记录进行核对；
   - ②评价费用是否确属本期实际发生的成本；
   - ③确定是否已根据适用的财务报告编制基础确认了相关税费（如适用）；
   - ④核实费用/采购已在利润表中进行了适当分类；
   - ⑤记录样本量和选样依据。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 凭证号 | 文本 | 明细账 | 非空 |
| 记账日期 | 日期 | 明细账 | 非空 |
| 供应商 | 文本 | 发票 | 与供应商清单一致 |
| 摘要 | 文本 | 凭证 | 非空 |
| 金额 | 金额 | 明细账 | 与发票一致 |
| 发票号 | 文本 | 发票原件 | 非空 |
| 支持性附件 | 文本 | 附件清单 | 枚举（齐备/缺失） |
| 追查结论 | 文本 | 人工填写 | 枚举（相符/不符） |
| 说明 | 文本 | 人工填写 | 不符项必有 |

## 质量门

- 抽样样本量由 sampling_draw 以固定 seed 生成，可复现
- 每笔样本 100% 追查至发票与接收证据
- 不符项均有说明

## 升级路径

- 无货物或服务接收证据的费用 → 升级项目经理，评估虚构费用风险
- 发现关联方供应商 → 升级，联动关联方交易检查程序
