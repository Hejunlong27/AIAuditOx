# P01 实质性分析程序

> 来源：S6601 程序库 分析1、分析2、分析3、分析4、分析5、分析6｜认定：C、E、A、V｜产出：S-9-01
> 执行方式：自动（按月/占比/同业对比测算）+人工判断｜确定性工具：threshold_flag、recalc_check、sampling_draw

## 输入

- 销售费用明细账（按月、按费用项目）
- 主营业务收入明细
- 上年度数与本期预算数
- 同行业费用率参考数据
- 实际执行的重要性水平

## Steps

1. 【规则】分析销售费用变动的合理性
   - 了解并核查公司销售模式，分析申报期是否发生重大变化，核查销售费用构成项目是否存在异常或变动幅度较大的情况及其合理性。
2. 【规则】分析销售费用变动趋势与营业收入的变动趋势是否一致
   - 了解并核查公司销售费用的变动趋势与营业收入的变动趋势的一致性，销售费用的项目和金额与当期公司与销售相关的行为是否匹配，是否存在相关支出由其他利益相关方支付的情况。
3. 【规则】按月对销售费用进行详细分析：
   - （1）计算分析各个月份销售费用总额及主要项目金额占主营业务收入的比率，并与上一年度进行比较，判断变动的合理性；
   - （2）计算分析各个月份销售费用中主要项目发生额及占销售费用总额的比率，并与上一年度进行比较，判断其变动的合理性。
4. 【规则】考虑销售费用具体项目与相关财务数据及非财务数据的逻辑关系
   - （1）偶发性的费用；
   - （2）没有经济实质的费用；
   - （3）与相应经济活动内容或规模不相符的费用；
   - （4）原始凭证或单据不完整的费用；
   - （5）与关联方的费用；
   - （6）与特殊事项或特殊会计处理相关的费用。
   - 考虑具体费用项目与相关财务数据及非财务数据的逻辑关系，如公司收入与销售佣金、运输费用是否同步增长，或未同步增长的原因；销售模式的变更对佣金的影响；员工人数是否与公司业务规模相匹配等。对于存在异常的情况，应考虑舞弊的可能。
   - 除此以外，还应当关注费用项目中异常的大额费用，了解费用的合理性，审计过程中可以通过以下方面发现被审计单位的异常费用：
   - 对于发现的异常费用，注册会计师除获取相关的合同、发票和付款凭证外，还应结合被审计单位的业务需求分析该费用的合理性。
5. 【规则】将销售费用率与同行业比较
   - 了解并核查公司销售费用率与同行业上市公司销售费用率相比，是否合理。
6. 【规则】分类考虑各类费用的合理性
   - （1）按类别对费用作出预期；
   - （2）将实际值与预期值进行比较；
   - （3）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 费用项目名称 | 非空 |
| 本期实际数 | 金额 | 明细账 | 与总账一致 |
| 上期数 | 金额 | 上年明细账 | 与上年审定数一致 |
| 预算数 | 金额 | 预算表 | 有依据 |
| 占收入比率 | 百分比 | 本期实际 ÷ 主营业务收入 | = 比值 |
| 上期占比 | 百分比 | 上期实际 ÷ 上期收入 | = 比值 |
| 变动率 | 百分比 | (本期 − 上期) ÷ 上期 | 脚本计算 |
| 与收入变动趋势一致性 | 文本 | 与收入变动率比较 | 枚举（一致/不一致） |
| 是否超重要性水平 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明与证据 | 文本 | 人工填写 | 超限项必有 |

## 质量门

- 按月份、按项目、按占收入比率三个维度全覆盖，无遗漏
- 与营业收入变动趋势不一致的项目均有解释
- 与同行业对比偏离显著的项目已说明原因

## 升级路径

- 费用与收入变动趋势背离且无法解释 → 升级项目经理，转 P05 扩大重点费用检查
- 发现偶发性、无经济实质或与关联方相关的费用 → 升级，评估舞弊风险
