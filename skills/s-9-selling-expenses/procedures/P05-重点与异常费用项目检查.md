# P05 重点与异常费用项目检查

> 来源：S6601 程序库 其他6、其他7、其他8｜认定：C、E、A、V｜产出：S-9-05
> 执行方式：自动（阈值打标+抽样）+人工确认｜确定性工具：threshold_flag、sampling_draw、rule_check

## 输入

- 佣金合同与结算单
- 广告宣传合同与投放证明
- 业务招待费明细与审批记录
- 发票原件
- 税前扣除限额标准

## Steps

1. 【规则】检查销售佣金支出
   - 检查销售佣金支出是否符合规定，审批手续是否健全，是否取得有效的原始凭证；如超过规定，是否按规定进行了纳税调整。
2. 【规则】检查广告费、宣传及业务招待费支出
   - 检查广告费、宣传费、业务招待费的支出是否合理，审批手续是否健全，是否取得有效的原始凭证；如超过规定限额，应在计算应纳税所得额时调整。
3. 【规则】检查异常的销售费用
   - 选择重要或异常的销售费用，检查销售费用各项目开支标准是否符合有关规定，开支内容是否与被审计单位的产品销售或专设销售机构的经费有关，计算是否正确，原始凭证是否合法，会计处理是否正确。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 费用项目 | 文本 | 明细账 | 枚举（销售佣金/广告宣传费/业务招待费/其他） |
| 对方单位 | 文本 | 发票或合同 | 非空 |
| 金额 | 金额 | 明细账 | 与凭证一致 |
| 合同编号 | 文本 | 合同 | 有合同要求时必有 |
| 支持性附件 | 文本 | 附件清单 | 枚举（齐备/不齐备） |
| 税前扣除限额 | 金额 | 税法规定 | 有依据 |
| 是否超限额 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 是否异常 | 文本 | 人工判断 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 异常或超限项必有 |

## 质量门

- 敏感项目 100% 检查合同与附件齐备性
- 超税前扣除限额部分已识别并评估纳税调整
- 异常项目均有说明与佐证

## 升级路径

- 无合同或无实质支持文件的大额费用 → 升级项目经理，评估真实性与舞弊风险
- 超税前扣除限额未作纳税调整 → 升级，联动应交税费与所得税费用程序
