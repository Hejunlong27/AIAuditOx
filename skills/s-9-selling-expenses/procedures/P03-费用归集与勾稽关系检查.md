# P03 费用归集与勾稽关系检查

> 来源：S6601 程序库 其他2、其他3、其他4｜认定：E、A、V｜产出：S-9-03
> 执行方式：自动（勾稽重算+归集校验）｜确定性工具：recalc_check、rule_check

## 输入

- 销售费用明细账（含部门辅助核算）
- 销售部门人员与薪酬清单
- 固定资产折旧分配表
- 无形资产摊销表
- 费用归集政策

## Steps

1. 【规则】复核销售部门人工变动
   - 复核专设的销售部门当年人工成本的变动：1.考虑去年的人工成本、本期员工人数变化的调整、员工构成的变化、工资上涨或下降等因素，确认本年的人工成本；2.获取员工平均人数的计算，并且以某一员工为样本验证其全年工资；3.通过董事会决议/授权批准文件确认工资的上升或下降比例，或选取一名员工做样本，查看工资变化前后该员工的工资情况。
2. 【脚本】检查工资、折旧等相关项目的勾稽关系
   - 将专设销售部门的工资、折旧等与相关的资产、负债科目核对，检查其勾稽关系的合理性：(1)检查归入本部门使用的固定资产清单，检查折旧计算的准确性；(2)检查归入本部门使用的无形资产清单，检查摊销额计算的准确性；(3)检查人工成本：①获取本部门人工成本计算文件披露；②复核并确保已经按照企业会计准则和法规要求对人工成本进行了核算与列报，同时考虑对临时人工成本的处理；③通过以下方法验证员工节假日工资的计提：a）复核员工合同、工会合同及/或员工手册来确认休假政策和每个工作日应计提的节假日工资率；b）抽样核对人工成本金额与人事档案来验证用以计算的输入数据；c）检查应付节假日工资的计算并且确保该计提符合客户的会计政策和企业会计准则；④复核和确认应付福利费：a）复核客户对应付员工福利费的计算（保险、休假、假期、病假、养老金、利润分享、奖金等）并通过支持性文档和期后支付来验证该计算；b）确保该计提符合客户的会计政策和企业会计准则。
3. 【规则】检查各明细项目是否与销售机构相关
   - 检查各明细项目是否与被审计单位销售商品和材料、提供劳务以及专设的销售机构发生的各种费用有关。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 费用项目 | 文本 | 明细账 | 非空 |
| 归集部门 | 文本 | 辅助核算 | 枚举（销售部门/其他） |
| 本期金额 | 金额 | 明细账 | 与总账一致 |
| 与工资费用勾稽 | 金额 | 与 6604 工资费用分配表比对 | 差异 ≤ 容差 |
| 与折旧摊销勾稽 | 金额 | 与折旧分配表比对 | 差异 ≤ 容差 |
| 归集是否恰当 | 文本 | rule_check 校验 | 枚举（恰当/不恰当） |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 工资、折旧等跨科目勾稽项目 100% 核对
- 归集部门与费用性质相符，无销售与管理费用混记
- 异常归集已查明原因

## 升级路径

- 存在销售费用与管理费用混记 → 升级，评估重分类调整
- 勾稽差异无法解释 → 升级项目经理
