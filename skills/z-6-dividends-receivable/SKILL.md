## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：所有应收股利均已记录（含未列示于账面者）；存在（E）：记录的应收股利于资产负债表日存在且归被审计单位拥有或控制；准确性（A）：金额正确计算、适当加总且准确记录；计价（V）：按恰当金额计价（含减值、摊销、公允价值等调整）；列报（P）：分类、披露恰当 |
| 所需资料 | 应收股利明细表（按被投资单位）、被投资单位分红决议或股东大会决议、持股数量与持股比例台账、总账与明细账、坏账准备明细账、股利凭证与现金收据、银行收款流水与对账单、被投资单位公司章程与股东协议（境外投资）、财务报表附注 |
| 所需数据 | 各被投资单位期末余额、本期增减发生额、持股数量与持股比例、每股股利、股权登记日与支付日、期后回款金额与日期、外币折算汇率、账龄（挂账日至资产负债表日天数）、实际执行的重要性水平 |
| 核对逻辑 | 1. 实质性分析程序（将实际值与预期值进行比较。）；2. 应收股利明细表编制（获取或编制应收股利明细表）；3. 应收股利增减变动检查（检查应收股利增减变动）；4. 股利收入计算确认（确认股利收入的计算）；5. 期后回款情况检查（检查期后应收股利回款情况）；6. 境外投资股利汇回限制检查（结合投资审计，确定境外投资应收股利汇回不存在重大限制，如果存在，已充分披露。）；7. 应收股利披露检查（审计应收股利的披露） |
| 底稿编制内容 | 见「产出清单」，全部底稿采用四段式制式：底稿名称与表头（项目基本信息）→ 审计目标和程序说明 → 审计程序执行结果 → 审计说明。共 7 张底稿。 |
| 输出格式 | xlsx 工作簿（模板见 templates/Z-6应收股利审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/Z-6应收股利/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性（见六要素「所需资料」）；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → P02 → P03 → P04 → P05 → P06 → P07；人工程序标记待办并跟踪完成状态。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：按各程序卡「升级路径」处理，发现异常事项逐级升级。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P07 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：明细表合计数 = 总账数 = 报表数；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源；差异事项均有解释与支持文件。
- 异常闭环：所有异常事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料 只读）；跳过强制程序。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 被投资单位已宣告分配但未记录应收股利 → 完整性认定错报；须核对全部持股单位的分红决议，不能只看账面已记录项
- 权益法核算的长期股权投资，被投资单位宣告分红应冲减长期股权投资而非确认股利收入，勿混淆核算口径
- 同一被投资单位跨年度多次分红，易漏记或重复确认，须按股权登记日逐次核对
- 境外被投资单位的股利汇回可能受当地外汇管制限制，须评估可收回性并检查是否充分披露
- 长期挂账未收回的应收股利应评估减值，勿长期按原值列示
- 分红决议的股权登记日与支付日跨期时，注意截止测试与跨期确认
