# P06 境外投资股利汇回限制检查

> 来源：Z1131 程序库 其他5｜认定：E、P｜产出：Z-6-06
> 执行方式：人工为主（查阅限制性文件/访谈）｜**必须留人**（Agent 不得代替执行）

## 输入

- 境外被投资单位公司章程/股东协议/当地外汇管制规定
- 管理层关于汇回限制的书面说明
- 境外投资审计底稿（长期股权投资）

## Steps

1. 【规则】结合投资审计，确定境外投资应收股利汇回不存在重大限制，如果存在，已充分披露。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 境外被投资单位 | 文本 | 投资台账 | 非空 |
| 应收股利金额 | 金额 | 明细表 | 与总账一致 |
| 是否存在汇回限制 | 文本 | 章程/法规/访谈 | 枚举（是/否） |
| 限制依据 | 文本 | 文件名称与条款 | 存在限制时必有 |
| 已披露情况 | 文本 | 报表附注 | 枚举（已披露/未披露/不适用） |
| 审计结论 | 文本 | 人工填写 | 非空 |

## 质量门

- 每家境外被投资单位均有明确结论（不存在限制 / 存在且已充分披露）
- 结论有文件或访谈记录支持，不得仅凭管理层口头说明
- 本卡必须人工执行，Agent 仅可整理底稿

## 升级路径

- 存在限制但未披露 → 升级项目经理，按列报认定错报处理，要求调整附注
- 无法获取限制性文件 → 本卡挂起并升级，评估对审计意见的影响
