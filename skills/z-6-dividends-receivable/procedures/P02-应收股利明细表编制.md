# P02 应收股利明细表编制

> 来源：Z1131 程序库 其他1｜认定：A、V｜产出：Z-6-02
> 执行方式：自动（脚本核对）｜确定性工具：recalc_check、balance_confirm

## 输入

- 应收股利明细表（按被投资单位）
- 总账 1131 余额及明细账合计数
- 资产负债表日即期汇率表（存在外币应收股利时）
- 上年审定数

## Steps

1. 【规则】获取或编制应收股利明细表：
   - （1）复核加计正确，并与总账数和明细账合计数核对是否相符；结合坏账准备科目与报表数核对是否相符；
   - （2）检查非记账本位币应收股利的折算汇率及折算是否正确。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 被投资单位 | 文本 | 明细表 | 非空 |
| 币种 | 文本 | 明细表 | 枚举（CNY/USD/HKD 等） |
| 原币金额 | 金额 | 明细表 | 与凭证一致 |
| 折算汇率 | 汇率 | 即期汇率表 | 资产负债表日汇率 |
| 本位币金额 | 金额 | 原币金额 × 折算汇率 | = 乘积 |
| 坏账准备 | 金额 | 坏账准备明细账 | 与明细账一致 |
| 账面价值 | 金额 | 本位币金额 − 坏账准备 | = 差额 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数（四方相符）
- 外币项目 100% 有折算汇率且为资产负债表日即期汇率
- 差异项均有初步说明，无说明不得提交

## 升级路径

- 明细表与总账差异无法解释 → 升级 Z-6 助理，联动 P03 检查增减变动
- 存在未入账的应收股利 → 升级项目经理，按完整性认定错报处理
