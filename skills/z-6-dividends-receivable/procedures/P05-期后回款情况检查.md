# P05 期后回款情况检查

> 来源：Z1131 程序库 其他4｜认定：C、E｜产出：Z-6-05
> 执行方式：自动（抽样）+人工（函证/询问）｜确定性工具：sampling_draw、threshold_flag

## 输入

- 资产负债表日至审计报告日之间的银行收款流水
- 银行对账单、收款凭证、股利分配方案
- 长期未收回且金额较大的应收股利清单
- 被投资单位公开信息/工商信息（必要时）

## Steps

1. 【规则】检查期后应收股利回款情况：
   - （1）对至审计时已收回金额较大的款项进行常规检查，如核对收款凭证、银行对账单、股利分配方案等；
   - （2）关注长期未收回且金额较大的应收股利，询问被审计单位管理人员及相关职员或者查询被投资单位的情况，确定应收股利的可收回性。必要时，向被投资单位函证股利支付情况，复核并记录函证结果。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 被投资单位 | 文本 | 明细表 | 非空 |
| 期末余额 | 金额 | 明细表 | 与总账一致 |
| 期后回款金额 | 金额 | 银行流水 | 与对账单一致 |
| 回款比例 | 百分比 | 回款金额 ÷ 期末余额 | = 比值 |
| 长期未收回账龄 | 整数 | 资产负债表日 − 挂账日（天） | 脚本计算 |
| 可收回性判断 | 文本 | 人工判断/函证结果 | 大额项必有 |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 至审计时已收回的大额款项 100% 有常规检查记录
- 长期未收回大额项均有可收回性结论（询问/查询/函证）
- 函证由人工执行，Agent 不得代为寄发或跟函

## 升级路径

- 期后回款比例显著偏低 → 升级项目经理，评估减值迹象（联动 S-14 信用减值）
- 被投资单位经营异常或失联 → 升级项目经理，考虑全额计提并提请披露
