# P01 预期信用损失检查（强制）

> 来源：S6702 程序库 其他1｜认定：C、E、A、V、P｜产出：S-14-01
> 执行方式：自动（账龄分桶+计提测算）+人工判断｜确定性工具：ageing_bucket、provision_calc、threshold_flag

## 输入

- 应收款项/合同资产账龄明细表（挂账日、金额、对手方）
- 预期信用损失模型参数（各账龄区间计提比例、前瞻性调整因子）
- 坏账准备明细账本期计提与转回数
- 单项计提判断依据（对手方信用状况、诉讼、破产信息）
- 上期计提数与本期实际核销数

## Steps

1. 【规则】检查预期信用损失（强制要求）
   - 请使用《B5.01 （新金融工具准则）金融工具工作簿（非金融机构）》记录实施的与预期信用损失相关的审计程序。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 账龄区间 | 文本 | ageing_bucket 分桶 | 枚举（1年以内/1-2年/2-3年/3年以上） |
| 期末余额 | 金额 | 账龄明细表 | 与明细表一致 |
| 计提比例 | 百分比 | 公司会计政策/模型参数 | 有政策依据 |
| 应计提额 | 金额 | provision_calc 测算 | = 余额 × 比例 |
| 账面已计提 | 金额 | 坏账准备明细账 | 与总账一致 |
| 差异 | 金额 | 应计提 − 已计提 | = 差额 |
| 单项计提项 | 文本 | 人工判断 | 大额/异常项必有 |
| 是否超重要性水平 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明与证据 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 账龄分桶由脚本按资产负债表日回溯计算，Σ各桶金额 = 期末余额
- 计提比例与公司会计政策一致，前瞻性调整有书面依据
- 应计提与账面差异超重要性水平项均有说明，并取得管理层计提依据
- 本卡为强制程序，不得以「不适用」跳过

## 升级路径

- 差异超重要性水平且管理层拒绝调整 → 升级项目经理，累积为错报并评估对审计意见的影响
- 发现账龄划分错误或跨期挂账 → 退回账龄明细表，联动应收款项科目程序卡重算
- 存在明显应单项计提而未计提 → 升级，要求补充计提并提请披露
