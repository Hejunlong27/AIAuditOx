# 审计底稿规范《函证地址核对执行记录》

## 一、底稿定位

| 项目 | 内容 |
|---|---|
| 底稿名称 | 函证地址核对执行记录 |
| 索引号 | B-3-1（函证程序 → 地址核对，可按事务所底稿体系调整） |
| 所属循环 | 货币资金 / 应收账款 / 应付账款 等涉及函证的认定循环 |
| 编制层级 | 由助理人员编制，项目经理或质控复核 |
| 归档属性 | 与函证清单、**工商信息查询界面截图附件**、邮寄凭证、回函一并归档 |
| 附件索引规则 | `<底稿索引号>-<记录序号两位>`，如 `B-3-1-05`；同一条记录多张截图追加 `-2` |

## 二、必须体现的两组信息

底稿的核心是**两栏对照**，任何一条记录都必须同时呈现下列两组信息，缺一不可：

| 组别 | 公司名称 | 地址 | 其他 |
|---|---|---|---|
| **被审计单位提供的询证信息** | 函证上列示的单位名称 | 函证地址 | 统一社会信用代码、联系电话、联系人、函证类型 |
| **工商登记信息** | 工商登记名称 | 注册地址 | 来源平台、**查询网址**、查询日期、**查询界面截图（附件索引号）** |

底稿不得只呈现单侧信息或直接给出"一致/不一致"结论而不列示原始取值。

## 三、固定章节与撰写要求

### 一、审计目的
说明对被审计单位提供的询证信息（公司名称、函证地址）与工商登记信息（公司名称、注册地址）执行一致性核对的目的，关联到具体认定（存在性、完整性、权利与义务），并说明其与函证程序适当性、函证结果可依赖性的关系。

### 二、执行程序
按实际执行顺序编号列示，**必须包含**：
1. 取得被审计单位提供的函证清单并提取信息；
2. **通过公开工商信息渠道查询被函证单位的登记名称与注册地址，记录查询平台、查询网址与查询日期**；
3. **对查询界面进行截图留存，按索引号编制附件并与核对记录建立索引关系**；
4. 标准化处理、三级匹配与逐项差异比对；
5. 风险识别与审计判断；
6. 编制本执行记录。

### 三、数据来源
分述两组来源，并载明：
- **询证信息来源**：源文件名、格式、解析方式、表头行、有效记录数、字段映射关系；
- **工商信息来源**：来源平台清单＋**获取渠道要求**（官方优先：国家企业信用信息公示系统 <https://www.gsxt.gov.cn>，含地方市场监督管理局公示入口；备选第三方：企查查 <https://www.qcc.com>、天眼查 <https://www.tianyancha.com>，须与官方公示结果交叉验证后使用），并以**可点击超链接**形式列出查询入口；
- 声明被审计单位对其提供信息的真实性、完整性负责，并说明对工商信息的查询时点。

### 四、核验方法
逐条列明标准化方法、三级匹配算法（含权重与阈值）、行政区划冲突上限、**逐项差异比对项目（公司名称 / 省份 / 地市 / 区县 / 道路 / 门牌号 / 楼栋 / 房间楼层）**、判定标准，使复核人可**独立复现**结论。

### 五、被审计单位提供的询证信息与工商登记信息对照
以表格形式逐条列示：序号 / 被审计单位提供的询证信息（公司名称 + 函证地址）/ 工商登记信息（公司名称 + 注册地址）/ 信息来源及查询网址 / 附件索引号 / 差异结论。
未提供的项目显示"（未提供）"，不得留空或臆测。

### 六、逐项差异说明
**仅列示存在差异或无法比对的记录**，逐项展开，格式：
```
记录 5｜广州天成贸易有限公司（附件索引号 B-3-1-05）
【差异】地级市/自治州：被审计单位提供「广州市」，工商登记信息「深圳市」。表述不一致
【差异】门牌号：被审计单位提供「200号」，工商登记信息「100号」。表述不一致
【待确认】房间/楼层：被审计单位提供「空」，工商登记信息「1806室」。一方缺失（被审计单位提供信息缺失），该项无法比对（不确定）
综合结论：不一致；匹配度 36.5；风险等级 高风险。
```
逐项比对无差异的记录在第五节对照表中标注"无差异"即可，不必重复展开。

### 七、异常事项
逐条列示命中高风险与中风险的记录，含风险等级、规则编号、异常说明（量化依据）、**附件索引号**与处置建议。

### 八、审计结论
按风险分层表述，并明确：
- 高风险 N 条 → 已提请暂缓寄发、拟执行的补充程序
- 中风险 N 条 → 已建议核实/补齐证据后寄发
- 低风险 N 条 → 按既定程序寄发并保留邮寄凭证
- **兜底声明**：结论仅基于所述询证信息、工商登记信息来源与核验方法；无法取得充分适当证据的事项已标注"不确定"，未作一致性假设；**工商登记信息以查询时点的公示信息为准，此后登记事项变更不影响查询时点的核对结论**。

### 附录一：工商登记信息来源记录
附件索引号 / 被函证单位 / 工商信息来源（平台）/ **查询网址（超链接）** / 查询日期 / 附件文件名。
此附录是"来源可追溯"的直接证据，**不得省略**。

### 附录二：工商信息查询界面截图
逐张嵌入查询界面截图，每张图上方标注：附件索引号｜被函证单位｜来源平台｜查询日期。
截图须与 `附件/` 目录中的文件一一对应，文件名与索引号一致。

## 四、签字与复核

底稿页首载明：被审计单位/项目、索引号、编制人、复核人、编制日期。
页尾设编制人 / 复核人 / 日期签署栏。

## 五、"判断必须留痕"的落地要求

| 要求 | 实现方式 |
|---|---|
| 所有判断保留依据 | Excel「逐项差异明细」工作表 + JSON `diff_rows` / `evidence` |
| 两组信息必须对照呈现 | Excel 主表两栏分组表头 + Word 第五节对照表 |
| 工商来源必须可追溯 | 逐条记录来源平台 + **查询网址超链接** + 查询日期；汇总于附录一 |
| 查询截图必须留存 | 附件按索引号归档 + Excel「查看截图」超链接 + Word 附录二嵌入图片 |
| 不允许直接假设地址一致 | 缺乏比对基准一律判"无法比对"并命中 M8；名称/信用代码缺失命中 M3/M4 |
| 无法确认的信息标注"不确定" | 风险描述中显式标注"（不确定）"，并在底稿数据来源章说明程序受限范围 |
| 符合事务所底稿习惯 | 索引号 + 编制/复核签署 + 固定章节结构 + 附录体系 + 量化依据 |
| 专业、审计化语言 | 使用"函证程序适当性""替代程序""舞弊风险""充分适当的审计证据"等准则术语 |

## 六、复核要点（供复核人使用）

1. 输入记录的完整性与字段映射是否准确（对照「数据来源与口径」工作表）
2. **两组信息是否均已列示**，是否存在只给结论不给原始取值的情形
3. **每条记录是否记录了工商信息来源、查询网址与查询日期**（附录一完整性）
4. **附件索引号是否连续、唯一**，Excel 超链接能否打开对应截图，Word 附录二图片是否与之一致
5. 高风险记录是否均已列示处置建议，结论是否与之一致
6. "无法比对/不确定"记录是否说明原因，是否存在被不当升级或降级的情形
7. 是否存在对同名近似企业未经核实即判定一致的情况（检查名称相似度列）
8. 结论段是否包含免责、程序受限与查询时点效力声明
