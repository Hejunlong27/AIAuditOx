# 输入 / 输出 Schema

## 一、输入：函证清单 + 查询截图

### 1.1 支持的格式

| 格式 | 扩展名 | 解析方式 |
|---|---|---|
| Excel | `.xlsx` / `.xlsm` | openpyxl 读取首工作表；自动定位表头行（前 12 行内打分定位） |
| CSV | `.csv` | 自动嗅探分隔符与编码（utf-8-sig / gb18030 / utf-8 / big5） |
| PDF | `.pdf` | pdfplumber 优先抽表格；无表格时退化为文本键值行解析 |
| Word | `.docx` | python-docx 优先读表格；无表格时读段落键值行 |

> 旧版 `.xls` / `.doc` 不支持，需另存为新格式。
> 查询截图通过命令行 `--attach-dir` 指定目录传入，不在清单中嵌入图片。

### 1.2 字段定义

#### A. 被审计单位提供的询证信息

| 标准字段 | 中文列名示例（别名库，可扩展） | 必填 | 说明 |
|---|---|---|---|
| `entity_name` | 被函证单位名称 / 单位名称 / 企业名称 / 客户名称 / 供应商名称 | ✅ | 函证上列示的单位名称 |
| `confirm_address` | 函证地址 / 收件地址 / 邮寄地址 / 通讯地址 / 发函地址 | ✅ | 拟投递的地址 |
| `uscc` | 统一社会信用代码 / 社会信用代码 / 纳税人识别号 / 税号 | ○ | 18 位，参与校验位校验 |
| `phone` | 联系电话 / 电话 / 联系方式 | ○ | 参与区号与地址城市一致性校验 |
| `contact` | 联系人 / 收件人 / 对接人 | ○ | 仅作留痕，不参与判定 |
| `confirm_type` | 函证类型 / 函证类别 / 往来类型 | ○ | 取值含"银行/客户/供应商"等，参与 M6 校验 |

#### B. 工商登记信息

| 标准字段 | 中文列名示例 | 必填 | 说明 |
|---|---|---|---|
| `registered_name` | 工商登记名称 / 工商名称 / 营业执照名称 | ○ | 参与名称一致性校验；缺失则标"不确定"（M3） |
| `registered_address` | 注册地址 / 工商注册地址 / 营业执照地址 / 住所 | ○ | 一致性比对基准；缺失则判"无法比对"（M8） |
| `reg_source` | 工商信息来源 / 信息来源 / 查询来源 / 来源平台 | ○ | 如"国家企业信用信息公示系统""企查查"；缺失命中 M9 |
| `reg_source_url` | 来源网址 / 工商信息网址 / 查询网址 / 来源链接 | ○ | 具体查询页 URL；缺失命中 M9 |
| `query_date` | 查询日期 / 核对日期 / 截图日期 | ○ | 查询时点，决定结论的时点效力 |
| `screenshot` | 查询界面截图附件 / 查询截图 / 截图文件名 / 附件文件名 | ○ | 截图文件名，多个用 `\|` 分隔；缺失命中 M10 |
| `reg_change_count` | 注册地址变更次数 / 工商变更次数 | ○ | 提供则参与 H4 判定；未提供按"不确定"处理 |

**别名匹配规则**：三轮匹配 —— ① 精确匹配归一化表头；② 包含关系且长度差 ≤ 3；③ 宽松包含（别名 ≥3 字）。
需扩展别名时，修改 `scripts/reader.py` 的 `FIELD_ALIASES`。

### 1.3 输入示例（CSV 表头）

```csv
被函证单位名称,统一社会信用代码,函证地址,注册地址,联系电话,联系人,函证类型,工商登记名称,工商信息来源,来源网址,查询日期,查询界面截图附件,注册地址变更次数
长沙湘江科技有限公司,91430100MA4L1A2B3F,湖南省长沙市岳麓区麓谷大道627号,湖南省长沙市岳麓区麓谷大道627号,0731-88886666,李会计,客户函证,长沙湘江科技有限公司,国家企业信用信息公示系统,https://www.gsxt.gov.cn/index.html,2026-09-08,01.png,
```

**截图目录约定**（`--attach-dir`）：目录内放置 `01.png`、`02.png`……，或在清单「查询界面截图附件」列写明文件名。
匹配优先级：① 清单指定文件名 → ② 序号约定（`5.png` / `05.png` / `B-3-1-05.png`）→ ③ 文件名含被函证单位字号。

## 二、输出：交付物

### 2.1 Excel 核对记录表（`函证地址核对记录表_YYYYMMDD.xlsx`，5 个工作表）

#### Sheet1「函证地址核对结果」—— 两栏对照结构

**第 1 行：信息分组表头（合并单元格）**

| 列区 | 分组标题 |
|---|---|
| A | 序号 |
| B:E | **被审计单位提供的询证信息** |
| F:J | **工商登记信息（核对来源）** |
| K:P | 核对结论 |
| Q:T | 审计判断 |
| U:V | 核对留痕附件 |

**第 2 行：明细列名**

| 列 | 字段 | 说明 |
|---|---|---|
| A | 序号 | 与附件索引号后两位对应 |
| B | 公司名称 | 被审计单位提供的询证信息 |
| C | 统一社会信用代码 | 同上 |
| D | 函证地址 | 同上 |
| E | 函证类型 | 同上 |
| F | 公司名称 | 工商登记名称；未提供显示"（未提供）" |
| G | 注册地址 | 工商登记注册地址；未提供显示"（未提供）" |
| H | 信息来源 | 如"国家企业信用信息公示系统" |
| I | 来源网址 | **超链接**，点击打开查询页 |
| J | 查询日期 | 结论的时点依据 |
| K | 匹配结果 | 一致 / 基本一致 / 部分一致 / 不一致 / 无法比对 |
| L | 匹配度 | 0.0~100.0；无法比对时留空 |
| M | 风险等级 | 高风险 / 中风险 / 低风险（带底色） |
| N | 逐项差异说明 | 按比对项目压缩的一句话差异描述 |
| O | 异常说明 | 规则编号 + 规则描述，多条以"；"分隔 |
| P | 审计建议 | 与风险规则对应的处置建议 |
| Q | 是否建议发送函证 | 建议发送 / 建议核实后再发送 / 暂缓发送，核实后重新评估 |
| R | 是否需电话确认 | 是 / 否 |
| S | 是否需获取工商变更资料 | 是 / 否 |
| T | 是否需扩大审计程序 | 是 / 否 |
| U | 附件索引号 | 如 `B-3-1-05`；多条以"、"分隔 |
| V | 查看截图 | **超链接**，点击直接打开附件图片 |

> 冻结窗格 `B3`；第 2 行启用自动筛选。

#### Sheet2「逐项差异明细」

每行一个比对项目：序号 / 被函证单位 / 比对项目 / 被审计单位提供（询证信息）/ 工商登记信息 / 是否一致 / 差异说明 / 附件索引号。
"是否一致"列按结果着色：存在差异（红）/ 无法比对（黄）/ 一致（绿）。

**八个比对项目**：公司名称、省份/直辖市、地级市/自治州、区/县、道路/街道、门牌号、楼栋、房间/楼层。

#### Sheet3「附件索引表」

| 列 | 字段 | 说明 |
|---|---|---|
| A | 附件索引号 | `B-3-1-01`；同一记录多张追加 `-2` |
| B | 对应记录序号 | 与 Sheet1 序号一致 |
| C | 被函证单位 | |
| D | 附件类型 | 工商信息查询界面截图 / 其他附件 |
| E | 附件文件名 | `B-3-1-01.png` |
| F | 打开附件 | **超链接**（相对路径 `附件\B-3-1-01.png`） |
| G | 工商信息来源 | |
| H | 来源网址 | **超链接** |
| I | 查询日期 | |
| J | 说明 | |

#### Sheet4「风险汇总」
风险等级数量与占比 + H1~H4 / M1~M10 规则命中统计。

#### Sheet5「数据来源与口径」
询证信息来源 / 工商信息来源 / 工商信息获取渠道要求（官方优先，第三方备选并交叉验证）/ 来源网址记录 / 证据留痕 / 字段映射 / 匹配算法 / 判定阈值 / 未确认信息处理原则 / 编制日期。

### 2.2 Word 审计底稿《函证地址核对执行记录》

| 章节 | 内容 |
|---|---|
| 一、审计目的 | 询证信息与工商登记信息一致性核对的目的与认定关联 |
| 二、执行程序 | 含"通过公开工商信息渠道查询并记录查询平台、网址、日期""查询界面截图留存并编制索引号" |
| 三、数据来源 | 询证信息来源与工商信息来源分述；**官方查询入口超链接**（gsxt.gov.cn 优先，企查查/天眼查备选） |
| 四、核验方法 | 标准化 / 三级匹配 / **逐项差异比对（八个项目）** / 判定标准 |
| 五、**信息对照** | 对照表：序号 / 被审计单位提供的询证信息 / 工商登记信息 / 信息来源及查询网址（可点击）/ 附件索引号 / 差异结论 |
| 六、**逐项差异说明** | 仅列示存在差异或无法比对的记录，逐项展开：`【差异】门牌号：被审计单位提供「200号」，工商登记信息「100号」。表述不一致` |
| 七、异常事项 | 逐条列示高/中风险，含规则编号与附件索引号 |
| 八、审计结论 | 分层结论 + 程序受限与免责声明 + 查询时点效力说明 |
| **附录一** | 工商登记信息来源记录：附件索引号 / 被函证单位 / 来源平台 / **查询网址（超链接）** / 查询日期 / 附件文件名 |
| **附录二** | 工商信息查询界面截图：**嵌入图片**，每张图上方标注索引号、被函证单位、来源平台、查询日期 |
