# 风险识别规则库与审计判断

## 一、风险等级定级原则

- 单条记录可同时命中多条规则，**最终等级取所命中规则的最高级**（高 > 中 > 低）
- 每条风险必须保留**规则编号 + 规则描述**，写入"异常说明"列与底稿"异常事项"章
- 无任何规则命中 → **低风险**
- 证据不足、无法核实的事项一律标注**"不确定"**，不得推定一致，亦不直接升级为高风险

---

## 二、高风险规则（H）

| 编号 | 触发条件 | 风险含义 | 处置建议 |
|---|---|---|---|
| **H1** | 匹配度 < 60，或存在省级/市级/区县级行政区划冲突 | 函证地址与注册地址实质不一致，存在寄送对象错误、函证无效风险 | 暂缓寄发；取得最新营业执照或经国家企业信用信息公示系统核实注册地址；如系迁址，取得工商变更登记资料；考虑执行替代程序（合同、验收单、结算凭据、期后回款） |
| **H2** | 函证地址为空，或无法解析出任何有效地址元素 | 地址不可用或疑似不存在，函证程序无法执行 | 重新获取有效投递地址后寄发；无法获取时由项目组现场递交或执行替代程序 |
| **H3** | 注册/函证地址聚簇，同一地址对应 ≥ 3 个不同主体 | 涉嫌一址多照、空壳注册或集中托管，舞弊风险 | 核查是否为注册托管地址、是否存在关联方集中代收；结合舞弊风险评估扩大函证范围并加强函证过程控制 |
| **H4** | `reg_change_count ≥ 2` | 注册地址在报告期内频繁变更，地址稳定性存疑 | 获取工商变更登记档案；询问管理层变更原因；评估对交易真实性的影响 |

> **H4 未取得数据时**：不触发规则，但需在底稿"数据来源"中说明"未取得注册地址变更次数，该程序未执行（不确定）"，不得默认无变更。

## 三、中风险规则（M）

| 编号 | 触发条件 | 风险含义 | 处置建议 |
|---|---|---|---|
| **M1** | 匹配结果 ∈ {基本一致, 部分一致} | 指向同一地点但表述存在差异，投递存在偏差可能 | 寄发前通过电话或公开渠道核实，确保投递地址准确 |
| **M2** | 一方有楼层/房号、另一方无 | 具体投递点不明确 | 补齐楼层房号后再寄发 |
| **M3** | 未提供工商登记名称；或 `name_sim < 0.95` | 主体唯一性未确认，存在函证对象串户风险 | 取得工商登记全称，确认被函证主体唯一性后再寄发 |
| **M4** | 信用代码校验位错误；或信用代码为空 | 主体身份标识异常 | 核对统一社会信用代码，防止函证对象串户 |
| **M5** | 电话区号与地址所在城市不一致 | 地址或联系方式可能被篡改 | 核实联系电话归属，防范地址与联系方式被篡改 |
| **M6** | 函证类型与主体性质不匹配（如"银行函证"但名称无金融机构特征） | 函证类型划分可能有误 | 复核函证类型划分与函证对象性质的匹配性 |
| **M7** | 函证地址可解析但缺少门牌号 | 投递点不明确，存在无法送达或错投风险 | 补充门牌号等投递点信息后寄发，必要时改用快递面单地址回执留痕 |
| **M8** | 注册地址缺失（函证地址非空） | 无法执行一致性核验，一致性结论未取得 | 向被审计单位索取被函证单位工商登记地址，补充核验后再行寄发 |
| **M9** | 未记录工商信息来源（平台及网址） | 工商登记信息缺乏可追溯来源，核对结论无法复现 | 在底稿中补充来源平台与查询网址；官方渠道优先采用国家企业信用信息公示系统（www.gsxt.gov.cn），第三方平台（企查查/天眼查）仅作补充并与官方交叉验证 |
| **M10** | 未附工商信息查询界面截图 | 核对过程缺乏证据留痕，不足以作为审计证据留存 | 补充查询界面截图，按索引号归档后作为本核对程序的审计证据 |

> **M9 判定细节**：仅记录来源平台但未记录网址时，判定为 M9 较轻情形，异常说明中写明"来源可追溯性不足（仅标注来源平台：XX）"。
> **M10 前提**：截图为核对程序的关键证据。若项目组另行取得工商登记档案（如企业提供的营业执照、变更登记页），需在底稿"数据来源"中说明并相应调整该判定。
> **关闭方式**：命令行加 `--no-require-evidence` 可整体关闭 M9/M10 强制校验（适用于仅做地址一致性核验、不要求工商证据留痕的项目）。

## 四、审计判断矩阵

| 风险等级 | 是否建议发送函证 | 电话确认 | 获取工商变更资料 | 扩大审计程序 |
|---|---|---|---|---|
| 低风险 | 建议发送 | 否 | 否 | 否 |
| 中风险 | 建议核实后再发送 | 是 | 否（M3/M4/M8 视情形） | 否 |
| 高风险（H1/H2/H3） | 暂缓发送，核实后重新评估 | 是 | 是 | 是 |
| 高风险（仅 H4） | 建议核实后再发送 | 是 | 是 | 视评估结论 |

> M9/M10 属于**程序留痕不足**，不改变地址本身的一致性结论，但会使该条记录的整体风险等级升至中风险；
> 其应对为"补齐来源网址与截图"而非"更换投递地址"。

## 四·补、工商信息来源要求

| 层级 | 渠道 | 网址 | 使用要求 |
|---|---|---|---|
| 首选（官方） | 国家企业信用信息公示系统 | https://www.gsxt.gov.cn | 以官方公示结果为最终依据；含各地方市场监督管理局公示入口 |
| 备选（第三方） | 企查查 | https://www.qcc.com | 可作为效率工具，但登记信息应与官方公示结果**交叉验证**后使用 |
| 备选（第三方） | 天眼查 | https://www.tianyancha.com | 同上 |
| 其他 | 企业提供的营业执照、工商变更登记档案 | — | 属被审计单位提供证据，需注明来源与取得方式 |

**底稿必须记录的内容**：查询平台名称、具体查询网址（URL）、查询日期、查询界面截图（按索引号归档）。
以上四项任一缺失，对应记录即命中 M9 或 M10。

## 五、"不确定"的适用情形

以下情形**必须**标注"不确定"，不得作一致性假设：

| 情形 | 表现 |
|---|---|
| 注册地址缺失 | 匹配结果 = 无法比对；命中 M8 |
| 未提供工商登记名称 | 名称一致性未执行；命中 M3 |
| 统一社会信用代码为空 | 校验未执行；命中 M4 |
| 未记录工商信息来源或来源网址 | 来源不可追溯；命中 M9 |
| 未附查询界面截图 | 证据留痕不足；命中 M10 |
| 印章/扫描件导致的 PDF 无法解析 | 读取阶段中止，输出明确错误提示，不产出结论 |
| 注册地址变更次数未提供 | H4 未执行，底稿中说明程序受限范围 |

## 六、函证地址有效性说明（重要边界）

本 Skill 的"地址真实性/有效性"判断基于以下**内部一致性证据**：

1. 函证地址与注册地址的一致性（三级匹配）
2. 地址结构可解析性（省市区/道路/门牌是否齐全）
3. 信用代码、电话区号、函证类型的内部逻辑自洽
4. 同批次数据内的地址聚簇异常

**不包含**外部工商登记库实时核验。如需"地址对应多个异常企业""注册地址频繁变化"等外部事实的最终确认，应通过以下渠道补充证据后回填 `reg_change_count` 字段并复核：

- 国家企业信用信息公示系统
- 企业信用信息查询服务（如以 MCP 方式接入企查查/天眼查等连接器）
- 被审计单位提供的营业执照与工商变更登记档案

> 审计判断不得仅依赖本工具的自动化结论；工具输出为**风险提示与程序建议**，最终结论由项目组依据充分适当的审计证据作出。
