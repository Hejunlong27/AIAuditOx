# Z-1-2 银行存款技能组（助理级主技能）

> **【技能来源与使用声明】**
> **归属**：本技能属于「审小牛 AuditOx」开源审计技能组。
> **作者与许可**：何小疯27 · 免费开源 · 禁止商用转售
> **技能主页**：aiauditox.l.cd ｜ **开发动态**：公众号‘小小审计员日记’
> **使用声明**：本技能输出内容仅供学习与工作参考，不构成任何审计意见或专业建议；请勿将客户敏感数据用于公开的 AI 服务。

> **底稿制式：强制遵循全局标准技能 auditox-wp-standard（四段式制式：一、项目基本信息/二、审计目标和程序说明/三、审计程序执行结果/四、审计说明 + 副本先行 + 修订记录），编制任何底稿前先加载该规范。**

> 技能库分组：资产类 Z → Z-1 货币资金 → Z-1-2 银行存款（对应所内科目编号 1002 / 程序库 Z1002）

> 程序来源：《审计程序库——Z1002银行存款》（立信技术标准部 2024/10 版，编号 Z1002）。

## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 存在性（E）：记录的银行存款于资产负债表日存在且归被审计单位拥有或控制；完整性（C）：所有银行存款均已记录；准确性（A）：金额正确计算与记录；计价（V）：按恰当金额计价（含外币折算）；列报（P）：分类、披露恰当 |
| 所需资料 | 银行存款余额明细表/科目余额表、银行对账单（全账户全期间）、银行存款日记账、已开立银行结算账户清单、银行询证函及回函、银行存款余额调节表、定期存单/开户证实书、资金池协议（如有）、开户/销户资料、财务报表及附注 |
| 所需数据 | 各账户：开户行、账号、账户性质、币种、期初/期末账面余额、对账单余额；流水明细：日期、摘要、借/贷方金额、对手方；利息收入账面数；适用利率 |
| 核对逻辑 | ① 期初数核对上年审定数、加计核对总账/明细账/报表数；② 已开立账户清单与账面双向核对；③ 调节表重算+四类未达账项逐项检查；④ 日记账↔对账单双向核对；⑤ 期末前后收付款截止测试；⑥ 按累计余额×利率测算利息收入并与账面比较，差异超过实际执行重要性水平阈值须调查 |
| 底稿编制内容 | 见「产出清单」，全部底稿采用四段式制式：底稿名称与表头（项目基本信息）→ 审计目标和程序说明 → 审计程序执行结果 → 审计说明 |
| 输出格式 | xlsx 工作簿（模板见 templates/Z-1-2银行存款审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/Z-1-2银行存款/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性：余额明细表、对账单、日记账缺一不可；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → （P02、P08 可并行）→ P04 → P06 → P07 → P10；P03/P05 标记人工主导任务并跟踪完成状态；P09 视资金池/集团情况决定是否启用。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：P04 发现大额或长期未达账项 → 激活 P06 扩样并提示 P05 函证关注；P08 利息差异超阈值 → 激活 P06 核查异常流水并升级助理；P02 发现清单外账户 → 立即升级助理并考虑舞弊风险迹象（对照程序15核对表）。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P10 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：余额明细表合计数 = 总账数 = 报表数；调节后余额双向一致；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源（对账单/日记账/清单）；差异事项均有解释与支持文件。
- 异常闭环：所有异常激活事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料只读）；跳过强制程序（函证不适用必须记录理由并经人工批准）。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 零余额账户和本期内注销的账户必须纳入函证与完整性检查范围，遗漏是常见错误。
- 外币账户须分别核对原币与本位币折算，汇率使用资产负债表日即期汇率。
- 调节表「调节后余额相等」不等于无风险：须逐项检查大额/长期未达账项是否为截止错报。
- 利息测算差异阈值使用实际执行的重要性水平，不得随意放宽。

## Verification

- 工作簿公式重算无错误；合计数与总账/报表数核对一致。
- 每张底稿「审计程序执行结果」与「审计说明」均有实质内容或明确的不适用声明。
- 修订记录 .md 与工作簿版本一一对应。
