# P04 银行存款余额调节表检查

> 来源：Z1002 程序库 程序5（检查银行存款余额调节表）｜认定：C、E、A｜产出：Z-1-2-04 余额调节表检查表

## 输入

- 各账户期末银行对账单
- 被审计单位编制的银行存款余额调节表（如无则协助编制）
- 期后银行对账单（检查未达账项期后到账）
- 银行询证函回函（函证完成后回填核对）

## Steps

1. 【脚本】针对所有银行账户重算调节表：
   - 调节后余额（企业侧）= 企业日记账余额 + 银行已收企业未收 − 银行已付企业未付；
   - 调节后余额（银行侧）= 对账单余额 + 企业已收银行未收 − 企业已付银行未付；
   - 校验两侧调节后余额是否一致、账面余额与总账每笔金额是否一致。
2. 【脚本】核对每个账户银行对账单余额与银行询证函回函金额一致性（回函到位后执行，未回函标注待补）。
3. 【规则】逐类检查调节事项：
   - 企收银未收：检查收款入账原始凭证，核实是否已在期后对账单反映；
   - 银收企未收：检查收款内容及金额，判断是否截止错报；
   - 企付银未付：检查付款原始凭证及期后对账单反映情况，并与支票存根核对（支票编号/金额）；
   - 银付企未付：检查付款内容及金额，判断是否截止错报。
4. 【规则】大额或长期未达账项（超过设定账龄阈值，默认 3 个月）逐笔追查原因、检查支持文件，判断是否错报、是否需提请调整。
5. 结果写入 Z-1-2-04 表：调节表重算区 + 四类未达账项明细区（日期/凭证号/金额/期后反映/截止判断/备注）。
6. 同步修订记录。

## 质量门

- 所有账户均有调节表重算记录（账户多时按账户分表）；
- 调节后余额不一致的账户 100% 有原因追查；
- 大额/长期未达账项逐笔有结论（是否错报、是否调整）；
- 未达账项与期后对账单的核对有据可查。

## 升级路径

- 调节后余额仍不一致且无法解释 → 升级 Z-1 助理；
- 大额长期未达账项疑似异常 → 激活 P06 扩大双向核对样本，提示函证程序重点关注。
