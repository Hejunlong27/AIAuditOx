## 底稿制式（四段式）

每张底稿统一结构：

1. 底稿名称与表头——一、项目基本信息：被审计单位、审计期间、编制人、编制日期、审核人、审核日期、索引号
2. 二、审计目标和程序说明——审计目标段 + 程序表（序号/程序/认定/是否已实施/执行结果）
3. 三、审计程序执行结果——数据表（含公式自动计算）
4. 四、审计说明——编号说明行 + 编制/审核签字行 + 修订记录伴随声明

模板中灰色斜体行为示例行，实际使用时删除。

## 与方案的对应关系

- 角色模型：SKILL.md = Z-1 助理持有（分解/分派/一级复核）；procedures/*.md = 实习生执行；
- 安全执行层（方案 M8）：工作目录门禁、副本先行、修订记录模板均已内置；
- 动作边界：SKILL.md「边界与禁止事项」+ 各程序卡升级路径；
- 办公文件能力层（方案 M9）：底稿产出全部走 xlsx file_ops。

## 安装方式（试点期）

将本目录复制到技能安装目录即可作为单个技能加载（SKILL.md 为入口）；程序卡作为技能内部引用文档，由主技能按调度流程读取执行。
