## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：所有管理费用均已记录（含未列示于账面者）；存在（E）：记录的管理费用于资产负债表日存在且归被审计单位拥有或控制；准确性（A）：金额正确计算、适当加总且准确记录；计价（V）：按恰当金额计价（含减值、摊销、公允价值等调整）；列报（P）：分类、披露恰当 |
| 所需资料 | 管理费用明细表与明细账（含部门辅助核算）、工资费用分配表、无形资产与长期待摊费用摊销表、固定资产折旧分配表、董事会决议与会议纪要、中介服务合同与发票、诉讼案件资料、业务招待费明细与审批记录、供应商清单、服务机构协议、报表附注 |
| 所需数据 | 各费用项目本期发生额与上年同期数、预算数、管理部门人数与薪酬、摊销与折旧分配金额、各项经费与董事会费的审批依据、中介费与诉讼费金额、税前扣除限额、实际执行的重要性水平 |
| 核对逻辑 | 1. 实质性分析程序（按月分析管理费用）；2. 管理费用明细表编制与核对（获取管理费用明细表）；3. 费用归集与明细项目设置检查（检查工资、摊销等相关项目的勾稽关系）；4. 重点费用项目合规性检查（检查相关经费的合规性）；5. 特殊与异常费用检查（检查筹建期间发生的费用）；6. 费用凭证抽样追查（从总账中选取费用样本并追查至供应商发票及收到的货物/服务）；7. 舞弊风险应对—供应商与发票重复性测试（舞弊—针对与费用相关的职责分离不充分的测试）；8. 服务机构费用检查（服务机构—费用）；9. 管理费用披露检查（审计管理费用的披露） |
| 底稿编制内容 | 见「产出清单」，全部底稿采用四段式制式：底稿名称与表头（项目基本信息）→ 审计目标和程序说明 → 审计程序执行结果 → 审计说明。共 9 张底稿。 |
| 输出格式 | xlsx 工作簿（模板见 templates/S-10管理费用审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/S-10管理费用/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性（见六要素「所需资料」）；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → P02 → P03 → P04 → P05 → P06 → P07 → P08 → P09；人工程序标记待办并跟踪完成状态。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：按各程序卡「升级路径」处理，发现异常事项逐级升级。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P09 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：明细表合计数 = 总账数 = 报表数；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源；差异事项均有解释与支持文件。
- 异常闭环：所有异常事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料 只读）；跳过强制程序。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 筹建期费用（开办费）与正常经营期费用的划分依据须充分，开办费应在开始生产经营当期一次计入损益
- 环保投入中应资本化（形成环保设施）的部分易被整体费用化，须核对在建工程与固定资产明细
- 董事会费、中介费、诉讼费须有决议或合同依据；无依据的大额支出须评估真实性与商业合理性
- 诉讼费用涉及未决诉讼的，须联动或有事项与预计负债程序，勿单独下结论
- 管理费用与生产成本、销售费用混记会同时影响存货计价与损益，重分类须评估双向影响
- 「其他」类明细金额重大且无明细的，须要求管理层拆分
