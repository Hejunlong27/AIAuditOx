# P05 特殊与异常费用检查

> 来源：S6602 程序库 其他9、其他10、其他11｜认定：E、A、V｜产出：S-10-05
> 执行方式：自动（阈值打标）+人工判断｜确定性工具：threshold_flag、rule_check

## 输入

- 筹建期费用明细与开办期认定依据
- 环保投入清单与环保部门文件
- 异常或偶发性费用明细
- 费用资本化政策

## Steps

1. 【规则】检查筹建期间发生的费用
   - 结合相关资产的检查，核对筹建期间发生的开办费（包括人员工资、办公费、培训费、差旅费、印刷费、注册登记费以及不计入固定资产成本的借款费用等）是否直接计入管理费用。
2. 【规则】检查环保费用
   - 针对特殊行业，检查排污费等环保费用是否合理计提。针对特殊行业，检查排污费等环保费用是否合理计提。
3. 【规则】检查异常的管理费用
   - 选择重要或异常的管理费用，检查费用的开支标准是否符合有关规定，计算是否正确，原始凭证是否合法，会计处理是否正确。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 费用项目 | 文本 | 明细账 | 枚举（筹建期费用/环保费用/其他异常费用） |
| 金额 | 金额 | 明细账 | 与凭证一致 |
| 发生依据 | 文本 | 支持性文件 | 非空 |
| 是否应资本化 | 文本 | 人工判断 | 枚举（是/否） |
| 会计处理 | 文本 | 账务记录 | 枚举（费用化/资本化/处理不当） |
| 是否异常 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 筹建期与经营期的划分依据充分，开办费处理符合准则
- 环保费用中应资本化的部分已正确资本化
- 异常费用均有说明与支持证据

## 升级路径

- 应资本化而费用化的金额重大 → 升级项目经理，评估对资产与损益的连带影响
- 发现与经营活动无关或无法解释的异常费用 → 升级，评估舞弊风险
