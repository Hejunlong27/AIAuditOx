# P04 重点费用项目合规性检查

> 来源：S6602 程序库 其他4、其他5、其他6、其他7、其他8｜认定：E、A、V｜产出：S-10-04
> 执行方式：自动（阈值+抽样）+人工确认｜确定性工具：threshold_flag、sampling_draw、rule_check

## 输入

- 相关经费的审批制度与执行记录
- 董事会决议与会议纪要
- 中介服务合同与发票
- 诉讼案件资料与律师函
- 业务招待费明细与审批记录
- 税前扣除限额标准

## Steps

1. 【规则】检查相关经费的合规性
   - 检查公司经费(包括行政管理部门职工薪酬、物料消耗、低值易耗品摊销、办公费和差旅费)是否系经营管理中发生或应由公司统一负担，检查相关费用报销内部管理办法，是否有合法原始凭证支持。
2. 【规则】检查相关董事会费的合规性
   - 检查董事会费（包括董事会成员津贴、会议费和差旅费等），检查相关董事会及股东会决议，是否在合规范围内开支费用。
3. 【规则】检查相关中介费用的合规性
   - 检查聘请中介机构费、咨询费（含顾问费），检查是否按合同规定支付费用，有无涉及到诉讼及赔偿款项支出。
4. 【规则】检查诉讼费用
   - 检查诉讼费用并结合或有事项审计,检查涉及的相关重大诉讼事项是否已在附注中进行披露，还需进一步关注诉讼状态，判断有无或有负债，或是否存在损失已发生而未入账的事项。
5. 【规则】检查业务招待费支出
   - 检查业务招待费的支出是否合理，如超过规定限额，应在计算应纳税所得额时调整。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 费用项目 | 文本 | 明细账 | 枚举（相关经费/董事会费/中介费/诉讼费/业务招待费） |
| 对方单位 | 文本 | 发票或合同 | 非空 |
| 金额 | 金额 | 明细账 | 与凭证一致 |
| 审批手续 | 文本 | 审批记录 | 枚举（齐备/不齐备） |
| 合同或决议依据 | 文本 | 合同/决议 | 有依据时必有 |
| 税前扣除限额 | 金额 | 税法规定 | 有依据 |
| 是否超限额 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 合规性结论 | 文本 | 人工判断 | 枚举（合规/不合规） |
| 说明 | 文本 | 人工填写 | 不合规或超限项必有 |

## 质量门

- 重点费用项目 100% 检查审批手续与合同依据
- 超税前扣除限额部分已识别并评估纳税调整
- 不合规事项均有说明与后续处理意见

## 升级路径

- 大额费用无审批或无合同依据 → 升级项目经理，评估真实性与内控缺陷
- 诉讼费用涉及未决诉讼 → 升级，联动或有事项与预计负债程序
