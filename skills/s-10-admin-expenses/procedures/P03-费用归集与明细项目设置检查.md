# P03 费用归集与明细项目设置检查

> 来源：S6602 程序库 其他2、其他3｜认定：E、A、V｜产出：S-10-03
> 执行方式：自动（勾稽重算+设置校验）｜确定性工具：recalc_check、rule_check

## 输入

- 管理费用明细账（含部门辅助核算）
- 工资费用分配表
- 无形资产与长期待摊费用摊销表
- 固定资产折旧分配表
- 费用明细项目设置表

## Steps

1. 【脚本】检查工资、摊销等相关项目的勾稽关系
   - 将管理费用中的职工薪酬、无形资产摊销、长期待摊费用摊销额等项目与各有关账户进行核对，分析其勾稽关系的合理性，并作出相应记录。
2. 【规则】检查明细项目设置是否合理
   - 检查管理费用的明细项目的设置是否符合规定的核算内容与范围，结合成本费用的审计，检查是否存在费用分类错误，若有，应提请被审计单位调整。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 费用项目 | 文本 | 明细账 | 非空 |
| 归集部门 | 文本 | 辅助核算 | 枚举（管理部门/其他） |
| 本期金额 | 金额 | 明细账 | 与总账一致 |
| 与工资费用勾稽 | 金额 | 与 6604 工资费用分配表比对 | 差异 ≤ 容差 |
| 与摊销折旧勾稽 | 金额 | 与摊销折旧分配表比对 | 差异 ≤ 容差 |
| 明细项目设置是否合理 | 文本 | rule_check 校验 | 枚举（合理/不合理） |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 工资、摊销、折旧等跨科目勾稽项目 100% 核对
- 明细项目设置能反映费用性质，无笼统归集的大额「其他」
- 异常归集已查明原因

## 升级路径

- 存在管理费用与销售费用或生产成本混记 → 升级，评估重分类调整
- 「其他」类明细金额重大且无明细 → 升级，要求管理层补充拆分
