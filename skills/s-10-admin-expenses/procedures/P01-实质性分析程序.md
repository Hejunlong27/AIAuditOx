# P01 实质性分析程序

> 来源：S6602 程序库 分析1、分析2｜认定：C、E、A、V｜产出：S-10-01
> 执行方式：自动（按月/分类测算）+人工判断｜确定性工具：threshold_flag、recalc_check

## 输入

- 管理费用明细账（按月、按费用项目）
- 上年度数与本期预算数
- 费用分类标准与会计政策
- 实际执行的重要性水平

## Steps

1. 【规则】按月分析管理费用
   - 比较本期各月份管理费用，对有重大波动和异常情况的项目应查明原因，必要时作适当处理。
2. 【规则】分类考虑各类费用的合理性
   - （1）按类别对费用作出预期；
   - （2）将实际值与预期值进行比较；
   - （3）调查与预期值之间存在的xxxx以上的差异（实际执行的重要性水平的%，特定金额），并针对这些差异获取解释和佐证证据。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 费用项目名称 | 非空 |
| 本期实际数 | 金额 | 明细账 | 与总账一致 |
| 上期数 | 金额 | 上年明细账 | 与上年审定数一致 |
| 预算数 | 金额 | 预算表 | 有依据 |
| 占收入比率 | 百分比 | 本期实际 ÷ 主营业务收入 | = 比值 |
| 上期占比 | 百分比 | 上期实际 ÷ 上期收入 | = 比值 |
| 变动率 | 百分比 | (本期 − 上期) ÷ 上期 | 脚本计算 |
| 是否超重要性水平 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明与证据 | 文本 | 人工填写 | 超限项必有 |

## 质量门

- 按月份与按费用类别两个维度全覆盖，无遗漏
- 超实际执行的重要性水平的差异项目均有解释与佐证
- 分类口径与会计政策一致，跨期分类可比

## 升级路径

- 差异无法解释且金额超整体重要性水平 → 升级项目经理，转 P04/P05 扩大检查
- 发现无经济实质或与关联方相关的费用 → 升级，评估舞弊风险
