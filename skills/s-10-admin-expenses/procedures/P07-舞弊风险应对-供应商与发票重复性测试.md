# P07 舞弊风险应对—供应商与发票重复性测试

> 来源：S6602 程序库 其他13｜认定：E｜产出：S-10-07
> 执行方式：人工为主（职业怀疑+舞弊迹象判断）｜确定性工具：rule_check、excel_read｜**必须留人**（Agent 不得代替执行）

## 输入

- 供应商清单（名称、地址、银行账号、税号）
- 本年支付及年末应付发票清单
- 员工名册（用于比对同名或同址）

## Steps

1. 【规则】舞弊—针对与费用相关的职责分离不充分的测试
   - （1）获取供应商清单，查找重复的供应商和/或重复的地址。
   - （2）获取本年支付或年末应付的发票清单：
   - （3）实施审计程序，测试上述测试中使用的所有IPE的可靠性。
   - ①识别异常或可疑发票（例如，具有相同描述的多张发票、发票编号重复的供应商、同一日期相同金额的发票、在非营业日开具的发票、在批准截止日期或之后的多张发票等）
   - ②获取证据，核实发票作为业务费用的有效性

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 测试项 | 文本 | 测试类型 | 枚举（重复供应商名称/重复地址/重复银行账号/重复发票号/员工关联供应商） |
| 涉及供应商 | 文本 | 供应商清单 | 非空 |
| 关联记录数 | 整数 | 比对结果 | ≥ 2 |
| 涉及金额 | 金额 | 发票清单 | 合计 |
| 风险等级 | 文本 | 人工判断 | 枚举（高/中/低） |
| 已实施程序 | 文本 | 人工填写 | 非空 |
| 结论 | 文本 | 人工填写 | 非空 |

## 质量门

- 供应商名称、地址、银行账号、税号四个维度全覆盖比对
- 发现的重复项 100% 跟进至管理层解释与佐证
- 本卡必须人工判断，Agent 仅提供比对结果与线索

## 升级路径

- 发现员工关联供应商或虚构供应商 → 立即升级项目经理与项目合伙人，按舞弊事项处理
- 重复项无法合理解释 → 升级，扩大费用检查范围
