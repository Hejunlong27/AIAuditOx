## 六要素（技能工厂确认记录）

| 要素 | 内容 |
|------|------|
| 审计目标 | 完整性（C）：所有应付股利均已记录（含未列示于账面者）；存在（E）：记录的应付股利于资产负债表日存在且归被审计单位拥有或控制；准确性（A）：金额正确计算、适当加总且准确记录；计价（V）：按恰当金额计价（含减值、摊销、公允价值等调整）；列报（P）：分类、披露恰当 |
| 所需资料 | 应付股利明细表与明细账、公司章程、股东会或股东大会与董事会会议纪要、利润分配方案、税后可供分配利润计算表、股利计算表、股本结构与持股明细、股利支付凭证与银行流水、股利分配公告、个人所得税代扣记录、报表附注 |
| 所需数据 | 各股东持股数量、每股股利、应付股利金额、已付股利金额、期末余额、决议日期、公告规定支付日期、实际支付日期与金额、代扣个人所得税金额、可分配利润余额、实际执行的重要性水平 |
| 核对逻辑 | 1. 实质性分析程序（将实际值与预期值进行比较。）；2. 应付股利明细表编制与核对（获取或编制应付股利明细表，复核加计是否正确，并与报表数、总账数及明细账合计数核对相符。）；3. 股利分配程序与计提合规性检查（审阅公司章程、股东会（或股东大会）和董事会会议纪要中有关股利的规定，了解股利分配标准和发放方式是否符合有关规定并经法定程序批准。）；4. 股利支付检查（检查股利支付的原始凭证的内容、金额和会计处理是否正确。检查现金股利是否按公告规定的时间、金额予以发放。）；5. 拟分配股利与披露检查（检查董事会或类似机构通过的利润分配方案中拟分配的现金股利或利润的会计处理和披露是否正确。） |
| 底稿编制内容 | 见「产出清单」，全部底稿采用四段式制式：底稿名称与表头（项目基本信息）→ 审计目标和程序说明 → 审计程序执行结果 → 审计说明。共 5 张底稿。 |
| 输出格式 | xlsx 工作簿（模板见 templates/F-11应付股利审计工作簿模板.xlsx），每份底稿同路径伴随「底稿名称+修订记录」.md |

## Steps（助理调度流程）

1. 确认项目工作目录已由项目经理指定（未指定则拒绝启动，升级项目经理）；在 `02_工作底稿/F-11应付股利/` 下基于模板创建工作簿副本。
2. 校验输入资料完整性（见六要素「所需资料」）；缺失时向项目经理列明缺口清单并挂起。
3. 按依赖顺序分派实习生程序：P01 → P02 → P03 → P04 → P05；人工程序标记待办并跟踪完成状态。
4. 每个程序卡执行遵守「副本先行」：修改任何既有底稿前先创建副本入 `.auditox_backups/`；底稿每次生成/修订同步更新同路径「底稿名称+修订记录」.md。
5. 异常激活：按各程序卡「升级路径」处理，发现异常事项逐级升级。
6. 汇总各程序卡产出至工作簿，执行一级复核（见下方复核清单），复核通过后提交人工二级复核。

## 一级复核清单（助理执行，独立于编制上下文）

- 完整性：P01~P05 计划实施的程序均有底稿或「不适用+理由」记录；索引号连续无缺。
- 勾稽：明细表合计数 = 总账数 = 报表数；底稿间交叉索引正确。
- 证据充分性：每项结论可回溯到数据源；差异事项均有解释与支持文件。
- 异常闭环：所有异常事项有处理结果记录；未回函/回函差异已实施替代程序。
- 制式合规：每张底稿四段式结构完整，表头七要素齐全，修订记录同步。

## 边界与禁止事项

- 允许操作范围：仅项目工作目录内文件；仅调用 file_ops（读/写/改/格式）、数据核对脚本、Excel 计算。
- 禁止：物理删除任何文件（删除一律移入可恢复区）；向项目目录外发送客户数据；代替人工执行函证寄发/跟函/监盘动作；修改原始资料目录（01_原始资料 只读）；跳过强制程序。
- 数字核对一律使用脚本精确匹配，禁止以模型估算代替；差异原因说明可用模型起草，但必须标注「待人工确认」。

## Pitfalls

- 资产负债表日后由董事会或类似机构通过的利润分配方案，只能披露不得确认为资产负债表日负债（企业会计准则第29号），误确认会虚增负债并减少权益
- 股利分配必须经法定程序批准（股东会决议），仅凭董事会决议或管理层决定计提的股利不得确认
- 分配来源必须是税后可供分配利润；从资本公积或未弥补亏损中分配属于违规，须评估合规风险
- 现金股利未按公告规定时间与金额发放可能构成违约，须评估并检查披露
- 个人股东股利的个人所得税代扣代缴是法定义务，未代扣会形成税务风险与或有负债
- 持股数量须与股本结构、实收资本明细核对，不一致可能同时影响股本与负债的准确性
