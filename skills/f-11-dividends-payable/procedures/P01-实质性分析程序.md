# P01 实质性分析程序

> 来源：F2232 程序库 分析1、分析2、分析3｜认定：C、E、A｜产出：F-11-01
> 执行方式：自动（预期值测算）+人工判断｜确定性工具：threshold_flag、recalc_check

## 输入

- 应付股利明细账
- 董事会或股东会通过的利润分配方案
- 股本结构与持股明细
- 上年分配数据
- 实际执行的重要性水平

## Steps

1. 【规则】将实际值与预期值进行比较。
2. 【规则】检查xxxx以上（实际执行的重要性水平的%，特定金额）相对于预期值的差异，并获取相关说明和证据。
3. 【规则】在无适当的说明或确切的证据可以证明差异时，考虑是否需要计划并实施额外工作及/或记录发现的任何差错。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 分析项目 | 文本 | 股东或股份类别 | 非空 |
| 持股数量 | 数值 | 股本结构表 | 与股本明细一致 |
| 每股股利 | 金额 | 利润分配方案 | 与方案一致 |
| 测算应付股利 | 金额 | 持股数量 × 每股股利 | = 乘积 |
| 账面应付股利 | 金额 | 明细账 | 与总账一致 |
| 差异 | 金额 | 测算 − 账面 | = 差额 |
| 差异率 | 百分比 | 差异 ÷ 测算 | 脚本计算 |
| 是否超重要性水平 | 文本 | threshold_flag 判定 | 超限标注「是」 |
| 说明与证据 | 文本 | 人工填写 | 超限项必有 |

## 质量门

- 按利润分配方案对全部股东或股份类别 100% 测算，无遗漏
- 差异超实际执行的重要性水平的项目均有解释与佐证
- 测算过程由脚本产出，每股股利与方案一致

## 升级路径

- 测算与账面差异重大 → 升级项目经理，转 P02/P03 核查计提依据
- 存在未按方案计提的股份类别 → 升级，评估完整性错报
