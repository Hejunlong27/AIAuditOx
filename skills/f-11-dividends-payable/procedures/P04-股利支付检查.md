# P04 股利支付检查

> 来源：F2232 程序库 其他4｜认定：C、E、A｜产出：F-11-04
> 执行方式：自动（抽样+核对）+人工确认｜确定性工具：sampling_draw、balance_confirm

## 输入

- 股利支付凭证与银行流水
- 股利分配公告（含支付时间与金额）
- 股东名册
- 个人所得税代扣记录

## Steps

1. 【规则】检查股利支付的原始凭证的内容、金额和会计处理是否正确。检查现金股利是否按公告规定的时间、金额予以发放。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 股东名称 | 文本 | 股东名册 | 非空 |
| 应付股利 | 金额 | 明细账 | 与总账一致 |
| 实付金额 | 金额 | 银行流水 | 与流水一致 |
| 支付日期 | 日期 | 银行流水 | 非空 |
| 公告规定支付日期 | 日期 | 分配公告 | 非空 |
| 是否按期发放 | 文本 | 人工判断 | 枚举（是/否） |
| 代扣个人所得税 | 金额 | 代扣记录 | 与税法规定一致 |
| 银行流水匹配 | 文本 | 银行对账单 | 枚举（相符/不符） |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 股利支付 100% 核对至银行流水，凭证内容、金额与会计处理正确
- 现金股利按公告规定的时间与金额予以发放
- 个人所得税代扣代缴金额符合税法规定

## 升级路径

- 未按公告规定时间或金额发放 → 升级项目经理，评估违约风险与披露
- 个税代扣不足或未代扣 → 升级，评估税务风险与或有负债
- 实付与银行流水不符 → 升级，评估资金流向异常与舞弊风险
