# P05 拟分配股利与披露检查

> 来源：F2232 程序库 其他5、其他7｜认定：E、A、P｜产出：F-11-05
> 执行方式：自动（schema 校验）+人工判断｜确定性工具：rule_check

## 输入

- 董事会或类似机构通过的利润分配方案（拟分配）
- 资产负债表日后事项资料
- 报表附注
- 应付股利明细表
- 未分配利润明细

## Steps

1. 【规则】检查董事会或类似机构通过的利润分配方案中拟分配的现金股利或利润的会计处理和披露是否正确。
2. 【规则】审计应付股利的披露
   - 检查相关财务报表附注披露的准确性和完整性。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 事项 | 文本 | 事项类型 | 枚举（拟分配现金股利/拟分配利润/披露事项） |
| 方案内容 | 文本 | 利润分配方案 | 非空 |
| 决议日期 | 日期 | 董事会决议 | 非空 |
| 是否属资产负债表日后事项 | 文本 | 人工判断 | 枚举（是/否） |
| 会计处理 | 文本 | 账务记录 | 枚举（确认为负债/仅披露/处理不当） |
| 披露内容 | 文本 | 报表附注 | 非空 |
| 是否符合准则 | 文本 | rule_check 校验 | 枚举（是/否） |
| 说明 | 文本 | 人工填写 | 异常项必有 |

## 质量门

- 拟分配的现金股利或利润的会计处理与披露符合企业会计准则
- 资产负债表日后拟分配的股利已按日后事项准则处理（仅披露，不确认为资产负债表日负债）
- 附注金额与底稿明细表金额一致

## 升级路径

- 拟分配股利在资产负债表日确认为负债 → 升级项目经理，按日后事项准则要求调整
- 披露缺项 → 升级，提请管理层补充披露
- 分配方案与未分配利润余额不匹配 → 升级，联动权益类科目核查
