# P02 应付股利明细表编制与核对

> 来源：F2232 程序库 其他1｜认定：V｜产出：F-11-02
> 执行方式：自动（脚本核对）｜确定性工具：recalc_check、balance_confirm

## 输入

- 应付股利明细表（按股东）
- 总账 2232 余额及明细账合计数
- 股本结构与持股明细
- 上年审定数

## Steps

1. 【脚本】获取或编制应付股利明细表，复核加计是否正确，并与报表数、总账数及明细账合计数核对相符。

## 输出契约

| 列名 | 类型 | 来源 | 校验 |
|------|------|------|------|
| 序号 | 整数 | 顺序编号 | 连续无缺 |
| 股东名称 | 文本 | 明细表 | 非空 |
| 持股数量 | 数值 | 股本明细 | 与股本结构一致 |
| 每股股利 | 金额 | 利润分配方案 | 与方案一致 |
| 应付股利 | 金额 | 明细表 | 与方案测算一致 |
| 已付股利 | 金额 | 明细账借方 | 与凭证一致 |
| 期末余额 | 金额 | 应付 − 已付 | = 应付 − 已付 |
| 核对差异 | 金额 | 明细表合计 − 总账余额 | = 0 或列示差异 |
| 备注 | 文本 | 人工填写 | 差异项必有 |

## 质量门

- 加计由脚本重算，明细表合计 = 明细账合计 = 总账余额 = 报表数（四方相符）
- 持股数量与股本结构、实收资本明细核对一致
- 差异项均有初步说明

## 升级路径

- 与股本结构核对不符 → 升级项目经理，联动实收资本程序核查
- 与总账差异无法解释 → 升级 F-11 助理，联动 P03 检查计提依据
